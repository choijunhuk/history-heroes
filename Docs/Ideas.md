# 💡 아이디어 보관함

떠오른 아이디어는 바로 만들지 말고 여기에 적어둬요. 지금 버전이 끝나면 검토해서 [로드맵](GameDesign.md#10-로드맵)에 넣을지 정해요.

## 적는 방법

```
### 아이디어 이름
- 날짜: 2026-10-25
- 내용: 한두 줄 설명
- 왜 재밌을까:
- 어느 버전에 맞을까: v0.x / 출시 이후 / 모르겠음
```

---

## 검토 대기

### 스킬 시너지
- 날짜: 2026-10-25
- 내용: 같은 태그 스킬을 일정 개수 모으면 추가 효과가 생긴다. (예: 불 태그 3개 → 처치 시 폭발)
- 왜 재밌을까: 빌드 방향을 정하는 이유가 생긴다.
- 어느 버전에 맞을까: v0.3 이후
- 메모 (Codex 1차 리뷰): 별도 세트 보너스를 만들기 전에 관통·둔화·연사 같은 기존 효과의 조합부터 검증하자.

---

## 채택됨 (로드맵으로 이동)

### 보스 상성 → 보스 패턴으로 변경
- 날짜: 2026-10-25
- 원래 내용: 보스마다 약점과 면역 속성 (예: 불 면역 보스)
- 결과: 완전 면역 대신 **패턴 차이**로 빌드를 시험하는 방식으로 [기획서 7-4](GameDesign.md#7-4-보스맵)에 채택 (Codex 1차 리뷰)
