# 💡 아이디어 보관함

떠오른 아이디어는 바로 만들지 말고 여기에 적어둬요. 지금 버전이 끝나면 검토해서 [로드맵](GameDesign.md#10-로드맵)에 넣을지 정해요.

## 적는 방법

```
### 아이디어 이름
- 날짜: 2026-10-25
- 내용: 한두 줄 설명
- 왜 재밌을까:
- 어느 버전에 맞을까: v0.x / 출시 이후 / 모르겠음
```

## 검토 대기

### 보스 상성 시스템
- 날짜: 2026-10-25
- 내용: 보스마다 약점과 면역 속성이 있다. (예: 불 면역 보스, 얼음에 약한 보스)
- 왜 재밌을까: "어떤 기록을 들고 갈까?" 고민이 깊어진다.
- 어느 버전에 맞을까: v0.2 이후

### 스킬 시너지
- 날짜: 2026-10-25
- 내용: 같은 태그 스킬을 일정 개수 모으면 추가 효과가 생긴다. (예: 불 태그 3개 → 처치 시 폭발)
- 왜 재밌을까: 빌드 방향을 정하는 이유가 생긴다.
- 어느 버전에 맞을까: v0.3 이후
