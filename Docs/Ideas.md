떠오른 아이디어는 바로 만들지 말고 여기에 적어둬요. 지금 버전이 끝나면 검토해서 [로드맵](GameDesign.md#11-로드맵)에 넣을지 정해요.

## 적는 방법

```
### 아이디어 이름
- 날짜: 2026-10-25
- 내용: 한두 줄 설명
- 왜 재밌을까:
- 어느 버전에 맞을까: v0.x / 출시 이후 / 모르겠음
```
