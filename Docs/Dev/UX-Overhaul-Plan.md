## 1. 개발자 피드백 (2026-10-29)

1. 여자 영웅이 없어서 아쉽다.
2. 미션이 홈에 없고 따로 있어서 불편하다.
3. 보상 같은 데 그림이 너무 없다. 이미지 생성을 하든 어떻게 하든 꾸며 달라.
4. 게임에 집중한 나머지 시각성을 포기한 느낌. 글씨 위아래(줄 간격)가 짧아서 뭉쳐 보인다.
5. 영웅 화면은 **탕탕특공대 방식**으로: 캐릭터가 강해지는 것, 캐릭터 레벨, 장비, 펫, 무기, 유물.
6. 역사 느낌의 유물. 가상의 인물·신도 좋다 (예: 부처). 애니메이션 『종말의 발키리』의 신 · 역사 인물 · 아담 같은 인물 묘사를 참고.

## 2. 지금 있는 것 vs 탕탕특공대

| 탕탕특공대 | 지금 게임 | 문제 |

| 캐릭터 레벨 | ✅ 영웅 Lv1~30 (골드) | 화면 구석 단추 하나 |
| 캐릭터 강화 | ✅ 각성 ★1~5 (영웅 조각) · 수련 (계정 공용) | 단추가 흩어져 있다 |
| 장비 6칸 · 합성 | ✅ 3칸 (무기 · 갑옷 · 장신구) · 슬롯 강화 · 합성 | 영웅 화면에서 따로 열어야 보인다 |
| 펫 | ✅ 4마리 | 영웅 화면의 작은 단추 |

## 4. 신 vs 인류 (2026-10-29 개발자 결정)

- **컨셉 확정: "신 vs 인류"** (개발자: "신 vs 인류 괜찮은 것 같은데? 컨셉 괜찮은데"). 『종말의 발키리』는 구도만 참고, 그림 · 설정 · 대사는 따라 하지 않는다 (저작권).
- **종교 인물도 넣는다** (개발자: "그런 거로 막힐 가능성은 별로 없음"). 부처 · 아담 같은 인물도 후보. 묘사는 존중하는 쪽으로 (조롱 · 비하 없이, 각 인물의 상징을 멋있게).
- **신 캐릭터도 쓸 수 있게 (제안):** 개발자 고민 "신 캐릭터도 쓰고 싶지 않을까?" → 두 진영 모두 플레이. 인류 영웅 = 기본(진행으로 해금), 신 영웅 = 드물게 (뽑기 · 큰 목표). 적·보스 쪽에도 신이 나온다 (구간 보스 = 신의 사도 등). 진영 간 상성은 나중 (Ideas).
- 후보 — 인류: 잔 다르크 · 선덕여왕 · 클레오파트라 · 부처 · 아담 · 여포 · 사사키 고지로 · 레오니다스 / 신: 토르 · 제우스 · 포세이돈 · 헤라클레스 · 시바 · 아폴론 · 스사노오 · 오딘
