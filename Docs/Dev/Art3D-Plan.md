## 원칙
- **판정은 2D 그대로** (Rigidbody2D · Collider2D · XY 평면). 3D는 **보이는 것만** — 게임 규칙·테스트·밸런스는 안 바뀐다.
- 땅은 XY 평면, "위"는 -Z (카메라 쪽). 캐릭터 모델은 2D 오브젝트를 따라가고 움직이는 쪽으로 몸을 돌린다.
- 동작은 **실제 게임 사건**으로 (이동 속도 · 공격 · 맞음 · 쓰러짐). 샘플(`Dev/ArtPreview3D`)처럼 짐작하지 않는다.
- 폰에서 30fps 이상 (서바이벌 적 250마리 포함). 텍스처는 1024 이하.
- 에셋은 CC0만, `Docs/Credits.md`에 적는다. 큰 동작 파일(UAL FBX 24MB×2)은 쓰는 동작만 뽑아 올린다.

## 다시 만들기 순서
1. 겉모습(옷·색·동작·적 배정)을 바꿨으면 **`Art3DCharacters.BuildAll()`** (메뉴 History Heroes → 3D 캐릭터 다시 만들기). 에셋은 그 자리에서 고쳐서 GUID가 그대로다.
2. 그다음 **`SceneBuilder.BuildAll()`** — 데이터·프리팹·장면이 만들어진 3D 프리팹을 경로로 읽는다 (없으면 임시 도형 그대로).

## 알아 둘 것
- 카메라: 받침(`CameraRig`, 서바이벌 따라가기) → 거치대(`CameraMount`, `CameraFit`이 거리·기울기를 푼다) → 카메라(`CameraShake`). 로비는 2D 렌더러(0번) 그대로.
- 바닥 스프라이트(예고 원·함정·구덩이·문·연못·멈춤 고리·경험치 구슬)는 2D 그대로, 3D 바닥(z=+0.02) 위에 보인다. 6단계에서 투사체·이펙트를 바꿀 때까지 화살·구슬도 2D.
- 내장 원기둥·공 메시는 지름 2 (상자·판 1) → `Stage3D.Add`가 메시 크기로 나눠 맞춘다. 빌드에서 `CreatePrimitive`는 안 쓴다 (엔진 코드 빼기로 실패할 수 있다).
