## 작업 방식
- Claude가 구조와 대부분의 코드를 짜고, ✍️ 표시는 **뼈대와 TODO만** 남겨서 개발자가 직접 구현한다.
- 단계마다 에디터에서 컴파일·실행을 확인한다 (`unity command`, 에디터 Play).
- 기능 묶음이 끝날 때마다 Codex 코드 리뷰(`high`, 읽기 전용) → `Docs/Reviews/`.
- 숫자는 전부 ScriptableObject로 빼고, 기준값은 [Stats](../Design/Stats.md)를 따른다.
