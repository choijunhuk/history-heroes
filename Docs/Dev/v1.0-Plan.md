## 순서 (의존성)
1. **판 안 편의** — 일시정지·자동 일시정지·포기·이어하기가 있어야 폰에서 시험할 수 있다
2. **저장 보호** — 출석·7일 미션·순찰이 보석·골드를 주기 전에
3. **출석부 · 신규 7일 미션 · 순찰 · 로컬 알림** — 튜토리얼 보스 격파 때 함께 열린다
4. **튜토리얼** — 3의 해금을 튜토리얼 보스에 묶는다
5. **이야기 · 설정 · 사운드 · 법 화면**
6. **밸런스 패스** (v0.6에서 넘어온 것)
7. 폰 시험 → 갈래 2

## 정해서 진행하는 것 ([제안], 개발자가 바꾸면 따른다)

설계 문서끼리 어긋난 곳과 빈칸:

| 빈칸 · 어긋남 | 이렇게 한다 | 이유 |
|---|---|---|
| 일반 판 이어하기 (Modes 2-4 "앱이 꺼져도 같은 판" vs 5장 "생기면") | **방 시작 지점부터 이어하기** (던전·보스맵·균열·일일 도전 연습). 서바이벌은 이어하기 없음 (10분짜리, 적 수백 마리) | 적 위치까지 저장하면 복잡하고 깨지기 쉽다. 방 시작이면 판의 흐름은 그대로 |
| 일일 도전 공식 판 이어하기 | **이어하기 없음** (지금 규칙: 끄면 0점) | 방 시작부터 다시 하면 "어려운 방 다시 하기"가 된다 |
| 이어하기로 카드 다시 뽑기 | 난수 3갈래의 **뽑은 횟수를 저장해 다시 돌린다** → 껐다 켜도 같은 카드 (GameDesign 6-7) | 리롤 광고·전설 희귀함을 지킨다 |
| 이어하기와 ★2 (피격 한도) | 방 시작 때의 피격 수로 되돌린다 | 방을 다시 하는 만큼은 허용 (드물고, 끄는 수고가 크다) |
| 출석부 해금 (Missions 10-1 "상점과 같이" vs Systems 3장 "튜토리얼 보스") | **튜토리얼 보스 격파** (Systems 3장) | 해금 순서 표가 기준 |
| 첫 펫 (Pets 표 "튜토리얼 보스" vs 7-1 "첫 던전 클리어, v1.0에 바꾼다") | **튜토리얼 보스 격파** (7-1의 "v1.0에 바꾼다"를 실행) | 튜토리얼이 생겼다 |
| 첫 고급 상자 무료 (UX 4 vs Gacha 2 "고급 상자는 무료로 안 준다") | **튜토리얼 보상 1번만 예외**로 Gacha 2장에 적는다 | 첫 10분에 장비 뽑기를 맛보게 |
| 처음 3판 하트 없음 (Economy 3-2) | **튜토리얼 판은 세지 않는다** (튜토리얼 다음 3판) | "튜토리얼 직후 이탈 방지"가 목적 |
| 신규 7일 미션의 "하루" | **시작한 날부터의 날짜** (05:00 기준) — 2일째 칸은 다음 날 05:00에 열림, 지난 칸도 기한(14일) 안이면 할 수 있다 | 매일 들어올 이유 + 놓쳐도 따라잡기 |
| 백업 개수 (LiveOps 20 "최근 3개" vs GameDesign 12-2 "1개") | **3개** | 판이 끝날 때마다 돌리면 하나가 깨져도 둘이 남는다 |
| 저장 해시 키 | 앱 안 상수 (공개 저장소라 **숨길 수 없다** — 손쉬운 편집만 막는다). 진짜 막기는 서버 저장(갈래 2) | LiveOps 15장의 "서버와 다르면 서버 쪽" |
| 확률표 위치 (Gacha 6 ScriptableObject vs LiveOps 16-1 Remote Config) | v1.0 오프라인은 **ScriptableObject**, 서버가 생기면 Remote Config가 덮어쓴다 | 서버 없이도 화면이 있어야 한다 |
| 흔들림 설정 (UX 3단 vs LiveOps "줄이기") | **3단** (끔/약하게/보통) | 더 자세한 쪽 |
| 색약 (UX "늘 색+테두리" vs LiveOps 토글) | **늘 색 + 테두리** (토글 없음) | 끌 이유가 없다 |
| 조이스틱 기본값 | **터치한 자리에 생긴다** (지금 그대로), 설정에서 고정 | UX 2장 |
| 볼륨 슬라이더 (믹서 4그룹 vs 설정 2개) | 설정은 **배경음 · 효과음** 두 개 (효과음이 UI·음성도 같이) | 단순하게 |
| 대사 빈도 | 같은 상황 대사는 **판마다 1번** (체력 낮음은 판마다 1번, 사망·보스 격파는 매번) | 말풍선이 전투를 가리지 않게 |
| `Docs/Credits.md`, `Docs/Design/StorySources.md` (문서가 가리키지만 없음) | 이번에 만든다 | |

## 4. 개발자에게 필요한 것 (갈래 2)

계정·돈이 들어서 Claude가 혼자 못 하는 것. **갈래 1이 끝날 때 한꺼번에 묻는다.**

| 무엇 | 왜 | 개발자가 할 일 |
|---|---|---|
| **구글 플레이 콘솔** | 스토어 출시, 결제 상품, 등급(IARC), 데이터 보안 | 개발자 계정 등록 ($25, 한 번). 개인 계정은 **비공개 테스트 12명 × 14일 연속**을 거쳐야 정식 출시 신청 가능 ([플레이 콘솔 도움말](https://support.google.com/googleplay/android-developer/answer/14151465), 2023-11-13 이후 만든 개인 계정) |
| **Unity Gaming Services** (UGS) | 로그인·클라우드 저장·랭킹·친구·원격 설정·분석·결제 검증 (Monetization 8장 추천) | Unity 계정에서 프로젝트 연결 (무료 한도 안) |
| **광고** (LevelPlay 또는 AdMob) | 보상형 광고 (리롤 1종) | 광고 계정 + 앱 등록. 그 전에는 테스트 광고 |
| **결제** (Unity IAP) | 보석·패키지·월정액·시즌 패스 유료 트랙 | 플레이 콘솔에 상품 등록, 판매자 계정(정산) |
| **그래픽 방향** (Art 3장 "비교 실험으로 결정") | 임시 도형 → 진짜 그림 | Claude가 2~3가지 샘플(무료 에셋 · 생성 도구)을 만들어 보여 주면 고른다 |
| 개인정보 처리방침 연락처 | 법적 필수 | 문의 이메일 (공개용) |
