# 보상 연출·영웅 정체성 개선

작성: 2026-11-04. 사용자 요청: 부족해 보이는 이유와 플레이하지 않을 이유를 감사하고 직접 수정한다. 기존 3D 방향을 유지하며 부족한 그림은 새로 제작할 수 있다.

## 확인한 문제

1. `ShopPanel.ShowResults`/`ShowRelicResults`는 결과 줄의 등장만 제공한다. 상자 개봉·보상에 집중하는 화면·장비 그림을 크게 확인하는 순간이 빠져 있다. 장비 결과 공개 중 재구매를 막는 장치도 없다.
2. `HeroData.exclusiveActive`는 21명 모두 연결돼 있으나 `HeroPanel.Render`에는 전용 액티브 안내가 없고 `SkillCardView.Show`는 공용/전용 모두 액티브라고 표시한다.
3. `SkillManager.BoostExclusive`는 재플레이 첫 카드에 50% 확률만 적용한다. 영웅을 바꿨는데 공용 카드만 보이는 경험이 가능하다.
4. 기존 전투 캡처에는 큰 파란 띠와 강한 영웅 고리가 보인다. 띠 원인은 런타임에서 미확정이므로 추측으로 삭제하지 않는다. 구간 아트 반복과 실제 첫 10분의 이해도는 추가 검증 대상이다.

## 구현 결정

- 뽑기 저장 성공 → 닫힌 상자/유물 봉인 기대 모션 → 열린 상자/빛 → 실제 결과 카드 공개 → 확인. 장비/유물 1회·10회가 같은 개봉 흐름을 쓴다.
- 지급은 기존 서비스가 담당한다. 연출은 이미 확정된 결과만 받으며 재추첨·재지급·저장을 하지 않는다. 저장 실패 시 연출도 없다.
- 결과 확인까지 뽑기 버튼의 중복 입력을 막는다. 건너뛰기는 결과를 모두 즉시 보이며 닫기·비활성화·재진입 때 입력과 크기를 복원한다.
- 기존 UI 키트·아이템 그림·효과음·시간정지와 무관한 모션을 재사용한다. 부족한 열린 상자와 장비 슬롯 대표 그림을 추가한다. 큰 섬광·흔들림은 번쩍임 줄이기 설정을 따른다.
- 매 판 첫 일반 카드 묶음에 선택 가능한 영웅 전용 액티브 한 장을 보장한다. 튜토리얼 고정 카드·조합 카드·슬롯·밴·복원 상태를 침범하지 않는다. 자동 지급하지 않는다. 이후 카드와 상점 확률·천장은 유지한다.
- 영웅 화면에서 대표 효과·전용 액티브·전용 진화 정보를 구분한다. 기존 스크롤을 쓰고 작은 글씨로 밀어 넣지 않는다. 전용 카드에 영웅 전용 표기를 준다.
- 실제 화면에서 확인한 상세 설명 축소는 안내 행의 높이를 글에 맞춰 해결한다. 영웅 요약은 이름·진입 안내를 짧게 두고, 긴 설명은 상세 창에서 본문 34/1080 이상으로 읽는다. 안내 행 확대는 다음 목록 재사용 때 템플릿으로 복원한다.
- 전투 중에는 전용 액티브의 실제 발동·다음 발동까지의 시간을 작은 HUD로 표시한다. 공용기와 구분하고 전용 진화로 바뀌면 실제 기술 이름으로 갱신한다. 자동 발동 규칙은 유지하며 새 수동 버튼을 만들지 않는다.
- 같은 원형 파동과 별 아이콘을 공유하는 선덕여왕·무측천·퀴리는 별빛·각진 인장·분광 문양으로 아이콘과 짧은 중심 표식을 구별한다. 기존 파동·타깃·위치·피해는 그대로 유지하고 기존 풀에 문양만 얹는다. 카드·전투 HUD·기록 아이콘도 같은 문양을 사용한다.
- 2026-11-05 실제 장면에서 파란 띠가 `CreekFlow`인 것을 확인했다. 물 alpha 0.88과 흐름에 직각인 0.12×0.7 물결을, 바닥이 보이는 물색·흐름 방향의 짧은 물결과 둑으로 보정한다. 충돌 크기·동선·물 재질 원본은 유지한다.
- 영웅 고리는 `ui_ring`의 실제 스프라이트 단위 때문에 지름 2.816으로 커져 있었다. 런타임에서 지름 약 1.6 월드 단위로 정규화하고 강도를 줄인다. 정지 준비 표시·공격 판정은 유지한다.
- 보스 모드는 카드 선택이 없으므로, 기록에 전용기가 없는 HUD 안내를 기록 기준으로 표시한다.
- 저장 ID·형식·재화·구매 정책·핵심 조작·수치는 변경하지 않는다. 새 의존성을 추가하지 않는다.

## 검증과 종료 기준

- 전용기 첫 카드 보장/튜토리얼 보호/다른 영웅 카드 누수/밴·슬롯 보호 회귀 검사.
- 장비·유물 성공/실패, 1회·10회, 중복 입력, skip, 닫기, 비활성화, 감소 효과, timeScale=0에서 공개 상태 검사.
- 모든 변경 C# 컴파일, 관련 검사와 가능한 전체 EditMode 검사. 실행할 수 없는 검사는 NOT_RUN으로 남긴다.
- 실제 화면 1080×1920·2340에서 레이아웃/입력/결과 전체 접근성 비교. 기존 mat6/font2의 원본 바이트 보존 확인.
- 감사 문서에 수정한 결함·나머지 한계·실행 증거를 구분한다. 실제 플레이 없이 재미·기기 성능·출시 검증 완료를 주장하지 않는다.

## 현재 환경 제한

Unity Pipeline은 실행 중인 에디터를 찾았으나 서버에 연결할 수 없다. 컴퓨터 사용 도구는 Unity 접근을 거부했다. 자동 승인 정책 때문에 작업 상태 쓰기 도구도 거부됐다. 안전 경계를 우회하지 않고 사용 가능한 로컬 검사부터 수행한다.
