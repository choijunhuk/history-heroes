## 완료 기준
- 플레이어가 **새 기록을 만들러 다시 던전에 들어가는가**
- 저장 테스트 4개 통과: 같은 빌드 복원(조합·진화 포함), 두 번 불러도 중복 없음, 옛 버전 읽기 실패 시 원본 보존, 저장 중 강제 종료해도 이전 기록 생존

## 작업 방식
- v0.1과 같다: 코드는 Claude가 전부, 단계마다 컴파일·실행 확인, 묶음마다 커밋·푸시, Codex 리뷰는 `Docs/Reviews/`.
- 판단 기준이 기획서에 없으면 기획서에 먼저 적고(추천안 + 이유) 그대로 구현한다.
