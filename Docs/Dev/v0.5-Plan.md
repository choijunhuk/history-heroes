# 🛠️ v0.5 개발 계획 — 서바이벌 모드 + 펫 + 미션·업적

> 기준: [GameDesign 8장 서바이벌](../GameDesign.md#8-서바이벌-모드-뱀서-모드) · [11장 v0.5](../GameDesign.md#v05--서바이벌-모드) · [Modes 2-10·4·5](../Design/Modes.md) · [Pets](../Design/Pets.md) · [Missions 2·3·7](../Design/Missions.md) · [Systems 1장](../Design/Systems.md) (v0.5: 서바이벌, 무한 모드, 일일 도전, 펫, 미션, 업적)
> 브랜치: `feature/v0.5-survival` · 시작: 2026-10-26
> 범위 규칙: 그래픽은 여전히 임시 도형.

## 완료 기준 (GameDesign 11장)
- 수백 마리 적이 나와도 **폰에서 끊기지 않는가** (저사양 기준 10분 30fps, 적 최대 300 · 투사체 최대 500)
- **"멈출까 피할까" 판단이 실제로 일어나는가** (자동 측정: 판 전체 기본 공격 비중 약 30%, GameDesign 3-3 서바이벌 목표)
- 같은 진행도에서 **서바이벌의 분당 재화 ≤ 던전의 분당 재화** (8-4)

## 순서 바꾸기 (의존성)
[Systems](../Design/Systems.md)는 무한 모드·일일 도전도 v0.5에 두었지만, 둘 다 **2~5구간 보스가 있어야** 돌아간다 (무한: 10층마다 보스맵 보스 5명이 차례로 / 일일 도전: 3구간 보스 격파 후 해금). 그래서:
- **v0.5 = 서바이벌 + 펫 + 미션·업적** (지금 콘텐츠로 끝까지 시험 가능)
- **v0.6 = 구간 2~5 콘텐츠 + 무한의 균열 + 일일 도전** ([로드맵](../GameDesign.md#v06--구간-25-콘텐츠))
