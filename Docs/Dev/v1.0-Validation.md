## 1. 처음 깐 사람 흐름

새 저장(빈 폴더)으로 로비를 열면 오프닝 3장면 → 튜토리얼 던전(칭기즈 칸) → 기록 저장 → 튜토리얼 보스 → 로비.

| 단계 | 확인 |
|---|---|
| 오프닝 | 3장면 + 건너뛰기, 마지막 "시작하기" → 튜토리얼 던전 |
| 튜토리얼 던전 | 방 1/6 (빈 방 · 클리오 이동 안내), 궁병 → 돌진병 → 섞어서 → 엘리트. 카드는 회전 칼날 → 방어력 순서 → Lv8에 **강철 회오리(조합)** |
| 기록 저장 | 용량 = 빌드 비용 − 1 → 패시브 한 레벨만 빼면 된다, "저장 안 함" 없음 → 저장하면 바로 튜토리얼 보스 |
| 튜토리얼 보스 | 별 표시 없음, 쓰러질 만큼 맞으면 체력 50%로 → 격파: 🪙500 + 🎫1, 출석부 · 7일 미션 · 사냥매 열림, 별·구간 해금 없음 |
| 로비 | "튜토리얼 끝! 이제 1구간 던전에 도전하세요" |

자동 조종(카드 무작위, 문까지 걷기 생략) 3판: **모두 클리어, 싸움 31초, Lv9, 가장 낮은 체력 96%** (궁병만 맞힘).
사람은 걷기 · 카드 고르기(8번) · 클리오 말풍선 읽기를 더해 던전 약 2~3분, 기록 저장 1분, 보스 1분 남짓 → **첫 판 약 5분** (Content 2장 "첫 판(튜토리얼) 약 5분"과 맞다).

## 2. 균형 (v0.6에서 넘어온 것)

**5구간 보스 (망각의 왕):** 27pt 완성 빌드 + 1개월 성장으로 처음엔 다 졌다 (받은 피해의 2/3가 졸개) → 졸개 체력 0.5배 · 공격 0.55배 · 최대 5마리 → **추천 빌드(조합 1 + 기본 공격)만 이긴다** (체력 26%). 자세히: [v0.6 검증 "5구간 다시 보기"](v0.6-Validation.md)

[v1.0-Plan F21](v1.0-Plan.md): 광역 스킬 세기를 올렸다 (낙뢰 150% · 불꽃 장판 초당 40% · 독 구름 33% · 뇌화 폭풍 165%).

| 빌드 (칸, 1개월, dps) | 2구간 | 4구간 |
|---|---|---|
| 광역 (조합 없이) | 201 → **169초** | 244 → **200초** |
| 광역 (뇌화 폭풍) | 248 → **234초** | 286 → **264초** |
| 단일 화력 | 128 → 123초 | 124 → 123초 |

- 서바이벌 (실전 ×4): 칸 7:06 · 테슬라 6:31 쓰러짐 (전에는 6:51 · 6:51) → 쉬워지지 않았다.
- 칸(기본 공격 영웅)에게는 아직 단일 화력이 1등 → **영웅 정체성으로 둔다** (스킬 영웅으로 2구간 광역을 다시 볼 것).
