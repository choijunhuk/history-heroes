전체 아트 교체는 아직 선택되지 않았다. 1차는 기존 정체성을 보존하는 확정 결함 수정이다.
게임 규칙·보상량·저장 스키마·상점 상품을 이 작업의 부수 효과로 바꾸지 않는다.
실제 계정/저장에 영향을 주지 않도록 기존 `QaTools.SandboxSave`를 사용한다.

## 화면 수정 전 관찰

- 1080×1920 영웅 화면: 하단 영웅 목록이 레벨업·수련 버튼 뒤에 겹친다.
- 공통 `PinToEdges`가 목록은 하단, 성장 버튼은 상단에 고정하고, 페이지가 탭 공간 200을 제외해 상대 위치가 달라진다.
- 선택 영웅 탭의 scale=(1.05,1.16,1)이 누름/떼기 후 (1,1,1)로 바뀐다.
- 출석·탭 전환·클리어·결과 보상 모션은 이미 있다. 중복 구현하지 않는다.

## 검증 기록

1차 단계 1~5는 구현·검증을 마쳤다. 테스트 846개, 서버 96개, 확률표 4개, 실행기 4개 통과. 중첩 스크롤 입력도 보완했다.
실행 결과와 한계는 [전체 점검 기록](../Reviews/2026-11-04-mobile-quality.md)에 갱신한다.
기존 재질 6개와 BlackHanSans 폰트 수정은 작업 시작 시부터 존재했으므로 커밋에 포함하지 않는다.

## 2차: 기록 비교와 감각 설정

- 기록 보관함은 검증된 스킬 중 높은 레벨의 대표 4개를 기존 아이콘·이름·레벨로 보여 준다. 남은 개수·역할·용량·패치 안내는 유지한다.
- 고정 좌표 카드가 서로 겹치는 문제를 내용 높이에 맞는 카드와 세로 스크롤로 해결한다. 빈 칸·잠김·임시 기록도 같은 배치 원칙을 쓴다.
- `RecordFormat.Details`의 다른 소비자는 기존 전체 스킬 표시를 유지한다. 저장 스키마·기록 선택·비용 계산은 바꾸지 않는다.
- 보스 격파도 번쩍임 줄이기 설정을 지킨다. 해당 설정을 켰을 때 흰 번쩍임과 신규 카메라 흔들림만 생략하고 기존 소리·슬로모션·폭발·띠는 유지한다.
- 완료 조건: 대표 스킬/원본 불변/빈칸·잠금·임시 기록 회귀검사, 설정 켜기·끄기 검사, 전체 EditMode, 짧고 긴 화면·스크롤·기록 잠금 실제 Editor 확인, 독립 리뷰, 변경별 커밋·push.

## 3차: 결과 보상 정보 위계

- 결과 화면의 모호한 `그리고` 제목을 `추가 보상`으로 정리한다.
- 계정 경험치·레벨 승급·추가 재화·하트 충전을 의미 단위로 나누고 승급만 크게 강조한다.
- 보상 계산, `RunText.Level`, `RewardCards.Split`, 숫자 증가·건너뛰기·첫 클리어·각 모드 결과 흐름은 유지한다.
- 완료 조건: 보상 정보가 빠지거나 중복되지 않는 문자열 회귀검사, 전체 EditMode, 실제 결과 화면과 건너뛰기·3모드 확인, 독립 리뷰, 별도 커밋.
