## 완료 기준 (GameDesign 11장 + Heroes 8장)
- 영웅마다 대표 효과 때문에 **플레이 감각이 확실히 다른가** (사람)
- 4명 모두 **전설 없이** 1구간 보스를 깰 수 있는가
- 관우(근접)가 원거리 영웅보다 보스 처치 시간이 **1.5배 이상 느리지 않은가**
