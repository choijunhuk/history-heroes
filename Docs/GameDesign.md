## 1. 한 줄 소개

**전 세계 역사 인물이 되어 아처(Archero) 스타일로 던전을 돌파하고, 액티브·패시브 스킬을 조합해 만든 빌드를 기록해 보스에게 도전하는 모바일 로그라이크.**

### 핵심 재미 4가지
1. **빌드 쌓기**: 레벨업할 때마다 액티브·패시브 스킬 3장 중 1장을 골라 이번 판의 빌드를 만든다.
2. **조합 발견**: 액티브 + 패시브, 액티브 + 액티브를 조합하면 더 강한 스킬이 된다. 처음엔 레시피가 숨겨져 있다.
3. **귀한 전설**: 전설 스킬은 처음부터 끝까지 잘 안 나온다. 그래서 뜨면 짜릿하다. **단, 전설 없이도 모든 보스를 깰 수 있다.**
4. **기록 → 보스**: 잘 나온 판을 기록으로 저장하고, 보스맵에 어떤 기록을 들고 갈지 고른다. (카제나의 세이브 데이터에서 착안)

### 🔁 핵심 순환 (게임이 멈추지 않는 이유)

```
 ┌──▶ 던전에서 빌드 만들기 ──▶ 기록 저장 ──▶ 기록 골라서 보스 도전
 │                                                    │
 │                                          보스 최초 격파
 │                                                    │
 └──── 새 보스는 다른 패턴 → 다른 기록이 필요 ◀── 다음 구간 개방
```

- **보스를 깨면 다음 구간(새 던전 + 새 보스)이 열린다.**
- 새 보스는 **패턴이 달라서** 예전 최강 기록이 항상 정답은 아니다. → 다시 던전에 들어가 새 기록을 만들 이유가 생긴다.
- 최초 격파 보상은 크게, 같은 보스 반복 격파 보상은 작게 한다. (같은 보스만 도는 게 최고의 성장 방법이 되지 않도록)

### 🎮 게임 모드

| 모드 | 느낌 | 기록 |
|---|---|---|
| **던전 모드** (메인) | 아처. 방을 하나씩 돌파 | 기록 저장 → 보스맵 |
| **보스맵** | 기록을 골라서 보스전 | 기록 사용 |
| **서바이벌 모드** | 뱀서. 몰려오는 적 속에서 버티기 | 기록 없음. 대신 조합 레시피 발견, 보상 ([8장](#8-서바이벌-모드-뱀서-모드)) |

## 3. 게임 흐름

```
[메인 화면]
   ├─ 영웅 선택 (+ 스킨 선택)
   ├─ 장비 / 룬 장착
   │
   ├─▶ [던전 모드] (구간별)
   │     방 입장 → 적 처치 → 경험치 → 레벨업 → 스킬 3장 중 1장 선택
   │     방 클리어 → 다음 방 ... 반복 ...
   │     (확장 1차: 3·9번 뒤 갈림길 = 평범 / 도전 방 · 엘리트 / 저주받은 엘리트,
   │      6·11번 보상 방의 25%는 기억의 석비 — Design/Expansion1.md 3장)
   │     판 종료 (사망 또는 클리어)
   │        └─▶ [기록 저장] 남길 스킬 고르기 → 기록 보관함
   │
   ├─▶ [보스맵]
   │     기록 1개 선택 → 그 빌드 그대로 보스전
   │     최초 격파 → 다음 구간 개방
   │
   └─▶ [서바이벌 모드]
         넓은 맵에서 정해진 시간 동안 버티기 → 마지막 보스
```

### 3-1. 조작 (아처 방식)
- 가상 조이스틱으로 이동
- **기본 공격은 멈춰야 나간다.** 움직이는 동안에는 기본 공격을 하지 않는다. ("멈춤" = 조이스틱 입력이 0.1초 이상 없음, [Stats 1-1](Design/Stats.md#1-1-멈춤-판정))
- **액티브 스킬은 이동 중에도 쿨다운마다 자동으로 발동한다.**
- 즉, 움직이면 액티브로 버티고, 멈추면 기본 공격까지 더해서 몰아친다.

### 3-2. 전투 원칙 ("멈추면 쏜다"가 재밌으려면)
- **적은 공격 전에 예고하고, 공격 후 빈틈이 있다.** 플레이어가 "지금 멈춰서 두 발 쏠 수 있다"고 판단할 수 있어야 한다.
- 압박이 너무 강하면 공격할 틈이 없고, 너무 약하면 제자리에 서서 쏘기만 하는 게임이 된다. → 적 배치와 공격 주기로 조절한다.
- **표적 선택:** 사거리 안에 있고 벽에 가리지 않은 적 중 가장 가까운 적. 표적이 너무 자주 바뀌지 않게 한다.
- **멈춘 뒤 첫 공격까지 걸리는 시간**은 조정값으로 두고 실제 폰에서 맞춘다.
### 3-3. 멈춤의 가치 (액티브가 강해져도 멈출 이유)
액티브가 많아지고 조합까지 만들면 "그냥 계속 움직이는 게" 유리해질 수 있다. 이걸 막는 규칙:

| 장치 | 내용 |
|---|---|
| **역할 분리** | 기본 공격 = **단일 대상 고화력** (보스에 강함). 액티브 = **광역·보조** (잡몹 정리에 강함) |
| **멈춤 전용 패시브** | 흡혈, 공격속도, 멀티샷은 **기본 공격에만** 적용된다. 회복하려면 멈춰야 한다 |
| **빈틈 보장** | 적과 보스는 공격 후 **기본 공격 1~2발을 넣을 빈틈**을 반드시 준다 |
| **목표 지표** | 최종 빌드에서도 전체 피해의 **약 40% 이상이 기본 공격**에서 나오게 한다 (서바이벌은 약 30%) |
| **검증 방법** | 같은 빌드로 보스를 **"이동만"** vs **"빈틈마다 정지"**로 잡아본다. 정지 쪽이 확실히(예: 30% 이상) 빨라야 한다 |

## 4. 영웅 (역사 인물 × 직업)

- 범위: **전 세계** 역사 인물
- 원칙
  - 역사적 업적이나 일화를 능력으로 바꾼다. (예: 과학자 → 마법사, 발명가 → 소환사)
  - **영웅마다 플레이에서 눈에 보이는 대표 효과가 1개 이상 있어야 한다.** 이름과 외형만 다른 직업이 되지 않게.
  - **핵심 조작 규칙(기본 공격은 멈춰야 나감)을 깨는 영웅은 만들지 않는다.** 차이는 공격 형태와 전용 스킬로 만든다.
  - 영웅 설명에서 **사실 / 전승 / 게임 각색**을 구분해서 보여준다. (예: "📜 사실: 포병 장교 출신 · 🎮 각색: 대포 포격")

| 직업 | 인물 후보 | 대표 효과 |
|---|---|---|
| 궁수 | 칭기즈 칸 | 멈추는 순간 **공격 준비 시간 0** (기마궁수의 속사) |
| 궁수 | 이성계 ✅ | 백발백중 (멈춘 시간만큼 3단으로 모으는 화살) · 편전 — [Heroes 6-2](Design/Heroes.md) |
| 전사 | 관우 | 전용 액티브: 청룡언월도 회전 베기 |
| 전사 | 잔 다르크 | 성녀의 깃발 (영역 안 정지 기본 공격·방어 강화) · 깃발의 파동 · 오를레앙의 빛 — [Heroes 6-5](Design/Heroes.md) |
| 전사 | 부디카 | 되찾는 자리 (1초 정지 뒤 다음 기본 공격으로 밀침, 재사용 6초) · 이케니의 함성 · 되찾은 터전 — [Heroes 6-7](Design/Heroes.md) |
| 전사 | 토르 | 천둥의 무게 (정지 3번째 기본 공격 충격파) · 귀환 망치 · 천둥의 귀환 — [Heroes 6-8](Design/Heroes.md), 신화·각색 |
| 총잡이 | 나폴레옹 | 포병 출신. 전용 액티브: 대포 포격 (범위 피해) |
| 총잡이 | 오다 노부나가 | 조총 3단 사격 |
| 법사 | 니콜라 테슬라 | 전용 액티브: 번개 연쇄 |
| 법사 | 제갈량 ✅ | 동남풍 (멈추면 둘레 적 탄 -40%) · 팔진도 — [Heroes 6-4](Design/Heroes.md) |
| 법사 | 선덕여왕 | 별자리 관측 (1초 정지 뒤 다음 기본 공격 1회 관통) · 첨성대 별빛 · 별자리의 길 — [Heroes 6-6](Design/Heroes.md) |
| 총잡이 | 이순신 ✅ | 철갑 (멈추면 받는 피해 -25%, 막은 피해를 쌓아 다음 포탄에) · 거북선 돌격 — [Heroes 6-1](Design/Heroes.md) |
| 소환사 | 레오나르도 다빈치 ✅ | 작업대 (멈춰서 비행 기계 조립) · 장갑 전차 — [Heroes 6-3](Design/Heroes.md) |

### 영웅마다 다른 것
- 기본 공격 방식 (화살 / 근접 / 총알 / 마법)
- 기본 능력치
- **전용 스킬**: 영웅 ID로 명시적으로 지정한다. (태그로 정하지 않는다) 주로 전용 액티브.
- **전용 조합**: 영웅 전용 액티브가 들어간 조합은 그 영웅만 만들 수 있다.

### ⚠️ 인물·주제 관리
- 피할 것: 독재자·전범, 유족이나 재단이 이름·초상권을 관리하는 근현대 인물, 특정 국가끼리 대결하는 구도
- **종교 인물도 후보로 허용** (2026-10-29 개발자 결정). 사실·신앙 전승·게임 각색을 구분하고 조롱·비하 없이 묘사한다.
- 정복자나 전쟁 영웅은 지역마다 평가가 다르다. 출시 지역에 맞춰 검토한다.
- **보스는 실제 국가·민족이 아닌 가상의 존재로 만든다.**
- 그림·서체·음원은 출처와 이용 조건을 기록한다.

### 4-1. 신 vs 인류 (토르 1차 코드 작성, 나머지 📝 기획)

개발자 결정인 ‘신 vs 인류’ 구도를 기존 망각의 군단·클리오·기록 수호자의 이야기 뒤에 잇는다.
5구간과 망각의 왕을 유지하고, 그 뒤 보스맵의 별도 난도 **신의 시련**을 단계적으로 연다.
이번 묶음은 **토르 시련과 플레이 토르 1명만** 구현한다. 사람 11명+신 1명=영웅 12명. 본인 망각왕 첫 격파 뒤 시련 개방 → 첫 10조각 + 서로 다른 기록 주간 목표 5조각 → 30개 소비 해금이다. 성장 한도는 인간과 같고 신·신 조각 뽑기·새 재화·별·랭킹은 없다. 나머지 신 3명과 시련 4개는 후속 설계안이다.
확장 인간 영웅 여섯 명 중 선덕여왕과 부디카의 상세 기술과 해금은 [Heroes 6-6·6-7](Design/Heroes.md)·[Skills](Design/Skills.md)에 정했다. 원안의 누적 20·30판 해금 대신 두 영웅 모두 보석 2,000 또는 기존 던전 10판 기념 한 명 무료 선택을 쓴다. 나머지 네 명, 부품·경제·검증 기준과 도입 순서는 [신 vs 인류 상세 기획](Design/GodsVsHumanity.md)을 따른다. **Unity 검증 완료·출시 승인 표시가 아니다.**

## 5. 스킨

**같은 인물을 스킨마다 다른 분위기로 표현한다. 능력치는 같고 겉모습만 바뀐다.**

```
관우
 ├─ 기본 스킨: 실제 비율 로우폴리 3D (아기자기하지 않게 — 2026-10-27 결정)
 ├─ 코믹 스킨: 수염이 바닥까지 끌리는 패러디 관우
 └─ 진지 스킨: 웅장한 무신 관우 (판타지)
```

- 처음에는 **기본 스킨만** 만든다.
- 스킨은 캐릭터 애착이 확인된 뒤(출시 이후) 추가한다. (수익원)
- 코믹 스킨도 인물을 비하하지 않는다. 유명한 일화를 재밌게 비트는 정도로.
- 기술: 휴머노이드 동작을 모든 몸이 같이 쓰고(Animator Override Controller로 공격 동작만 바꿈), 스킨은 3D 모델·재질만 바꾼다.

## 6. 스킬 시스템 (판 안 성장)

### 6-1. 스킬 종류: 액티브 / 패시브 / 조합

| 종류 | 무엇인가 | 예시 | 레벨 | 슬롯 (던전 모드, 임시) |
|---|---|---|---|---|
| ⚔️ **액티브** | 쿨다운마다 **자동으로 발동하는 기술**. 이동 중에도 나간다 | 회전 칼날, 낙뢰, 불꽃 장판, 화살비 | Lv 1~5 | **4칸** |
| 🛡️ **패시브** | **능력치와 기본 공격을 강화**한다 | 공격력, 공격속도, 최대체력, 방어력, 체력재생, 흡혈, 멀티샷, 관통 | Lv 1~5 | **4칸** |
| ✨ **조합** | 조건을 채우면 나오는 **강화된 액티브** | 강철 회오리, 뇌화 폭풍 | 진화: 없음 · 합체: Lv 1~3 | 액티브 칸을 씀 |

- 패시브 안에는 **능력치 강화**(공격력, 체력, 흡혈, 방어력 등)와 **기본 공격 강화**(멀티샷, 관통, 벽 튕김 등)가 있다.
- **슬롯 제한이 선택을 만든다.** 칸이 다 차면 새 스킬은 더 이상 안 나오고, 가진 스킬의 레벨업만 나온다. 그래서 초반에 무엇으로 칸을 채울지가 빌드 방향이 된다.

### 6-2. 조합 시스템 ✨

| 조합 방식 | 조건 | 결과 | 예시 |
|---|---|---|---|
| **진화** (액티브 + 패시브) | 액티브 **최대 레벨** + 지정된 패시브 보유 | 액티브가 진화 형태로 **바뀐다** (패시브는 그대로 남음) | 회전 칼날 Lv5 + 방어력 → **강철 회오리** |
| **합체** (액티브 + 액티브) | 두 액티브가 모두 **Lv3 이상** | 두 액티브가 **하나로 합쳐진다** → 액티브 칸 1개가 비어서 새 스킬을 받을 수 있다 | 낙뢰 + 불꽃 장판 → **뇌화 폭풍** |

#### 조합 카드
- **조건을 채우면 다음 레벨업 카드 3장 중 1장이 조합 카드로 확정 등장한다.** 안 골라도 되고, 그러면 다음 레벨업에 또 나온다.
- 거절한 조합이 계속 자리를 차지하지 않게, 카드에 **"이번 판에서 숨기기"** 버튼을 둔다.
- 조합은 빈 칸이 없어도 할 수 있다. 조합한 뒤에 칸을 다시 계산한다.
- 조합은 **확률이 아니라 선택으로 얻는다.** 그래서 "전설은 귀하다" 원칙과 충돌하지 않는다. 운이 아니라 빌드를 잘 짠 보상이다.
- **막히는 조합 경고:** 조합 카드를 고르면 사라지는 재료(진화 = 액티브, 합체 = 둘 다)가 **발견한** 다른 조합의 재료이기도 하면 카드 아래에 "※ 고르면 이번 판엔 막혀요 / 불꽃 발자국 · 뇌신의 분노"를 띄운다. 발견하지 않은 조합은 말하지 않는다. (v0.3, 조사 A4)

#### 조합 규칙 (빈틈 막기)
| 규칙 | 이유 |
|---|---|
| **재료는 그 판에서 다시 나오지 않는다.** (진화 전 액티브, 합체 재료 2개 모두) | 재료를 다시 얻어서 또 합체하는 반복 방지 |
| **같은 조합 결과는 한 판에 1개만** | 같은 결과를 여러 개 쌓는 것 방지 |
| **조합 결과는 다시 조합 재료가 되지 않는다** (v1.0 기준) | 연쇄 조합은 밸런스를 잡기 어렵다. 출시 후 검토 ([아이디어 보관함](Ideas.md)) |
| **합체 시작 레벨 = 1 + (재료의 Lv3 초과분 합 ÷ 2, 내림)**, 최대 Lv3 | Lv5까지 올린 뒤 합체해도 손해가 없게. 예: Lv5 + Lv3 → 초과 2 → Lv2로 시작 |
| 진화는 액티브 MAX가 조건이라 초과 레벨이 없다 | — |
| 방어·회복 계열 조합에는 **상한**을 둔다 (예: 칼날 하나당 1초에 투사체 1발만 막음) | 막기 + 회복이 겹쳐서 무적이 되는 것 방지 |

#### 레시피 공개
- **도감에서 미리 볼 수는 없다(???).** 조건을 처음 채우면 조합 카드가 뜨면서 **효과와 사라질 재료를 보여준다.** 고르면 도감에 기록된다. → 발견하는 재미
- 한 번 발견한 레시피는 그 뒤로 재료 카드 아래에 **결과 · 짝 재료 · 진행도**가 뜬다. 예: "◆ 강철 회오리 ← 방어력 보유 · 회전 칼날 4/5". 한 스킬이 여러 조합의 재료면 완성에 가장 가까운 것 1개 + "외 n". 고르면 조건이 다 채워질 때는 "◆ 고르면 다음 레벨업에 뇌화 폭풍!". 이번 판에 이미 만든·숨긴·재료가 사라진 조합은 빼고 찾는다. (v0.3, 조사 A3)
- 도감은 미발견 조합의 결과·짝을 계속 숨기고, 스킬마다 **"이 스킬이 들어가는 조합 n개 (m개 발견)"**만 보여준다. (v0.3, 조사 A3)
- 전설 액티브도 조합 재료가 될 수 있다. 전설이 들어간 조합은 가장 강한 결과가 나온다.
- 영웅 전용 액티브가 들어간 조합은 그 영웅만 만들 수 있다.

### 6-3. 스킬 데이터
스킬 정의는 ScriptableObject 에셋으로 만든다. 숫자만 바꿔서 밸런스를 조절할 수 있다.

| 항목 | 설명 |
|---|---|
| ID | 저장용 고유 문자열 (예: `spinning_blade`). 한 번 정하면 바꾸지 않는다 |
| 종류 | 액티브 / 패시브 / 조합 |
| 이름 / 아이콘 / 레벨별 설명 | 카드에 표시 |
| 등급 | 일반 / 희귀 / 전설 (조합은 등급 없음) |
| 태그 | `[불] [번개] [투사체] [근접]` 등. 효과 분류, 룬, 시너지에 사용 |
| 최대 레벨 | 보통 5 |
| 레벨별 수치 | 피해량, 쿨다운, 개수 등 |
| 저장 비용 | 기록에 저장할 때 **레벨 1개당** 드는 포인트 |
| 기록 가능 여부 | 1회성 효과(즉시 회복 등)는 기록에 남지 않음 |
| 용도 메모 | 던전 / 보스 / 둘 다. 보스전에서 쓸모없는 스킬이 너무 많지 않은지 점검용 |

조합 레시피는 별도 데이터(`FusionRecipe`)로 만든다: 재료 A, 재료 B, 각 재료의 필요 레벨, 결과 스킬, (있다면) 전용 영웅 ID.

### 6-4. 레벨업 카드 3장 뽑기 규칙
레벨업은 **적을 처치해서 얻는 경험치**로 한다.

0. **조합 확인:** 조건을 채운 조합이 있으면 **1장은 조합 카드**로 확정한다. (여러 개면 하나를 무작위로 고르고, 그 레시피 ID를 저장해서 리롤해도 바뀌지 않게 한다)
1. **후보 고르기:**
   - 새 스킬: 해당 종류(액티브/패시브)의 **빈 칸이 있을 때만** 후보
   - 가진 스킬: **최대 레벨이 아닐 때만** 레벨업 후보
   - 이 영웅이 쓸 수 있는 스킬만 (전용 스킬은 영웅 ID로 확인)
   - **액티브와 패시브는 한 후보 목록에 섞여 있다.** 그래서 무엇이 뜰지는 랜덤이다.
2. **나머지 카드 한 장마다:** ① 층별 확률로 **등급을 먼저 뽑고** → ② 그 등급의 후보 중에서 스킬을 하나 뽑는다.
3. 같은 스킬이 두 장 나오지 않게 한다. (이미 뽑힌 카드는 다음 카드의 후보에서 뺀다)
4. 뽑힌 등급에 남은 후보가 없으면 **다른 등급에서** 찾는다.
   - 전설 → 희귀 → 일반 순서로 내려간다.
   - 일반이 비었으면 희귀로 **올라간다.** (일반을 다 MAX로 찍어도 희귀 레벨업은 나와야 한다)
   - **전설로는 절대 올라가지 않는다.** ("전설은 귀하다" 원칙)
5. 그래도 없으면 **기본 카드**(체력 회복, 골드 등)로 채운다. 기본 카드는 중복해서 나와도 된다.
6. 테스트할 상황: 액티브 칸만 다 참 / 패시브 칸만 다 참 / 둘 다 참 / 등급 하나가 고갈 / 전부 MAX

### 6-5. 전설 확률: 처음부터 끝까지 귀하게
**초반에도 나올 수 있지만 확률이 낮고, 끝까지 가도 나오기 힘들게 한다. 확정 보장(천장)이나 누적 보정은 없다.**

| 구간 | 전설 **등급 추첨률** (카드 한 장마다, 예시) |
|---|---|
| 1~5층 | 약 1% |
| 6~15층 | 1% → 2.5% |
| 16층~끝 | 최대 약 4% |

- "등급 추첨률"은 등급이 뽑힐 확률이다. 전설 후보가 없으면 아래 등급으로 내려가므로 **실제 등장률은 이보다 낮을 수 있다.**
- 확률은 에디터의 AnimationCurve(그래프)로 조절한다.
- 감 잡기: 카드 한 장 1%로 고정이고 한 판에 레벨업이 15번(카드 45장)이면, 전설을 한 번도 못 볼 확률은 **약 64%**다.
- 그래서 **전설 없는 판도 충분히 재밌어야 한다.** 일반·희귀 + 조합만으로 서로 다른 전투 방식이 나와야 한다.
- 전설은 "없으면 못 깨는 열쇠"가 아니라 **"플레이가 확 바뀌는 순간"**으로 설계한다.
- 확인할 지표: 전설 없이 끝난 판의 재도전률, 전설 미출현 연속 판 수

### 6-6. 스탯 계산 방식
```
최종 공격력 = (기본 공격력 + 고정 보너스 합) × (1 + % 보너스 합)
```
- 보너스는 리스트에 모아두고 매번 다시 계산한다. (스킬을 먹는 순서와 관계없이 결과가 같다.)
- 보너스마다 **출처**(스킬 / 장비 / 룬 / 영웅)를 붙인다.
- 보너스마다 **적용 대상**(기본 공격 / 액티브 / 둘 다)을 정한다. ([3-3 멈춤의 가치](#3-3-멈춤의-가치-액티브가-강해져도-멈출-이유) 참고)
- 공격속도, 둔화, 방어력(피해 감소), 흡혈 회복량 같은 값에는 **상한·하한**을 둔다.
- 주의: 스탯은 순서와 무관하지만 관통·튕김·분열 같은 **투사체 효과는 순서가 중요**하다. 파생 투사체(튕긴 화살, 갈라진 화살)가 다시 효과를 발동하는지 스킬마다 정한다.

### 6-7. 리롤
- 카드가 마음에 안 들면 **광고를 보고 다시 뽑는다.** 조합 카드가 있으면 **조합 카드는 고정, 나머지 2장만** 다시 뽑는다.
- **판당 최대 2회** (임시값). 무제한이면 광고로 전설을 캐서 기록에 영구 저장하는 게 최선이 된다.
- 리롤은 "다시 뽑을 기회"이지 더 좋은 카드를 보장하지 않는다고 화면에 알린다.
- **방금 화면에 있던 일반 카드는 다시 뽑지 않는다.** (광고를 보고 같은 카드가 또 뜨지 않게. 후보가 모자라면 등급 대체 → 기본 카드) — [조사 A1](Research/2026-10-26-mobile-roguelike-research.md)
- 광고가 실패하거나 취소되면 횟수를 차감하지 않는다.
- **앱을 껐다 켜도 같은 카드가 나와야 한다.** 화면에 뜬 카드 3장, 남은 리롤 횟수, 광고 보상 처리 상태를 같이 저장한다.

### 6-7-1. 카드 빼기 · 목표 레시피 (2026-10-29, 전체 기획 검토 3번 "선택 실패 줄이기")
- **카드 빼기 (판당 무료 2번):** 레벨업 화면 리롤 옆 **[빼기 (남은 2)]** → 누르면 빼기 상태 (카드에 빨간 테두리) → 카드를 누르면 그 스킬은 **이번 판에 다시 안 나오고**, 그 자리에 같은 뽑기 규칙으로 새 카드 1장. 한 번 더 누르면 빼기 취소.
  - 대상: 새 스킬 · 레벨업 카드. **조합 카드는 빼기 대신 "이번 판 숨기기"**, 기본 카드(체력 회복 등)와 균열 강화는 뺄 수 없다.
  - 튜토리얼 판엔 없다 (정해 둔 카드). 뺀 스킬과 남은 횟수는 판 이어하기에 같이 저장한다. 광고 없음, 리롤과 따로 센다.
  - 뺀 스킬이 재료인 조합은 그 판에선 못 만든다 (조합 카드의 "고르면 막혀요" 경고처럼 빼기 상태 카드에 "막히는 조합" 이름을 보여 준다).
- **목표 레시피 ★ (최대 2개, 계정 저장):** 조합 도감에서 발견한 레시피를 ★로 고른다. 판 중 레벨업 카드가 그 재료면 카드 힌트 줄에 **"★ 목표: 결과 이름"**. **뽑기 확률은 바꾸지 않는다** (표시만).

| 전설 | 화살비 | 6초마다 화면 전체에 화살 | 전체 |

**조합 2개** (서로 다른 액티브 기반)

| 방식 | 레시피 | 결과 |
|---|---|---|
| 진화 | 회전 칼날 Lv5 + 방어력 | **강철 회오리**: 칼날 수 2배, 칼날이 적 투사체를 막음 (칼날당 1초에 1발) |
| 합체 | 낙뢰 Lv3+ + 불꽃 장판 Lv3+ | **뇌화 폭풍**: 번개가 떨어진 자리에 불꽃 장판. 액티브 칸 1개 비워짐 |

**빌드 유형 3가지** (강점이 서로 겹치지 않게)

| 빌드 | 핵심 조합 | 강점 | 약점 |
|---|---|---|---|
| 🏹 **연사형** | 공격속도 + 멀티샷 + 공격력 + 흡혈 | **멈춤 화력** (단일 보스) | 잡몹 떼, 계속 움직여야 하는 상황 |
| 🛡️ **칼날 탱커형** | 회전 칼날 → 강철 회오리 + 방어력 + 최대체력 | **차단·근접** (탄막, 몰려오는 적) | 멀리 있는 적, 화력 |
| ⚡ **번개 광역형** | 낙뢰 + 불꽃 장판 → 뇌화 폭풍 + 최대체력 | **광역·지속** (잡몹을 부르는 보스) | 단일 대상 순간 화력 |

**레벨업 횟수 기준:** 던전 모드 한 판에 레벨업 **약 15회** (임시). 조합 하나에 최소 7회가 든다. (진화: 칼날 5 + 방어력 1 + 조합 카드 1 / 합체: 3 + 3 + 조합 카드 1) → 한 판에 조합 2개를 다 만들기는 빠듯하다. **어느 조합을 노릴지가 선택**이 된다.

**검증 방법:** 같은 레벨업 횟수로 세 빌드를 만들어 **단일 보스 / 잡몹 다수 / 탄막** 세 상황에서 화력·생존·정지 비율을 비교한다. 상황마다 1등이 달라야 한다.

## 7. 기록 시스템 & 보스맵 ⭐ 이 게임의 핵심

### 7-1. 기록에 저장되는 것
- 사용한 영웅
- 가진 **액티브·패시브·조합 스킬의 ID와 저장한 레벨**
- **만들 당시의 판 밖 성장 상태(스냅샷):** 영웅 레벨·각성, 수련, 장비 ID와 강화값, 유물 보너스, 펫 ID와 레벨을 그대로 고정 저장 (v0.4 이후). 나중에 계정이 강해져도 옛 기록은 그대로 → 새 기록을 만들 이유가 남는다
- 도달한 층, 클리어 여부, 날짜, 기록 고유 ID

### 7-2. 기록 용량 (카제나 방식에서 착안)

**비용 = 스킬별 레벨당 비용 × 저장할 레벨**

| 종류 | 일반 | 희귀 | 전설 |
|---|---|---|---|
| 패시브 (레벨당) | 1pt | 2pt | 6pt |
| 액티브 (레벨당) | 2pt | 3pt | 6pt |
| 조합 | **조합별 고정 비용** (아래) | | |

| 조합 | 저장 비용 (예시) | 계산 |
|---|---|---|
| 진화 (강철 회오리) | **10pt** + 필요한 패시브 비용 따로 | 칼날 진화 10 + 방어력 Lv1 1 = 11pt. 패시브를 진화 비용에 넣지 않는다 (이중 계산 방지) |
| 합체 (뇌화 폭풍) | **Lv1 15pt, 레벨당 +3** | Lv1 15pt. 비운 칸에 회전 칼날 Lv1을 더 받으면 +2 = 17pt |

- 합체로 비운 칸에 또 액티브를 받으면 비용이 늘어나는 게 맞다. 화력이 늘었기 때문이다.

#### 용량은 고정값이 아니라 "비율"로 정한다
판마다 레벨업 횟수가 달라서 고정값(예: 30pt)은 너무 크거나 너무 작아진다. 그래서 **"대표 완성 빌드의 총비용"을 기준(100%)**으로 정한다.

| 상황 | 저장 가능 용량 (기준 대비, 예시) | 느낌 |
|---|---|---|
| 끝까지 **클리어** | 약 **80%** | 핵심은 다 남기고, 자잘한 것 1~2개만 버림 |
| 중간에 **사망** | 약 **80% × 깬 방 비율** | 늦게 죽을수록 많이 남김 |
| 초반에 사망 | 아주 적음 | 전설 하나 겨우 남기거나 못 남김 |

- 계산식 예: `용량 = 기준 비용 × 0.8 × (깬 방 수 ÷ 전체 방 수)`, 클리어하면 비율 = 1
- **일부러 죽는 전략 방지:** 초반에 전설을 얻고 바로 죽으면 그 전설을 담을 용량이 거의 없다.
- **개발 전 기준값 (임시 확정):** 대표 완성 빌드(레벨업 15회: 액티브 3~4개 평균 Lv3 + 패시브 4개 평균 Lv2.5) 비용 = **34pt**, 클리어 시 80% = **27pt**. v0.2 플레이 기록으로 다시 맞춘다.
- 판 밖 성장(기록 용량 증가)은 이 80%를 조금씩 올리는 방식이다. (예: 80% → 90%)

#### 저장 화면 규칙
- 용량을 넘으면 **어떤 스킬을 남길지 직접 고르는** 화면이 나온다.
- 레벨 일부만 남길 수 있다. (예: 회전 칼날 Lv5 중 Lv3만)
- **진화 스킬은 통째로 남기거나 통째로 뺀다.**
- **합체 스킬은 레벨을 낮춰서 남길 수 있다.** (예: 뇌화 폭풍 Lv3 중 Lv1만) 합체 결과는 재료와 상관없이 자기 레벨로 복원된다.
- 진화 형태를 남기려면 **진화에 필요한 패시브도 같이 남겨야 한다.** 빼면 **진화 전 액티브 Lv5로 돌아간다.** 저장 화면에서 돌아갈 형태와 바뀌는 비용을 미리 보여준다.
- 카제나처럼 저장이 확률로 실패하는 방식은 쓰지 않는다.
- **이번 판 피해 비율을 같이 보여준다.** 액티브·조합 줄마다 "이번 판 피해 n%"가 붙고, 결과 화면에는 피해 상위 5개(기본 공격·영웅 대표 효과 포함)가 나온다. 무엇을 남길지 고르는 근거다. (v0.3, 조사 A5)
- **처음 추천값(자동 맞추기)은 피해를 많이 낸 액티브를 남긴다.** 깎는 순서: 진화·합체는 마지막 → 등급이 낮은 것 먼저 → 패시브 먼저 → 같은 등급 액티브는 피해 비율이 낮은 것 먼저 → 레벨이 높은 것부터 한 단계씩. 다시 고르기(보스 도전 화면)에는 판 피해 기록이 없어서 피해 비율을 쓰지 않는다.

### 7-3. 기록 사용 규칙 (확정)
- **재사용형:** 보스전에 써도 기록이 사라지지 않는다. 져도 잃지 않는다.
- 기록 슬롯은 처음 3개 (임시값)
- **임시 칸 1개 (무료, 2026-10-29 전체 기획 검토 2번):** 보관함이 다 찼을 때 기록 저장 화면에서 **[임시 칸에 두기]**를 고를 수 있다 (덮어쓸 칸을 고르지 않아도 된다). 임시 기록도 보스전에 쓴다. 임시 칸에 새 기록을 두면 옛 임시 기록은 사라진다 (확인 창). 보관함에 빈 칸이 생기면 임시 기록을 **[보관함으로 옮기기]**. 임시 칸은 칸 수(`recordSlots`)·"기록 n개 가짐" 미션에 세지 않는다.
- **기록 잠금 🔒:** 보관함 기록마다 잠글 수 있다. 잠근 기록은 덮어쓰기·지우기 칸으로 고를 수 없다 (먼저 풀어야). 임시 칸은 잠글 수 없다. 잠금은 보스전 사용에는 영향 없음.
- 저장 형식: 기존 값에 **덧붙이기만** (`RunRecord.locked` 기본 false, 임시 기록 하나) → 예전 저장 파일은 그대로 읽힌다.
- 보스전은 기록에 저장된 상태 그대로 싸운다. **현재 장비를 덧붙이지 않는다.** (그래야 새 기록을 만들 이유가 남는다)
- 보스전에서는 레벨업하지 않는다. 기록의 빌드로만 싸운다.

### 7-4. 보스맵
- 구간마다 보스가 있고, 최초 격파 시 다음 구간이 열린다.
- **보스는 완전 면역 대신 패턴으로 빌드를 시험한다.**
  - 예: 짧은 빈틈에만 맞는 보스 → 기본 공격 연사 빌드가 유리
  - 예: 잡몹을 계속 부르는 보스 → 액티브 광역 빌드가 유리
  - 예: 투사체를 마구 쏘는 보스 → 칼날 탱커형이 유리
- 성공 기준: **플레이어가 보스에 따라 실제로 다른 기록을 고르는가.**
- **기록 강점 (v0.3, 조사 A8):** 스킬마다 역할 1개(단일·광역·방어·없음, [Skills 7장](Design/Skills.md#7-스킬-역할-기록-강점용))를 두고, 기록의 강점 = 역할별 **저장 비용 합**이 가장 큰 것. 기록 카드에 10칸 막대 + "단일 60% · 광역 30% · 방어 10%"(색만으로 구분하지 않게 글자도), 이름에 빌드 유형("칭기즈 칸 연사형" / 광역형 / 탱커형, 강점이 없으면 기본형). 저장하지 않고 볼 때 계산한다(패치로 비용·역할이 바뀌어도 맞게).
- **보스 추천 역할:** 보스마다 추천 역할을 두고, 강점이 같은 기록에 "◎ 추천" 배지. 고르는 건 플레이어 자유. 균열의 수문장 = 단일(멈춤 타이밍). [제안] 다음 보스: 망령 군주 = 광역, 강철 거상 = 방어, 그림자 쌍둥이 = 단일, 망각의 왕 = 없음.

### 7-5. 패치(밸런스 변경) 정책
| 저장하는 것 | 패치 후 동작 |
|---|---|
| **스킬:** ID + 레벨 | 수치는 최신 스킬 데이터에서 가져온다 → **밸런스 패치가 옛 기록에도 적용된다** |
| **장비:** ID + 강화값 (만들 당시 고정) | 장비를 새로 사거나 강화해도 옛 기록은 그대로. 장비 자체의 수치 패치만 적용된다 |

- 둘은 충돌하지 않는다. "무엇을 가졌는지"는 만들 당시로 고정하고, "그게 얼마나 센지"는 최신 데이터를 쓴다.
- 스킬이 삭제되면: 기록에서 빼고 플레이어에게 알린다. **그 스킬이 재료인 조합도 다시 검사한다.**
- 조합 레시피가 바뀌면: 기록에 있는 조합 스킬은 **결과 스킬 그대로 유지**한다. (이미 만든 건 빼앗지 않는다)
- 패치로 비용이 올라 용량을 넘으면: 다음 사용 때 **남길 스킬을 다시 고르는 화면**을 띄운다.

## 8. 서바이벌 모드 (뱀서 모드)

**같은 영웅과 스킬 시스템으로, 끝없이 몰려오는 적 속에서 정해진 시간을 버티는 모드.**

### 8-1. 규칙
| 항목 | 던전 모드 | 서바이벌 모드 |
|---|---|---|
| 맵 | 방 단위 | **넓은 열린 맵** (카메라가 따라감) |
| 목표 | 방을 차례로 클리어 | **10분 생존** (임시) → 마지막 보스 |
| 적 | 방마다 정해진 수 | **시간이 지날수록 더 많이, 더 세게** |
| 레벨업 | 경험치 | 경험치 보석을 주워서 (뱀서 방식) |
| 스킬 슬롯 | 액티브 4 · 패시브 4 | **액티브 6 · 패시브 6** (판이 길어서) |
| 전설 확률 곡선 | 층 기준 | **경과 시간 기준** (예: 0분 1% → 10분 4%) |
| 기본 공격 | 멈춰야 나감 | **똑같이 멈춰야 나감** |
| 기록 | 저장 → 보스맵 | **저장 안 함** |

### 8-1-1. 적 생성·성장 (v0.5에서 정함, 벤치로 맞춘 [제안] 값)
| 항목 | 값 | 이유 |
|---|---|---|
| 생성 방식 | **분마다 정한 마리 수를 유지** (0분 8 → 2분 40 → 6분 130 → 10분 250, 모자라면 0.25초마다 최대 5마리) | 처음엔 "몇 초마다 몇 마리"로 했더니 잡는 속도보다 훨씬 빨리 나와서 4분 반에 300마리 상한에 붙었다. 유지 방식이면 약한 빌드도 같은 밀도를 상대하고, 강한 빌드는 더 많이 잡아 더 빨리 큰다 (뱀서와 같은 방식) |
| 뒤처진 적 | 화면 바깥 거리의 1.8배보다 멀어지면 화면 바로 밖으로 옮긴다 (엘리트 제외) | 달려서 무리를 떼어 내도 압박이 따라온다 |
| 적 체력·공격력 | 체력 ×(0.6 + 분 × 0.25), 공격력 ×(0.8 + 분 × 0.1). 궁병은 1분 30초부터 (25%), 폭탄병 3분부터 (10%) | 처음엔 한두 대에 쓰러져 "쓸어 담는" 맛, 10분에 체력 ×3.1 · 공격력 ×1.8. 첫 판이 2분 만에 끝나지 않게 초반 공격력을 낮췄다 |
| 엘리트 | 2·4·6·8분 (돌진병·궁병 번갈아) | |
| 마지막 보스 | 10분에 "마지막 보스가 와요!" → **남은 무리가 한꺼번에 무너진다** (경험치는 그대로) → 1구간 보스 (체력 ×160) | 300마리 속 보스는 "멈출까 피할까"가 사라진다. 무리를 걷고 1:1로 |
| 경험치 | 던전의 **×0.4** | ×1이면 10분에 Lv50 → 슬롯 12칸이 다 차고 기본 공격 비중이 7%까지 떨어졌다 |
| 카메라 | 던전보다 1.35배 넓게 (꼭 보이는 영역 13.5×24) | 200마리가 몰리면 화면이 적으로 꽉 차서, 무리 사이 길이 보이게 |
| 해금 | **1구간 보스 격파 = 맵 1** (확장 1차에서 2구간 → 1구간), 맵 2·3은 앞 맵 클리어. 하트 **1** (2 → 1). 개발 빌드는 늘 열림 | 확장 1차 6-1장 |
| 보상 | 골드 분당 50, 🏺 2분당 1 (판당 5), 계정 경험치 분당 10, 첫 클리어 🔗 인연의 룬, 유물 대체 고대 파편 보상 3개 (5분 생존·클리어·영웅 2명 클리어) | 8-4 |

### 8-1-2. 큰 모드 (확장 1차 6장, 2026-10-28) — [Expansion1 6장](Design/Expansion1.md)

### 8-2. 이 게임만의 뱀서
- 보통 뱀서는 이동만 하면 모든 공격이 자동이다. 이 게임은 **"멈추면 기본 공격까지 더해진다"**는 규칙을 그대로 쓴다.
- → 몰려오는 적 사이에서 **"지금 잠깐 멈춰서 몰아칠까, 계속 피할까"** 판단하는 재미가 생긴다.
- 액티브가 중심이고, 멈춤은 순간 화력을 더하는 선택지다.

### 8-3. 왜 기록을 저장하지 않나
- 서바이벌은 판이 길고 레벨업이 훨씬 많아서 빌드가 매우 강해진다. 이걸 보스맵에 가져가면 던전 모드의 기록이 의미가 없어진다.
- 대신 서바이벌의 보상:
  - **조합 레시피 발견** → 조합 도감에 기록됨. 던전 모드에서도 힌트가 뜬다. ("조합 실험실" 역할)
  - 재화 (장비·룬 성장용, v0.4 이후)
  - 생존 시간 기록, 영웅별 최고 기록

### 8-4. 메인 루프를 잡아먹지 않게
- 기록을 막아도, 서바이벌에서 재화를 너무 잘 벌면 "서바이벌 반복 → 장비로 보스 돌파"가 최선이 된다.
- 규칙: **같은 진행도에서 서바이벌의 분당 재화 ≤ 던전 모드의 분당 재화**
- 서바이벌만 주는 보상은 **조합 발견과 기록(생존 시간)** 중심으로 한다.

### 8-5. 기술 주의점 (휴대폰 성능)
| 항목 | 기준 (임시) |
|---|---|
| 오브젝트 풀링 | 적, 투사체, 경험치 보석, 피해 숫자, 이펙트 모두 |
| 동시 개수 상한 | 적 최대 300, 투사체 최대 500, 보석은 일정 개수 넘으면 합쳐서 큰 보석으로 |
| 충돌 처리 | 물리 엔진 대신 **공간 분할**(격자로 나눠서 가까운 것만 검사) + 거리 계산 |
| 화면 | 겹치는 피해 숫자는 줄이거나 합친다 |
| 검증 | **저사양 폰에서 10분 플레이 후** 30fps 이상 유지, 발열·메모리 확인 |

### v1.0 출시 범위 (작고 단단하게)
**장비·룬·여러 직업·서바이벌 모드는 출시 전에 모두 넣는다.** 대신 처음엔 단순한 형태로 넣고, 깊이는 출시 후에 늘린다.

| 시스템 | v1.0에 넣는 것 | 출시 이후로 미루는 것 |
|---|---|---|
| 직업 | 궁수, 전사, 총잡이, 법사 (각 1명) | 소환사, 직업별 추가 인물 |
| 장비 | **6칸, 슬롯 강화 + 합성 (확장안 결정)**, 고정 부가 능력치 | 무작위 옵션, 고유 효과, 희귀→전설 합성 |
| 룬 | 슬롯 1~2칸, 태그 가중치형 | 룬 조합 효과 |
| 펫 | 4마리, 1칸, 펫마다 다른 행동 | 펫 추가, 펫 스킨 |
| 유물 | 24개 컬렉션 + 6세트 | 유물 추가 |
| 서바이벌 | 맵 1개, 10분 생존 + 보스 1 | 맵 추가 |
| 무한의 균열 · 일일 도전 | 포함 | 보스 러시 (v1.1) |
| 해금 | [Systems.md 3장](Design/Systems.md#3-해금-순서) 기준 | |

- 룬은 **등급 확률(전설이 나올 확률)은 건드리지 않는다.** "전설은 귀하다" 원칙을 지키기 위해서다.
- 균형 점검: 대표 보스에서 **"기본 성장 + 잘 짠 빌드"**가 **"높은 성장 + 대충 고른 빌드"**보다 쉽게 이겨야 한다. 반대면 판 밖 성장이 너무 강한 것이다.

### 12-2. 설계 원칙

| 영역 | 규칙 |
|---|---|
| **정의 vs 상태** | ScriptableObject(`SkillData`)에는 **변하지 않는 정의만** 둔다. 레벨, 쿨다운, 발동 상태는 판마다 새로 만드는 런타임 객체(`SkillInstance`)에 둔다. SO 값을 플레이 중에 바꾸면 에디터에서 원본이 바뀌어버린다. |
| **`Apply()` 계약** | 기록을 불러올 때는 ① 플레이어 상태를 초기화하고 ② **현재 레벨 기준으로** 다시 구성한다. 이벤트 구독은 해제 후 다시 등록한다. 두 번 불러와도 효과가 중복되면 안 된다. |
| **조합** | 조합이 일어나면 재료 `SkillInstance`를 정리(이벤트 해제, 소환물 제거)한 뒤 결과 스킬을 만든다. 합체는 액티브 칸을 하나 비운다. |
| **효과 구현** | 숫자만 다른 스킬은 공통 구현을 재사용한다. 새로운 동작이 필요한 액티브만 별도 클래스로. |
| **태그** | 태그는 효과 분류용. **영웅 전용 스킬은 영웅 ID로** 지정한다. 태그 조건은 AND/OR 의미를 명시한다. |
| **모드 공유** | 던전·보스·서바이벌은 **같은 스킬 코드**를 쓴다. 모드마다 다른 것(슬롯 수, 레벨업 방식, 적 생성)은 모드 설정 데이터로 뺀다. |
| **ID와 버전** | 에디터에서 ID 중복을 검사한다. 저장 파일에는 **저장 구조 버전**과 **밸런스 버전**을 따로 둔다. |
| **저장** | 임시 파일에 먼저 쓰고 → 성공하면 교체 + 백업 1개 유지. 방 클리어, 스킬 선택 확정 같은 **안전한 시점에 저장**한다. 모바일에서는 `OnApplicationQuit`가 호출된다고 믿으면 안 된다. 불러오기에 실패해도 기존 파일은 지우거나 덮어쓰지 않는다. |
| **광고** | 인터페이스(`IRewardedAdService`) 뒤에 숨긴다. 가짜 광고에는 **성공 / 실패 / 취소 / 지연** 모드를 둔다. |
| **성능** | 적·투사체·이펙트는 **오브젝트 풀링**. 서바이벌 모드 기준으로 설계한다. |

### 12-3. 저장 테스트 체크리스트
- [ ] 저장 → 불러오기 후 같은 빌드가 복원되는가 (조합·진화 포함)
- [ ] 두 번 불러와도 효과가 중복되지 않는가
- [ ] 옛 버전 기록을 읽다 실패해도 원본 파일이 보존되는가
- [ ] 저장 중 앱을 강제 종료해도 이전 기록이 살아있는가

### 12-4. 핵심 뽑기 로직
- [x] `PickSkills(candidates, count, floor)`: 카드마다 등급을 먼저 뽑고, 그 등급에서 스킬을 중복 없이 뽑기 (6-4 규칙)
- [x] `FindAvailableFusions(loadout, recipes)`: 지금 가진 스킬로 만들 수 있는 조합 찾기 (6-2 규칙)
