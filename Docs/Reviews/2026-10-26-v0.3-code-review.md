## 원문

`main...feature/v0.3-heroes`의 **`5df4cba` 기준**으로 검토했습니다. 미커밋 변경은 제외했습니다.

1. **[P1] 관우가 이동 중에도 연속 기본 공격을 합니다.**  
   [PlayerController.cs:382](../../Game/Assets/Scripts/Player/PlayerController.cs:382)  
   멀티샷으로 첫 베기를 시작한 뒤 이동하면, 남은 베기와 검기가 이동한 위치에서 계속 발생합니다. `Swings()`는 사망만 검사합니다. 기본 공격은 정지 중에만 허용한다는 규칙에 어긋납니다. **각 베기 직전에 이동 여부를 검사하고 남은 연속 공격을 취소해야 합니다.**

2. **[P2] 쌍 부메랑의 분열 조각이 돌아오지 않습니다.**  
   [BoomerangBehaviour.cs:54](../../Game/Assets/Scripts/Skills/Effects/BoomerangBehaviour.cs:54), [BoomerangMover.cs:61](../../Game/Assets/Scripts/Skills/Effects/BoomerangMover.cs:61)  
   분열 조각에 `distance = 0`을 넘기는데, 귀환 속도를 `distance / _outTime`으로 계산합니다. 조각은 분열 지점에 정지한 채 최대 4초 후 사라집니다. **귀환 속도를 이동 거리와 별도로 전달하거나 주인까지의 거리로 계산해야 합니다.**

3. **[P2] 쌍 부메랑의 귀환 개수와 피해도 표와 다릅니다.**  
   [BoomerangBehaviour.cs:55](../../Game/Assets/Scripts/Skills/Effects/BoomerangBehaviour.cs:55), [BoomerangMover.cs:83](../../Game/Assets/Scripts/Skills/Effects/BoomerangMover.cs:83)  
   조각 피해는 `0.8 × 0.5 = 0.4`, 즉 공격력의 **40%**입니다. Skills 4-4는 각 **50%**입니다. 원본도 분열 후 그대로 80% 귀환 공격을 계속합니다. **원본을 두 조각으로 교체하고, 조각 계수는 공격력 기준 `0.5`로 적용해야 합니다.**

4. **[P2] 서리 창의 확정 치명타가 피해를 중복 증폭합니다.**  
   [IceShardBehaviour.cs:51](../../Game/Assets/Scripts/Skills/Effects/IceShardBehaviour.cs:51)  
   이미 적용한 본타의 치명타 여부를 확인하지 않고 추가 피해를 주며, 추가 피해도 다시 치명타를 굴립니다. 공격력 100·계수 60%·치명타 배수 1.5에서 둘 다 치명타이면 **90 대신 135** 피해입니다. **피격 대상의 빙결 상태를 피해 적용 전에 확인해, 한 번의 확정 치명타로 처리해야 합니다.**

5. **[P2] 맹독 개화의 3중첩 상한이 적용되지 않습니다.**  
   [PoisonCloudBehaviour.cs:38](../../Game/Assets/Scripts/Skills/Effects/PoisonCloudBehaviour.cs:38), [DamageZone.cs:103](../../Game/Assets/Scripts/Skills/Effects/DamageZone.cs:103)  
   각 구름이 독립적으로 피해를 줍니다. 번진 구름 4개가 겹치면 같은 적에게 초당 120%가 적용되어, 표의 3중첩 상한인 90%를 넘습니다. `EnemyStatus.MaxPoisonStacks`는 이 경로에서 사용하지 않습니다. **적별로 독 구름 기여도를 집계해 최대 3개까지만 적용해야 합니다.**

6. **[P2] 구름 안에서 다른 공격으로 죽인 적은 맹독 개화를 퍼뜨리지 않습니다.**  
   [DamageZone.cs:104](../../Game/Assets/Scripts/Skills/Effects/DamageZone.cs:104)  
   번짐은 해당 장판의 틱이 직접 막타를 넣었을 때만 발생합니다. 구름 안의 적을 기본 공격이나 낙뢰로 처치하면 번지지 않습니다. Skills 4-4의 조건은 “구름 안에서 죽은 적”입니다. **사망 이벤트에서 구름 포함 여부를 검사하고, 구름 종료·스킬 제거 시 구독을 해제해야 합니다.**

7. **[P2] 조합·`ClearAll()` 후에도 재료 스킬의 투사체가 남습니다.**  
   [PlayerController.cs:438](../../Game/Assets/Scripts/Player/PlayerController.cs:438), [PlayerController.cs:451](../../Game/Assets/Scripts/Player/PlayerController.cs:451)  
   만궁 연사와 얼음 파편의 투사체는 플레이어 소유 풀에 생성됩니다. 스킬 제거는 해당 풀의 활성 투사체를 회수하지 않으므로, 얼음 파편을 눈보라로 합체한 뒤에도 기존 파편이 피해와 둔화를 적용합니다. 기록을 다시 적용할 때도 같습니다. **투사체에 스킬 소유자를 연결하고 `Dispose()`에서 해당 소유자의 투사체·콜백을 취소해야 합니다.** GameDesign 12-2의 재료 효과 정리 계약에 해당합니다.

8. **[P2] 나폴레옹의 포탄 주기가 ‘3발’이 아니라 ‘3회 공격’입니다.**  
   [PlayerController.cs:260](../../Game/Assets/Scripts/Player/PlayerController.cs:260)  
   멀티샷 Lv1이면 공격당 총알이 2발인데, 3회 공격해 **6발을 발사해야 포탄 1개**가 나옵니다. Heroes 5장의 “기본 공격 3발마다”와 다릅니다. **실제 발사한 기본 탄환 수를 누적하고 3발마다 포탄을 발생시켜야 합니다.**

- **[P3] `AttackFx` 정적 풀은 씬 전환 때 유지되지 않습니다.**
