## 2차 — Codex 재확인 (`74f7b6d`) + 자동 보안 리뷰

| 3 | 🔴 ③ 받다 만 B 임시 파일이 새 게스트 진행이 됨 | **디스크까지 되돌리고, B에 머문다.** `SaveStore.Save`가 어느 단계(임시 파일 쓰기 · 본 파일 → 백업 · 임시 → 본 파일)에서 실패해도 백업으로 옮긴 본 파일을 되돌리고 임시 파일을 지운 뒤 실패를 알린다 (되돌리기가 실패해도 임시 파일은 지워 다음 실행은 백업을 읽는다 — 받다 만 글을 완성본으로 올리지 않는다). 계정 바꾸기에서 B 진행으로 **바꾸기 시작한 뒤에는** 실패해도 게스트로 돌아가지 않고 B 표시 · 세션을 지킨 채 B에 머물러 다음에 다시 고른다. 시작할 때 B 표시인데 B가 아닌 세션이면 그 플레이어로 이어 가지 않는다 (오프라인 + 문의 — 이 기기 저장에 B 진행이 있을 수 있다). 시험: 단계마다 입출력 오류 주입 → `SaveSystem.Replace` 실패 · 메모리 A · 디스크 본 파일 A · 임시 파일 없음 · 다음 실행 A, 되돌릴 백업까지 사라져도 임시 파일은 지워져 B를 올리지 않음, `DecideSwitchTarget`(다른 플레이어 세션 → 기다림) |
