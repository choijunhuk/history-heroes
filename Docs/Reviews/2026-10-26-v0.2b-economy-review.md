## 원문

검토 기준은 `b7640db..782a754`입니다. 미커밋 에셋·설정 변경은 제외했습니다. 다음 문제를 확인했습니다.

1. **[P2] 원본 보존에 실패해도 저장 파일을 삭제합니다.**  
   위치: [SaveStore.cs:72](../../Game/Assets/Scripts/Records/SaveStore.cs:72)  
   `PreserveBroken()`은 복사 실패 시 `null`을 반환하지만, 바로 다음 줄에서 원본을 삭제합니다. 예를 들어 상위 스키마 파일을 읽지 못하고, 공간 부족으로 보존 복사도 실패하면 다음 저장에서 해당 파일을 잃습니다. 이전 리뷰 수정이 정상 백업은 보호하지만 원본 보존까지 보장하지는 않습니다.  
   **수정:** 보존 사본이 확보된 경우에만 원본을 제거하고, 실패하면 저장 실패로 반환하세요.

2. **[P2] 임시 파일 복구 중 이름 변경 실패가 초기화를 중단시킵니다.**  
   위치: [SaveStore.cs:106](../../Game/Assets/Scripts/Records/SaveStore.cs:106)  
   정상 `.tmp`를 읽은 뒤 실행하는 `File.Move()`는 예외 처리 밖에 있습니다. 읽기는 가능하지만 이동이 실패하는 상태에서는 `Load()`가 예외를 던지고, `SaveSystem.Data`를 읽는 로비 초기화가 중단됩니다.  
   **수정:** 이동 실패를 처리하고 복구 데이터를 반환하되, 보호하지 못한 `.tmp`를 이후 저장이 덮어쓰지 못하도록 차단하세요.

3. **[P2] 보스 ★3이 실제 전투에 사용한 빌드와 다른 구성을 비교합니다.**  
   위치: [Stars.cs:98](../../Game/Assets/Scripts/Economy/Stars.cs:98)  
   보스전은 `RecordValidator`로 보정한 스킬을 적용하지만, 별 판정은 원본 `record.skills`를 비교합니다. 패치로 강철 회오리가 회전 칼날로 복원된 기록과, 원래 회전 칼날을 가진 기록으로 각각 승리하면 실제 빌드는 같아도 ID 차이 2개로 ★3을 받습니다. 재선택으로 바뀐 기록에도 과거 격파 표시가 유지되어 비슷한 오판정이 가능합니다.  
   **수정:** 승리 당시 실제 적용한 액티브 구성과 기록 ID를 별도 저장하고 그 이력을 비교하세요.

4. **[P2] 하트가 없으면 보스 연습도 할 수 없습니다.**  
   위치: [GameSession.cs:43](../../Game/Assets/Scripts/Common/GameSession.cs:43), [BossIntroPanel.cs:127](../../Game/Assets/Scripts/UI/BossIntroPanel.cs:127)  
   첫날 무료 판을 소진하고 하트가 0이면 보스 진입은 충전 창으로만 이어집니다. `Economy.md` 3-4가 요구하는 보상 없는 보스 연습 경로가 없습니다.  
   **수정:** 연습 진입과 세션 상태를 추가하고, 연습에서는 하트 소비·환급과 보상·별·해금 지급을 제외하세요.

5. **[P2] 보스 패배 시 계정 경험치 50이 누락됩니다.**  
   위치: [BossRun.cs:130](../../Game/Assets/Scripts/Modes/BossRun.cs:130)  
   `Stats.md` 7장은 보스맵 경험치를 승패 조건 없이 50으로 정의하지만, 지급 호출이 승리 분기 안에만 있습니다. 정상 도전을 끝내고 패배해도 경험치와 그에 따른 레벨업·하트 충전을 받지 못합니다.  
   **수정:** 정상 보스 도전의 경험치는 승패 공통 종료 경로에서 지급하세요.

낮은 우선순위 문제입니다.

6. **[P3] 보스 패배 환급 한도가 보스별이 아닌 계정 전체에 적용됩니다.**  
   위치: [Hearts.cs:110](../../Game/Assets/Scripts/Economy/Hearts.cs:110)  
   `Economy.md` 3-3은 **같은 보스당 하루 5회**인데, 구현은 단일 `daily.heartRefunds`만 사용합니다. 보스 A에서 5회를 쓰면 아직 깨지 않은 보스 B에서도 환급되지 않습니다. 현재 보스가 한 종류라 영향은 제한적입니다.  
   **수정:** 보스 ID별 일일 카운터로 저장하고, 서로 다른 두 보스의 한도가 독립적인지 테스트하세요.

7. **[P3] 지연 광고 콜백이 파괴된 하트 창을 갱신합니다.**  
   위치: [HeartPanel.cs:95](../../Game/Assets/Scripts/UI/HeartPanel.cs:95)  
   가짜 광고를 `Delay`로 설정하고 광고 시작 → 창 닫기 → 자연 충전된 하트로 전투 진입하면, 장면 전환 뒤에도 광고 콜백이 실행됩니다. 보상 저장 후 파괴된 UI에 `Render()`를 호출하여 `MissingReferenceException`이 발생합니다.  
   **수정:** 보상 지급과 화면 갱신을 분리하고, 콜백에서 컴포넌트가 살아 있을 때만 UI와 `_onChanged`를 호출하세요.
