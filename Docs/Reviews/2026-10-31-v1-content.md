# Batch D — 긴 방과 기능 첫 사용 안내

## 변경

- A-5: 1~5구간마다 긴 모양 2종, 일반 7·12번 중 시드로 고른 한 곳에만 배치한다. 세로 22칸, 기존 적 예산을 2무리로 나누고 두 번째 무리는 영웅이 y=2에 닿으면 예고 후 나온다. 문은 y=14.7이다.
- 기존 카메라 화면 크기는 유지하고 긴 방에서만 추적 영역 8×14를 지정해 세로로 0~8칸 이동한다. 문 모델은 출구 판정의 자식으로 두고 상단 장식도 함께 이동한다. 일반 방에 돌아오면 복원한다.
- 클리오 안내 띠와 대상 단추 테두리로 7일 미션·영웅 레벨업·장비·미션·무료 소환권을 조건에 맞게 소개한다. 로비 진입당 하나, 본 안내는 저장한다. 다른 창·전투에서는 표시하지 않고 저장 실패도 이번 로비에서는 한 번만 시도한다.
- 7일 미션 단추는 열린 날 N/7일과 기존 받을 보상 빨간 점을 쓴다. 모두 받으면 출석부로 돌아간다. 저장 구조 10→11은 기존 진행을 보존하고 안내 이력만 빈 상태로 연다.
- 자동 결제 제안은 접속당 최대 1회, 실행 뒤 첫 10분과 전투 중에는 0회로 문서화했다. 현재 자동 결제 제안 호출은 없어 가드를 추가하지 않았다. 상점과 광고는 사용자가 직접 누르는 기존 경로다.

- 방: `DungeonRun.cs`, `DungeonData.cs`, `Encounter.cs`, `RoomLayout.cs`, `CameraFollow.cs`, `SceneBuilder.Dungeon/Rooms/Scene/Decor.cs`. 기존 적·장치·방 계획·카메라 맞춤을 재사용한다.

- 문서: `GameDesign.md`, `TODO.md`, `Design/Expansion1.md`, `Design/UX.md`, `Design/Monetization.md`.
- 기존 `DungeonTests.cs`, `CameraFitTests.cs`, `LayoutReachabilityTests.cs`를 보강하고 `FirstUseHintTests.cs`, `LobbyGuideTests.cs`와 메타를 추가했다. 새 의존성은 없다.
