# 3D 전투 화면 점검 (Codex, 2026-10-27)

- 점검: Codex `gpt-6-sol` (read-only, effort medium) — 에디터 캡처 6장 (던전 2 · 서바이벌 · 보스맵 · 영웅 앞모습 · 나폴레옹/테슬라 색 바꿈)
- 총평: 3D로 바꿔 "아기자기함"과 "앞뒤가 같은" 문제는 풀렸다. 폰 크기에서 전투 정보가 작고, 바닥 효과·벽이 위험 신호를 가리는 게 먼저다.

## 원문

**총평:** 3D 전환으로 이전의 귀여운 2D 느낌은 줄었고, 인물의 앞뒤와 동작도 더 잘 구분됩니다. 다만 휴대폰 크기로 보면 전투 정보가 작고, 바닥 효과와 벽이 위험 신호를 가리는 문제가 우선입니다. UI를 숨긴 캡처이므로 HUD 자체의 가독성은 판단에서 제외했습니다.

1. **[문제] 전투 대상이 너무 작음 — `b3d_3.png`, `surv_1.png`**  
   영웅과 고블린이 좁은 실루엣으로 보여 생존 모드에서는 군중 속 영웅을 즉시 찾기 어렵습니다. **[개선]** 전투 카메라나 캐릭터 표시 크기를 조정하고, 영웅 발밑에 적·이펙트와 겹쳐도 보이는 고유 표식을 넣으세요.

2. **[문제] 위험 영역이 지형과 겹쳐 읽기 어려움 — `qa_dungeon.png`, `boss_3.png`, `surv_1.png`**  
   주황 원은 벽에서 잘리고, 보스 경기장의 두꺼운 벽은 아래쪽 영웅과 원의 경계를 가립니다. 초록 독 영역은 잔디와 색이 비슷합니다. 피해야 할 범위를 순간적으로 판단하기 어렵습니다. **[개선]** 위험 영역에 밝은 외곽선과 바닥 무늬를 더하고, 벽 앞에서도 경계가 보이도록 표시 순서를 조정하세요. 독은 잔디와 다른 색상으로 바꾸는 편이 좋습니다.

3. **[문제] 화면의 위아래 빈 공간이 큼 — `qa_dungeon.png`, `b3d_3.png`, `boss_3.png`**  
   검은 공간에 비해 실제 전투 영역과 캐릭터가 작습니다. 상단 HUD가 들어와도 하단의 빈 공간은 크게 남을 것으로 보입니다. **[개선]** HUD와 조작 영역을 얹은 실제 플레이 화면에서 방 크기와 카메라 배치를 다시 잡고, 적과 영웅이 더 크게 보이는 구도를 확인하세요.

4. **[문제] 픽업과 효과의 시각 언어가 섞임 — `surv_1.png`, `qa_dungeon.png`**  
   민트색 보석이 발광 탄이나 효과 점처럼 보이고, 던전의 어두운 직사각형 구덩이는 그림자처럼 보일 수 있습니다. **[개선]** 픽업에는 보석 형태·테두리·가벼운 부유 동작을, 구덩이에는 깊이가 드러나는 가장자리를 주세요. 3D 캐릭터와 평면 효과 사이의 차이도 줄어듭니다.

5. **[문제] 영웅 인지도가 고르지 않음 — `heroes_front_big.png`, `np_tesla.png`**  
   관우는 긴 수염과 청룡도로, 나폴레옹은 이각모로 비교적 잘 읽힙니다. 칭기즈 칸은 일반 병사에 가깝고, 테슬라는 재색상 뒤에도 평범한 민간인처럼 보입니다. 전투 크기에서는 차이가 더 줄어듭니다. **[개선]** 칭기즈 칸에는 기마궁수 정체성이 드러나는 활·화살통 실루엣을, 테슬라에는 멀리서도 보이는 코일·전기 장비와 청색 발광을 추가하세요. 나폴레옹의 파란 복장은 이전보다 구분에 도움이 됩니다.

6. **[개선] 지면 질감 정리 — `surv_1.png`, `b3d_3.png`**  
   잔디의 흙무늬 반복이 눈에 띄고, 석재 바닥은 균일해 캐릭터와 효과가 따로 놓인 듯합니다. 타일 변주와 약한 접지 그림자를 더하면 공간감이 좋아집니다. 캡처에서 뚜렷한 지면 관통이나 화면 깨짐은 보이지 않습니다.
