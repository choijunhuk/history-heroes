# 전체 그래픽 · UI/UX 검토

> Codex (gpt-6.1-sol, high, 화면 22장), 2026-10-28. 로비·영웅·상점·미션·기록·도감·설정·레벨업·갈림길·일시정지·결과·기록 남기기·3구간 방·보스·서바이벌 3맵·상자·학익진·칠성단

**현재 3D가 한계에 도달한 것은 아닙니다. 다만 지금 모습에서 소품과 이펙트만 더하면 완성도가 크게 오르기는 어렵습니다.** 모델·배경·UI·효과를 하나의 스타일로 정리해야 합니다. 제 추천은 **3D를 테스트용으로 유지하면서, LPC 2D로 작은 완성 장면을 만들어 비교하는 것**입니다.

첨부된 22장 기준 평가입니다. 애니메이션 속도, 타격감, 실제 조작감은 정지 화면만으로 확정할 수 없습니다.

**1. 아트 방향 판단**

현재 가장 큰 문제는 각진 모델보다 **서로 다른 표현 방식의 충돌**입니다. 영웅은 사실적인 신체 비율인데, 적은 귀여운 장난감 같고, UI는 원색의 둥근 버튼이며, 전장은 탁한 갈색입니다. 금빛 외곽선과 청록색 고리가 이를 연결하기보다 따로 강조합니다.

3D는 다음 방법으로 상당히 개선할 수 있습니다.

- **조명:** 밝은 주광과 약한 보조광으로 얼굴·몸통·무기를 구분합니다. 지금은 관우의 의상이 배경과 비슷하게 어둡습니다.
- **색 보정:** 전체를 갈색으로 물들이기보다 바닥의 채도를 낮추고 영웅의 대표색을 살립니다. 녹슨 공방에는 주황 조명과 차가운 철색처럼 대비를 줍니다.
- **외곽선:** 영웅에 가는 외곽선을 쓰되, 지금의 금빛 전신 발광은 줄입니다. 작은 적까지 굵게 둘러싸면 군중이 더 복잡해집니다.
- **재질:** 천·피부·금속의 밝기와 반사 정도를 구분합니다. 적절한 면에는 부드러운 음영을 적용할 수 있지만, 이것만으로 각진 실루엣까지 둥글어지지는 않습니다.
- **카메라:** 원근을 약하게 하고 위아래 캐릭터 크기 차이를 줄입니다. 전면 벽은 낮추거나 가려질 때 투명하게 만듭니다.
- **VFX:** 빛의 양보다 공격의 형태를 만듭니다. 학익진은 배의 배열과 일제사격, 칠성단은 일곱 지점과 바람 방향이 먼저 보여야 합니다.
- **UI 틀:** 짙은 먹색 패널, 절제한 황동 장식, 영웅별 문장으로 역사 판타지 분위기를 맞춥니다.

무료 모델로도 **일관된 스타일의 출시 화면**까지 갈 여지는 있습니다. 다만 얼굴·복식·무기의 고유 형태가 부족한 부분은 직접 수정해야 합니다. 조명만으로 고급 역사 캐릭터가 되지는 않습니다.

**LPC 2D는 현재 화면보다 정돈되고 완성돼 보일 가능성이 높습니다.** 캐릭터·타일·효과의 표현 단위를 맞추기 쉽기 때문입니다. 그러나 다음 위험이 있습니다.

- **64px는 성숙한 인체 비율을 보장하지 않습니다.** LPC의 기본 규격은 64×64 프레임이며, 걷기·베기·사격·시전 등의 동작 기반을 제공합니다. 프레임 크기와 실제 몸 크기는 구분해야 합니다. [LPC 공식 저장소](https://github.com/liberatedpixelcup/Universal-LPC-Spritesheet-Character-Generator)
- 복고 RPG 인상이 강해질 수 있습니다. 웅장함을 원한다면 색감·초상화·공격 연출에서 보강해야 합니다.
- 픽셀 캐릭터에 현재의 매끈한 버튼과 흐린 발광을 그대로 붙이면 또 다른 혼합 스타일이 됩니다.
- 적 250마리의 겹침은 2D에서도 남습니다. 영웅 표시, 공격 예고, 효과 밀도 관리가 필요합니다.
- 관우의 수염·언월도, 이순신의 투구·갑옷, 제갈량의 관·부채처럼 **이름 없이도 구별되는 형태**가 필요합니다. 기본 의상 조합만으로는 평범한 RPG 직업처럼 보일 수 있습니다.
- 앞뒤 차이는 필수입니다. 앞면의 얼굴·가슴 장식과 뒷면의 머리·등판·옷자락을 다르게 그리고, 모든 동작에서 유지해야 합니다.
- 4방향 몸체가 대각선 적을 공격할 때 무기 방향과 동작이 어긋나지 않는지도 확인해야 합니다.

**관우·이순신 2명, 적 3종, 방 1개, 대표 스킬 2개, 레벨업 UI까지 실제로 움직이는 2D 비교본을 권합니다.** 같은 전투를 적 30마리와 250마리로 보고 결정하세요. 기본 LPC 에셋을 배치한 화면만으로 전환을 결정하기에는 부족합니다.

**2. 화면별 UI/UX**

| 화면 | 평가 |
|---|---|
| 1. 기본 로비 | 구간·모드·하단 탭은 구분됩니다. 섬 아래 검은 덩어리는 크고 영웅은 작으며, 구간 설명·별 조건은 너무 작습니다. |
| 2. 3구간 로비 | 톱니·통·화로로 테마 변화가 보입니다. 같은 섬에 소품을 교체한 느낌이 강하고, 갈색 배경과 바닥이 붙습니다. |
| 3. 영웅 | 큰 모델과 선택된 관우는 잘 보입니다. 카드 속 전신은 너무 작고, 특성·각성·능력치가 한 패널에 몰려 있습니다. |
| 4. 상점 | 가격과 뽑기 횟수는 찾기 쉽습니다. 상품 그림 없이 버튼만 나열돼 관리 페이지 같고, 아래쪽은 크게 비어 있습니다. |
| 5. 미션 | 일일·주간·업적 구분은 명확합니다. 보상 글자가 작고, 완료 행을 누르면 수령되는지 즉시 알기 어렵습니다. |
| 6. 기록 보관함 | 세 기록의 구획은 분명합니다. 스킬 목록이 빽빽하고 작은 색 막대의 의미가 불명확하며, 삭제 버튼이 지나치게 눈에 띕니다. |
| 7. 조합 도감 | 발견 수는 읽힙니다. 같은 `???` 문장의 반복으로 수집의 재미가 약하고, 18개 중 나머지를 보는 방법이 화면에서 드러나지 않습니다. |
| 8. 설정 | 항목별 묶음은 좋습니다. 모든 설정이 같은 버튼이라 음량·선택값·켜짐 상태의 차이가 약하고 보충 설명은 작습니다. |
| 9. 레벨업 | 세 선택지와 제목은 가장 게임답습니다. 아이콘은 작고 설명은 줄바꿈이 많으며, 카드의 넓은 면적이 어두운 빈 상자로 보입니다. |
| 10. 갈림길 | 두 문과 선택의 차이는 이해됩니다. 가운데 닫힌 문까지 있어 출구가 셋처럼 보이고, 도전 조건의 작은 글씨가 묻힙니다. |
| 11. 일시정지 | 계속·설정·포기가 명확합니다. 전체 배경 교체와 큰 버튼 세 개가 전투의 맥락을 끊고 웹 메뉴처럼 보입니다. |
| 12. 결과 | 기록 남기기가 주 행동인 점은 좋습니다. 통계가 보고서처럼 나열되고, `목표 40% 이상`은 플레이어에게 개발용 지표처럼 보입니다. |
| 13. 기록 남기기 | 용량 막대와 저장 버튼은 명확합니다. `뺌·0pt·+`를 해석해야 하며, 저장 뒤 어떤 빌드가 되는지 미리보기는 부족합니다. |
| 14. 3구간 방 | 화로·철창·폭탄 적으로 변화가 보입니다. 넓은 갈색 바닥이 여전히 지배적이고, 영웅보다 고리와 펫이 먼저 보입니다. |
| 15. 보스 기록 선택 | 추천 표시와 선택 상태는 좋습니다. 기록 설명이 너무 작고, 시험할 보스의 모습이 없어 도전의 기대감이 약합니다. |
| 16. 보스전 | 큰 보스와 체력바는 분명합니다. 강철 거상이 붉은 생물처럼 보이고, 원형 벽과 큰 영웅 고리가 이동 가능 공간을 복잡하게 만듭니다. |
| 17. 서바이벌 맵 선택 | 제목·별·시작 버튼은 읽힙니다. 거대한 공통 불꽃 아이콘이 맵 미리보기를 대신하며, 뒤쪽 창과 닫기 버튼이 겹쳐 보입니다. |
| 18. 서바이벌 초원 | 녹색 지형으로 모드 차이는 납니다. 카드 뒤로 보이는 부분에서는 공간의 특징과 목적지가 약합니다. |
| 19. 서바이벌 공장 | 컨베이어의 형태와 경고색은 분명합니다. 검은 띠가 화면을 강하게 자르고, 이동 방향과 위험 여부는 정지 화면에서 불명확합니다. |
| 20. 서바이벌 상자 | 상자의 금색은 눈에 들어옵니다. 적과 붉은 선이 겹쳐 영웅·피할 틈·상자 접근로를 읽기 어렵습니다. |
| 21. 학익진 | 다수의 발사체에서 강한 공격 의도는 느껴집니다. 배보다 수직 기둥과 불티가 먼저 보여 학익진의 형태가 약합니다. |

**HTML 같은 느낌의 주원인은 사각형 자체가 아닙니다.** 모든 화면이 같은 무늬 배경 위에 비슷한 버튼과 굵은 글자를 얹고, 내용에 맞는 이미지·정보 위계·선택 상태가 부족하기 때문입니다.

**3. 영향순 개선 15개**

번호는 두 묶음을 합친 전체 우선순위입니다. 크기는 **540px 캡처 기준 출발값**이며 실제 폰에서 확인해야 합니다.

**3D·2D 공통 — UI와 전투 표현**

| 순위 | 구체적 수정 |
|---|---|
| **1** | **전투 시야 확보:** 붉은 조준선은 실제 공격 직전인 적에만 표시합니다. 영웅 주변에서는 아군 효과를 옅게 하고 적의 위험 경계선을 우선합니다. |

| **10** | **스킬 연출:** 학익진은 부채꼴 배치와 포격 궤적, 칠성단은 일곱 빛과 바람 흐름을 강조합니다. 상시 입자 수는 현재의 절반부터 비교합니다. |
| **12** | **영웅 선택:** 작은 전신 대신 얼굴·상체를 카드에 담습니다. 능력치와 성장 기능을 분리하고 대표 특성을 가장 먼저 읽히게 합니다. |
| **13** | **상점·도감·맵 선택:** 상자 그림, 조합 아이콘, 실제 맵 미리보기를 넣습니다. 버튼·문장 목록이 화면의 주인공인 구성을 바꿉니다. |
| **14** | **중단·결과·저장:** 일시정지는 어두워진 전투 위 패널로 표시합니다. 결과는 도달 방·보상·기록 행동을 우선하고, 저장 화면에는 선택된 스킬과 남은 용량을 고정 표시합니다. |
