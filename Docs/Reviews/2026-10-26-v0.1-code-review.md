## Codex 원문

커밋 `465065e`의 `main...HEAD` C# 변경분을 정적 검토했습니다. 미커밋 작업은 제외했고, 파일은 수정하지 않았습니다. Unity 실행·빌드·테스트는 수행하지 않았습니다.

**🔴 꼭 고칠 것**

1. **약한 입력으로 이동하면서 기본 공격을 계속할 수 있습니다.**  
   [StopDetector.cs:29](../../Game/Assets/Scripts/Player/StopDetector.cs:29), [PlayerController.cs:111](../../Game/Assets/Scripts/Player/PlayerController.cs:111)  
   `StopDetector`는 크기 0.1 미만 입력을 정지로 처리하지만, 실제 이동에는 같은 입력을 그대로 사용합니다. 입력을 `(0.05, 0)`으로 유지하면 기본 이동속도 기준 초당 0.25만큼 움직이면서 사격합니다. `GameDesign` 3장의 핵심 규칙 위반입니다.  
   **수정:** 데드존을 적용한 입력 하나를 이동과 정지 판정에서 함께 사용하세요.

2. **최대체력 패시브 레벨업이 기존 증가분까지 다시 회복합니다.**  
   [PassiveSkillData.cs:47](../../Game/Assets/Scripts/Skills/Data/PassiveSkillData.cs:47), [Health.cs:38](../../Game/Assets/Scripts/Combat/Health.cs:38)  
   기존 보정 제거와 새 보정 추가가 각각 `Changed`를 발생시킵니다. 최대체력 1,150·현재체력 500에서 Lv2로 올리면, 최대체력이 `1,150 → 1,000 → 1,250`으로 바뀌면서 **100 대신 250을 회복**합니다. 같은 레벨로 재적용해도 회복이 반복되어 `Apply()` 계약도 깨집니다.  
   **수정:** 보정 교체를 묶어 최종 상태에서 한 번만 알리고, 교체 전후 최대체력의 실제 증가분만 회복하세요.

3. **일시정지 중에도 새 칼날과 장판이 피해를 줄 수 있습니다.**  
   [OrbitBladesBehaviour.cs:66](../../Game/Assets/Scripts/Skills/Effects/OrbitBladesBehaviour.cs:66), [DamageZone.cs:65](../../Game/Assets/Scripts/Skills/Effects/DamageZone.cs:65)  
   `timeScale == 0`이어도 `Update()`의 판정 코드는 실행됩니다. 레벨업 두 번이 대기 중일 때 첫 카드로 칼날을 얻거나 강화하면, 다음 카드 화면이 열린 상태에서 새 칼날이 적을 때립니다. 장판도 `_tickTimer == 0`이면 `deltaTime == 0`에서 첫 틱을 처리합니다.  
   **수정:** 전투 갱신 진입점에 일시정지 검사를 추가하세요. 플레이어·적·액티브 공통 갱신도 같은 기준으로 막아야 합니다.

4. **장판이 만료 프레임에 추가 피해를 줍니다.**  
   [DamageZone.cs:58](../../Game/Assets/Scripts/Skills/Effects/DamageZone.cs:58), [DamageZone.cs:71](../../Game/Assets/Scripts/Skills/Effects/DamageZone.cs:71)  
   첫 틱을 즉시 주면서 만료 검사는 피해 처리 뒤에 합니다. 동일한 float32 타이머 계산에서 60fps 기준 **3초 장판은 7틱으로 105%**, **2초 장판은 5틱으로 75%**가 됩니다. 기획상 총량은 각각 90%, 60%입니다.  
   **수정:** 첫 틱과 종료 시점의 규칙을 통일해 총 피해량을 제한하세요. 30/60fps와 긴 프레임에서도 총량이 같은지 검증해야 합니다.

5. **강철 회오리의 ‘같은 적에게 0.3초 간격’이 칼날별로 적용됩니다.**  
   [OrbitBladesBehaviour.cs:29](../../Game/Assets/Scripts/Skills/Effects/OrbitBladesBehaviour.cs:29), [OrbitBladesBehaviour.cs:100](../../Game/Assets/Scripts/Skills/Effects/OrbitBladesBehaviour.cs:100)  
   피격 기록이 각 `Blade`에 따로 있습니다. 적 하나가 두 칼날의 판정에 동시에 겹치면 같은 프레임에 50% 피해를 두 번 받습니다. `Skills` 4-4의 적별 0.3초 제한과 다릅니다.  
   **수정:** 강철 회오리는 스킬 전체가 공유하는 적별 피격 기록을 사용하세요. 투사체 차단 쿨다운은 지금처럼 칼날별로 유지하면 됩니다.

    **수정:** 재사용 버퍼로 여러 충돌을 받고, 이전 적을 제외한 가장 가까운 유효 충돌을 처리하세요.
