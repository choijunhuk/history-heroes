# 2026-11-01 UI 글자 점검

개발자 요청: 모든 화면에서 글자가 잘 보이는지, 배치가 맞는지, 이상하게 작거나 크거나 튀어나온 게 없는지.

## 도구
- `QaTools.TextAudit(minSize = 15)` (Play 중에만): 보이는 모든 TMP 글자를 훑어 칸 밖(OVF) · 마스크에 잘림(CLIP) · 화면 밖(OFF) · 작음(SMALL) · 자동 축소 바닥(MIN) · 겹침(OVL)을 한 줄씩 보고한다. 1080 기준 해상도 단위, 같은 화면 안 글자끼리만 겹침 비교, 스크롤 목록 가장자리는 제외.
- 한계: 글 안의 `<size=NN%>` 는 재지 않는다 (눈으로 확인).

## 훑은 화면 (1080×1920 · 일부 1080×2340)
로비 홈, 영웅 · 장비 · 펫 · 룬 · 유물, 상점, 미션, 7일 미션, 조합 도감, 기록 보관함, 설정, 보스 선택, 서바이벌 맵, 던전 레벨업 카드, 보스 연습 HUD · 일시정지 · 설정 · 결과, 첫 사용 안내 띠.
못 본 화면: 일반 던전 HUD 단독 컷(레벨업이 연달아 떠서), 기록 저장 화면, 신의 시련 탭 상세, 결제/법적 문서 화면.

## 찾은 문제와 고친 것
| 화면 | 문제 | 조치 |
|---|---|---|
| 로비 상단 | 계정 레벨 "Lv" 글자가 화면 위로 6px 삐져나감 | 상단 바를 아래로 10px (`SceneBuilder.LobbyMain.cs`) |
| 로비 왼쪽 | "조합 도감 0/31" 한 줄이 단추 가장자리에 붙음 | 두 줄로 (`LobbyScreen.cs`) |
| 로비 아래 탭 | "기록 보관함 1/3" 이 탭 폭 꽉 참 | "기록 1/3" |
| 로비 서바이벌 | 보조 줄 20px로 작음 | 60 → 70%, 문구 "맵 3개" 빼서 짧게. 순찰 보조 줄 70 → 80% |
| 로비 첫 사용 안내 띠 | 위에서 460px 고정이라 옆 단추(7일 미션 · 조합 도감 · 설정 · 순찰)를 가림, 긴 폰에서는 더 심함 | 화면 가운데 기준 +340 (`SceneBuilder.Onboarding.cs`) |

그 외 화면은 자동 점검 문제 0건, 눈으로도 이상 없음 (보조 줄은 대체로 18~22px로 기준 15px 이상).

## 남긴 것
- 7일 미션 단추 보조 줄(75%)은 테스트가 문자열을 고정하고 있어 그대로 둠.
- 던전 카드 위 흐릿한 "기록 용량" 안내가 레벨업 화면 뒤로 비침 (정상 동작, 손대지 않음).
