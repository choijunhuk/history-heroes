# 인류 영웅 17~19 구현 인계

2026-10-29 · `feature/humans-c` · 커밋하지 않은 코드와 문서 변경이다.

## 수치

| 영웅 | 체력 / 공격력 / 공속 / 사거리 / 이동속도 | 대표 효과 ★1 → ★3 → ★5 |
|---|---|---|
| 토모에 고젠 `tomoe` | 950 / 100 / 1 / 6 / 5 | 두 번째 정지 공격의 주화살만 좌우 8° 두 갈래. 각 60% → 70% → 80%. 이동하면 횟수 초기화 |
| 무측천 `wuzetian` | 900 / 90 / 1 / 5.5 / 5 | 같은 적 3회 명중 → 주변 다른 일반 적 한 명 이동 정지 0.6초 → 0.8초 → 탐색 반경 2.5에서 3. 보스만 남으면 15% 둔화, 대상별 6초 제한 |
| 마리 퀴리 `curie` | 900 / 90 / 1 / 5.5 / 5 | 적 한 명 표식 → 다음 공격에 그 적 주변 파동. 피해 40% → 55% → 반경 1.2에서 1.6. 소비한 공격은 다시 표식을 남기지 않음 |

세 영웅 모두 보석 2,000 또는 기존 던전 10판 한 명 무료 선택이다. 새 무료 선택 횟수나 신 성장 규칙은 없다.

| 영웅 | 전용 액티브 | 전용 진화 |
|---|---|---|
| 토모에 | 겹시위: 7초, 화살 3발·각 55%, 레벨마다 +10%p | 겹시위 Lv5 + 공격속도 Lv1. 교차하는 바람: 7초, 5발씩 두 번·각 60%, 레벨마다 +12%p |
| 무측천 | 기록의 칙령: 8초, 반경 1.5·100%, 레벨마다 +20%p | 칙령 Lv5 + 방어력 Lv1. 정연한 서책: 같은 자리 3파·각 65%, 레벨마다 +15%p |
| 퀴리 | 분광의 빛: 8초, 반경 1.6·110%, 레벨마다 +20%p | 분광의 빛 Lv5 + 기술 숙련 Lv1. 관측의 스펙트럼: 직선 3파·각 70%, 레벨마다 +15%p |

액티브는 희귀 Lv1~5·레벨당 3pt, 진화는 희귀 Lv1~3·첫 12pt·이후 +4pt다. 진화 뒤 패시브는 남는다.

## 검증과 한계

- 설치된 Unity 6000.3.27f1 모듈과 설치 템플릿의 패키지 DLL로 별도 C# 컴파일: 런타임 274파일·에디터 44파일·EditMode 52파일 모두 오류 0. 런타임 경고 662개, 에디터·테스트 경고 0개.
- 대표 효과의 실제 NUnit 메서드를 별도 관리 코드 하네스로 실행해 33/33 통과. 하네스는 Unity의 생성·파괴를 건너뛰고 소스에 선언된 영웅 필드 초기값을 주입했다. 별도 네이티브 생성 검사 3개는 제외했다. **Unity EditMode 전체 실행 결과가 아니다.**
- 독립 정적 검토에서 퀴리의 고공속·최대 사거리 지연 명중 누락을 발견하고 수정했다. A 공격 → B 공격 시작 → A 명중 → C 공격에서 파동 순서와 소비 전 탄 무효화 회귀를 추가했다. 재검토에서 추가 확정 결함은 없었다.
- 공백 검사, 새 스크립트와 `.meta` 짝·GUID 중복·미완성 표시 검사를 통과했다. `.unity`·`.prefab`·`.asset`·폰트 SDF는 바꾸지 않았다. 시작 때부터 수정 상태로 표시된 바이너리 파일도 편집하지 않았다.
- Unity 실행·프로젝트 패키지 해석·물리 명중·소품 위치·초상·폰트·Android·성능·밸런스는 미검증이다. 기존 생성 에셋을 읽는 명단 검사는 재생성 뒤 실행해야 한다.
- 임시 컴파일 응답 파일과 로그는 `/private/tmp/hh-humans-c-validation/`에 있다.

리드는 Edit 모드에서 `Art3DCharacters.BuildAll()` → `SceneBuilder.BuildAll()` 순서로 재생성한 뒤 컴파일·전체 EditMode·화면을 확인한다. `Hero1..Hero19` 가로 선택 줄, 잠긴 영웅 체험, 해금·기록 복원, 세 별 단계와 같은 빌드 벤치를 확인한다. 맨 마지막 커밋도 리드가 맡는다.
