# v0.5 코드 리뷰 (Codex, 2026-10-26)

> 범위: `main...feature/v0.5-survival` (서바이벌·펫·미션·업적). 모델: gpt-6-sol (gpt-6.1-sol 용량 초과로 대신), `--sandbox read-only`, effort high.

1. **[버그] 보스 등장 전 정리가 실제 처치와 피해로 집계됩니다.** [SurvivalRun.cs](Game/Assets/Scripts/Survival/SurvivalRun.cs:237)에서 남은 적에게 대량 피해를 주면 일반 처치와 같은 경로로 경험치, 처치 미션, `DamageLog`가 갱신됩니다. 10분 시점에 적이 많이 남아 있으면 플레이어가 쓰러뜨리지 않은 적 수백 마리가 처치 수에 더해지고 기본 공격 피해 비중도 왜곡됩니다. 정리 전용 비활성화 경로를 만들고 보석 지급 여부를 별도로 결정하세요.

2. **[버그] 맵 가장자리에서 적이 플레이어 바로 옆에 생성될 수 있습니다.** [SurvivalRun.cs](Game/Assets/Scripts/Survival/SurvivalRun.cs:181)의 `RingPosition()`은 유효한 원형 위치를 못 찾으면 좌표만 경계로 자릅니다. 플레이어가 모서리 근처에 있으면 원래 멀리 있던 생성점이 플레이어 위치 가까이 압축됩니다. 바위 충돌도 검사하지 않습니다. 경계 안에서 플레이어와의 최소 거리 및 장애물 검사를 모두 통과하는 위치를 다시 뽑아야 합니다.

3. **[위험] 멀리 있는 적을 공격 상태 그대로 순간 이동시킵니다.** [SurvivalRun.cs](Game/Assets/Scripts/Survival/SurvivalRun.cs:137)에서 위치만 바꾸므로 궁병의 예고·공격 상태와 속도가 유지됩니다. 화면 밖에서 예고 중이던 적이 재배치 직후 새 위치에서 공격할 수 있습니다. 재배치 시 공격을 취소하고 이동 상태로 초기화하거나, 공격 중인 적은 재배치 대상에서 제외하세요.

4. **[위험] 적토마의 피해량에 기획상 펫 피해 비중 상한이 없습니다.** [PetBehaviours.cs](Game/Assets/Scripts/Pets/PetBehaviours.cs:322)는 질주 중 초당 최대 3회, 매회 영웅 공격력의 10%를 가합니다. 무리 속을 계속 달려 기본 공격이 멈춘 상황에서는 펫 피해가 영웅 전체 피해의 약 10%를 쉽게 넘을 수 있습니다. 실제 전투 피해 로그로 비중을 측정하고 계수·빈도에 제한을 두세요.

5. **[버그] 비둘기가 가져온 골드는 즉시 저장 대상으로 표시되지 않습니다.** [PetBehaviours.cs](Game/Assets/Scripts/Pets/PetBehaviours.cs:618)는 `Wallet.Grant`만 호출합니다. 골드 수령 직후 앱이 백그라운드로 가면 `SaveIfDirty()`는 변경을 감지하지 못해 화면에 표시된 골드를 잃을 수 있습니다. 지급 뒤 `SaveSystem.MarkDirty()`를 호출하거나 저장이 보장되는 보상 경로로 옮기세요.

6. **[위험] 저장 구조를 추가했지만 스키마 버전이 그대로입니다.** [SaveData.cs](Game/Assets/Scripts/Records/SaveData.cs:15)에 생존·펫·미션 데이터가 추가됐는데 `CurrentSchemaVersion`은 `main`과 같은 3입니다. 이전 빌드가 새 저장 파일을 구분하지 못하고 다시 저장하면 신규 진행 데이터를 지울 수 있으며, 향후 마이그레이션도 버전으로 구분하기 어렵습니다. 버전을 올리고 3→4 이행 경로를 명시하세요.

읽기 전용 정적 리뷰이며, Unity 실행 검증은 하지 않았습니다.
