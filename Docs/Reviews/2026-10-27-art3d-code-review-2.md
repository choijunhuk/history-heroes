## 원문

1. **[버그] 경험치 보석의 3D 위치와 크기가 줍기 판정에서 벗어납니다.** `Editor/SceneBuilder.Fx3D.cs:142–147`, `Scripts/Progress/ExperienceGem.cs:24–27` — 빌더는 루트 배율 `0.28`을 기준으로 모델을 Z `-1.14`에 놓지만, `Drop()`은 루트 Z 배율을 `1`로 바꿉니다. 실제 보석은 판정점보다 약 1.14유닛 높고, XY 크기도 의도한 값의 약 1.6배가 됩니다. 플레이어가 보석 그림에 닿기 전에 획득하거나, 합쳐진 보석이 지나치게 커질 수 있습니다. 모델의 월드 높이를 런타임 배율과 무관하게 유지하도록 축별 배율과 위치를 계산하세요.

2. **[위험] 초상 카메라 네 대가 가려진 화면에서도 매 프레임 렌더링합니다.** `Scripts/UI/HeroPortraits.cs:36–47, 84–98` — 영웅 화면에서 장비·펫 화면을 열어도 영웅 패널은 활성 상태여서, 초상 카메라와 모델 애니메이션이 계속 돕니다. 모바일에서는 다른 로비 화면을 보는 동안에도 렌더링 비용이 발생합니다. 하위 화면을 열 때 카메라를 끄거나, 초상 변경·드래그 때만 다시 렌더링하세요.

3. **[버그] 떨어지는 화살과 포탄의 착지 그림이 바닥에 절반 묻힙니다.** `Scripts/Skills/Effects/StrikeVisual.cs:24, 68–69, 103`, `ArrowRainBehaviour.cs:40–41`, `CannonBarrageBehaviour.cs:47–48` — 세운 스프라이트의 중심을 착지 시 Z `0`에 두면서 두 호출 모두 `visualOffset=Vector2.zero`를 넘깁니다. 따라서 화살과 포탄 그림의 아래쪽 절반은 바닥 아래에 놓입니다. 그림 중심을 크기의 절반만큼 `-Z`로 올리거나, 착지점을 스프라이트 아래끝으로 정의하세요.

4. **[개선] 초상 RenderTexture 객체를 명시적으로 파괴하지 않습니다.** `Scripts/UI/HeroPortraits.cs:49–57` — `Release()`는 렌더 버퍼를 해제하지만 `new RenderTexture`로 만든 Unity 객체 자체는 파괴하지 않습니다. 로비를 반복해서 다시 열면 객체 회수가 지연될 수 있습니다. 카메라와 `RawImage`의 참조를 끊은 뒤 `Destroy(s.Texture)`도 호출하세요.
