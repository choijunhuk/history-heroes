# 확장 1차 묶음 설계 검토 (Codex, 2026-10-28)

- 검토: Codex `gpt-6-sol` (read-only, effort xhigh) — [확장 1차 설계](../Design/Expansion1.md)
- 결정: **모두 반영** (설계 문서 9장 "검토 반영"에 규칙으로 적었다)

## 원문

## 총평

승인된 방향인 던전 다양화, 서바이벌 확장, 기믹 보스는 기존 게임의 재미와 잘 맞습니다.  
다만 분기·보상·별·보스 기믹은 현재 코드에 없는 상태와 저장 규칙이 필요해, 구현 전에 문장을 더 정해야 합니다.  
특히 15방을 유지해도 새 선택과 전투가 더해지면 8~10분 목표는 다시 측정해야 합니다.

## 꼭 고칠 것

1. **[막힘] 3-1~3-3, 일일 도전과 갈림길.** 일일 도전은 7방이라 9번 뒤 갈림길이 없고, 현재는 방 계획을 시작할 때 전부 만듭니다. **15방 던전에만 두 번 분기**를 적용하고 일일 도전의 기존 7방은 유지한다고 명시하세요. 분기 양쪽의 방·적·도전 종류를 시드로 미리 정하되, 선택이 뒤쪽 방이나 카드 난수에 영향을 주지 않게 해야 합니다. 이어하기에는 선택한 문도 저장해야 합니다.

2. **[막힘] 3-3, 도전 방의 종료 조건.** “20초 버티기”는 적이 남아도 끝나지만 현재 방은 모든 적이 죽어야 문이 열립니다. 버티기 종료 시 남은 적의 처리와 경험치 지급 여부를 정하세요. 무피격 도전은 첫 피격 즉시 실패 표시를 띄우되, 남은 적을 잡아야 진행하게 하고 사망·함정 피격·재시작 때도 판정이 유지되게 하세요.

3. **[막힘] 5, 그림자 쌍둥이.** 현재 쌍둥이는 체력 하나를 공유하는 보스와 피격되지 않는 유령입니다. 따라서 “한쪽 사망→8초 안에 다른 쪽 처치”는 그대로 구현할 수 없습니다. 두 몸의 체력·피격·부활을 새로 설계하거나, 공유 체력을 유지하는 **교대 약점 기믹**으로 문구를 바꾸세요. “순서대로”라면 정답 순서와 예고도 명시해야 합니다.

4. **[막힘] 5, 균열 보스의 무작위 기믹.** 균열은 10층마다 서로 다른 기존 보스가 나옵니다. 쌍둥이 전용 기믹 등을 아무 보스에게나 붙일 수 없습니다. 보스별 호환 기믹 표를 만들고, 층 시드로 그 목록에서만 고르세요. 기존 균열 패턴과 합쳐졌을 때도 공격 후 빈틈을 보장해야 합니다.

5. **[중요] 6-1·6-5, 서바이벌 진행·보상 저장.** 현재 최고 시간은 영웅별 하나이고 별은 던전·보스의 30개 상자와 연결돼 있습니다. 맵별 해금·최고 시간·별·첫 클리어 보상을 별도 저장 키로 정의하세요. 서바이벌 맵 1의 수문장을 잡아도 **던전 기록 저장이나 2구간 해금은 일어나지 않는다**고 명시하세요. 기존 저장 파일의 최고 시간은 어느 맵에 귀속할지도 정해야 합니다.

6. **[중요] 6-1·6-4, 보물 상자와 재화.** 상자의 “조합 먼저”는 현재 레벨업마다 조합 후보를 확인하는 방식과 맞지 않습니다. 상자의 1~3회 선택을 **한 번씩 순서대로** 열고 매 선택 뒤 조합을 다시 확인하도록 정하세요. 금화 주머니까지 합산한 반복 골드에 맵별 상한을 두어 승인된 ‘분당 재화 ≤ 던전’을 지키세요. 7분 맵의 엘리트·중간 보스·마지막 보스 시각도 따로 적어야 합니다.

7. **[중요] 1~2·4, ‘데이터만’이라는 구현 범위.** 지금은 엘리트·보상·중간 보스가 한 `specialLayout`을 공유하고, 함정 종류도 구간 하나와 자리 번호로 결정됩니다. 쇠창살·이동 톱니·레버·회복 드롭·속성은 새 동작이 필요합니다. 레이아웃별 장치 종류와 전용 방 선택을 데이터에 추가하고, **닫힌 쇠창살을 포함한 모든 상태**에서 출구·적까지 갈 수 있는지 검사하세요. 속성은 엘리트에만 적용한다고 못 박고, 분열 자식의 보상·소환 수·방 전멸 판정을 정하세요.

## 고치면 좋은 것

- **[중요] 3-4·3-5, 카드와 석비.** “희귀 이상 3장”은 추가 선택 세 장 모두의 희귀 보장으로 읽힙니다. 전설 추첨은 기존 곡선을 그대로 쓰고, 희귀를 몇 장 보장하는지 정확히 적으세요. 석비에서 ‘지나가기’를 고르면 기존 6·11번 보상 방이 빈 방이 됩니다. 기본 보상과 석비의 관계를 정하고, 최대 체력이 변할 때 현재 체력 처리도 명시하세요.
- **[중요] 2·4, 피할 수 있는 위험.** 폭약 통은 플레이어·일반 적·엘리트·보스의 피해 상한과 처치 보상 귀속을 분리해 정하세요. 깜빡이는 속성은 멈춰 쏜 첫 탄을 매번 헛치게 해서는 안 됩니다. 순간이동 뒤 재조준 가능한 빈틈을 주고, 속성 두 개가 겹쳐도 그 빈틈을 남기세요.
- **[중요] 5~6, 화면 판독성.** 쇠창살의 닫힘 시각과 안전한 통로, 컨베이어 방향·끝자리, 무너지는 바닥의 안전 칸을 작은 세로 화면에서 구분할 수 있어야 합니다. 5분 울타리는 군중 100마리 안팎이 살아 있는 시점에 생기므로, 생성·재배치·퇴로 규칙을 먼저 정하세요.
- **[제안] 3-1, 시간 목표.** 기존 표만 합해도 전투·보상 방이 약 **7분 50초~9분 10초**, 카드 선택 1~2분을 더하면 약 **8분 50초~11분 10초**입니다. 갈림길 선택·저주 엘리트·석비를 넣은 뒤에는 방별 시간 예산을 다시 잡으세요.

## 순서/범위 조정 제안

- **[제안] 8, 구현 순서.** 분기·도전·상자보다 먼저 방 종류, 난수, 저장 상태를 설계하세요. 이후 전용 레이아웃과 도달 검사 → 장치·속성 → 특수 방 → 서바이벌 → 보스 순서가 변경 영향을 줄입니다.
- **[제안] 5, 중간 보스.** 그림자 사냥꾼의 ‘진짜만 그림자’는 이미 구현돼 있습니다. 1차에서는 가짜 공격 시 기절의 공정성만 점검하고, 새 연출·패턴 작업은 다른 기믹에 집중할 수 있습니다. 긴 방은 승인된 범위를 유지하되 현재 문서대로 1차 마지막에 두는 편이 적절합니다.

## 테스트로 꼭 확인할 것

- **[중요]** 같은 일일 시드의 연습·공식 판에서 방, 적, 카드 순서가 같고 분기 선택이나 이어하기가 뒤 난수를 바꾸지 않는지.
- **[중요]** 도전 실패·분열 속성·소환 졸개 뒤에도 문이 막히거나 보상이 중복되지 않는지.
- **[중요]** 석비, 폭약 통, 새 함정이 던전 ★2 피격 수와 ★3 전설 판정을 의도대로 처리하는지.
- **[중요]** 서바이벌 상자 연속 선택·조합, 5분 울타리, 맵별 별·해금·하트 1개, 기존 저장 파일 전환이 정상인지.
- **[중요]** 실제 안드로이드 기기에서 적 300마리와 드롭·경고 연출이 겹칠 때 프레임, 입력 반응, 공격할 수 있는 정지 시간이 유지되는지.
