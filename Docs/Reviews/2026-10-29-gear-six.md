# 장비 6칸 검토

- 대상: `feature/gear-six`, 2026-10-29 작업 변경분. Unity 실행과 커밋은 리드가 맡는다.
- 판정: 정적 검토에서 차단할 결함을 찾지 못했다. 저장 번호 0·1·2와 기존 ID를 유지하고 새 3칸만 뒤에 추가한다.
- 힘 예산: 전설 Lv40 공격력 15+10=25%, 체력 12.5+7.5+5=25%, 목걸이 공속 8%. 부가 능력치 최대 합도 기존 장비 몫과 같다.
- 비용: 6 × 50 × (1+…+39) = 234,000골드. 상자 등급 확률·천장·조각 가격은 그대로다.
- 데이터: 실제 빌더 정의 42종의 ID가 겹치지 않고, 각 슬롯은 일반 1·고급 2·희귀 2·전설 2종이다. 테스트도 같은 정의를 쓴다.

## 확인한 것

- 설치된 Unity 6000.3.27f1 참조 DLL로 런타임·에디터·전체 EditMode 테스트 코드를 별도 C# 컴파일: 오류 0. 런타임 경고 636개는 주로 직렬화 필드 미할당 경고이며, 무경고 판정은 아니다.
- 실제 `SaveStore.Migrate`·`Normalize` 함수를 별도 C# 실행으로 점검: 목걸이 Lv0·12·40 보존과 반복 복구, 긴 배열·null 배열 복구까지 8개 검사 통과. Unity JSON 읽기 검증을 대신하지 않는다.
- 새 EditMode 테스트 9개 사례 작성: 저장 이전, 배열 복구, 42종, 슬롯별 장착, 최대 예산, 강화 총액, 두 상자의 슬롯별 추첨·표시 확률.
- `git diff --check`, 아이콘 키 6개, 새 `.meta` GUID 중복 여부 확인. 장면·프리팹·데이터 에셋·폰트는 수정하지 않았다.

## 리드가 확인할 것

- `SceneBuilder.BuildAll()`로 기존 데이터 에셋과 로비의 직렬화 참조를 갱신한 뒤 Editor 컴파일·EditMode 테스트·화면 점검. 이번 환경에서는 모두 실행하지 않았다.
- 6칸 장착·강화·합성·상자, 잠긴 영웅 체험·각성·수련·영웅 선택, 보조 단추 접근과 글 잘림을 화면에서 확인한다.
- 기존 계정은 새 칸을 채우기 전 공격력·체력과 일부 부가 능력치가 낮아진다. 옛 기록도 기존 패치 정책대로 최신 장비 수치를 쓴다. 아이템과 강화 레벨은 보존한다.
- 전설 1개 획득 속도는 같지만 특정 슬롯의 확률은 절반이다. 6칸 완성 속도는 실제 플레이로 다시 확인한다.
