# 확장 1차 묶음 설계 — "맵이 달라 보이게 + 두 큰 모드 + 기믹 보스"

> 근거: [콘텐츠 확장 기획안](../Dev/Content-Expansion-Proposal.md) 7장(개발자 결정 2026-10-27)·8장(추가 요청) · [GameDesign](../GameDesign.md) · [Modes](Modes.md) · [Content](Content.md)
> 개발자 말: "맵도 너무 단조로운거 같은데", "뱀서류로도 하나… 모드를 두개정도로 하자", "어려운 맵에서는 기믹형 보스가 있었으면 좋겟고 … 뽕맛이 있으면 좋겟어"
> 상태: **구현 중** (설계 검토 반영 9장). ✅ A 방 세트 · ✅ D 엘리트 속성 · ✅ C 특수 방 · ✅ B 구간 장치 · ✅ F 서바이벌 · ✅ E 기믹 보스 (2026-10-28) · ☐ A-5 긴 방. 바꾸지 않는 원칙: 기본 공격은 멈춰야 나간다 · 서바이벌은 기록을 저장하지 않는다 · 모든 위험은 예고가 있다 · 전설 확률은 건드리지 않는다 · 서바이벌 분당 재화 ≤ 던전.

## 1. 방 세트 (A)

방은 지금처럼 9×14(판정 반폭 4 · 반높이 7). 판정은 2D 장애물 3종(높은 · 낮은 · 부서지는)과 함정 칸이라 **데이터만** 늘린다.

### 1-1. 새 모양 (모든 구간 공용 틀)
| 이름 | 모양 | 시험하는 것 |
|---|---|---|
| 십자 광장 | 네 모서리에 큰 덩어리(높은), 가운데 기둥 1 | 네 팔에서 오는 적, 엄폐 |
| 고리 회랑 | 가운데 큰 구덩이(낮은, 탄은 넘어감) 둘레를 돈다 | 원거리 견제, 돌아가는 길 |
| 지그재그 | 좌우로 엇갈린 긴 벽 3개 → S자 길 | 관통 · 부메랑 · 근접 몰이 |
| 다리 방 | 구덩이 띠 2줄 + 다리(빈칸) 3곳 | 길목 지키기, 건너편 원거리 |
| 원형 투기장 | 둘레 기둥 8개, 가운데 비움 | 엘리트 · 저주받은 엘리트 전용 |

- 모든 방은 **근접 도달 규칙**(Modes 2-2: 관우가 모든 적에게 닿는다)과 **문 앞 1.5칸·시작 자리 2칸 비움**을 지킨다. 빌더에 검사 테스트를 둔다 (모든 방 · 모든 적 생성 자리에서 시작 자리까지 길이 있는가 = 격자 BFS).

### 1-2. 구간 전용 방 (구간마다 6개 = 30)
- 위 틀 4종 + 지금 6종 틀을 구간 장치와 섞은 것. 예: 1구간 "개울 건너기"(다리 방 + 개울), 2구간 "성문 앞"(십자 광장 + 폭약 통), 3구간 "조립 라인"(지그재그 + 컨베이어 + 레버).
- 4·5구간은 새 장치 없이 지금 함정(낙석·덩굴 / 망각 균열)과 새 모양으로 만든다.
- **뽑기:** 일반 방은 구간 전용 60% · 공용 40% (공용은 지금 24개 중 좋은 12개만 남김). 같은 방 두 번 금지 · 같은 틀 연속 금지는 그대로.

### 1-3. 전용 모양
- 엘리트 방(5·10) = 원형 투기장 (지금은 빈 방).
- 보상 방(6·11) = 작은 받침대가 있는 방 (가운데 1×1 낮은 장애물 + 상자 3D).
- 중간 보스 방(15) = 구간마다 1개 (지금 함정이 둘레를 도는 원 등, 데이터로).

## 2. 구간 장치 (B)

**규칙:** 모든 장치는 예고가 있고 **적에게도 똑같이** 작용한다. 어둠·시야 제한은 쓰지 않는다. 일반 방의 약 40%에 그 구간 함정 1~2칸을 가볍게 깐다 (지금은 함정 전용 방 4개에만).

| 구간 | 새 장치 ① | 새 장치 ② |
|---|---|---|
| 1 균열의 초원 | **열매 덤불** (부서짐, 2번 맞으면 회복 구슬: 최대체력 5%, 방마다 최대 2개) | **개울** (낮은 장애물 띠, 탄은 넘어감, 물 무늬) |
| 2 잊힌 성채 | **폭약 통** (3번 맞으면 1초 깜빡 → 반경 1.5 폭발, 적·나 모두 최대체력 15% / 적은 공격력 200%) | **쇠창살 문** (방을 가로지르는 줄, 8초마다 3초 내려옴, 1초 전 그림자 예고. 내려오면 높은 장애물) |
| 3 녹슨 공방 | **회전 톱니** (정해진 두 점 사이를 왕복하는 높은 장애물, 닿으면 밀림 + 피해 10%) | **레버** (쏘면 3초간 컨베이어 반대 / 증기 멈춤, 쿨다운 6초) |

- 숫자는 [제안]. 폭약 통 연쇄 폭발은 최대 3개까지.

### 2-1. 구현 메모 (2026-10-28)
| 장치 | 방 | 만든 대로 |
|---|---|---|
| 열매 덤불 | c1_creek · c1_grove · c1_halls · c1_brook | 부서지는 장애물(2번). 회복 구슬은 둥실 떠서 빛나고, 닿으면 최대체력 5%. 방마다 2개까지 |
| 개울 | c1_creek(다리 방의 구덩이 띠 → 물) · c1_brook(새 방: 긴 개울 + 한쪽 여울) | 몸만 막고 탄은 넘어간다. 물 띠 위로 밝은 물결 줄이 흐른다 |
| 폭약 통 | c2_gate · c2_storage · c2_portcullis | 3번 맞으면 1초 빨간 원 예고(깜빡) → 반경 1.5. 나 15% · 일반 적 공격력 200% · 엘리트 100% · 보스 50%. 옆 통은 0.25초 뒤 연쇄 (3개까지). 상자는 부수지 않는다 |
| 쇠창살 | c2_portcullis (새 방, 줄 4.6칸) | 들어오고 4초 뒤 첫 닫힘, 그 뒤 8초마다 3초. 바닥 밑에서 솟아오른다(바닥이 가린다). 1초 전 그림자 + 양옆 통로 초록 표시. 솟을 때 줄 안의 몸은 위·아래로 밀려난다. 닫혀도 양옆으로 지나간다 (도달 검사) |
| 회전 톱니 | c3_saws (새 방, 2개) | 어두운 홈이 늘 보인다. 초당 1.6칸 왕복, 닿으면 0.9칸 밀림 + 최대체력 10% (같은 몸 0.8초에 한 번, 적도 같다) |
| 레버 | c3_line · c3_halls (함정 방에만) | 쏘거나 베면 3초 동안 그 방 컨베이어 반대(주황) · 증기 멈춤(파랗게 식음), 쿨다운 6초. 바닥 고리: 초록 쏠 수 있음 · 주황 켜짐 · 회색 쉬는 중 |
- 바닥 장식(깔개 등)은 개울 · 쇠창살 줄 · 톱니 홈 · 함정 칸을 피해서 깐다.
- 회복 구슬은 줍는 물건이라 **영웅만** 줍는다 ("적에게도 똑같이"는 위험 장치 규칙, 코드 검토 2026-10-28 6번).

## 3. 특수 방 (C)

### 3-1. 한 판 리듬 (15방, 길이 8~10분 그대로)
| 방 | 지금 | 바뀜 |
|---|---|---|
| 1~3 | 일반 | 일반 → 3번 끝에 **갈림길 ①** |
| 4 | 일반 | 갈림길 ① 결과: 일반 / **도전 방** |
| 5 | 엘리트 | 엘리트 (원형 투기장, 2구간부터 속성 1개) |
| 6 · 11 | 보상 | 보상 방 75% · **기억의 석비** 25% |
| 7~9 | 일반 | 일반 → 9번 끝에 **갈림길 ②** |
| 10 | 엘리트 | 갈림길 ② 결과: 엘리트 / **저주받은 엘리트** |
| 12~14 | 일반 | 일반 |
| 15 | 중간 보스 | 중간 보스 (4·5구간은 기믹, 5장) |

### 3-2. 갈림길
- 방을 깨면 문이 **2개** (왼쪽·오른쪽 아치). 문 위에 다음 방 그림판(아이콘 + 짧은 글): "평범한 방" / "도전 방: 보상 +1", "엘리트" / "저주받은 엘리트: 희귀 카드".
- 들어간 문으로 다음 방 종류가 정해진다. 판의 씨앗(seed)으로 미리 정해 두어서 **일일 도전도 같은 갈림길**이 나온다 (공정).
- 방 진행 바(HUD)는 갈림길 칸을 두 갈래 아이콘으로 보여 주고, 고른 뒤 그 종류로 바뀐다.

### 3-3. 도전 방
- 둘 중 하나 (씨앗으로): **"20초 버티기"** (무리 3번이 몰려옴, 적을 다 잡을 필요 없음) / **"맞지 않고 깨기"** (적은 평소의 70%).
- 성공: 레벨업 카드 1장 더 + 골드 (방 보상의 2배). 실패: 진행은 그대로, 보상만 없음 (HUD에 "도전 실패" 알림).

### 3-4. 저주받은 엘리트
- 엘리트 1마리에 속성 2개 (4장 표에서 무작위, 같은 것 금지). 잡으면 확정 레벨업 + **희귀 이상 카드 3장 중 1장** 1번 더 (전설 확률은 평소 곡선 그대로).

### 3-5. 기억의 석비 (축복과 대가)
- 석비 3D + 카드 2장 + "그냥 지나가기". 이번 판 동안:
  - "투지": 공격력 +20% / 받는 피해 +15%
  - "서두름": 쿨다운 -15% / 최대체력 -15%
  - ~~"통찰": 다음 레벨업 카드 4장 / 회복량 -30%~~ → **"지혜": 바로 레벨업 1번 / 받는 피해 +10%** (구현 때 바꿈: 레벨업 화면이 3장 틀이라 4장이 들어가지 않는다)
  - "강철": 최대체력 +25% / 이동속도 -10%
- 2개를 무작위로 보여 준다. 기록에는 남지 않는다 (판 안 효과).
- **"받는 피해 +%"는 새 능력치(받는 피해 증가, 0~100%)로 따로 곱한다.** 피해 감소는 0% 밑으로 내려가지 않아서 "피해 감소 -15%"로는 피해가 늘지 않는다 (일일 도전 "빠르지만 약하게"의 받는 피해 +20%도 같은 이유로 이제야 먹는다).

### 3-6. 구현 메모 (2026-10-28)
- 판 시작 때 갈림길 난수로 한꺼번에: 도전 종류 → 6·11번 석비 여부와 축복 2개 → 저주 속성 2개 → 버티기 무리 3번 · 맞지 않기 적. 어느 문을 골라도 방·적·카드 난수는 그대로 (테스트).
- 갈림길 문 = 가운데 문 양옆(±2.4) 벽 앞에 선 작은 아치 + 문 모양 빛(왼쪽 파랑 · 오른쪽 주황) + 표지판 + 카메라를 보는 그림판. 가운데 문은 닫힌 채. 모든 일반 방에서 두 문 앞까지 갈 수 있다 (도달 검사).
- 방 진행 바: 갈림길 칸 = 문 아이콘(노랑) → 고르면 시계·방패(도전) / 룬(저주). 지나온 석비 칸 = 석비 아이콘(하늘색).
- 보상 방 받침대 = 금 상자 모델, 석비 방 = 석비 모델. 석비 화면은 보상 방 화면을 그대로 쓰고 아이콘·색만 바꾼다.
- 도전 보상·저주 보상·석비는 "받음" 표시를 저장해서 껐다 켜도 다시 못 받는다. 맞지 않기 실패도 저장 (다시 도전 못 함).
- 코드 검토 반영 ([원문](../Reviews/2026-10-28-expansion1-code-review-cd.md)): 적 난수는 방마다 (씨앗, 방 번호)로 새로 → 고른 문이 뒤 방 적 자리·속성을 바꾸지 않는다. 도전·저주 보상 카드는 갈림길 난수로. 보상을 받고 카드까지 고른 뒤 그 방을 다시 저장. 문을 고르는 순간 선택 저장.
- "20초 버티기"는 셋째 무리(14초)까지 나온 뒤 모두 잡으면 그 자리에서 성공 (빈 방에서 기다리지 않게).

## 4. 엘리트 속성 (D)

| 속성 | 효과 | 보이는 표시 | 시험 |
|---|---|---|---|
| 분노한 | 체력 50% 아래에서 이동·공격 속도 +30% | 빨간 김 | 마무리 화력 |
| 보호막 | 체력 30%짜리 보호막, 깨지면 2초 기절 | 파란 껍질 | 빈틈 |
| 부르는 | 10초마다 졸개 2 | 보라 마법진 | 광역 |
| 불타는 | 지나간 자리에 불 장판 2초 | 주황 발자국 | 위치 |
| 갈라지는 | 죽으면 작은 엘리트 2 (체력 25%, 속성 없음) | 초록 금 | 광역 |
| 깜빡이는 | 내가 멈춰 쏘기 시작하면 2초 뒤 옆으로 3칸 순간이동 (0.5초 전 반짝, 쿨다운 6초) | 푸른 반짝 | 멈춤 타이밍 |
| 연사하는 | 원거리 공격이 3갈래 | 노란 테 | 회피 |
| 지키는 | 반경 4 안 다른 적 받는 피해 -30% | 금빛 줄 | 우선 표적 |

- 1구간 0개 · 2~3구간 1개 · 4~5구간 1~2개 (40%로 2개) · 무한의 균열 층 = 5층마다 +1 (최대 2). 이름 앞에 붙는다 ("분노한 돌진병").
- **어떤 속성도 빈틈을 없애지 않는다.** 속성 엘리트는 보상이 그대로 (저주받은 엘리트만 추가 카드).

## 5. 기믹 보스 (E)

**원칙:** "피하고 때리기"에 **풀어야 하는 장치 하나**를 더한다. 장치를 무시해도 이길 수는 있지만 훨씬 오래 걸리거나 위험하다. 장치는 처음 나올 때 보스 소개 글 아래에 한 줄로 알려 준다.

| 대상 | 기믹 | 내용 |
|---|---|---|
| 4구간 보스 그림자 쌍둥이 | **순서대로 잡기** | 지금: 맞지 않는 쪽(유령)이 번갈아. 추가: 한쪽이 쓰러지면 8초 안에 다른 쪽을 잡아야 한다. 못 잡으면 쓰러진 쪽이 체력 40%로 다시 일어난다 (발밑 시계 원) |
| 5구간 보스 망각의 왕 | **기둥 보호막** | 방 네 귀퉁이 수정 기둥 4개(부서짐, 체력 = 보스 3%)가 보스에게 보호막(받는 피해 -75%). 기둥을 부술 때마다 25%씩 줄어든다. 2단계에서 기둥 2개가 다시 솟는다 |
| 5구간 보스 2단계 | **무너지는 바닥** | 바닥 칸이 1.2초 금 → 3초 사라짐 (망각 균열을 보스 단계로), 안전한 칸이 줄어든다 |
| 4구간 중간 보스 그림자 사냥꾼 | **거울 분신** | 분신 2명 중 진짜만 그림자가 있다. 가짜를 치면 0.5초 기절 (나) |
| 5구간 중간 보스 망각의 집행자 | **불길 반쪽** | 12초마다 방 반쪽이 불길(1.5초 예고) → 보스를 반대편으로 끌고 간다 |
| 무한의 균열 보스 층 | 위 기믹 중 하나 무작위 | |

- 어려운 난이도(출시 후)는 기믹이 하나 더 겹친다.

### 5-1. 구현 메모 (2026-10-28)
| 기믹 | 붙는 곳 | 만든 대로 |
|---|---|---|
| 수정 기둥 보호막 | 망각의 왕 (보스맵) · 균열 수문장/망각의 왕 | 네 귀퉁이 수정 기둥(적 편 체력 = 보스 3%, 영웅이 겨냥한다). 보호막 = 75% − 부순 기둥 × 25% → **셋을 부수면 0** ("보호막 깨짐!"). 보스 둘레 보라 고리가 보호막 세기. 망각의 왕 2단계: 부서진 기둥 2개가 다시 솟고 무너지는 바닥 시작 |
| 무너지는 바닥 | 망각의 왕 2단계 · 균열 망각의 왕 | 1.8칸 바닥 칸에 망각 균열 함정(1.2초 금 → 3초 사라짐). 처음 3칸, 6초마다 1칸씩 싸움터의 45%까지 |
| 그림자 표식 | 그림자 쌍둥이 (보스맵 · 균열) | 8초 뒤부터 15초마다 표식 3개 (영웅 자리 + 둘레 2). 4초 안에 보스를 5번 맞히면 "표식 해제!", 못 하면 표식 안에 있을 때 최대체력 25% |
| 거울 분신 | 그림자 사냥꾼 (던전 4구간 · 서바이벌 맵 2) | 분신을 **기본 공격**으로 맞히면 0.5초 기절 (스킬은 기절 없음, 2.5초에 한 번까지) |
| 불길 반쪽 | 망각의 집행자 (던전 5구간) · 균열 강철 거상 | 6초 뒤부터 12초마다: 보스가 있던 반쪽에 1.5초 예고 → 보스는 반대편으로 건너가고 2초 불길 (0.5초마다 최대체력 12%) |
- 균열 보스 층은 검토 4번 표의 기믹만, (판 씨앗, 층)으로 골라서 같은 판이면 같은 기믹. 보스 등장 때 알림 한 줄, 로비 보스 시작 전 화면에 "기믹: …" 한 줄.

## 6. 서바이벌 큰 모드 (F)

### 6-1. 바뀌는 규칙
| 항목 | 지금 | 바뀜 |
|---|---|---|
| 해금 | 2구간 보스 격파 | **1구간 보스 격파** |
| 하트 | 2 | **1** |
| 맵 | 1개 (80×80 풀밭, 10분) | **3개** (아래) |
| 줍는 물건 | 보석만 | **자석 · 폭탄 · 고기 · 금화 주머니** |
| 엘리트 보상 | 레벨업 1회 | **보물 상자** (레벨업 1회 70% · 2회 25% · 3회 5%, 조합 준비되면 조합 먼저) |
| 중간 | 없음 | **5분 중간 보스** + 울타리 (보스가 나오면 지름 14 원 울타리, 잡으면 열림) |
| 무리 | 화면 밖 원에서 하나씩 | + **무리 모양 4가지** (6-3) |
| 진행 | 없음 | **맵마다 별 3개**, 앞 맵 클리어로 다음 맵 |

### 6-2. 맵 3개 (출시)
| # | 이름 | 크기·모양 | 지형 | 시간 | 마지막 보스 | 열림 |
|---|---|---|---|---|---|---|
| 1 | 균열의 들판 | 80×80 | 바위 · 연못 · 짚더미(부서짐 → 줍는 물건) | **7분** | 균열의 수문장 | 1구간 보스 |
| 2 | 무너진 성곽 도시 | 80×80 | 무너진 집 블록이 **골목**을 만든다 · 화로(부서짐) | 10분 | 횃불 기사 | 맵 1 클리어 |
| 3 | 증기 공장 | 100×60 가로 | 맵을 가로지르는 **컨베이어 띠 3줄** · 증기 구역 | 10분 | 강철 거상 | 맵 2 클리어 |

### 6-3. 무리 모양 (모든 맵, 맵마다 비율)
- **포위 고리:** 졸개 24마리가 지름 12 원으로 나타나 1.5초 멈췄다 조여 온다. 틈 2곳. (2:30 · 6:00)
- **한 줄 돌격:** 돌진병 10마리가 화면을 가로질러 일직선 (0.8초 빨간 화살표 줄 예고).
- **까마귀 떼:** 빠르고 약한 새 6~8마리가 한쪽에서 반대쪽으로 지나감 (쫓아오지 않음).
- **큰 덩치 행진:** 느리고 단단한 적 6마리 (광역보다 단일 화력 시험).
- 위험 2초 전 화면 가장자리에 경고 띠 + 화살표 (조사 "Survivor.io 무리 경고").

### 6-4. 줍는 물건
| 물건 | 효과 | 나오는 곳 |
|---|---|---|
| 자석 | 화면의 보석을 0.3초 뒤 다 끌어온다 | 짚더미·화로 15%, 엘리트 |
| 폭탄 | 화면의 적에게 공격력 300% (보스 제외) | 짚더미·화로 10% |
| 고기 | 체력 20% 회복 | 짚더미·화로 35% |
| 금화 주머니 | 골드 (분당 재화 상한 안에서) | 짚더미·화로 40% |
- 짚더미·화로는 맵에 6~8개 유지 (부서지면 90초 뒤 다른 자리에 다시).

### 6-5. 별 · 보상
- ★1 클리어 · ★2 맵 임무 (맵 1 "짚더미 10개 부수기", 맵 2 "화로 8개 부수기", 맵 3 "6분 전에 엘리트 3마리") · ★3 전설 없이 클리어.
- 맵 첫 클리어 💎 + 별 5개마다 서바이벌 별 상자. **분당 재화 ≤ 던전**은 그대로 (별·첫 클리어는 1회성).

### 6-6. 화면
- 로비 "서바이벌" 큰 카드 → **맵 고르기** (맵 카드 좌우 넘기기: 3D 미리보기 그림 · 별 · 최고 시간 · 잠금 조건) → 시작.

### 6-7. 구현 메모 (2026-10-28)
- 맵 = 숫자(SurvivalData: Survival_Main = 맵 1 · Survival_city · Survival_factory) + 장면 안 지형 묶음 3개. BattleBootstrap이 고른 맵만 켜고 카메라 경계(가로·세로 따로)를 맞춘다.
- 맵 2 집 블록은 판정을 **둥글게** (적이 모서리에 끼지 않고 미끄러져 돈다), 보이는 건 무너진 집 모델. 맵 3 컨베이어·증기는 던전 함정(TrapZone)을 그대로 깔고 판 시작 때 켠다.
- 짚더미·화로는 쏴서도, **몸으로 밀어서도** 부서진다 (임무를 일부러 할 수 있게). 금화 주머니 = 15골드, 분당 30 상한.
- 무리: "까마귀 떼"는 새 적이 없어서 **빠른 졸개 떼**(속도 ×1.8, 작게)로. 지나가는 무리는 화면 밖 반대쪽 점을 향해 가다가 닿거나 8초 뒤 조용히 사라진다 (경험치 없음, 잡으면 경험치).
- 중간 보스 울타리 = 쇠창살 조각 24개가 원으로 솟는다 (판정은 원 모양 선). 울타리 안에서는 포위 고리를 쉰다. 마지막 보스가 오면 울타리를 연다.
- 3D 미리보기 그림 대신 맵 색 띠 + 아이콘 (다음 그래픽 작업 때 그림으로).

## 9. 검토 반영 (Codex 설계 검토 2026-10-28, [원문](../Reviews/2026-10-28-expansion1-design-review.md))

| # | 문제 | 정한 규칙 |
|---|---|---|
| 1 | 일일 도전(7방)·씨앗·이어하기 | 갈림길은 **15방 던전에만** (일일 도전 7방·무한의 균열은 그대로). 갈림길 양쪽의 방 종류·적 편성·도전 종류는 판 시작 때 **따로 떼어 둔 난수**로 미리 정한다 → 어느 문을 골라도 뒤 방·카드 난수는 같다. 고른 문은 이어하기 저장(RunSnapshot)에 넣는다 |
| 2 | 도전 방 끝내기 | "20초 버티기": 20초가 되면 남은 적이 연기로 사라진다 (경험치·처치 수 없음) → 문이 열린다. "맞지 않고 깨기": 첫 피격(함정 포함) 순간 "도전 실패" 알림, 방은 평소처럼 적을 다 잡아야 끝난다. 판정은 방 상태로 저장 (이어하기·사망과 무관하게 그대로) |
| 3 | 쌍둥이 기믹이 지금 구조(체력 하나 공유 + 맞지 않는 유령)와 안 맞음 | **"그림자 표식"으로 바꾼다:** 15초마다 바닥에 표식 3개 (지름 2.5, 4초 뒤 터짐). 그 4초 안에 **맞는 쪽 쌍둥이를 5번** 맞히면 표식이 사라진다 (못 하면 터진다, 피해 최대체력 25%). 공유 체력·교대는 그대로 |
| 4 | 균열 보스에 아무 기믹이나 | 보스마다 **맞는 기믹 목록**에서만 층 씨앗으로 고른다: 수문장 = 기둥 보호막 / 강철 거상 = 불길 반쪽 / 쌍둥이 = 그림자 표식 / 망각의 왕 = 기둥 보호막 · 무너지는 바닥. 공격 뒤 빈틈은 기존 패턴 그대로 |
| 5 | 서바이벌 저장·진행 | 맵마다 따로 저장: 해금 · 최고 시간 · 별 3칸 · 첫 클리어 보상 받음. 서바이벌의 보스는 **던전 기록·구간 해금·보스 별과 관계없다**. 지금 저장의 영웅별 최고 시간은 **맵 1** 기록으로 옮긴다. 서바이벌 별은 던전·보스 별 30개 상자와 **따로 센다** |
| 6 | 보물 상자 · 조합 · 재화 | 상자 1~3회는 **한 번씩 차례로** 레벨업 창을 열고, 매번 조합 후보를 다시 확인한다. 금화 주머니를 포함한 서바이벌 반복 골드는 **맵별 분당 상한 = 같은 진행도 던전의 분당 골드** 안에서만 준다. 맵 1(7분) 시간표: 엘리트 1:45 · 4:30, 중간 보스 3:30(울타리), 마지막 보스 7:00. 맵 2·3(10분): 엘리트 2·4·6·8분, 중간 보스 5:00, 마지막 10:00 |
| 7 | "데이터만"이 아니다 | 레이아웃 데이터에 **장치 칸(종류 + 자리)** 과 **용도**(일반·엘리트·보상·중간 보스·도전·석비)를 넣고 그에 맞는 방을 뽑는다. 쇠창살·톱니·레버·열매·속성은 새 동작. 빌더 테스트: 모든 방에서 **쇠창살이 닫힌 상태를 포함해** 시작 자리 → 문 · 모든 적 생성 자리 길 (격자 BFS). 속성은 **엘리트에만**. 갈라지는 속성의 작은 엘리트·부르는 속성의 졸개는 방을 끝내려면 잡아야 하고, 경험치는 일반 적 수준, 확정 레벨업은 원래 엘리트 1번만. 부르는 졸개는 동시에 4마리까지 |
| 8 | 희귀 카드 · 석비 | 저주받은 엘리트 추가 선택: 3장 중 **2장 이상 희귀 이상**, 전설은 평소 곡선. 석비는 그 자리의 보상 방 **대신** 나온다. "지나가기" = 체력 10% 회복. 최대체력이 바뀌면 지금 체력도 같은 비율로 |
| 9 | 폭약 통 · 깜빡이는 속성 | 폭약 통 피해: 나 = 최대체력 15% (상한), 일반 적 = 공격력 200%, 엘리트 = 100%, 보스 = 50%. 통으로 잡은 적은 내 처치 (액티브 피해로 센다). 깜빡이는 속성: 멈춰 쏘기를 시작하고 **2초 뒤** 한 번만 순간이동, 그 뒤 **1.2초 제자리**(다시 조준할 빈틈), 쿨다운 6초. 속성 2개가 겹쳐도 이 빈틈은 남긴다 |
| 10 | 작은 화면에서 읽기 | 쇠창살: 닫히기 1초 전 바닥 그림자 + 열린 통로 표시 줄. 컨베이어: 띠 위 화살표가 흐른다 · 끝자리 표시. 무너지는 바닥: 안전 칸은 밝은 테두리. 5분 울타리: 생길 때 울타리 안 일반 적은 밖으로 밀려나고(경험치 없음 아님 — 그대로 산다), 울타리 밖 생성만 한다 |
| 11 | 시간 목표 | 방별 시간 예산을 벤치로 다시 잰다 (지금 표 합계 약 8분 50초~11분 10초). 넘치면 도전 방·석비를 판당 1번으로 줄인다 |

**구현 순서 (검토 반영):** ① 방 용도·난수 줄기·저장 상태 → ② 전용 레이아웃 + 도달 검사 → ③ 구간 장치 · 엘리트 속성 → ④ 특수 방 → ⑤ 서바이벌 → ⑥ 기믹 보스 → ⑦ 긴 방.
