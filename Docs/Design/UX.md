## 1. 로비 구조 (아래쪽 탭 5개)

```
┌─────────────────────────────┐
│🪙12,400 💎350 ❤️4/5  📬 👥 ⚙️│  ← 위: 재화, 하트, 우편함, 친구, 설정
│                             │
│      [ 영웅 그림 ]           │
│                             │
│   ▶ 던전 (구간 3)            │  ← 큰 버튼
│   👹 보스 도전  🧟 서바이벌   │
│                             │
├─────┬─────┬─────┬─────┬─────┤
│ 상점 │ 영웅 │ ⚔️전투│ 기록 │ 도감 │  ← 아래 탭 (가운데가 기본)
└─────┴─────┴─────┴─────┴─────┘
```

| 탭 | 내용 |
|---|---|
| **상점** | 추천 상품, 보석, 상자, 패키지 ([과금](Monetization.md#5-결제-흐름과-화면)) |
| **영웅** | 영웅 선택, 레벨업, 장비 6칸, 룬, 스킨. 잠긴 영웅은 해금 옆 [3분 체험] (보조 단추): 지금 도전 중인 구간 던전, Lv1 ★1, 하트·보상·기록·이어하기 저장 없음 |
| **전투** (기본) | 던전 / 보스 / 서바이벌 시작 |
| **기록** | 기록 보관함 (번호 칸 + 무료 임시 칸 1개), 기록 상세 (강점 막대 "단일·광역·방어", 빌드 유형 이름, 스킬 목록, 비용), 잠금 🔒, 삭제 |
| **도감** | 조합 도감 (발견한 레시피 / ???), 영웅 이야기 (사실·전승·각색) |

- 한 손 엄지로 닿는 **아래쪽**에 주요 버튼을 둔다.
- 보관함이 다 차면 기록 저장 화면에서 **[임시 칸에 두기]**를 고른다. 기존 임시 기록이 있으면 교체 전에 확인한다. 보관함에 빈 칸이 생기면 임시 기록 옆 **[보관함으로 옮기기]**를 누른다. 임시 기록도 보스 기록 선택에 나오지만 보관함 개수·보유 미션에는 세지 않는다.
- 보관함 카드엔 강점 막대 · **대표 스킬 4개 (레벨 높은 순) + "외 N개"** · 비용 (2026-10-29, 전체 UI 검토 9번: 전체 목록이 카드를 채우지 않게)
- 번호 칸마다 **[잠그기 / 잠금 풀기]** (게임 글꼴에 🔒 이모지가 없어 글자로)를 둔다. 잠근 기록은 덮어쓰기·삭제 대상으로 고를 수 없고 보스전에는 그대로 쓴다. 임시 칸에는 잠금이 없다. 임시·이동·잠금은 파란 보조 단추, 삭제는 기존 위험 색을 쓴다.
- 해금 전 탭은 자물쇠 + "1구간 보스를 깨면 열려요"처럼 **조건을 보여준다.**
  - 장비 칸·강화는 **1구간 보스 격파**, 룬·유물·수련은 **2구간 보스 격파**부터다. ([Systems 3장](Systems.md#3-해금-순서)이 기준)

---

- **홈 미션 띠** (2026-10-29 개발자: "미션이 홈에 없어서 불편"): 재화 줄 바로 아래 가로 띠 — 오늘 활동 점수 · 받을 보상 수 · 아직 안 끝난 첫 미션 + 진행 막대. 누르면 미션 창 (아래 탭 "미션"과 같은 창)

- **영웅 화면 (탕탕특공대식, 2026-10-29)**: 가운데 큰 영웅 3D · 양옆 장비 6칸 (왼쪽 무기 · 목걸이 · 장갑, 오른쪽 갑옷 · 허리띠 · 신발 — 칸 글은 슬롯 이름과 지금 낀 것, 장비는 등급 색, 누르면 그 슬롯 탭) · 아래 **공격력 · 체력** 크게 (판 밖 성장을 다 더한 값) · 바로 아래 작은 [펫] [룬] [유물] 한 줄 · 큰 [레벨업] (주 행동) + [각성] · [수련] [이 영웅으로 하기] · 맨 아래 영웅 8명 한 줄. 잠긴 영웅은 [3분 체험] [해금]

## 2. 전투 화면 (HUD)

```
┌─────────────────────────────┐
│ [Lv 8]█████████░░░░░░░░░░░░  │  ← 맨 위 전체 폭 경험치 막대 + 왼쪽 끝 레벨 배지
│  ⏸️       [ 방 7/15 ]   처치 12│  ← 방 번호 가운데 · 일시정지 왼쪽 위 · 처치 수 오른쪽
│          ▫▫▫▪▫▫★▫▫▫          │  ← 방 진행 칸
│                             │
│          ┌─ 893 ─┐           │  ← 영웅 머리 위 체력 막대 (안에 숫자)
│            (영웅)            │
│        ( 조이스틱 )           │  ← 화면 아래 어디든 터치하면 생김
└─────────────────────────────┘
```

- **Archero 식 전투 HUD (2026-11-01, 개발자가 고른 배치)**: 위쪽에는 체력 막대가 없다. 체력은 영웅 머리 위 막대 하나뿐 (아래 "전투 체력 표시"). 맨 위는 전체 폭 경험치 막대 (높이 38) + 왼쪽 끝 레벨 배지 (104), 그 아래 가운데 방 번호 · 방 진행 칸, 일시정지는 배지 바로 아래 왼쪽. 보스 체력 막대는 일시정지 단추 아래 (y -226)에 놓아 겹치지 않는다. 보스맵에서는 경험치 막대 · 레벨 배지 · 처치 수를 숨긴다
- 조이스틱은 **화면 아래 절반 어디든** 엄지를 대면 그 자리에 생긴다. (고정 위치 아님)
- **방 진행 바** (방 이름 아래): 방마다 작은 칸. 지난 방은 채움, 지금 방은 크게, 엘리트 방은 금색 + ★ — 다음 엘리트까지 계획할 수 있게 ([조사 A6](../Research/2026-10-26-mobile-roguelike-research.md)). 보스맵에서는 숨김
- **방을 깰 때마다 기록 용량 알림** 1.8초: "기록 용량 지금 13pt · 클리어하면 27pt" — 깬 방만큼 용량이 늘어난다는 걸 보여줘서 "한 방만 더"의 동기가 되게 ([조사 A7](../Research/2026-10-26-mobile-roguelike-research.md))
- **멈췄을 때 기본 공격이 나간다는 걸 눈으로 보여준다:** 멈추면 영웅 발밑에 작은 원이 차오르고 → 화살이 나감
- 레벨업 카드가 뜨는 동안 게임은 멈춘다. 카드 3장 + [리롤 📺 (2/2)]

- **일시정지** (2026-10-29, 2026-11-01 카드 모양): 전투 위에 어두운 반투명 창 (배경을 통째로 바꾸지 않는다) + 가운데 카드 (제목 리본 · 안내 · 단추 셋). [계속] 주 행동 · [설정] 보조 · [판 포기] 위험(두 번 눌러 확인). **세 단추는 높이 150 · 글자 크기 같음**. 튜토리얼에선 포기 단추 없이 "튜토리얼은 지지 않아요" (튜토리얼은 쓰러지지 않아서 포기가 안 됐다), 창이 떠 있는 동안 안내 띠는 숨긴다
- **기록 저장 화면** (2026-10-29): 남기지 않는 스킬은 "안 남김"(0pt는 숨김), 단추 아래에 **"저장되는 빌드"** 미리 보기 (강점 막대 · 남는 스킬 · 비용)
- **결과 화면** (2026-10-29): 도달한 방 → 받은 것 → 남길 수 있는 기록 용량을 먼저, 시간·처치·레벨·피해·조합·스킬은 아래 작게. "기본 공격 피해 비중 (목표 40%)" 같은 개발용 숫자는 화면에서 뺀다 (벤치 기록에는 남는다)
- **클리어 연출** (2026-11-01, 실기 피드백 "끝냈을때 이펙트도 없이 글자만 나와서 클리어한 맛이 없다"): 판을 이기면 결과 화면 전에 1.2초 박자. 0.6초 슬로모션(0.25배, 이어서 부드럽게 1배) + 하얀 번쩍임 + 화면 흔들림 + 카메라 살짝 당겨 보기(시야 7%) + "클리어!" / "격파!" / "생존!" 띠가 통 튀어나옴 + 색종이 + `victory` 소리. 보스는 BossDown이 이미 느려짐 · 번쩍임 · 소리를 내서 띠 · 색종이 · 당겨 보기만 더한다. 졌을 땐 색종이 없이 회색 막이 0.9초 동안 천천히 덮고 결과로 넘어간다. 코드는 `HypeFx.Clear/Defeat/Beat`.
- **결과 화면 연출**: 판이 아래에서 올라오고(졌을 땐 천천히 나타남) → 제목이 통 튀어나오고 → 보상 카드 숫자가 0에서 올라가며(`coin` 틱, 카드마다 `reward`) → 첫 클리어면 "첫 클리어!" 띠 → 단추가 나타난다. 별은 글 줄이라 따로 튀지 않는다.
- **연출 규칙**: 화면을 아무 데나 새로 누르면 바로 끝 상태로 건너뛴다 (누르고 있던 조이스틱은 안 센다. 단추는 손을 뗀 뒤 눌린다). 모든 시간은 실제 시간(unscaled)이라 멈춘 결과 화면에서도 돈다. **번쩍임 줄이기** 설정이 켜져 있으면 하얀 번쩍임 · 화면 흔들림을 뺀다 (슬로모션 · 당겨 보기는 그대로).

## 3. 레벨업 카드

```
┌────────┐ ┌────────┐ ┌────────┐
│ 조합!   │ │ 액티브  │ │ 패시브  │
│ 강철    │ │ 낙뢰    │ │ 방어력   │
│ 회오리  │ │ Lv2→3  │ │ Lv1 NEW │
│ (재료:  │ │ ★ 목표: │ │ 조합재료 │
│ 칼날+방어)│ │ 뇌화폭풍│ │         │
└────────┘ └────────┘ └────────┘
       [다시 뽑기 (남은 2)]  [빼기 (남은 2)]
                 [이번 판 숨기기]
```

- 카드 바탕색 = 등급 (일반 회색, 희귀 파랑, 전설 금색, 조합 무지개)
- **카드 맨 위 띠 색 = 종류**: 액티브 주황, 패시브 초록, 조합 보라, 기본(체력 회복) 짙은 회색. 글자를 읽지 않아도 한눈에 구분 (2026-10-26 폰 테스트 피드백)
- 설명은 어두운 판 위에 본문 크기(36 = 540 기준 18px, 길면 24까지 자동 축소), **위쪽 정렬**이라 세 카드가 같은 높이에서 시작한다. 아이콘 136 (540 기준 68px). 카드 336 × 560 (2026-10-29, 전체 UI 검토 3·6번)
- **이미 가진 스킬(Lv2→3 등)은 바뀌는 수치만** 노란 글씨로: "개수 3 → 4", "피해 180% → 225%", "피해 감소 +14% → +18%" (많아야 2줄). 설명의 숫자는 1레벨 기준이라 같이 두면 헷갈려서 뺀다. 수치를 못 구하는 스킬은 원래 설명
- 테두리: 일반은 차분한 회청색, 희귀(파랑)·전설(금색)만 진하게 + 뒤 빛
- **전투 체력 표시 (2026-11-01, 실기기 시험 "체력이 잘 안 보인다")**: ① 영웅 **머리 위 막대** 224×34 (1080 기준, 안에 현재 체력 숫자 — 굵은 글꼴 + 어두운 테두리) — 모델 머리 위를 카메라로 화면 좌표로 바꿔 매 프레임 따라감 (오버레이 캔버스, 안전 영역 안쪽에 머묾). 색 초록(>50%) · 노랑(25~50%) · 빨강(<25%), 맞으면 흰 잔상이 0.35초 뒤 천천히 따라 내려옴, 보호막은 막대 윗부분 하늘색 띠, 25% 미만이면 은은한 맥박 ("번쩍임 줄이기"면 맥박 없음). 쓰러지거나 일시정지 · 레벨업 창이면 숨김 (`UI/HeroHpBar.cs`). ② 위쪽 체력 막대는 없앴다 (머리 위 막대가 대신). 일시정지 단추는 맨 위 왼쪽
- **UI 화면 채우기 규칙 (2026-11-01, 개발자: "궁수의 전설은 화면이 채워져 있는데 우리는 작게 구석에 박혀 있고 비어 있다". 샘플 = 설정 · 로비 첫 화면, 승인 뒤 다른 화면으로 넓힘)**:
  - 채움: 내용이 안전 영역 전체 폭 (좌우 여백 24)과 높이를 쓴다. 세로로 긴 폰에서 가운데가 비면 줄 · 간격을 키우거나 스크롤
  - 큰 터치: 줄 · 단추 높이 120 이상 (서로 다른 줄 간격 12~22), 아이콘 64~96, 글자 본문 28 이상 · 이름표 26 이상 · 작은 메모 22 이상 · 제목 44 이상
  - 위계: 화면당 제목 리본 하나 + 묶음마다 카드(제목) + 전체 폭 줄, 주 행동이 가장 크고 눈에 띄게 (로비 던전 카드 260)
  - 부품: UI 키트 스프라이트 (`SceneBuilder.UiKit`) + `Art/UI/Icons` 흰 아이콘을 색칠해서 + 보상 아이콘. 새 부품을 그리지 않는다
  - 설정 화면: 소리 · 그래픽 / 화면 / 조작 / 알림 / 계정 / 정보 카드, 줄마다 왼쪽 아이콘 + 이름 + 오른쪽 조절 (켜기/끄기 = 스위치, 음량 · 여러 값 = 고르기 칸 `SettingRow`), 세로 스크롤 + 아래 큰 [닫기] + 오른쪽 위 X. 저장 값 · 계정 흐름은 그대로
  - 로비 첫 화면: 위 재화 칸 96 (레벨 배지 108) · 오늘 미션 띠 108 · 영웅 양옆 큰 아이콘 단추 170×200 (7일 미션 · 조합 도감 / 설정 · 순찰) · 구간 카드 270 · **던전 카드 전체 폭 260** · 보조 모드 3칸 (서바이벌 · 균열 · 일일, 아이콘 위 + 글 아래) · 아래 탭 높이 200 (고른 탭이 위로 솟음)
- **서브 화면 꾸밈 (2026-11-02, 개발자: "칙칙하다 · 모바일 게임스럽지 않다 · 홈 화면을 뺀 화면은 위가 안 채워져 홈이 비친다 · 보상 이펙트가 없다" — 조사: `Docs/Design/UI-Research-2026-11-02.md`)**:
  - 창 바탕은 안전 영역 밖(상태 표시줄 · 카메라 구멍 · 제스처 바)까지 깐다 (`Overlay` → `Bleed`). 팝업 덮개도 같다
  - 위 띠: 왼쪽 뒤로 화살표 · 가운데 빨간 제목 리본 · 오른쪽 골드 · 보석 칩 (`SceneBuilder.TopBar.cs`, 원래 "뒤로" 단추는 그대로 두고 화살표가 대신 누른다). 칩 숫자는 바뀌면 올라가며 바뀐다 (`WalletChip`)
  - 키 큰 폰: 내용을 위 묶음 · 아래 묶음으로 나눠 위는 띠 바로 아래, 아래(도전 · 뒤로)는 맨 아래에 붙이고 세로 목록이 남는 높이를 쓴다 (`PinToEdges`). 1920 화면은 위치 그대로
  - 색: 바탕 · 줄 · 칸은 채도 있는 파랑 (`UiTone`, 예전 거의 검정 0.1~0.16 → 밝은 카드), 보조 단추는 회색 대신 선명한 파랑. 회색 · 어두운 색은 못 누름 · 잠김만
  - 움직임: 창이 열릴 때 0.22초 살짝 커지며 나타남 (`PanelIntro`), 목록 줄은 위에서부터 차례로 (0.045초 간격 8줄, `ButtonList`)
  - 보상 받기: 어두운 덮개 + "획득!" 리본 + 도는 빛줄기 + 카드가 차례로 튀어나옴 → 누르면 골드 · 보석이 위 칩으로 날아가 칩이 튄다 (`RewardPopup`, 미션 상자 · 업적 · 신규 7일 · 순찰 · 결제 지급)
- **고르기 창 = 가운데 팝업 (2026-11-02, 개발자: "이어하기 · 그만두기 두 개면 가운데에 두 개 띄우고 왼쪽 오른쪽 선택 — 박스 안에 위로 정렬하면 너무 별로")**: 누를 수 있는 고르기가 1~2개면 화면 전체 목록이 아니라 **로비를 어둡게 덮은 가운데 카드** (높이 = 내용)에 **[왼쪽 | 오른쪽] 단추 한 줄**. 왼쪽 = 그만두기 · 취소 · 괜찮아요 (회색), 오른쪽 = 이어하기 · 구매 · 받을게요 (초록 강조), 되돌릴 수 없는 고르기 (계정 삭제 · 기록 포기)는 빨강. 고르기 1개면 [취소/나중에 | 고르기], 2개면 아래 작은 "나중에" 글 단추. 자세한 설명은 단추가 아니라 카드 글에. 3개 이상(전설 장비 8장)만 화면 가득 목록 (`UI/ChoicePanel.cs`)
- **빈 상자 금지 (2026-11-02 전체 화면 점검)**: 목록 칸(`ButtonList`)은 배경 없이 줄 카드만 보인다 (줄이 적을 때 빈 어두운 상자가 남지 않게). 빈 기록 칸은 위 한 줄이 아니라 카드 가운데 한 덩어리 ("2번 칸 · 비어 있음" + 안내). 긴 안내 글(무한의 균열 · 일일 도전)은 위에 붙이지 않고 글 높이만큼의 카드를 제목과 단추 사이 가운데에. 목록 줄 글은 34 이상, 칸을 넘는 줄만 혼자 줄어든다
- **같은 역할 버튼 = 같은 글자 크기 (2026-11-01, 개발자: "계속 / 설정 / 판 포기 글씨 크기가 달라서 보기 불편")**: 같은 부모 안에서 높이가 같은 단추는 한 묶음이다. 묶음의 글자는 모두 자동 크기로 한 번 재서 **가장 작은 값에 맞춘다** (`UI/ButtonTextGroup.cs`, 글이 바뀌면 — 예: "판 포기" → "정말 포기? 한 번 더" — 그 프레임에 다시 맞춤). 장면 빌더가 저장 직전에 묶음을 자동으로 붙이고 (`ApplyButtonGroups`), 고르기 창 줄처럼 런타임에 복제되는 목록은 `scanChildren`으로 묶는다. 글 길이가 제각각인 목록(장비 가방 · 교환소 등 `ButtonList`)은 묶지 않는다. 단추마다 `fontSize`를 따로 정하지 않는다 (역할이 다르면 높이를 다르게). `QaTools.TextAudit`가 크기가 다른 형제 단추를 `BTN-SIZE`로 알려 준다
- 줄 간격 (모든 화면): 최소 +26% (2026-10-29 개발자: "위아래가 짧아 뭉쳐 보인다")
- 글자 체계 (모든 화면): 보조 30 이상 (540 기준 15px, 좁은 칸은 원래 크기까지 자동 축소) · 본문 36~40 · 제목 56~68. 본문 테두리는 얇게, 굵은 테두리는 제목만
- 세로로 긴 폰(19.5:9 등)에서도 잘리지 않게 UI 기준 영역 1080 × 1920이 항상 다 보이게 한다. HUD는 안전 영역(카메라 구멍·상태 표시줄) 안에
- 이미 발견한 레시피의 재료면 카드 아래 어두운 칸에 "◆ 결과 ← 짝 재료 · 진행도" (조건을 채운 재료는 초록). 조합 카드에는 "※ 고르면 이번 판엔 막혀요" + 막히는 조합 이름 (GameDesign 6-2, 조사 A3·A4)
- 도감에서 발견한 레시피를 최대 2개까지 **★ 목표**로 고른다 (계정 저장). 신규·레벨업 재료 카드에는 기존 조합 힌트와 함께 **"★ 목표: 결과 이름"**을 표시한다. 목표는 표시만 하며 후보·등급 확률·룬 가중치를 바꾸지 않는다.
- 리롤 옆 보조 단추 **[빼기 (남은 N)]**: 판당 무료 2번, 광고·리롤 횟수와 따로 센다. 누르면 빼기 상태, 다시 누르면 취소. 신규·레벨업 카드에 빨간 테두리와 **"누르면 이번 판에서 빼요"**, 발견한 재료 조합이 있으면 **"막히는 조합: 이름"**을 보여 준다.
- 빼기 상태에서 재료 카드를 누르면 그 카드 한 장만 다시 뽑고 **빼기 상태는 꺼진다** (한 장 더 빼려면 다시 누른다), 그 스킬은 이번 판의 신규·레벨업 후보에서 제외한다. 이미 가진 효과는 남지만 그 재료가 필요한 조합은 만들 수 없다. 조합·기본 회복·균열 강화는 빼지 않고 짧게 안내한다. 조합은 기존 **[이번 판 숨기기]**를 쓴다.
- 빼기 목록과 남은 횟수는 이어하기에 남긴다. 다 쓰면 단추가 비활성화되고, 튜토리얼에서는 단추를 숨긴다.
- 힌트가 있으면 설명 칸이 위로 줄어들어 겹치지 않는다
- **오입력 막기:** 창이 뜬 뒤 0.4초(실제 시간) 동안은 누를 수 없고 반투명으로 보인다. 창이 뜰 때 화면을 누르고 있던 손가락은 한 번 뗄 때까지 무시한다 (조이스틱을 쥔 채 카드를 잘못 누르지 않게). 연달아 레벨업이 올라도 카드가 바뀔 때마다 다시 적용 — [조사 A2](../Research/2026-10-26-mobile-roguelike-research.md)
- 리롤 버튼 문구: "광고 보고 다시 뽑기 (남은 2)". 다 쓰면 버튼을 숨긴다

- 기존 `TutorialGuide`와 같은 클리오 안내 띠와 금빛 테두리로 대상 단추를 짚는다. 띠를 누르거나 대상 기능을 열면 닫히며 12초 뒤에도 사라진다. 다른 창이 열려 있거나 전투 중이면 표시하지 않는다. 본 순간 안내 ID를 계정 저장에 남겨 재접속해도 다시 보여 주지 않는다. 저장이 실패하면 이번에는 안내를 보류한다. 알림 권한 질문은 튜토리얼 다음 로비부터 유지한다.
- 튜토리얼에서는 **절대 지지 않게** 조절한다. (적 피해 감소)
- 첫 10분 동안 **결제 팝업을 띄우지 않는다.** 첫 결제 패키지는 첫 보스 격파 후 상점에 조용히 표시만.

## 6. 손맛 규칙 (v0.3, 조사 A9)

숫자는 모두 **[제안] 시작값**. 폰 테스트로 맞춘다.

| 효과 | 언제 | 값 | 구현 |
|---|---|---|---|
| **피해 숫자** | 적이 피해를 받을 때 | 같은 적 0.15초 안 피해는 하나로 합침. 기본 공격 흰색, 액티브 하늘색, 치명타 노란색 1.4배. 동시에 최대 40개(넘으면 가장 오래된 것 재사용). 0.6초 동안 위로 뜨며 사라짐. 1만 이상은 "1.2만" | `Combat/DamageNumbers` (풀), `Health.AnyDamaged` |
| **히트스톱** | 매 타격엔 **안 한다** (흰색 깜빡임만) | 엘리트 처치 0.08초, 보스 단계 전환 0.1초, 보스 처치 0.2초 + 0.5초 동안 0.3배 | `Common/HitStop` → `GamePause.RequestSlow` |
| **화면 흔들림** | 트라우마 방식 | 플레이어 피격 +0.3, 엘리트 처치 +0.4, 보스 강타·처치 +0.5. 크기 = 트라우마², 초당 1.5 감소, 최대 이동 0.3유닛·회전 2°, Perlin 노이즈 | `Common/CameraShake` (전투 카메라) |

- **멈춤이 언제나 이긴다:** 레벨업 창·결과 화면(멈춤 요청)이 하나라도 있으면 시간은 0. 아니면 느리게 요청 중 가장 작은 값. 느리게 시간은 실제 시간으로 세서, 창이 떠 있는 동안 끝나면 창을 닫은 뒤 원래 속도로 돌아온다.
- 피해 숫자·흔들림은 실제 시간으로 움직여서 레벨업 창이 떠도 마저 사라진다.
