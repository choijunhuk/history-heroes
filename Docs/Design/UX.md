## 1. 로비 구조 (아래쪽 탭 5개)

```
┌─────────────────────────────┐
│🪙12,400 💎350 ❤️4/5  📬 👥 ⚙️│  ← 위: 재화, 하트, 우편함, 친구, 설정
│                             │
│      [ 영웅 그림 ]           │
│                             │
│   ▶ 던전 (구간 3)            │  ← 큰 버튼
│   👹 보스 도전  🧟 서바이벌   │
│                             │
├─────┬─────┬─────┬─────┬─────┤
│ 상점 │ 영웅 │ ⚔️전투│ 기록 │ 도감 │  ← 아래 탭 (가운데가 기본)
└─────┴─────┴─────┴─────┴─────┘
```

| 탭 | 내용 |
|---|---|
| **상점** | 추천 상품, 보석, 상자, 패키지 ([과금](Monetization.md#5-결제-흐름과-화면)) |
| **영웅** | 영웅 선택, 레벨업, 장비 3칸, 룬, 스킨. 잠긴 영웅은 해금 옆 [3분 체험] (보조 단추): 지금 도전 중인 구간 던전, Lv1 ★1, 하트·보상·기록·이어하기 저장 없음 |
| **전투** (기본) | 던전 / 보스 / 서바이벌 시작 |
| **기록** | 기록 보관함 (번호 칸 + 무료 임시 칸 1개), 기록 상세 (강점 막대 "단일·광역·방어", 빌드 유형 이름, 스킬 목록, 비용), 잠금 🔒, 삭제 |
| **도감** | 조합 도감 (발견한 레시피 / ???), 영웅 이야기 (사실·전승·각색) |

- 한 손 엄지로 닿는 **아래쪽**에 주요 버튼을 둔다.
- 보관함이 다 차면 기록 저장 화면에서 **[임시 칸에 두기]**를 고른다. 기존 임시 기록이 있으면 교체 전에 확인한다. 보관함에 빈 칸이 생기면 임시 기록 옆 **[보관함으로 옮기기]**를 누른다. 임시 기록도 보스 기록 선택에 나오지만 보관함 개수·보유 미션에는 세지 않는다.
- 번호 칸마다 **[잠그기 / 잠금 풀기]** (게임 글꼴에 🔒 이모지가 없어 글자로)를 둔다. 잠근 기록은 덮어쓰기·삭제 대상으로 고를 수 없고 보스전에는 그대로 쓴다. 임시 칸에는 잠금이 없다. 임시·이동·잠금은 파란 보조 단추, 삭제는 기존 위험 색을 쓴다.
- 해금 전 탭은 자물쇠 + "1구간 보스를 깨면 열려요"처럼 **조건을 보여준다.**
  - 장비 칸·강화는 **1구간 보스 격파**, 룬·유물·수련은 **2구간 보스 격파**부터다. ([Systems 3장](Systems.md#3-해금-순서)이 기준)

## 2. 전투 화면 (HUD)

```
┌─────────────────────────────┐
│ ❤️████████░░  방 7/15   ⏸️  │
│ ⭐ Lv 8 ███████░░░            │  ← 경험치 바
│                             │
│         (전투 화면)           │
│                             │
│ [⚔️][⚔️][⚔️][ ]  액티브 칸     │  ← 쿨다운 표시
│ [🛡️][🛡️][ ][ ]  패시브 칸     │
│                             │
│        ( 조이스틱 )           │  ← 화면 아래 어디든 터치하면 생김
└─────────────────────────────┘
```

- 조이스틱은 **화면 아래 절반 어디든** 엄지를 대면 그 자리에 생긴다. (고정 위치 아님)
- **방 진행 바** (방 이름 아래): 방마다 작은 칸. 지난 방은 채움, 지금 방은 크게, 엘리트 방은 금색 + ★ — 다음 엘리트까지 계획할 수 있게 ([조사 A6](../Research/2026-10-26-mobile-roguelike-research.md)). 보스맵에서는 숨김
- **방을 깰 때마다 기록 용량 알림** 1.8초: "기록 용량 지금 13pt · 클리어하면 27pt" — 깬 방만큼 용량이 늘어난다는 걸 보여줘서 "한 방만 더"의 동기가 되게 ([조사 A7](../Research/2026-10-26-mobile-roguelike-research.md))
- **멈췄을 때 기본 공격이 나간다는 걸 눈으로 보여준다:** 멈추면 영웅 발밑에 작은 원이 차오르고 → 화살이 나감
- 레벨업 카드가 뜨는 동안 게임은 멈춘다. 카드 3장 + [리롤 📺 (2/2)]

## 3. 레벨업 카드

```
┌────────┐ ┌────────┐ ┌────────┐
│ ✨조합! │ │ ⚔️ 액티브│ │🛡️ 패시브 │
│ 강철    │ │ 낙뢰    │ │ 방어력   │
│ 회오리  │ │ Lv2→3  │ │ Lv1 NEW │
│ (재료:  │ │        │ │ 🔗조합재료│
│ 칼날+방어)│ │        │ │         │
└────────┘ └────────┘ └────────┘
       [📺 리롤 2/2]   [이번 판 숨기기]
```

- 카드 바탕색 = 등급 (일반 회색, 희귀 파랑, 전설 금색, 조합 무지개)
- **카드 맨 위 띠 색 = 종류**: 액티브 주황, 패시브 초록, 조합 보라, 기본(체력 회복) 짙은 회색. 글자를 읽지 않아도 한눈에 구분 (2026-10-26 폰 테스트 피드백)
- 설명은 어두운 판 위에 본문 크기(36 = 540 기준 18px, 길면 24까지 자동 축소), **위쪽 정렬**이라 세 카드가 같은 높이에서 시작한다. 아이콘 136 (540 기준 68px). 카드 336 × 560 (2026-10-29, 전체 UI 검토 3·6번)
- **이미 가진 스킬(Lv2→3 등)은 바뀌는 수치만** 노란 글씨로: "개수 3 → 4", "피해 180% → 225%", "피해 감소 +14% → +18%" (많아야 2줄). 설명의 숫자는 1레벨 기준이라 같이 두면 헷갈려서 뺀다. 수치를 못 구하는 스킬은 원래 설명
- 테두리: 일반은 차분한 회청색, 희귀(파랑)·전설(금색)만 진하게 + 뒤 빛
- 글자 체계 (모든 화면): 보조 30 이상 (540 기준 15px, 좁은 칸은 원래 크기까지 자동 축소) · 본문 36~40 · 제목 56~68. 본문 테두리는 얇게, 굵은 테두리는 제목만
- 세로로 긴 폰(19.5:9 등)에서도 잘리지 않게 UI 기준 영역 1080 × 1920이 항상 다 보이게 한다. HUD는 안전 영역(카메라 구멍·상태 표시줄) 안에
- 이미 발견한 레시피의 재료면 카드 아래 어두운 칸에 "◆ 결과 ← 짝 재료 · 진행도" (조건을 채운 재료는 초록). 조합 카드에는 "※ 고르면 이번 판엔 막혀요" + 막히는 조합 이름 (GameDesign 6-2, 조사 A3·A4)
- 힌트가 있으면 설명 칸이 위로 줄어들어 겹치지 않는다
- **오입력 막기:** 창이 뜬 뒤 0.4초(실제 시간) 동안은 누를 수 없고 반투명으로 보인다. 창이 뜰 때 화면을 누르고 있던 손가락은 한 번 뗄 때까지 무시한다 (조이스틱을 쥔 채 카드를 잘못 누르지 않게). 연달아 레벨업이 올라도 카드가 바뀔 때마다 다시 적용 — [조사 A2](../Research/2026-10-26-mobile-roguelike-research.md)
- 리롤 버튼 문구: "광고 보고 다시 뽑기 (남은 2)". 다 쓰면 버튼을 숨긴다

## 4. 첫 10분 (온보딩)

**목표: 10분 안에 "멈추면 쏜다 → 레벨업 → 조합 → 기록 → 보스"를 모두 맛보게 한다.** 첫 공격 20초 · 첫 카드 45초 · 첫 조합 3분 안 (2026-10-29 전체 기획 검토 1번: 빈 이동 방을 빼고 첫 방부터 쏜다, 첫 처치에 첫 레벨업)

| 시간 | 일어나는 일 | 가르치는 것 |
|---|---|---|
| 0:00 | 짧은 오프닝 컷 (3장면, 건너뛰기 가능): "역사가 지워진다…" | 세계관 |
| 0:30 | 칭기즈 칸으로 **튜토리얼 방 1**: 궁병 1마리. "끌면 움직이고, 멈추면 쏴요!" (**첫 공격 20초 안**) | 이동 · **멈추면 쏜다** |
| 0:50 | **첫 처치 = 첫 레벨업**: 카드 3장 (튜토리얼은 고정 카드, **첫 카드 45초 안**) | 스킬 선택 |
| 1:10 | 방 2: 돌진병. 예고선 → 피하고 → 쏘기 | 예고와 빈틈 |
| 2:30 | **조합 튜토리얼** (방 3~4): 회전 칼날과 방어력을 일부러 줘서 조합 카드 등장. 방 3에 들어서면 레벨업 하나 더 → 방 4까지 7번째 카드 (**첫 조합 3분 안**) | ✨ 조합 |
| 5:00 | 튜토리얼 던전(방 6개) 클리어 → 결과 화면 | 판의 끝 |
| 5:30 | **기록 저장 튜토리얼**: 용량이 넘쳐서 하나 골라 빼기 | 기록 |
| 6:30 | **첫 보스 도전** (튜토리얼 보스, 꼭 이기게) | 기록 → 보스 |
| 8:00 | 보스 격파 → **기록 보관함(3칸)** 해금 + **첫 펫(사냥매)** 지급 + 첫 고급 상자 무료. 일일 미션·출석부·신규 7일 미션도 함께 열림 | 판 밖 성장 |
| 9:00 | 로비 → "1구간 던전에 도전하세요" | 다음 목표 |

- **튜토리얼 직후 로비는 다음 목표 하나만:** "튜토리얼 끝! 이제 1구간 던전에 도전하세요" 한 줄. 출석부·7일 미션·펫은 단추 표시로 알리고, 알림 받기 질문 같은 창은 다음 로비부터 (2026-10-29 전체 기획 검토 1번)
- 튜토리얼에서는 **절대 지지 않게** 조절한다. (적 피해 감소)
- 첫 10분 동안 **결제 팝업을 띄우지 않는다.** 첫 결제 패키지는 첫 보스 격파 후 상점에 조용히 표시만.

## 5. 접근성·편의
- **설정 (v0.3 확정, 로비 오른쪽 위 "설정"):** 화면 흔들림 끄기/약하게(50%)/보통, 피해 숫자 켜기/끄기, 번쩍임 줄이기(반지름 2.5 이상 큰 폭발을 40% 옅게 + 1초에 3번까지, WCAG 2.3.1). 판 밖 저장(`SaveData.settings`), 누르면 바로 저장
- 진동 끄기/켜기 (진동을 넣을 때)
- 색맹 대응: 카드 등급을 색깔 + 테두리 모양으로 구분
- **단추는 세 가지뿐** (2026-10-29, 전체 UI 검토 4번): 주 행동 = 선명한 초록 (시작·계속·구매·강화·레벨업·각성) · 보조 = 차분한 남회색 (다른 화면 가기·설정·뒤로) · 위험 = 어두운 빨강, 덜 튀게 (지우기·분해·판 포기). 빌더 `Btn()`이 넘긴 색을 이 셋으로 바꾼다. 탭·칸의 "고름" 표시 색은 따로. 화면 배경 격자 무늬는 흐리게
- 글자 크기 2단계
- 한국어 기본, 영어 동시 지원 (Unity 공식 `localization` 스킬)

## 6. 손맛 규칙 (v0.3, 조사 A9)

숫자는 모두 **[제안] 시작값**. 폰 테스트로 맞춘다.

| 효과 | 언제 | 값 | 구현 |
|---|---|---|---|
| **피해 숫자** | 적이 피해를 받을 때 | 같은 적 0.15초 안 피해는 하나로 합침. 기본 공격 흰색, 액티브 하늘색, 치명타 노란색 1.4배. 동시에 최대 40개(넘으면 가장 오래된 것 재사용). 0.6초 동안 위로 뜨며 사라짐. 1만 이상은 "1.2만" | `Combat/DamageNumbers` (풀), `Health.AnyDamaged` |
| **히트스톱** | 매 타격엔 **안 한다** (흰색 깜빡임만) | 엘리트 처치 0.08초, 보스 단계 전환 0.1초, 보스 처치 0.2초 + 0.5초 동안 0.3배 | `Common/HitStop` → `GamePause.RequestSlow` |
| **화면 흔들림** | 트라우마 방식 | 플레이어 피격 +0.3, 엘리트 처치 +0.4, 보스 강타·처치 +0.5. 크기 = 트라우마², 초당 1.5 감소, 최대 이동 0.3유닛·회전 2°, Perlin 노이즈 | `Common/CameraShake` (전투 카메라) |

- **멈춤이 언제나 이긴다:** 레벨업 창·결과 화면(멈춤 요청)이 하나라도 있으면 시간은 0. 아니면 느리게 요청 중 가장 작은 값. 느리게 시간은 실제 시간으로 세서, 창이 떠 있는 동안 끝나면 창을 닫은 뒤 원래 속도로 돌아온다.
- 피해 숫자·흔들림은 실제 시간으로 움직여서 레벨업 창이 떠도 마저 사라진다.
