## 1. 원칙

| 원칙 | 내용 |
|---|---|
| **힘 예산** | 장비 전체(모든 슬롯 + 강화 + 합성)를 끝까지 올려도 **공격력 +25%, 체력 +25%**를 넘지 않는다 |
| **판 안이 먼저** | 장비는 기본 능력치만 올린다. 스킬 확률, 조합, 리롤에는 영향이 없다 |
| **영웅의 정체성은 영웅이 정한다** | 무기는 기본 공격의 **모양을 바꾸지 않는다.** 화살이 총알이 되는 일은 없다 |
| **무과금도 끝까지** | 전설 장비 없이 희귀 장비만으로도 모든 콘텐츠를 깰 수 있다 |
| **기록은 그때 그대로** | 기록에는 만들 당시의 장비(ID + 강화 레벨)를 고정 저장한다 ([GameDesign 7-5](../GameDesign.md#7-5-패치밸런스-변경-정책)) |

## 2. 두 가지 안

| | **(a) 최소안** | **(b) 확장안** ⭐ 추천 |
|---|---|---|
| 슬롯 | 무기 / 갑옷 / 장신구 | 같음 |
| 등급 | 일반 / 고급 / 희귀 / 전설 | 같음 |
| 수치 | 등급별 고정 (Economy.md 6장 그대로) | 등급별 기본값 + **강화** |
| 강화 | 없음 | **슬롯 강화** (골드) |
| 합성 | 없음 | **같은 슬롯·같은 등급 3개 → 다음 등급** (희귀까지) |
| 부가 능력치 | 없음 | 장비마다 **고정** 부가 능력치 1개 (무작위 아님) |
| 고유 효과 | 없음 | 없음 (출시 이후) |
| 무작위 옵션 | 없음 | 없음 (출시 이후) |
| 장점 | 만들기 쉽고 밸런스가 쉽다 | 성장 경로가 깊어서 오래 할 거리가 생긴다. 중복 장비가 쓸모 있다 |
| 단점 | 장비 하나 맞추면 할 게 없다 (아처 1의 문제) | 작업량이 늘고, 골드 소비처가 커진다 |

**추천: (b) 확장안.** 개발자가 성장 시스템을 풍부하게 원하고, 아처 1이 성장 경로가 얕아서 매출이 빨리 꺾였다는 교훈이 있다. 대신 **무작위 옵션과 고유 효과는 계속 뺀다.** 이 둘이 밸런스를 가장 크게 흔든다.

> 이하 내용은 **(b) 확장안** 기준이다.

## 3. 슬롯과 능력치

### 3-1. 슬롯별 역할

| 슬롯 | 주 능력치 | 부가 능력치 후보 | 해금 |
|---|---|---|---|
| 🗡️ **무기** | 공격력 % | 치명타 피해, 치명타 확률, 쿨다운 감소 | 1구간 보스 최초 격파 |
| 🛡️ **갑옷** | 최대체력 % | 피해 감소, 체력 재생 | 1구간 보스 최초 격파 |
| 💍 **장신구** | 공격속도 % | 치명타 확률, 이동속도, 경험치 획득 | 1구간 보스 최초 격파 |

- 세 슬롯이 한 번에 열린다. (Economy.md와 같음)

### 3-2. 등급별 기본값과 강화 상한

| 등급 | 무기 공격력 | 갑옷 체력 | 장신구 공격속도 | 강화 상한 |
|---|---|---|---|---|
| ⚪ 일반 | +3% | +3% | +2% | Lv 10 |
| 🟢 고급 | +6% | +6% | +4% | Lv 20 |
| 🔵 희귀 | +10% | +10% | +6% | Lv 30 |
| 🟡 전설 | +15% | +15% | +8% | Lv 40 |

### 3-3. 강화 1레벨당

| 슬롯 | 강화 Lv당 |
|---|---|
| 무기 | 공격력 +0.25% |
| 갑옷 | 최대체력 +0.25% |
| 장신구 | 공격속도 +0.1% |

### 3-4. 최대치 확인 (힘 예산)

| 상태 | 무기 공격력 | 갑옷 체력 | 장신구 공격속도 |
|---|---|---|---|
| 일반 Lv10 | 3 + 2.5 = **+5.5%** | +5.5% | 2 + 1 = +3% |
| 고급 Lv20 | 6 + 5 = **+11%** | +11% | 4 + 2 = +6% |
| 희귀 Lv30 | 10 + 7.5 = **+17.5%** | +17.5% | 6 + 3 = +9% |
| 전설 Lv40 | 15 + 10 = **+25%** ✅ | **+25%** ✅ | 8 + 4 = **+12%** |

- 공격력은 무기에서만, 체력은 갑옷에서만 나온다. → 슬롯 합계도 **+25% / +25%**로 예산 안이다.
- 공격속도 +12%는 Economy.md의 전설 장신구 값과 같다.

## 4. 강화: 장비가 아니라 "슬롯"에 붙는다

**강화 레벨은 슬롯이 가진다.** 장비를 바꿔 끼워도 강화 레벨은 그대로 남는다.

```
무기 슬롯 강화 Lv 25
 ├─ 희귀 장비를 끼우면 → Lv 25 적용 (상한 30 안이라 그대로)
 └─ 고급 장비를 끼우면 → Lv 20까지만 적용 (등급 상한), 나머지 5는 보관
```

| 항목 | 내용 |
|---|---|
| 왜 슬롯에? | 더 좋은 장비를 얻었을 때 **그동안 쓴 골드가 날아가지 않는다.** 초보자가 "강화했는데 바꾸면 손해"라고 고민할 일이 없다 |
| 적용 범위 | **계정 공용.** 슬롯 강화는 모든 영웅에게 같이 적용된다 (영웅을 바꿔도 다시 강화할 필요 없음) |
| 비용 | Lv n → n+1: 🪙 **100 × n** (Lv1→2: 100, Lv39→40: 3,900) |
| 총 비용 | 슬롯 하나 Lv40까지 🪙 **78,000**, 3슬롯 🪙 **234,000** |
| 실패 | **없다.** 강화는 항상 성공한다 (확률형 강화는 쓰지 않음) |
| 상한 | 끼운 장비 등급의 상한까지만 효과가 있다. 상한 넘는 강화는 막는다 (미리 올려둘 수 없음) |

> ⚠️ 골드 소비처가 커진다. 영웅 레벨(영웅당 🪙 약 87,000)과 합치면 Economy.md의 월 골드 수입(약 180,000)으로 **몇 달짜리** 목표가 된다. 경제 문서와 함께 조정 필요.

## 5. 합성

| 재료 | 결과 | 비용 |
|---|---|---|
| 같은 슬롯 · ⚪ 일반 3개 | 같은 슬롯 🟢 고급 1개 (그 슬롯 고급 장비 중 **선택**) | 🪙 500 |
| 같은 슬롯 · 🟢 고급 3개 | 같은 슬롯 🔵 희귀 1개 (그 슬롯 희귀 장비 중 **선택**) | 🪙 3,000 |
| 🔵 희귀 → 🟡 전설 | **합성 불가** | — |

- 재료는 **같은 슬롯, 같은 등급이면 아무거나** 된다. (같은 이름일 필요 없음)
- 결과는 **무작위가 아니라 플레이어가 고른다.** → 확률형 아이템이 아니다.
- 전설은 합성으로 못 만든다. 전설은 **고급 상자, 장비 조각 교환소, 보스 최초 격파 보상**으로만 얻는다. 희귀 3개로 전설을 만들 수 있으면 상자의 전설 2%가 의미 없어진다.
- 장착 중인 장비, 잠근 장비(🔒)는 재료로 자동 선택되지 않는다.

## 6. 무기: 직업별 모양, 수치는 공용

**무기는 "공용 아이템"이다. 끼운 영웅에 따라 모양만 바뀐다.**

| 영웅 | 같은 "장군의 무기"가 보이는 모양 | 기본 공격 (안 바뀜) |
|---|---|---|
| 🏹 칭기즈 칸 | 장군의 **각궁** | 화살 1발 |
| ⚔️ 관우 | 장군의 **언월도** | 근접 부채꼴 베기 |
| 💥 나폴레옹 | 장군의 **머스킷** | 총알 연사 |
| ⚡ 테슬라 | 장군의 **코일 지팡이** | 전기 구체 + 튕김 |

| 다른 방식 | 왜 안 쓰나 |
|---|---|
| 직업 전용 무기 (활은 궁수만) | 상자에서 내가 안 쓰는 영웅 무기가 나오면 허탈하다. 뽑기 풀이 4배로 쪼개진다 |
| 무기가 공격 모양을 바꿈 (활 → 석궁 연사) | 영웅의 개성이 흐려지고, 밸런스 조합이 영웅 수 × 무기 수로 늘어난다 |

- 전설 무기는 **투사체 색과 이펙트만** 바뀐다. (예: 시간 수호자의 무기 → 화살 끝에 푸른 잔상) 성능 차이 없음.

## 7. 장비 목록 (출시 21종)

슬롯마다 일반 1종 + 고급·희귀·전설 각 2종 = **7종 × 3슬롯 = 21종**. 같은 등급의 두 장비는 **고정 부가 능력치**만 다르다. → "공격형이냐 생존형이냐" 고르는 재미.

### 7-1. 🗡️ 무기

| 등급 | 이름 | 주 능력치 | 고정 부가 능력치 |
|---|---|---|---|
| ⚪ | 수습병의 무기 | 공격력 +3% | — |
| 🟢 | 정예병의 무기 | 공격력 +6% | 치명타 피해 +10% |
| 🟢 | 척후병의 무기 | 공격력 +6% | 쿨다운 감소 +3% |
| 🔵 | 장군의 무기 | 공격력 +10% | 치명타 피해 +20% |
| 🔵 | 책사의 무기 | 공격력 +10% | 쿨다운 감소 +6% |
| 🟡 | 시간 수호자의 무기 | 공격력 +15% | 치명타 확률 +5% |
| 🟡 | 정복자의 무기 | 공격력 +15% | 치명타 피해 +35% |

### 7-2. 🛡️ 갑옷

| 등급 | 이름 | 주 능력치 | 고정 부가 능력치 |
|---|---|---|---|
| ⚪ | 수습병의 갑옷 | 최대체력 +3% | — |
| 🟢 | 정예병의 갑옷 | 최대체력 +6% | 피해 감소 +2% |
| 🟢 | 순례자의 외투 | 최대체력 +6% | 체력 재생 +0.5%/5초 |
| 🔵 | 장군의 갑옷 | 최대체력 +10% | 피해 감소 +4% |
| 🔵 | 탐험가의 외투 | 최대체력 +10% | 체력 재생 +1%/5초 |
| 🟡 | 시간 수호자의 갑옷 | 최대체력 +15% | 피해 감소 +7% |
| 🟡 | 불굴의 망토 | 최대체력 +15% | 체력 재생 +1.5%/5초 |

### 7-3. 💍 장신구

| 등급 | 이름 | 주 능력치 | 고정 부가 능력치 |
|---|---|---|---|
| ⚪ | 낡은 부적 | 공격속도 +2% | — |
| 🟢 | 매의 깃털 장식 | 공격속도 +4% | 치명타 확률 +2% |
| 🟢 | 여행자의 나침반 | 공격속도 +4% | 이동속도 +3% |
| 🔵 | 황금 인장 반지 | 공격속도 +6% | 치명타 확률 +4% |
| 🔵 | 학자의 회중시계 | 공격속도 +6% | 경험치 획득 +5% |
| 🟡 | 시간의 모래시계 | 공격속도 +8% | 치명타 확률 +6% |
| 🟡 | 바람의 등자 | 공격속도 +8% | 이동속도 +6% |

- 부가 능력치는 강화로 오르지 않는다. (주 능력치만 강화)
- 부가 능력치 최대 조합 확인: 치명타 확률 기본 5% + 무기 5% + 장신구 6% = 16% (상한 60% 안), 피해 감소 최대 7% (상한 60% 안). 판 안 스킬이 상한까지 채울 여지를 남긴다.
- "부적"은 종교적 의미가 아닌 **행운 장식**으로 그린다.

## 8. 획득처

| 획득처 | 무엇을 | 확률/수량 (임시) | 확률 공개 필요? |
|---|---|---|---|
| 🎁 고급 상자 (💎 250 / 🎫) | 고급~전설 | [Gacha.md](Gacha.md) (전설 2%, 50회 천장) | **필요** (유료) |
| 📦 일반 상자 (🪙 5,000) | 일반~희귀 | [Gacha.md](Gacha.md) | 필요 (골드도 유료 재화로 일부 살 수 있으면 대상. 출시 전 확인) |
| 🏁 던전 클리어 | 일반~희귀 1개 | **30% 확률**, 일반 70% / 고급 25% / 희귀 5% | 불필요 (무료 플레이 보상). 그래도 게임 안에 공개 |
| 👹 보스 최초 격파 | 구간 1: 희귀 무기 확정, 구간 3: 희귀 갑옷 확정, 구간 5: **전설 1개 선택** | 확정 | 불필요 |
| 🔩 장비 조각 교환소 | 원하는 희귀 / 전설 | 🔩 60 / 300 | 불필요 (확정) |
| 🔨 합성 | 고급 / 희귀 (선택) | 확정 | 불필요 |

- **무과금 경로:** 5구간 보스 최초 격파로 전설 1개 확정. 나머지 전설은 조각 교환(300) 또는 상자.

## 9. 분해

| 등급 | 🔩 장비 조각 |
|---|---|
| ⚪ 일반 | 1 |
| 🟢 고급 | 3 |
| 🔵 희귀 | 10 |
| 🟡 전설 | 50 |

- 합성이 생기면서 **일반·고급 중복은 분해보다 합성이 이득**이 된다.
- 자동 분해 옵션: **기본값 = 희귀·전설 중복만 자동 분해.** 일반·고급은 합성 재료로 보관 (설정에서 바꿀 수 있음)
- 강화가 슬롯에 붙어 있으므로 분해해도 골드 환급이 필요 없다.

## 10. 영웅별 장착

| 항목 | 규칙 |
|---|---|
| 인벤토리 | 계정 공용 (최대 200칸, 넘으면 새 장비는 우편함 보관) |
| 장착 | **영웅마다 따로** 3칸을 고른다 |
| 같은 장비 동시 장착 | **가능.** 영웅 A와 B가 같은 전설 무기를 동시에 낄 수 있다 (장착 = "참조", 소모되지 않음) |
| 이유 | 영웅을 바꿀 때마다 장비를 옮겨 끼우는 귀찮음 제거. 영웅 수집의 부담을 줄인다 |
| 슬롯 강화 | 계정 공용 (4장 참고) |

## 11. 화면 흐름

```
[영웅 탭] → 영웅 선택
  ├─ 장비 3칸 (등급 색 테두리, 강화 레벨 "Lv 25/30")
  │    └─ 칸 터치 → [장비 목록] (같은 슬롯만, 정렬: 등급↓ 강화 가능↓)
  │          └─ 장비 터치 → [상세] 주 능력치, 부가 능력치, "끼우면: 공격력 +11% → +17.5%" 비교
  │                 [장착] [잠금 🔒]
  ├─ [강화] 버튼 → 슬롯 선택 → "Lv 25 → 26 · 🪙 2,500" [강화] [최대까지(+n)]
  └─ [합성] 버튼 → 슬롯·등급 필터 → 재료 3개 자동 추천 → 결과 장비 선택 → [합성]
```

- 비교 화면은 **최종 능력치 변화**(공격력 1,234 → 1,301)를 숫자로 보여준다.
- "최대까지" 버튼은 가진 골드로 갈 수 있는 레벨까지 한 번에 올린다. 확인 팝업에 총 비용 표시.

## 12. 구현 구조

| 클래스 | 종류 | 역할 |
|---|---|---|
| `EquipmentData` | ScriptableObject (정의) | `id`, `slot`, `rarity`, `mainStatPercent`, `secondaryStat`(종류+값), `iconsByHeroClass[4]`, `projectileVfx`(전설만) |
| `EquipmentTable` | ScriptableObject | 등급별 강화 상한, 강화 Lv당 값, 강화 비용 공식, 합성 비용, 분해 조각 |
| `EquipmentInstance` | 저장 데이터 (상태) | `uid`, `dataId`, `acquiredAt`, `locked` |
| `EquipmentInventory` | 런타임 서비스 | 추가, 분해, 합성, 잠금. 지갑(`CurrencyWallet`)과 함께 저장 |
| `SlotEnhancement` | 저장 데이터 | 슬롯별 강화 레벨 `int[3]` (계정 공용) |
| `HeroLoadout` | 저장 데이터 | 영웅 ID별 `uid[3]` |
| `EquipmentStatProvider` | 런타임 | 장착 장비 + 슬롯 강화 → 스탯 보너스 목록 (출처 = 장비) 을 스탯 계산기에 넘김 |

### 저장 데이터 예시
```json
{
  "equipment": {
    "items": [ { "uid": "e_0001", "dataId": "weapon_general_r", "locked": true } ],
    "slotLevels": [25, 18, 12],
    "loadouts": { "genghis": ["e_0001", "e_0004", "e_0009"] }
  }
}
```

### 처리 순서 (합성)
1. 재료 3개 검사 (같은 슬롯·등급, 잠금 아님, 장착 중 아님) → 2. 골드 차감 → 3. 재료 제거 + 결과 추가를 **한 번에 저장** → 4. 연출
- 중간에 앱이 꺼져도 "재료만 사라짐"이 없어야 한다.

### 직접 짜볼 부분 (연습)
- [ ] `GetMainStatPercent(data, slotLevel)`: 등급 기본값 + `min(slotLevel, 등급 상한) × Lv당 값` (5줄)
- [ ] `CanSynthesize(materials)`: 재료 3개가 합성 조건을 만족하는지 검사 (5~8줄)

## 14. 결정 필요

- [ ] **(a) 최소안 vs (b) 확장안**
  - **추천: (b) 확장안.** 성장 경로가 깊어지고 중복 장비가 쓸모를 가진다. 무작위 옵션·고유 효과는 빼서 위험을 줄인다.
- [ ] **강화를 장비에 붙일까, 슬롯에 붙일까**
  - 장비에 붙이면: 새 장비마다 다시 강화 → 골드 소비가 커지지만 교체가 손해처럼 느껴진다
  - **추천: 슬롯.** 초보자 친화적이고, 교체 고민이 없다.
- [ ] **희귀 → 전설 합성 허용?**
  - 허용하면 상자 전설 2%와 천장의 가치가 무너진다
  - **추천: 허용 안 함.** 전설은 상자·조각 교환·보스 보상으로만.
- [ ] **무기가 기본 공격 모양을 바꿀까?**
  - **추천: 안 바꾼다.** 모양은 영웅이 정하고, 전설 무기는 색·이펙트만 바꾼다.
- [ ] **같은 장비를 여러 영웅이 동시에 장착?**
  - **추천: 허용.** 영웅 교체의 귀찮음을 없앤다. 대신 영웅 레벨·각성이 영웅별 성장을 담당한다.
- [ ] **세트 효과 (같은 테마 3개 → 보너스)?**
  - 넣으면 장비 선택이 정답 하나로 굳기 쉽다
  - **추천: 출시 이후.** [Ideas.md](../Ideas.md)에 보관.
