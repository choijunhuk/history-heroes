# ⚔️ 장비·무기 설계

> 상위 문서: [GameDesign.md](../GameDesign.md) · 관련: [경제](Economy.md#6-장비) · [뽑기](Gacha.md) · [영웅](Heroes.md) · [유물](Relics.md) · [룬](Runes.md) · [펫](Pets.md)
> 작성: 2026-10-25 · 갱신: 2026-10-29 · **6칸 확정** (개발자: "탕탕특공대처럼 ㄱㄱ"). 숫자는 플레이 검증 전 기준값이다.

## 1. 원칙

| 원칙 | 내용 |
|---|---|
| **힘 예산** | 장비 전체(모든 슬롯 + 강화 + 합성)를 끝까지 올려도 **공격력 +25%, 체력 +25%**를 넘지 않는다 |
| **판 안이 먼저** | 장비는 기본 능력치만 올린다. 스킬 확률, 조합, 리롤에는 영향이 없다 |
| **보조 능력치 상한** | 판 밖 모든 출처(장비·수련·유물·펫)를 합친 보조 능력치 상한이 따로 있고, 장비는 그중 **장비 몫**만 쓴다 (3-5장 표). 장비의 어떤 조합·등급·강화로도 장비 몫을 넘지 않는다 |
| **경험치 획득 없음** | 판 밖 출처(장비 포함)는 **경험치 획득 +%를 주지 않는다.** 돈으로 판 안 레벨업 카드를 사는 셈이 되기 때문 |
| **지름길 없음** | 장비·강화·합성·기록을 💎로 바로 사는 길은 없다. 💎은 상자 뽑기에만 쓰이고, 강화와 합성은 골드·재료만 쓴다 |
| **영웅의 정체성은 영웅이 정한다** | 무기는 기본 공격의 **모양을 바꾸지 않는다.** 화살이 총알이 되는 일은 없다 |
| **무과금도 끝까지** | 전설 장비 없이 희귀 장비만으로도 모든 콘텐츠를 깰 수 있다 |
| **기록은 그때 그대로** | 기록에는 만들 당시의 장비(ID + 강화 레벨)를 고정 저장한다 ([GameDesign 7-5](../GameDesign.md#7-5-패치밸런스-변경-정책)) |

## 2. 두 가지 안

| | **(a) 최소안** | **(b) 확장안** ⭐ 추천 |
|---|---|---|
| 슬롯 | 무기 / 목걸이 / 장갑 / 갑옷 / 허리띠 / 신발 | 같음 |
| 등급 | 일반 / 고급 / 희귀 / 전설 | 같음 |
| 수치 | 등급별 고정 (Economy.md 6장 그대로) | 등급별 기본값 + **강화** |
| 강화 | 없음 | **슬롯 강화** (골드) |
| 합성 | 없음 | **같은 슬롯·같은 등급 3개 → 다음 등급** (희귀까지) |
| 부가 능력치 | 없음 | 장비마다 **고정** 부가 능력치 1개 (무작위 아님) |
| 고유 효과 | 없음 | 없음 (출시 이후) |
| 무작위 옵션 | 없음 | 없음 (출시 이후) |
| 장점 | 만들기 쉽고 밸런스가 쉽다 | 성장 경로가 깊어서 오래 할 거리가 생긴다. 중복 장비가 쓸모 있다 |
| 단점 | 장비 하나 맞추면 할 게 없다 (아처 1의 문제) | 작업량이 늘고, 골드 소비처가 커진다 |

**추천: (b) 확장안.** 개발자가 성장 시스템을 풍부하게 원하고, 아처 1이 성장 경로가 얕아서 매출이 빨리 꺾였다는 교훈이 있다. 대신 **무작위 옵션과 고유 효과는 계속 뺀다.** 이 둘이 밸런스를 가장 크게 흔든다.

> 이하 내용은 **(b) 확장안** 기준이다.

## 3. 슬롯과 능력치

### 3-1. 슬롯별 역할 (2026-10-29)

| 화면 | 슬롯 | 주 능력치 | 전체 예산 중 몫 | 전설 Lv40 최대 |
|---|---|---|---|---|
| 왼쪽 위 | 무기 | 공격력 % | 공격력의 60% | +15% |
| 왼쪽 가운데 | 목걸이 | 공격속도 % | 공격속도의 100% | +8% |
| 왼쪽 아래 | 장갑 | 공격력 % | 공격력의 40% | +10% |
| 오른쪽 위 | 갑옷 | 최대체력 % | 체력의 50% | +12.5% |
| 오른쪽 가운데 | 허리띠 | 최대체력 % | 체력의 30% | +7.5% |
| 오른쪽 아래 | 신발 | 최대체력 % | 체력의 20% | +5% |

- 6칸과 강화는 **1구간 보스 최초 격파**에 함께 열린다.
- 목걸이는 왼쪽 공격 계열이며 **옛 장신구의 공격속도 주 능력치를 그대로** 잇는다. 공격력까지 주면 기존 공속을 잃거나 공격력 예산이 늘어나므로 추가하지 않는다.
- 공격력·체력뿐 아니라 부가 능력치도 나눈다. 기존 무기 몫은 무기 60%·장갑 40%, 갑옷 몫은 갑옷 50%·허리띠 30%·신발 20%이다. 목걸이는 기존 몫 그대로다.
- 체력 재생·경험치 획득·고유 효과는 추가하지 않는다.

### 3-2. 등급별 기본값과 강화 상한

| 등급 | 무기 공격력 | 목걸이 공속 | 장갑 공격력 | 갑옷 체력 | 허리띠 체력 | 신발 체력 | 강화 상한 |
|---|---|---|---|---|---|---|---|
| 일반 | +1.8% | +1.5% | +1.2% | +1.5% | +0.9% | +0.6% | Lv10 |
| 고급 | +3.6% | +3% | +2.4% | +3% | +1.8% | +1.2% | Lv20 |
| 희귀 | +6% | +4.5% | +4% | +5% | +3% | +2% | Lv30 |
| 전설 | +9% | +6% | +6% | +7.5% | +4.5% | +3% | Lv40 |

### 3-3. 강화 1레벨당

| 슬롯 | 강화 Lv당 |
|---|---|
| 무기 | 공격력 +0.15% |
| 목걸이 | 공격속도 +0.05% |
| 장갑 | 공격력 +0.1% |
| 갑옷 | 최대체력 +0.125% |
| 허리띠 | 최대체력 +0.075% |
| 신발 | 최대체력 +0.05% |

주 능력치 = 등급 기본값 + `min(슬롯 레벨, 등급 상한) × 레벨당 값`. 새 슬롯은 Lv1부터 시작한다. 옛 저장의 Lv0은 그대로 보관한다.

### 3-4. 최대치 확인 (힘 예산)

| 같은 등급으로 모두 상한 강화 | 공격력 합 (무기+장갑) | 체력 합 (갑옷+허리띠+신발) | 목걸이 공속 |
|---|---|---|---|
| 일반 Lv10 | +5.5% | +5.5% | +2% |
| 고급 Lv20 | +11% | +11% | +4% |
| 희귀 Lv30 | +17.5% | +17.5% | +6% |
| 전설 Lv40 | **+25%** | **+25%** | **+8%** |

3칸 때와 총합이 같다. 기존 장비 하나의 공격력·체력·부가 수치는 나뉘므로 새 칸을 채우기 전에는 낮아진다. 아이템·강화 레벨은 없어지지 않는다. 옛 기록은 ID와 당시 레벨을 보존하며, 기존 패치 정책대로 최신 장비 수치를 적용한다.

### 3-5. 판 밖 보조 능력치 상한 확인

각 칸에서 그 능력치가 가장 큰 장비를 골랐을 때의 합이다. 서로 다른 부가 능력치를 동시에 모두 최대로 낼 수 있다는 뜻은 아니다.

| 능력치 | 전체 상한 | 장비 몫 = 장비 최대 합 | 6칸 검산 (%) |
|---|---|---|---|
| 공격속도 | +12% | +8% | 목걸이 6 + 강화 2 |
| 치명타 확률 | +8% | +5% | 무기 1.8 + 장갑 1.2 + 목걸이 2 |
| 치명타 피해 | +20% | +20% | 무기 12 + 장갑 8 |
| 쿨다운 감소 | +8% | +4% | 무기 1.2 + 장갑 0.8 + 목걸이 2 |
| 이동속도 | +5% | +5% | 갑옷 1 + 허리띠 0.6 + 신발 0.4 + 목걸이 3 |
| 피해 감소 | +10% | +6% | 갑옷 3 + 허리띠 1.8 + 신발 1.2 |
| 경험치 획득 | 0 | 0 | 없음 |

부가 능력치는 강화로 오르지 않는다. 수련·유물·펫 몫은 바꾸지 않는다.

## 4. 강화: 장비가 아니라 "슬롯"에 붙는다

**강화 레벨은 슬롯이 가진다.** 장비를 바꿔 끼워도 강화 레벨은 그대로 남는다.

```
무기 슬롯 강화 Lv 25
 ├─ 희귀 장비를 끼우면 → Lv 25 적용 (상한 30 안이라 그대로)
 └─ 고급 장비를 끼우면 → Lv 20까지만 적용 (등급 상한), 나머지 5는 보관
```

| 항목 | 내용 |
|---|---|
| 왜 슬롯에? | 더 좋은 장비를 얻었을 때 **그동안 쓴 골드가 날아가지 않는다.** 초보자가 "강화했는데 바꾸면 손해"라고 고민할 일이 없다 |
| 적용 범위 | **계정 공용.** 슬롯 강화는 모든 영웅에게 같이 적용된다 (영웅을 바꿔도 다시 강화할 필요 없음) |
| 비용 | Lv n → n+1: 🪙 **50 × n** (Lv1→2: 50, Lv39→40: 1,950) |
| 총 비용 | 슬롯 하나 Lv40까지 🪙 **39,000**, 6슬롯 🪙 **234,000** |
| 실패 | **없다.** 강화는 항상 성공한다 (확률형 강화는 쓰지 않음) |
| 상한 | 끼운 장비 등급의 상한까지만 효과가 있다. 상한 넘는 강화는 막는다 (미리 올려둘 수 없음) |

> ⚠️ 골드 소비처가 커진다. 영웅 레벨(영웅당 🪙 약 87,000)과 합치면 Economy.md의 월 골드 수입(약 180,000)으로 **몇 달짜리** 목표가 된다. 경제 문서와 함께 조정 필요.

## 5. 합성

| 재료 | 결과 | 비용 |
|---|---|---|
| 같은 슬롯 · ⚪ 일반 3개 | 같은 슬롯 🟢 고급 1개 (그 슬롯 고급 장비 중 **선택**) | 🪙 500 |
| 같은 슬롯 · 🟢 고급 3개 | 같은 슬롯 🔵 희귀 1개 (그 슬롯 희귀 장비 중 **선택**) | 🪙 3,000 |
| 🔵 희귀 → 🟡 전설 | **합성 불가** | — |

- 재료는 **같은 슬롯, 같은 등급이면 아무거나** 된다. (같은 이름일 필요 없음)
- 결과는 **무작위가 아니라 플레이어가 고른다.** → 확률형 아이템이 아니다.
- 전설은 합성으로 못 만든다. 전설은 **고급 상자, 장비 조각 교환소, 보스 최초 격파 보상**으로만 얻는다. 희귀 3개로 전설을 만들 수 있으면 상자의 전설 2%가 의미 없어진다.
- 장착 중인 장비, 잠근 장비(🔒)는 재료로 자동 선택되지 않는다.

## 6. 무기: 직업별 모양, 수치는 공용

**무기는 "공용 아이템"이다. 끼운 영웅에 따라 모양만 바뀐다.**

| 영웅 | 같은 "장군의 무기"가 보이는 모양 | 기본 공격 (안 바뀜) |
|---|---|---|
| 🏹 칭기즈 칸 | 장군의 **각궁** | 화살 1발 |
| ⚔️ 관우 | 장군의 **언월도** | 근접 부채꼴 베기 |
| 💥 나폴레옹 | 장군의 **머스킷** | 총알 연사 |
| ⚡ 테슬라 | 장군의 **코일 지팡이** | 전기 구체 + 튕김 |

| 다른 방식 | 왜 안 쓰나 |
|---|---|
| 직업 전용 무기 (활은 궁수만) | 상자에서 내가 안 쓰는 영웅 무기가 나오면 허탈하다. 뽑기 풀이 4배로 쪼개진다 |
| 무기가 공격 모양을 바꿈 (활 → 석궁 연사) | 영웅의 개성이 흐려지고, 밸런스 조합이 영웅 수 × 무기 수로 늘어난다 |

- 전설 무기는 **투사체 색과 이펙트만** 바뀐다. (예: 시간 수호자의 무기 → 화살 끝에 푸른 잔상) 성능 차이 없음.

## 11. 화면 흐름

```
[영웅 탭] → 영웅 선택
  ├─ 장비 6칸 (등급 색 테두리, 강화 레벨 "Lv 25/30")
  │    └─ 칸 터치 → [장비 목록] (같은 슬롯만, 정렬: 등급↓ 강화 가능↓)
  │          └─ 장비 터치 → [상세] 주 능력치, 부가 능력치, "끼우면: 공격력 +6.6% → +10.5%" 비교
  │                 [장착] [잠금 🔒]
  ├─ [강화] 버튼 → 슬롯 선택 → "Lv 25 → 26 · 🪙 1,250" [강화] [최대까지(+n)]
  └─ [합성] 버튼 → 슬롯·등급 필터 → 재료 3개 자동 추천 → 결과 장비 선택 → [합성]
```

- "최대까지" 버튼은 가진 골드로 갈 수 있는 레벨까지 한 번에 올린다. 확인 팝업에 총 비용 표시.

## 12. 구현 구조

| 클래스 | 종류 | 역할 |
|---|---|---|
| `EquipmentData` | ScriptableObject (정의) | `id`, `slot`, `rarity`, `mainStatPercent`, `secondaryStat`(종류+값), `iconsByHeroClass[4]`, `projectileVfx`(전설만) |
| `EquipmentTable` | ScriptableObject | 등급별 강화 상한, 강화 Lv당 값, 강화 비용 공식, 합성 비용, 분해 조각 |
| `EquipmentInstance` | 저장 데이터 (상태) | `uid`, `dataId`, `acquiredAt`, `locked` |
| `EquipmentInventory` | 런타임 서비스 | 추가, 분해, 합성, 잠금. 지갑(`CurrencyWallet`)과 함께 저장 |
| `SlotEnhancement` | 저장 데이터 | 슬롯별 강화 레벨 `int[6]` (계정 공용) |
| `HeroLoadout` | 저장 데이터 | 영웅 ID별 `uid[6]` |
| `EquipmentStatProvider` | 런타임 | 장착 장비 + 슬롯 강화 → 스탯 보너스 목록 (출처 = 장비) 을 스탯 계산기에 넘김 |

### 저장 데이터 예시
```json
{
  "equipment": {
    "items": [ { "uid": "e_0001", "dataId": "weapon_general_r", "locked": true } ],
    "slotLevels": [25, 18, 12, 1, 1, 1],
    "loadouts": { "khan": ["e_0001", "e_0004", "e_0009", "", "", ""] }
  }
}
```

### 처리 순서 (합성)
1. 재료 3개 검사 (같은 슬롯·등급, 잠금 아님, 장착 중 아님) → 2. 골드 차감 → 3. 재료 제거 + 결과 추가를 **한 번에 저장** → 4. 연출
- 중간에 앱이 꺼져도 "재료만 사라짐"이 없어야 한다.

### 저장 이전 (schema 7 → 8)

- 저장 번호는 **무기 0 / 갑옷 1 / 목걸이 2 / 장갑 3 / 허리띠 4 / 신발 5**. 화면 순서와 분리해 기존 에셋·기록의 번호를 보존한다.
- `HeroLoadout.uids`·`equipment.slotLevels`는 항상 6개로 복구한다. 옛 0~2칸 UID·레벨(0 포함)은 그대로, 새 3~5칸은 빈 UID·Lv1이다. 아이템 목록·ID·잠금·다른 영웅의 장착도 그대로 둔다.
- 빠진 칸은 빈 UID·Lv1로, null UID는 빈 문자열로 채운다. 넘친 장착 참조만 자르고 가방 아이템은 버리지 않는다. 레벨은 0~40 안으로 복구한다.
- 새 계정은 6칸 모두 Lv1이다. 옛 Lv0→1은 50골드이며, 그 이후는 같은 공식이다. 이미 쓴 강화 골드는 되돌리지 않는다.
- 영웅 화면 왼쪽 무기·목걸이·장갑, 오른쪽 갑옷·허리띠·신발. 칸을 누르면 그 슬롯 탭으로 열린다. 공격력·체력 아래에 펫·룬·유물 단추를 한 줄로 둔다.

## 14. 결정 필요

- [x] **(a) 최소안 vs (b) 확장안** → ✅ **개발자 결정 (2026-10-25): (b) 확장안.** 성장 경로가 깊어지고 중복 장비가 쓸모를 가진다. 무작위 옵션·고유 효과는 빼서 위험을 줄인다.
- [ ] **강화를 장비에 붙일까, 슬롯에 붙일까**
  - 장비에 붙이면: 새 장비마다 다시 강화 → 골드 소비가 커지지만 교체가 손해처럼 느껴진다
  - **추천: 슬롯.** 초보자 친화적이고, 교체 고민이 없다.
- [ ] **희귀 → 전설 합성 허용?**
  - 허용하면 상자 전설 2%와 천장의 가치가 무너진다
  - **추천: 허용 안 함.** 전설은 상자·조각 교환·보스 보상으로만.
- [ ] **무기가 기본 공격 모양을 바꿀까?**
  - **추천: 안 바꾼다.** 모양은 영웅이 정하고, 전설 무기는 색·이펙트만 바꾼다.
- [ ] **같은 장비를 여러 영웅이 동시에 장착?**
  - **추천: 허용.** 영웅 교체의 귀찮음을 없앤다. 대신 영웅 레벨·각성이 영웅별 성장을 담당한다.
- [ ] **세트 효과 (같은 테마 3개 → 보너스)?**
  - 넣으면 장비 선택이 정답 하나로 굳기 쉽다
  - **추천: 출시 이후.** [Ideas.md](../Ideas.md)에 보관.
