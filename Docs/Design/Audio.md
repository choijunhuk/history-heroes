## 1. 원칙
- **소리로 위험을 알린다.** 적 공격 예고에는 짧고 분명한 소리. 화면을 안 봐도 "곧 공격이 온다"를 알 수 있게.
- **많은 적 = 많은 소리**가 되지 않게. 같은 소리는 동시에 최대 4개까지만 재생. (서바이벌 대비)
- 모바일은 **소리를 끄고 하는 사람이 많다.** 소리 없이도 모든 정보가 화면에 보여야 한다.

## 2. 음악 (출시 때 7곡)

| 곡 | 장면 | 분위기 | 길이 |
|---|---|---|---|
| 로비 | 메인 화면 | 밝음, 모험 | 1~2분 반복 |
| 구간 1 | 균열의 초원 | 경쾌, 초원 | 2분 반복 |
| 구간 2 | 잊힌 성채 | 웅장, 북소리 | 2분 반복 |
| 구간 3~4 | 녹슨 공방, 그림자 협곡 | 기계음 / 어두움 (같은 곡 변주 가능) | 2분 반복 |
| 구간 5 | 망각의 왕좌 | 비장함 | 2분 반복 |
| 보스전 | 모든 보스 | 긴박함 | 1분 반복 |
| 서바이벌 | 서바이벌 모드 | 점점 빨라짐 (시간에 따라 층 추가) | 3분 반복 |

## 3. 효과음 (우선순위)

| 우선순위 | 소리 | 이유 |
|---|---|---|
| **필수** | 기본 공격 발사·명중 (영웅별) | 멈춰서 쏘는 손맛 |
| **필수** | 적 공격 예고 (돌진·조준·폭탄 낙하) | 피하기 신호 |
| **필수** | 피격, 사망 | |
| **필수** | 레벨업, 카드 선택, **조합 완성** (특별한 소리) | 보상감 |
| **필수** | 전설 카드 등장 (금빛 소리) | 짜릿함 |
| 중요 | 액티브 14종 발동 | 너무 시끄럽지 않게 작은 소리 |
| 중요 | 상자 열기 (등급별 다른 소리) | |
| 중요 | UI 버튼, 재화 획득 | |
| 있으면 좋음 | 영웅 감탄사 | 출시 이후 |

## 4. 진동 (햅틱)
| 순간 | 진동 |
|---|---|
| 피격 | 짧게 약하게 |
| 전설 카드 등장, 조합 완성 | 짧게 두 번 |
| 보스 격파 | 길게 |
- 설정에서 끌 수 있다. 기본값 켜짐.

## 6. 기술 메모
- Unity **Audio Mixer** 그룹: 음악 / 효과음 / UI / 음성 → 설정의 볼륨 슬라이더와 연결 (Unity 공식 `audio-setup-mixers` 스킬)
- 짧은 효과음은 메모리에 미리 올리고, 음악은 스트리밍 (Unity 공식 `optimize-audio` 스킬)
- 같은 소리 동시 재생 제한, 소리도 오브젝트 풀링
