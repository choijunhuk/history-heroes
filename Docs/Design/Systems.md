## 3. 해금 순서

**이 표가 기준이다.** (Modes·Missions·Runes·Pets 등 다른 문서와 다르면 이 표를 따른다)

| 시점 | 열리는 것 |
|---|---|
| 처음 (튜토리얼) | 던전 1구간, 칭기즈 칸, 레벨업 카드, 조합, 조합 도감 |
| 튜토리얼 보스 격파 | 기록 보관함(3칸), 펫 칸 + 사냥매, 일일 미션, 출석부, 신규 7일 미션 |
| **1구간 보스 격파** | 장비 3칸 + 강화, **관우**, 주간 미션, 2구간 |
| **2구간 보스 격파** | **나폴레옹**, 수련, 유물, 룬 1칸, **서바이벌**, 시즌 패스, 3구간 |
| **3구간 보스 격파** | **테슬라**, **무한의 균열**, **일일 도전**, 이벤트 던전, 4구간 |
| **4구간 보스 격파** | 룬 2칸, 5구간 |
| **5구간 보스 격파** | 칭호, (v1.1) 보스 러시 |
| 계정 Lv 5 + 계정 연동 | 친구, 랭킹 |
| 출시 이후 | 길드 (DAU 1,000 이상이 4주 유지되면) |

- 첫날(1구간 보스까지)엔 **새 시스템을 적게** 연다. 조작과 빌드에 먼저 익숙해지게.
- 한 번에 많이 열리는 2구간 보스는 로비 알림을 **하나씩 순서대로** 보여준다.
