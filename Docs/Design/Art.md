## 1. 결론부터

| 단계 | 그림을 어디서 | 이유 |
|---|---|---|
| **v0.1~v0.3** (재미 검증) | **무료 에셋 + AI가 코드로 만든 단순 도형** | 그림이 재미를 가리면 안 된다. 빨리, 싸게 |
| **v0.4~v1.0** (출시 준비) | **비교 실험 결과로 결정** (아래 3장) | 품질과 통일감이 중요해짐 |
| 출시 이후 (스킨) | 유료 에셋, AI 생성 도구, 외주 중 선택 | 스킨이 매출원이 되면 투자 |

**솔직한 평가:** Claude와 Codex는 **코드로 그리는 그림**(SVG 벡터, 셰이더, 파티클 이펙트, 단순한 픽셀 아트)은 꽤 잘 만든다. 하지만 **SD 캐릭터의 귀여운 얼굴, 자연스러운 걷기·공격 애니메이션**은 사람이 그린 에셋이나 이미지 생성 전용 AI보다 떨어진다. 그래서 둘을 직접 비교해보고 정한다.

## 2. 무료 에셋 후보

| 출처 | 라이선스 | 쓸 만한 것 |
|---|---|---|
| **Kenney** (kenney.nl) | **CC0** (출처 표시도 필요 없음, 상업 가능) | UI 버튼·아이콘, 2D 캐릭터, 파티클, 효과음 |
| **itch.io** (무료 에셋, CC0 필터) | 에셋마다 다름 | 픽셀 캐릭터, 몬스터, 타일셋 |
| **OpenGameArt** | 에셋마다 다름 (CC0, CC-BY 등) | 효과음, 음악 |
| **Unity Asset Store 무료** | Unity 표준 라이선스 (Unity 프로젝트 안에서 상업 가능, 원본 재배포 금지) | 2D 캐릭터 팩, UI 팩, 이펙트 |

### ⚠️ 라이선스 규칙
- 에셋을 넣을 때마다 **`Docs/Credits.md`에 출처·라이선스·URL을 기록**한다.
- **CC0 우선**, CC-BY는 크레딧 화면에 표시, **CC-BY-NC(비상업)는 절대 쓰지 않는다** (출시하면 상업이다)
- **공개 저장소 주의:** Asset Store 에셋은 원본 파일을 공개 저장소에 올리면 재배포가 될 수 있다. → Asset Store 에셋은 `Game/Assets/ThirdParty/AssetStore/`에 두고 **`.gitignore`로 제외**, 대신 목록만 기록한다.

## 3. 비교 실험: 무료 에셋 vs AI 직접 제작

**v0.3이 끝날 때** 같은 세트를 두 가지 방식으로 만들어서 비교한다.

### 비교할 세트 (한 화면 분량)
1. 칭기즈 칸 (대기, 이동, 공격 애니메이션)
2. 적 2종 (돌진병, 궁병)
3. 화살, 회전 칼날, 낙뢰 이펙트
4. 레벨업 카드 UI 1장
5. 바닥 타일 1종

### 방식
| | A. 무료 에셋 | B. AI 직접 제작 (Claude·Codex) |
|---|---|---|
| 방법 | Kenney·itch.io에서 고르고 색만 맞춤 | SVG/픽셀을 코드로 생성, 이펙트는 파티클·셰이더 |
| 장점 | 바로 쓸 수 있는 품질 | 게임에 딱 맞춤, 통일감, 라이선스 걱정 없음 |
| 단점 | 다른 게임과 비슷해 보임, 세트마다 그림체가 다름 | 캐릭터 품질이 낮을 수 있음 |

### 평가 기준 (각 1~5점)
| 기준 | 설명 |
|---|---|
| 첫인상 | 스크린샷 한 장만 봤을 때 받고 싶은가 |
| 통일감 | 캐릭터·적·UI가 한 게임처럼 보이는가 |
| 가독성 | 휴대폰 화면에서 적·투사체가 잘 구분되는가 |
| 확장성 | 영웅 4명, 적 6종, 스킬 수십 개로 늘릴 수 있는가 |
| 비용·시간 | 만드는 데 드는 시간 |

- 결과는 `Docs/Reviews/`에 스크린샷과 함께 남긴다.
- **섞는 것도 답이 될 수 있다.** 예: 캐릭터는 에셋, 이펙트와 UI는 AI 제작

## 4. 이미지 생성 도구 (필요하면 v1.0)

| 도구 | 하는 일 | 비용 |
|---|---|---|
| Gamelabs MCP | 투명 배경 스프라이트 + 애니메이션 시트 | 유료 (API 키) |
| Ludo AI MCP | 스프라이트, 애니메이션, 효과음, 음악 | 유료 |
| fal.ai (설치된 스킬 있음) | 이미지 생성 | 유료 (API 키) |

- 생성 이미지도 **상업 이용 조건을 확인**하고 Credits에 기록한다.
- 실존 인물은 **역사 기록 속 이미지를 바탕으로 한 SD 캐리커처**로 그린다. 실존 사진을 그대로 쓰지 않는다.

## 5. 그림체 가이드 (초안)
- **SD 2등신**, 굵은 외곽선, 밝은 채도
- 화면 높이 기준 캐릭터 크기 약 8%. 적과 투사체는 **실루엣만으로 구분**되게
- 아군 투사체는 따뜻한 색(노랑·주황), **적 투사체는 빨강·보라**로 고정 → 피해야 할 것이 바로 보이게
- 등급 색: 일반 회색 / 고급 초록 / 희귀 파랑 / 전설 금색 / 조합 무지개
- 스킬 종류 색 (레벨업 카드 맨 위 띠): 액티브 주황 / 패시브 초록 / 조합 보라. 등급 색은 카드 바탕, 종류 색은 띠에만 써서 섞이지 않게
