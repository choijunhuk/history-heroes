## 1. 한 줄 요약

**유물 = 역사 속 진짜 물건을 모으는 수집 도감.** 모을수록 계정 전체가 조금씩 강해지고, 유물마다 짧은 역사 이야기가 열린다.

| 원칙 | 내용 |
|---|---|
| **힘 예산** | 유물 20개를 전부 ★3으로 모아도 **공격력 +10%, 체력 +10%**. 그 밖에는 세트 효과로 **피해 감소 +4%** 하나만 (다른 보조 능력치는 없음) |
| **경험치 없음** | 유물은 경험치 획득 +%를 주지 않는다. 판 밖 출처가 판 안 레벨업 카드를 사는 길이 되면 안 된다 |
| **장착 없음** | 유물은 끼우는 아이템이 아니라 **모으면 바로 적용되는 컬렉션**이다. 판 안 규칙에 끼어들지 않는다 |
| **뽑기 없음** | 유물은 플레이로만 얻는다. 확정 보상 + 고대 파편 교환 |
| **팔지 않음** | 유물과 고대 파편은 상점에서 팔지 않는다 (시즌 패스 무료 트랙 보상은 OK) |
| **역사 존중** | 종교 성물, 무덤 부장품, 특정 국가끼리의 전쟁 전리품은 넣지 않는다 |

### 왜 넣나
- 이 게임의 테마("역사 영웅")를 **전투 밖에서도 느끼게** 한다. 유물 이야기 카드가 도감 탭의 볼거리가 된다.
- 장비·영웅 레벨과 다른 **"모으는" 성장 경로**를 하나 더 만든다. (Economy.md 원칙 3: 성장 경로는 여러 개)
- 무과금 유저가 꾸준히 하면 확실히 채울 수 있는 **안심되는 성장**이다.

## 2. 구조

```
유물 20개 = 테마 세트 5개 × 유물 4개
 ├─ 유물마다 ★1 ~ ★3
 │    └─ ★ 하나당: 공격력 +0.1%, 체력 +0.1%
 └─ 세트 4개를 모두 ★1 이상 → 세트 완성 보너스
```

### 힘 예산 계산

| 항목 | 개수 | 하나당 | 합계 |
|---|---|---|---|
| 별(★) | 20개 × ★3 = 60개 | 공격력·체력 +0.1% | **+6%** |
| 세트 완성 | 5세트 | 공격력·체력 +0.8% | **+4%** |
| **합계** | | | **+10% / +10%** ✅ |

- 세트 완성 보너스에는 공격력·체력 외에 **피해 감소 +0.8%**가 붙는다. 5세트 전부 완성하면 **피해 감소 +4%** (유물 몫 상한과 같음).

### 판 밖 보조 능력치 확인
| 능력치 | 전체 상한 | 유물 몫 | 유물 최대 합 | 확인 |
|---|---|---|---|---|
| 피해 감소 | +10% | +4% (세트 효과로만) | 0.8 × 5 = **+4%** | ✅ |
| 공격속도·치명타 확률·치명타 피해·쿨다운 감소·이동속도 | — | 0 | **0** | ✅ |
| 경험치 획득·골드 획득 | 0 | 0 | **0** | ✅ |

## 4. 획득처 (★1 = 첫 획득)

**유물 20개는 각각 획득처가 딱 하나다.** (한 유물이 두 곳에서 나오지 않는다)

| 획득처 | 개수 | 유물 | 메모 |
|---|---|---|---|
| 🦸 영웅으로 던전 **첫 클리어** | 4 | 칭기즈 칸의 파이자, 청룡언월도 조각, 나폴레옹의 이각모, 테슬라의 연구 노트 | 그 영웅으로 처음 던전을 깬 판의 결과 화면에서 지급. 칭기즈 칸은 처음부터 쓰니 첫날 유물 1개 |
| 👹 보스 최초 격파 (구간 1~5) | 5 | 구간 1: 측우기, 2: 로제타석 조각, 3: 안티키테라 기계, 4: 바이킹의 태양석, 5: 카이사르의 월계관 | 확정 |
| ⭐ 구간 별(★) 보상 | 4 | **N구간 던전 별 15개 중 10개를 모으면** 지급 (구간 1: 거북선 설계도, 2: 정화 함대의 나침반, 3: 마젤란의 항해 일지, 4: 혼천의) | 별 시스템은 채택됨 ([Systems.md](Systems.md)). 조건은 구간마다 위 한 줄 그대로 |
| 🧟 서바이벌 마일스톤 | 3 | 생존 5분: 앙부일구 / 10분 클리어: 아스트롤라베 / 영웅 2명으로 클리어: 갈릴레이의 망원경 | |
| 🏆 업적 | 4 | 조합 5종 발견: 다빈치의 비행기계 스케치 / 조합 10종 발견: 훈민정음 해례본 / 기록 10개 저장: 구텐베르크의 활자 / 영웅 4명 해금: 마그나 카르타 사본 | |
| **합계** | **20** | | 4 + 5 + 4 + 3 + 4 = 20 |

- 🏺 고대 파편 교환소(🏺 120)는 **획득처가 아니라 늦게 시작한 유저용 보험**이다. 위 방법으로 아직 못 얻은 유물을 대신 얻을 뿐, 유물 목록에 항목을 더하지 않는다.
  - **중복 방지:** 교환으로 유물을 얻은 뒤 나중에 그 유물의 원래 획득처에서 같은 유물을 얻게 되면, 유물은 중복으로 주지 않고 **🏺 120을 돌려받는다.**
- 유물 탭은 2구간 보스 격파 후 열린다 ([Systems.md](Systems.md) 3장). 그전(튜토리얼~1구간)에 얻은 유물은 보관되어 있다가 탭이 열릴 때 적용된다.
- 출시 콘텐츠만으로 20개 ★1을 **전부 무료로** 얻을 수 있다.

## 5. 별 올리기 (★2, ★3)

**새 재료: 🏺 고대 파편** (유물 전용, 다른 곳에 안 씀)

| 단계 | 비용 |
|---|---|
| ★1 → ★2 | 🏺 30 |
| ★2 → ★3 | 🏺 80 |
| 유물 하나 ★3까지 | 🏺 110 |
| 전체 20개 ★3 | 🏺 2,200 |

### 고대 파편 획득처
| 획득처 | 🏺 | 한도 |
|---|---|---|
| 일일 활동 상자 (100포인트) | 5 | 하루 1회 |
| 주간 상자 (120포인트) | 20 | 주 1회 |
| 보스 반복 격파 | 5 | 하루 3회 (Economy.md와 같은 한도) → 하루 최대 15 |
| 서바이벌 | 생존 2분당 1 | 판당 최대 5 |
| 시즌 패스 무료 트랙 | 60 | 시즌(28일)당 |
| 무한의 균열 | 20층 10 + 40층 10 | 주간 (매주 초기화) |
| 업적 | 10~50 | 1회성 (평균 계산에서 뺀다) |

### 하루 평균 (무과금, 매일 접속 가정)
| 항목 | 계산 | 하루 평균 🏺 |
|---|---|---|
| 일일 활동 상자 | 5 | 5.0 |
| 보스 반복 격파 | 5 × 3회 | 15.0 |
| 서바이벌 | 하루 1판, 평균 6분 생존 = 3 (판당 최대 5) | 3.0 |
| 주간 상자 | 20 ÷ 7 | 2.9 |
| 무한의 균열 | (10 + 10) ÷ 7 | 2.9 |
| 시즌 패스 무료 트랙 | 60 ÷ 28 | 2.1 |
| **합계** | | **약 30.9 → 약 31** |

| 목표 | 필요 🏺 | 걸리는 날 | 달 수 |
|---|---|---|---|
| 전체 20개 ★3 (교환 없음) | 2,200 | 2,200 ÷ 31 ≈ **약 71일** | 약 2.4개월 |
| 같은 목표 + 교환소 1회 | 2,200 + 120 = 2,320 | 2,320 ÷ 31 ≈ **약 75일** | 약 2.5개월 |
| **기록 용량 업그레이드 포함** (★3 전부 + 기록 용량) | 2,200 + 300 = **2,500** | 2,500 ÷ 31 ≈ **약 81일** | 약 2.7개월 |
| 위 + 교환소 1회 | 2,500 + 120 = 2,620 | 2,620 ÷ 31 ≈ **약 85일** | 약 2.8개월 |

- ⚠️ **🏺는 기록 용량 업그레이드에도 쓰인다** (80% → 85%: 100, 85% → 90%: 200 = **300**, [Economy 5장](Economy.md#5-사용처-sink--핵심-표)). 그래서 전체 🏺 수요는 ★3 전부 2,200 + 기록 용량 300 = **2,500**이고, 보험 교환을 쓰면 교환 1회당 120이 더 든다.

- 한 달(30일) 약 **930**. 업적 보상(10~50)은 계산에 안 넣었으니 실제로는 조금 더 빠르다.
- 보스 반복 격파 15를 매일 다 채운다는 가정이다. 보스 도전 횟수는 하트를 쓰므로 빠듯하면 실제는 더 느릴 수 있다. (Economy.md와 함께 확인)
- 고대 파편은 **유료로 팔지 않는다.**

## 6. 화면 흐름

```
[도감 탭] → [유물] 탭 (조합 도감 옆)
  ├─ 세트 5개 가로 줄, 유물 카드 4장씩 (없는 건 실루엣 + 얻는 방법)
  │    └─ 카드 터치 → [유물 상세]
  │          그림, ★, "📜 사실" / "🎮 이야기", 현재 보너스
  │          [★ 올리기 🏺 30]
  ├─ 위쪽: 유물 총 보너스 "공격력 +4.2% · 체력 +4.2%"
  └─ 세트 완성 시: 금빛 연출 + 세트 보너스 표시
```

- 새 유물을 얻으면 도감 탭에 빨간 점. 처음 얻을 때 짧은 "유물 발견!" 카드 연출 (건너뛰기 가능).

## 8. 구현 구조

| 클래스 | 종류 | 역할 |
|---|---|---|
| `RelicData` | ScriptableObject | `id`, `setId`, 그림, 사실/이야기 텍스트 (로컬라이징 키), 획득처 설명 |
| `RelicSetData` | ScriptableObject | `setId`, 유물 4개, 세트 보너스 (공격력·체력 % + 피해 감소 %) |

## 9. 결정 필요

- [ ] **유물을 장착형(칸에 끼우기)으로 할까, 컬렉션형으로 할까**
  - 장착형: 유물마다 특수 효과(예: "판 시작 시 회전 칼날 Lv1")를 줄 수 있어서 재밌지만, 판 안 빌드와 기록 비용을 흔든다
  - **추천: 컬렉션형.** 판 안 규칙을 건드리지 않고 밸런스가 쉽다. 특수 효과는 출시 이후 아이디어로.
- [ ] **보스맵에서 유물·수련 같은 계정 보너스를 기록 당시 값으로 쓸까, 현재 값으로 쓸까**
  - 현재 값: 유물을 모을수록 옛 기록도 강해져서 새 기록을 만들 이유가 약해진다
  - 기록 당시 값: 장비 규칙(만들 당시 고정)과 같아서 일관된다
  - **추천: 기록 당시 값.** 기록에 "계정 보너스 스냅샷"(공격력 %, 체력 %, 보조 능력치)을 함께 저장. ([GameDesign 7-1](../GameDesign.md#7-1-기록에-저장되는-것)에 추가 필요)
- [ ] **새 재료 🏺 고대 파편을 만들까, 장비 조각을 같이 쓸까**
  - 장비 조각과 섞으면 "장비 교환 vs 유물 별" 경쟁이 생겨 초보자가 헷갈린다
  - **추천: 고대 파편을 따로 만든다.** 대신 유물 화면에서만 보이게 해서 재화가 많아 보이지 않게.
- [ ] **유물을 팔까?**
  - **추천: 팔지 않는다.** 역사 수집의 성취감이 핵심이고, 무과금 신뢰를 지킨다.
