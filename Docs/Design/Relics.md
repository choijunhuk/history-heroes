> 상위 문서: [GameDesign.md](../GameDesign.md) · 관련: [경제](Economy.md) · [장비](Equipment.md) · [룬](Runes.md) · [펫](Pets.md) · [콘텐츠](Content.md)

## 1. 한 줄 요약

**유물 = 역사 속 진짜 물건을 모으는 수집 도감.** 모을수록 계정 전체가 조금씩 강해지고, 유물마다 짧은 역사 이야기가 열린다.

| 원칙 | 내용 |
|---|---|
| **힘 예산** | 유물 20개를 전부 ★3으로 모아도 **공격력 +10%, 체력 +10%** |
| **장착 없음** | 유물은 끼우는 아이템이 아니라 **모으면 바로 적용되는 컬렉션**이다. 판 안 규칙에 끼어들지 않는다 |
| **뽑기 없음** | 유물은 플레이로만 얻는다. 확정 보상 + 고대 파편 교환 |
| **팔지 않음** | 유물과 고대 파편은 상점에서 팔지 않는다 (시즌 패스 무료 트랙 보상은 OK) |
| **역사 존중** | 종교 성물, 무덤 부장품, 특정 국가끼리의 전쟁 전리품은 넣지 않는다 |

### 왜 넣나
- 이 게임의 테마("역사 영웅")를 **전투 밖에서도 느끼게** 한다. 유물 이야기 카드가 도감 탭의 볼거리가 된다.
- 장비·영웅 레벨과 다른 **"모으는" 성장 경로**를 하나 더 만든다. (Economy.md 원칙 3: 성장 경로는 여러 개)
- 무과금 유저가 꾸준히 하면 확실히 채울 수 있는 **안심되는 성장**이다.

## 2. 구조

```
유물 20개 = 테마 세트 5개 × 유물 4개
 ├─ 유물마다 ★1 ~ ★3
 │    └─ ★ 하나당: 공격력 +0.1%, 체력 +0.1%
 └─ 세트 4개를 모두 ★1 이상 → 세트 완성 보너스
```

### 힘 예산 계산

| 항목 | 개수 | 하나당 | 합계 |
|---|---|---|---|
| 별(★) | 20개 × ★3 = 60개 | 공격력·체력 +0.1% | **+6%** |
| 세트 완성 | 5세트 | 공격력·체력 +0.8% | **+4%** |
| **합계** | | | **+10% / +10%** ✅ |

- 세트 완성 보너스에는 공격력·체력 외에 **작은 부가 능력치**가 하나씩 붙는다. (3장)

## 3. 유물 목록 (출시 20개)

> 각 유물 카드: 그림 + "📜 사실" 2~3줄 + "🎮 게임 속 이야기" 1줄. ([Heroes.md](Heroes.md)의 사실/전승/각색 표시 규칙과 같다)

### 세트 1. 🔬 발명의 시대
| 유물 | 📜 사실 (요약) |
|---|---|
| 테슬라의 연구 노트 | 테슬라는 교류 전기와 무선 송전을 연구했다 |
| 다빈치의 비행기계 스케치 | 레오나르도 다빈치는 새의 날개를 본뜬 비행 장치를 스케치로 남겼다 |
| 갈릴레이의 망원경 | 갈릴레이는 망원경으로 목성의 위성을 관찰했다 |
| 안티키테라 기계 | 고대 그리스의 천체 계산 장치. 톱니바퀴로 이루어졌다 |
| **세트 보너스** | 공격력·체력 +0.8%, **쿨다운 감소 +2%** |

### 세트 2. ✍️ 기록과 문자
| 유물 | 📜 사실 (요약) |
|---|---|
| 로제타석 조각 | 같은 내용이 세 가지 문자로 새겨져 이집트 문자 해독의 열쇠가 되었다 |
| 훈민정음 해례본 | 한글을 만든 원리와 쓰임을 설명한 책 |
| 구텐베르크의 활자 | 유럽 활판 인쇄술을 퍼뜨린 금속 활자 |
| 마그나 카르타 사본 | 왕의 권력을 법으로 제한한 영국의 문서 |
| **세트 보너스** | 공격력·체력 +0.8%, **경험치 획득 +5%** |

### 세트 3. ⛵ 바다와 항해
| 유물 | 📜 사실 (요약) |
|---|---|
| 거북선 설계도 | 조선 수군의 철갑 지붕을 얹은 전선 (설계도는 게임 각색) |
| 정화 함대의 나침반 | 명나라 정화의 대규모 원정 항해 |
| 바이킹의 태양석 | 흐린 날 해의 위치를 찾았다고 전해지는 광물 (전승) |
| 마젤란의 항해 일지 | 세계 일주 항해의 기록 |
| **세트 보너스** | 공격력·체력 +0.8%, **이동속도 +3%** |

### 세트 4. ⚔️ 장수의 유품
| 유물 | 📜 사실 (요약) |
|---|---|
| 청룡언월도 조각 | 『삼국지연의』 속 관우의 무기 (전승) |
| 나폴레옹의 이각모 | 나폴레옹의 상징이 된 모자 |
| 칭기즈 칸의 파이자 | 몽골 제국의 통행·권한 증표 |
| 카이사르의 월계관 | 로마에서 승리와 영예를 상징한 관 |
| **세트 보너스** | 공격력·체력 +0.8%, **치명타 확률 +2%** |

### 세트 5. 🌌 하늘과 시간
| 유물 | 📜 사실 (요약) |
|---|---|
| 측우기 | 조선 시대에 비의 양을 재던 기구 |
| 혼천의 | 하늘의 움직임을 나타낸 천문 기구 |
| 앙부일구 | 그림자로 시각을 알려준 조선의 해시계 |
| 아스트롤라베 | 별의 높이를 재던 천문·항해 도구 |
| **세트 보너스** | 공격력·체력 +0.8%, **골드 획득 +5%** |

- 부가 능력치 확인: 쿨다운 감소 +2% (상한 40%), 치명타 확률 +2% (상한 60%) → 판 안 스킬이 채울 여지가 충분하다.
- 영웅 4명과 연결된 유물(테슬라, 청룡언월도, 이각모, 파이자)은 **그 영웅 해금 시 ★1로 함께 지급**한다. → 영웅을 얻는 기쁨이 하나 더.

## 4. 획득처 (★1 = 첫 획득)

| 획득처 | 유물 | 메모 |
|---|---|---|
| 영웅 해금 | 테슬라의 연구 노트, 청룡언월도 조각, 나폴레옹의 이각모, 칭기즈 칸의 파이자 | 칭기즈 칸은 처음부터 → 첫날 유물 1개 |
| 👹 보스 최초 격파 (구간 1~5) | 구간마다 1개 (구간 1: 측우기, 2: 로제타석 조각, 3: 안티키테라 기계, 4: 바이킹의 태양석, 5: 카이사르의 월계관) | 확정 |
| ⭐ 구간 별(★) 보상 | 구간마다 별 일정 개수 달성 시 1개 | 별 시스템을 채택하면 ([Systems.md](Systems.md)). 채택 안 하면 업적으로 대체 |
| 🧟 서바이벌 마일스톤 | 생존 5분 / 10분 클리어 / 영웅 2명으로 클리어 | 3개 |
| 🏆 업적 | 조합 5종 발견, 조합 10종 발견, 기록 10개 저장, 영웅 4명 해금 | 4개 |
| 🏺 고대 파편 교환소 | 아직 못 얻은 유물 아무거나 | 🏺 120 (늦게 시작한 유저용 보험) |

- 출시 콘텐츠만으로 20개 ★1을 **전부 무료로** 얻을 수 있다.

## 5. 별 올리기 (★2, ★3)

**새 재료: 🏺 고대 파편** (유물 전용, 다른 곳에 안 씀)

| 단계 | 비용 |
|---|---|
| ★1 → ★2 | 🏺 30 |
| ★2 → ★3 | 🏺 80 |
| 유물 하나 ★3까지 | 🏺 110 |
| 전체 20개 ★3 | 🏺 2,200 |

### 고대 파편 획득처
| 획득처 | 🏺 | 한도 |
|---|---|---|
| 주간 미션 완료 보상 | 40 | 주 1회 |
| 보스 반복 격파 | 5 | 하루 3회 (Economy.md와 같은 한도) |
| 서바이벌 | 생존 2분당 1 | 판당 5 |
| 일일 미션 전부 완료 | 5 | 하루 1회 |
| 시즌 패스 무료 트랙 | 시즌당 60 | |
| 업적 | 10~50 | |

- 무과금 하루 약 **25** (보스 15 + 일일 5 + 서바이벌 일부) + 주간 40 → **한 달 약 900** → 전체 ★3까지 **약 2~3개월**
- 고대 파편은 **유료로 팔지 않는다.**

## 6. 화면 흐름

```
[도감 탭] → [유물] 탭 (조합 도감 옆)
  ├─ 세트 5개 가로 줄, 유물 카드 4장씩 (없는 건 실루엣 + 얻는 방법)
  │    └─ 카드 터치 → [유물 상세]
  │          그림, ★, "📜 사실" / "🎮 이야기", 현재 보너스
  │          [★ 올리기 🏺 30]
  ├─ 위쪽: 유물 총 보너스 "공격력 +4.2% · 체력 +4.2%"
  └─ 세트 완성 시: 금빛 연출 + 세트 보너스 표시
```

- 새 유물을 얻으면 도감 탭에 빨간 점. 처음 얻을 때 짧은 "유물 발견!" 카드 연출 (건너뛰기 가능).

## 8. 구현 구조

| 클래스 | 종류 | 역할 |
|---|---|---|
| `RelicData` | ScriptableObject | `id`, `setId`, 그림, 사실/이야기 텍스트 (로컬라이징 키), 획득처 설명 |
| `RelicSetData` | ScriptableObject | `setId`, 유물 4개, 세트 보너스 (공격력·체력 % + 부가 능력치) |
| `RelicTable` | ScriptableObject | ★당 보너스, ★ 비용, 교환소 가격 |
| `RelicCollection` | 저장 데이터 | 유물 ID별 ★ (0 = 없음) |
| `RelicStatProvider` | 런타임 | ★ 합 + 완성 세트 → 스탯 보너스 목록 (출처 = 유물) |

### 저장 데이터 예시
```json
{ "relics": { "tesla_notes": 2, "rosetta_fragment": 1, "turtle_ship_plan": 0 }, "wallet": { "ancientShard": 145 } }
```

## 9. 결정 필요

- [ ] **유물을 장착형(칸에 끼우기)으로 할까, 컬렉션형으로 할까**
  - 장착형: 유물마다 특수 효과(예: "판 시작 시 회전 칼날 Lv1")를 줄 수 있어서 재밌지만, 판 안 빌드와 기록 비용을 흔든다
  - **추천: 컬렉션형.** 판 안 규칙을 건드리지 않고 밸런스가 쉽다. 특수 효과는 출시 이후 아이디어로.
- [ ] **보스맵에서 유물·수련 같은 계정 보너스를 기록 당시 값으로 쓸까, 현재 값으로 쓸까**
  - 현재 값: 유물을 모을수록 옛 기록도 강해져서 새 기록을 만들 이유가 약해진다
  - 기록 당시 값: 장비 규칙(만들 당시 고정)과 같아서 일관된다
  - **추천: 기록 당시 값.** 기록에 "계정 보너스 스냅샷"(공격력 %, 체력 %, 부가 능력치)을 함께 저장. ([GameDesign 7-1](../GameDesign.md#7-1-기록에-저장되는-것)에 추가 필요)
- [ ] **새 재료 🏺 고대 파편을 만들까, 장비 조각을 같이 쓸까**
  - 장비 조각과 섞으면 "장비 교환 vs 유물 별" 경쟁이 생겨 초보자가 헷갈린다
  - **추천: 고대 파편을 따로 만든다.** 대신 유물 화면에서만 보이게 해서 재화가 많아 보이지 않게.
- [ ] **유물을 팔까?**
  - **추천: 팔지 않는다.** 역사 수집의 성취감이 핵심이고, 무과금 신뢰를 지킨다.
