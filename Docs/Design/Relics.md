## 1. 한 줄 요약

**유물 = 역사 속 진짜 물건을 모으는 수집 도감.** 모을수록 계정 전체가 조금씩 강해지고, 유물마다 짧은 역사 이야기가 열린다.

| 원칙 | 내용 |
|---|---|
| **힘 예산** | 유물 24개를 전부 ★3으로 모아도 **공격력 +10%, 체력 +10%**. 그 밖에는 세트 효과로 **피해 감소 +4%** 하나만 (다른 보조 능력치는 없음) |
| **경험치 없음** | 유물은 경험치 획득 +%를 주지 않는다. 판 밖 출처가 판 안 레벨업 카드를 사는 길이 되면 안 된다 |
| **장착 없음** | 유물은 끼우는 아이템이 아니라 **모으면 바로 적용되는 컬렉션**이다. 판 안 규칙에 끼어들지 않는다 |
| **뽑기 중심** | 24종 모두 유물 뽑기에서 얻는다. 영웅 연결 8종은 그 영웅의 던전 첫 클리어에도 지급 |
| **같은 힘 예산** | 보석 뽑기도 허용하지만 유물 능력치 상한은 그대로. 고대 파편 직접 판매는 없음 |
| **역사 존중** | 종교 성물, 무덤 부장품, 특정 국가끼리의 전쟁 전리품은 넣지 않는다 |

### 왜 넣나
- 이 게임의 테마("역사 영웅")를 **전투 밖에서도 느끼게** 한다. 유물 이야기 카드가 도감 탭의 볼거리가 된다.
- 장비·영웅 레벨과 다른 **"모으는" 성장 경로**를 하나 더 만든다. (Economy.md 원칙 3: 성장 경로는 여러 개)
- 무과금 유저가 꾸준히 하면 확실히 채울 수 있는 **안심되는 성장**이다.

## 2. 구조

```
유물 24개 = 테마 세트 6개 × 유물 4개
 ├─ 유물마다 ★1 ~ ★3
 │    └─ ★ 하나당: 공격력·체력 +1/12% (약 +0.08333%)
 └─ 세트 4개를 모두 ★1 이상 → 세트 완성 보너스
```

### 힘 예산 계산

| 항목 | 개수 | 하나당 | 합계 |
|---|---|---|---|
| 별(★) | 24개 × ★3 = 72개 | 공격력·체력 +1/12% | **+6%** |
| 세트 완성 | 6세트 | 공격력·체력 +2/3% | **+4%** |
| **합계** | | | **+10% / +10%** ✅ |

- 세트 완성 보너스에는 공격력·체력 외에 **피해 감소 +2/3%**가 붙는다. 6세트 전부 완성하면 **피해 감소 +4%** (유물 몫 상한과 같음).

### 판 밖 보조 능력치 확인
| 능력치 | 전체 상한 | 유물 몫 | 유물 최대 합 | 확인 |
|---|---|---|---|---|
| 피해 감소 | +10% | +4% (세트 효과로만) | (2/3) × 6 = **+4%** | ✅ |
| 공격속도·치명타 확률·치명타 피해·쿨다운 감소·이동속도 | — | 0 | **0** | ✅ |
| 경험치 획득·골드 획득 | 0 | 0 | **0** | ✅ |

### 세트 6. 🧰 준비의 흔적

새 영웅 네 명이 싸움에 앞서 남긴 기록과 도구를 모은다. **새 세트에 정확히 4개**를 둔다. 기존 세트에 더 넣으면 4개 완성 규칙이 흔들리고, 일부 유물만 더 쉽게 보너스를 열 수 있다. 여섯 세트는 모두 같은 보너스를 주며, 별당 보너스와 세트 보너스를 종전의 **5/6**으로 함께 줄인다. 이로써 별 +6%, 세트 +4%, 피해 감소 +4%라는 총예산과 세트 사이 균형을 그대로 지킨다. 기존 20개에도 새 공통 수치를 적용한다.

| 유물 (저장 ID) | 영웅 | 📜 사실 / 📖 전승 / 🎮 각색 | 🎮 게임 속 이야기 | 기존 아이콘 키 |
|---|---|---|---|---|
| 난중일기 (`yisunsin_diary`) | 이순신 (`yisunsin`) | **사실:** 이순신이 전쟁 중 직접 쓴 일기다. **각색:** 게임 속 일기 한 권으로 표현한다 | 오늘 지킨 길을 적어, 내일의 길을 준비한다 | `archive` |
| 이성계의 활 (`yiseonggye_bow`) | 이성계 (`yiseonggye`) | **사실:** 이성계의 뛰어난 활솜씨가 기록에 남아 있다. **각색:** 이 활의 모습은 게임에서 만들었다. 현존 실물을 재현한 것이 아니다 | 활시위를 고르며 다음 한 발을 준비한다 | `heaven_bow` |
| 다빈치의 톱니바퀴 도면 (`davinci_gears`) | 다빈치 (`davinci`) | **사실:** 다빈치의 필사본에는 톱니바퀴와 기계 장치 그림이 남아 있다. **각색:** 여러 그림을 게임 속 한 장의 도면으로 묶었다 | 작은 톱니 하나도 제자리가 있어야 기계가 움직인다 | `dav_tank` |
| 전출사표 사본 (`zhuge_memorial`) | 제갈량 (`zhuge`) | **사실:** 제갈량의 전출사표는 후대에도 베끼고 새겨 전해졌다. **각색:** 게임 속 사본이며 제갈량의 친필이라는 뜻은 아니다 | 떠나기 전 남긴 뜻이 망각 속에서도 길을 잡아 준다 | `codex` |
| **세트 보너스** | 네 유물 모두 ★1 이상 | **공격력·체력 +2/3%, 피해 감소 +2/3%** | 별을 더 올려도 세트 보너스는 늘지 않는다 | |

- 네 유물 모두 기존 유물과 같은 컬렉션 효과다. 각 영웅으로 얻지만 **계정 전체에 적용**하며, 영웅 전용 기술이나 경험치·골드·공격속도 보너스는 주지 않는다.
- **각 유물 효과:** ★1 공격력·체력 **+1/12% (약 +0.08333%)**, ★2 **+1/6% (약 +0.16667%)**, ★3 **+1/4% (+0.25%)**. 이는 세트 보너스를 제외한 값이다. 내부 계산은 분수를 쓰고 화면만 반올림한다.
- 위 네 항목은 실존 기록을 바탕으로 하며, 따로 전승으로 소개하는 물건은 없다. 근거: [이야기 출처](StorySources.md#새-영웅-유물-2026-10-29).

- 피해 감소는 세트 6개를 다 채워야 +4%다. 장비 +6%와 합쳐도 판 밖 전체 상한 +10%를 넘지 않는다.
- 영웅 8명과 연결된 유물(테슬라, 청룡언월도, 이각모, 파이자, 난중일기, 이성계의 활, 톱니바퀴 도면, 전출사표 사본)은 **그 영웅으로 던전을 처음 클리어했을 때 지급**한다 (미보유면 ★1, 보유면 같은 중복 처리). 영웅을 해금하거나 사는 것만으로는 주지 않는다. → 영웅을 써서 깨는 기쁨이 하나 더, 영웅 구매가 유물로 바로 이어지지 않는다.

## 4. 획득처 (2026-10-29 개발자 결정: 유물 뽑기)

| 획득처 | 규칙 |
|---|---|
| 유물 뽑기 | 24종 전체, 등급 구분 없이 각각 **1/24 = 약 4.166667%** |
| 영웅 던전 첫 클리어 | 연결된 8종을 각각 한 번 지급. 없으면 ★1, 이미 있으면 뽑기와 같은 중복 처리 |
| 종전 보스·구간 별·서바이벌·업적 유물 | 같은 조건을 채우면 유물 대신 **고대 파편 20**을 한 번 지급. 이미 그 보상을 받은 저장은 다시 받지 않음 |

- 유물 화면·뽑기는 **2구간 보스 격파 후** 열린다. 이전에 받은 영웅 유물은 보관하고, 화면이 열릴 때 효과가 켜진다. 뽑기 무료분은 소급해 쌓이지 않는다.
- 기존 획득 조건·받은 표시를 보존한다. 이미 가진 유물과 별도 보존한다. 균열 20·40층의 파편 10씩 등 기존 파편 보상은 유지한다.

## 5. 중복·비용·보장

| 획득 전 상태 | 같은 유물 1개를 받으면 |
|---|---|
| 없음 | ★1, 새 유물 |
| ★1 | ★2 (중복 1개 필요) |
| ★2, 중복 0/2 | ★2, 중복 1/2 보관 |
| ★2, 중복 1/2 | ★3 (★2 이후 중복 2개 필요) |
| ★3 | 고대 파편 **5**으로 자동 변환 |

- 유물 한 종을 끝내려면 첫 획득 포함 **4개**가 필요하다. 파편으로 별을 직접 올리기와 미보유 유물 확정 교환은 없앤다. 중복만으로 별을 올리는 한 경로를 쓴다.

| 구매 | 고대 파편 | 보석 (선택) |
|---|---|---|
| 1회 | 100 | 100 |
| 10회 | 900 (10% 할인) | 900 (10% 할인) |
| 매일 무료 1회 | 0, 광고 없음 | 같은 무료분, 별도 제공 아님 |

- 파편/보석 중 한 재화로 전액 지불한다. 섞어 쓰거나 부족할 때 다른 재화를 자동 소모하지 않는다. 고급 소환권은 장비 상자 전용이다. 보석은 기존 `Wallet`처럼 **무료분부터, 유료분은 나중**에 쓴다.
- 날짜는 기존 `Clock.Today` (기기 시간대 자정)와 같다. 무료·파편·보석·10회는 같은 유물 보장 횟수를 쓴다. 장비 상자 보장과는 별개다.
- **새 유물을 19회 연속 못 얻으면 다음 20번째는 미보유 유물 중 균등 추첨.** 보통 회차에 새 유물이 나와도 횟수는 0. 10회 묶음도 한 장마다 적용한다. 24종을 모두 가지면 새 유물 보장은 쉬며 횟수는 0이다. ★3 완성 보장은 없다.
- 보통 회차는 각 1/24. 보장 회차에는 미보유 M종이 각각 1/M, 보유 유물은 0%. 전종 보유 후에는 다시 모든 회차가 1/24다. 구매 옆 확률 보기에서 **종류·개별 확률 / 조건별 확률·보장 / 중복 처리**를 모두 공개한다.

|---|---|
| 하루 30분, 파편 17/일, 보석 사용 안 함 | **약 199회, 약 174일 = 5.8개월** |
| 가정 | 7일째 유물 화면 개방, 매일 무료 1회, 파편은 기록 용량 300부터 쓰고 900이 모일 때마다 10회. 영웅 첫 클리어 8개는 초기 지급으로 가정 |
| 계산 | 고정 난수 729, 20,000계정 모의 계산. 평균 198.90회·173.69일, ★3 초과 중복 평균 110.90개 → 파편 554.5 환급. 1개월 30일 |

- 재계산: `python3 Tools/relic_gacha_economy.py`. 첫 클리어를 하나도 계산하지 않으면 약 208회·181일(6.0개월), 60분 유저(파편 33/일)는 약 199회·151일(5.0개월).
- 신규 파편 대체 보상 같은 일회 수입과 보석은 계산에서 뺐다. 영웅 8종을 늦게 깨거나 무료분을 놓치면 늦어진다. 결과는 평균이며 개인별 완성 시점은 다르다.
- 보석을 쓰지 않아도 종전 목표 5.8개월과 같다. **하루 보석 133은 장비 상자에 그대로 쓸 수 있다.** 유물에 보석 900을 선택하면 고급 상자 3.6회(1회 가격 기준)를 포기한다.

## 6. 화면

- 상점에 유물 뽑기 구역: 가진 파편·보석, 재화 선택, [1회] [10회] [무료 1회 (오늘)] [확률 보기]. 주 뽑기 단추만 초록, 다른 단추는 파랑.
- 유물 도감 [뽑기]도 같은 상점 화면을 연다. 상세는 별과 다음 별까지 중복 수를 보여준다.
- 결과는 저장 성공 후 팝업에 유물 그림·이름·★와 `NEW` / `★UP` / 중복 진행 / 파편 변환을 보여준다. 10회는 10장 모두 보인다. 저장 실패 시 재화·유물·무료분·보장 횟수를 전부 되돌린다.

## 8. 구현 구조

| 클래스 | 종류 | 역할 |
|---|---|---|
| `RelicData` | ScriptableObject | `id`, `setId`, 그림, 사실/이야기 텍스트 (로컬라이징 키), 획득처 설명 |
| `RelicSetData` | ScriptableObject | `setId`, 유물 4개, 세트 보너스 (공격력·체력 % + 피해 감소 %) |
| `RelicTable` | ScriptableObject | 기존 힘 예산 + 뽑기 비용·보장·중복 규칙 (화면과 추첨이 함께 읽음) |
| `RelicGachaService` | 순수 서비스 | 재화 확인·추첨·중복·보장·무료분. 저장은 상점에서 한 번에 |
| `RelicSave` / `RelicGachaSave` | 저장 데이터 | 별·다음 별 중복 수, 무료 날짜·보장·누적 횟수·최근 결과 |
| `RelicStatProvider` | 런타임 | ★ 합 + 완성 세트 → 스탯 보너스 목록 (출처 = 유물) |

### 저장 데이터 예시
```json
{ "relics": { "owned": [{ "id": "tesla_notes", "stars": 2, "duplicates": 1 }] }, "relicGacha": { "newRelicPity": 3, "totalPulls": 17, "freeDate": "2026-10-29", "log": [] }, "items": [{ "id": "ancient_shard", "count": 145 }] }
```

### 계산 규칙
- `RelicService.Calculate(owned, table)`: 공격력·체력 = ★ 합계 × 1/12% + 완성 세트 수 × 2/3%, 피해 감소 = 완성 세트 수 × 2/3%

## 9. 결정 필요

- [ ] **유물을 장착형(칸에 끼우기)으로 할까, 컬렉션형으로 할까**
  - 장착형: 유물마다 특수 효과(예: "판 시작 시 회전 칼날 Lv1")를 줄 수 있어서 재밌지만, 판 안 빌드와 기록 비용을 흔든다
  - **추천: 컬렉션형.** 판 안 규칙을 건드리지 않고 밸런스가 쉽다. 특수 효과는 출시 이후 아이디어로.
- [ ] **보스맵에서 유물·수련 같은 계정 보너스를 기록 당시 값으로 쓸까, 현재 값으로 쓸까**
  - 현재 값: 유물을 모을수록 옛 기록도 강해져서 새 기록을 만들 이유가 약해진다
  - 기록 당시 값: 장비 규칙(만들 당시 고정)과 같아서 일관된다
  - **추천: 기록 당시 값.** 기록에 "계정 보너스 스냅샷"(공격력 %, 체력 %, 보조 능력치)을 함께 저장. ([GameDesign 7-1](../GameDesign.md#7-1-기록에-저장되는-것)에 추가 필요)
- [ ] **새 재료 🏺 고대 파편을 만들까, 장비 조각을 같이 쓸까**
  - 장비 조각과 섞으면 "장비 교환 vs 유물 뽑기" 경쟁이 생겨 초보자가 헷갈린다
  - **추천: 고대 파편을 따로 만든다.** 대신 유물 화면에서만 보이게 해서 재화가 많아 보이지 않게.
