# 모바일 게임 UI 조사 (2026-11-02)

개발자 요청: "칙칙하다 · 모바일 게임스럽지 않다 · 꾸민 게 안 느껴진다 · 공간이 작은데 큰 글씨를 채우려니 꽉 차거나 텅 비거나 극단적 · 보상 이펙트가 없다 · 다른 게임은 어떻게 해결했는지 찾아봐".
조사 대상: 궁수의 전설, 탕탕특공대, 브롤스타즈, 클래시 로얄, AFK 저니, 러시 로얄, 버섯커 키우기.
주의: 게임별 정확한 px · 색은 공개 자료가 없어 업계 관행에서 정리한 **출발점**이다. 에디터 · 실기 캡처로 조정한다.

## 1. 서브 화면 구조
- 서브 화면도 화면 전체에 배경 (그라데이션 · 일러스트). 안전 영역 밖까지 채운다.
- 위 띠 (높이 130~160): 왼쪽 뒤로 (≈110), 가운데 제목 리본, 오른쪽 재화 칩 (높이 64~72, 아이콘 + 숫자).
- 팝업은 화면을 어둡게 덮고 가운데 카드.

## 2. 좁은 공간에 정보 넣기 (꽉 참 / 텅 빔 극단 없애기)
- 글자 크기 단계 (1080 폭): 제목 60 · 큰 단추 52 · 카드 제목 42 · 본문 34 · 캡션 28. **28 아래는 쓰지 않는다**. 큰 숫자 64~96.
- 간격 단계: 8 / 16 / 24 / 32 / 48. 화면 좌우 32, 카드 안 24, 카드 사이 16~24.
- 문장 → 아이콘 + 숫자 ("공격력이 15 증가" → ⚔ +15). 단추 글은 2~4자 ("받기", "강화", "구매").
- 카드 본문 최대 2줄, 더 길면 "i" 단추로 자세히 (단계적 공개).
- 숫자는 본문보다 1.5배, 색으로 구분 (증가 초록 · 감소 빨강 · 재화 금색). 1,000 이상 1.2K / 1만 이상 1.2만.
- 큰 글이 안 들어가면 글을 줄이지 말고 칸을 키우거나 내용을 덜어낸다. 한 화면 큰 요소 3~5개.

## 3. 꾸밈 (게임다운 느낌)
- 칙칙함의 직접 원인: 채도 낮은 어두운 바탕 + 회색 단추. 바탕은 채도 높게, 단추는 역할 색.
- 단추 역할 색: 주 행동 초록 · 보조 노랑 · 위험 빨강 · 중립 파랑. **회색은 못 누를 때만**.
- 두툼한 3D 단추: 면 + 위 안쪽 밝은 띠 + 아래 단단한 그림자 (누르면 내려간다).
- 글자: 흰색 + 어두운 테두리 + 아래 그림자.
- 리본 · 배너 (제목 · 섹션), 이중 테두리 (밖 어둡게 · 안 밝게), 희귀도 색 테두리 + 뒤 광채.
- 희귀도: 일반 #B0B7C0 · 고급 #4CD964 · 희귀 #3FA0F0 · 영웅 #B05CF0 · 전설 #FFB020. 금화 #FFD23F.
- 상자 안에 상자 금지: 구분선 · 여백 · 아이콘으로 나누고 배경이 보이게. 빈 목록은 그림 + 한 줄.

## 4. 보상 연출
- 어두운 덮개 (0.7) + "획득!" 리본 + 가운데 보상 줄 + 아래 "눌러서 받기".
- 아이템 뒤 회전 광선 (20~30°/초, 알파 0.6, 아이콘의 3~4배).
- 아이템 팝: 0 → 1.2 → 1.0 (OutBack) 0.25~0.3초, 0.08~0.12초 간격. 높은 등급은 광채 · 전설은 번쩍임.
- 재화는 5~10개 복사본이 0.5~0.7초 곡선으로 위 재화 칩까지 날아가고, 칩이 1.15배로 튀며 숫자가 0.6~1초 동안 올라간다.
- 팝마다 소리 (피치 조금씩 올림), 탭으로 건너뛰기.

## 5. 움직임
- 창 열기: 크기 0.85 → 1.0 + 투명 → 보임, 약 0.25초 (OutBack). 닫기 0.15초.
- 목록 줄: 0.04~0.06초 간격으로 아래에서 24px 올라오며 나타남 (최대 8줄).
- 단추 누름: 0.08초 0.94배 → 0.12초 복귀. 중요한 단추 1~2개만 1.5~2초 주기 맥동 · 빛 지나감.
- 알림 점: 처음 0 → 1.3 → 1.0, 그 뒤 3~4초마다 살짝 흔들림. 탭 전환: 0.2초 밀기 + 흐려짐.
