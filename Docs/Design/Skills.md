### 1-1. 기본 공격 패시브를 직업마다 어떻게 해석하나
멀티샷·관통·벽 튕김은 "화살" 기준이다. 근접·법사 영웅은 아래처럼 바꿔 적용한다. (같은 카드, 같은 저장 비용)

| 패시브 | 🏹 궁수 · 💥 총잡이 | ⚔️ 전사 (관우, 근접) | ⚡ 법사 (테슬라) |
|---|---|---|---|
| 멀티샷 | 발사체 +1 (발당 -10%) | **베기 1회 추가** (연속 베기, 회당 -10%) | 전기 구체 +1 (발당 -10%) |
| 관통 | 적을 뚫고 지나감 | **베기 각도 120° → 160°** | 구체가 적을 뚫고 지나감 |
| 벽 튕김 | 벽에 2번 / +1번 튕김 | **베기마다 검기 1발** (공격력 40%)이 날아가 벽에 튕김 | 구체가 벽에 튕김 |
| 영웅의 기세 | 그대로 | 그대로 | 그대로 |

- 근접 영웅이 투사체 패시브를 골라도 손해 보지 않게 하는 게 목적이다.

### 4-4. 조합의 기본 동작 (Codex 5차: 구현자가 지어내지 않게)

**공통 규칙**
- 피해는 모두 **공격력 기준 %**. 액티브 피해 증가(기술 숙련)와 치명타가 적용된다.
- 진화의 쿨다운은 **원래 액티브와 같다.** 합체의 쿨다운은 아래 표에 정한 값. 둘 다 쿨다운 감소가 적용된다.
- 이동 중에도 발동한다 (액티브 규칙 그대로).

| 조합 | 쿨다운 | 피해 | 표적·범위 | 그 밖에 |
|---|---|---|---|---|
| 강철 회오리 | 상시 | 칼날 **8개**, 닿을 때 50% (같은 적에게 0.3초 간격) | 몸 주위 반경 1.5 | 칼날당 1초에 적 투사체 1발 차단 |
| 불꽃 발자국 | 상시 + 장판 4초 | 지나간 자리 불길 2초, 초당 35% | 지나간 길 (폭 1.2) | 원래 불꽃 장판도 계속 깔림 |
| 서리 창 | 3초 | 파편 7개, 각 60%, 둔화 40% | 가까운 적부터 | 둔화 3번 쌓이면 1초 빙결 → 빙결한 적에게 치명타 확정 |
| 맹독 개화 | 5초 | 독 구름 초당 30% (3번까지 중첩) | 무작위 위치 | 구름 안에서 죽은 적 자리에 작은 구름(2초). 번짐은 최대 3번 연쇄 |
| 철벽 | 8초 | 깨질 때 폭발 200% | 반경 3 | 보호막 최대체력 26% |
| 뇌신의 분노 | 3초 | 번개 5개, 각 120%. 각 번개가 근처 3명에게 연쇄 (연쇄마다 -20%) | 무작위 적 | |
| 쌍 부메랑 | 4초 | 부메랑 5개, 각 80% (관통). 돌아올 때 2개로 갈라짐 (각 50%) | 가까운 적 방향 | |
| 뇌화 폭풍 | 3초 | 번개 3개, 각 165% (v1.0 밸런스) + 떨어진 자리 장판 2초 (초당 30%) | 무작위 적 | |
| 눈보라 | 6초 | 2.5초 동안 끌어모으며 초당 60%, 끝날 때 1.5초 빙결 | 적이 가장 많은 곳 | |
| 천궁 | 6초 | 화면 전체 화살, 적마다 150% + 되돌아오며 75% | 화면 전체 | |
| 천호의 화살비 | 5초 | 부채꼴 9발, 각 60%, 0.3초 간격으로 2번 | 가까운 적 방향 | 칭기즈 칸 전용 |
| 오관참장 | 6초 | 회전 베기 5번, 회당 120% | 주변 반경 2.5 | 회전 중 받는 피해 -50%. 관우 전용 |
| 아우스터리츠의 포화 | 7초 | 포탄 3발, 각 130% + 장판 2초 (초당 30%) | 적이 가장 많은 곳 | 나폴레옹 전용 |
| 워든클리프 탑 | 12초 | 탑 8초 유지, 1초마다 화면 안 적 최대 5명에게 번개 60% | 설치 위치 = 영웅 자리 | 테슬라 전용 |
| 파로스의 빛 | 8초 | 1초 간격 4회, 각 45%+레벨당 10%p | 설치 자리 반경 6에서 가까운 적을 찾고 그 자리 반경 0.6 | 첫 빛 즉시, 수호상은 4초 뒤 사라짐 |
| 알렉산드리아의 서고 | 8초 | 1초 간격 4회, 각 70%+레벨당 15%p | 파로스와 같은 탐색, 각 빛 반경 1.6 | 파로스의 빛을 대체 |

- 위 숫자는 기준값이다. v0.1~v0.3 플레이 테스트에서 [GameDesign 3-3 멈춤의 가치](../GameDesign.md#3-3-멈춤의-가치-액티브가-강해져도-멈출-이유) 지표(기본 공격 피해 비중 40% 이상)를 지키도록 조정한다.

## 5. 균형 점검표
| 점검 | 기준 |
|---|---|
| 기본 공격 전용 패시브 비율 | 패시브 18개 중 **6개** (공속, 흡혈, 멀티샷, 관통, 벽 튕김, 영웅의 기세) → 멈출 이유 |
| 액티브 전용 패시브 | 2개 (쿨감, 기술 숙련) → 액티브 빌드도 길이 있음 |
| 생존 패시브 | 6개 → 피하기 서툰 유저도 버틸 길 |
| 조합당 필요 레벨업 | 최소 7회 (한 판 약 15회) → 한 판에 조합 1~2개 |
| 전설 | 패시브 2 + 액티브 2 = 4개. 하나만 떠도 플레이가 바뀌는 효과 |
| 보스전에서 약한 스킬 | 경험치(배움) — 기록 저장 비용 1로 낮게, 용도 메모 "던전" |

## 7. 스킬 역할 (기록 강점용)

[GameDesign 7-4](../GameDesign.md#7-4-보스맵) 기록 강점과 보스 추천 배지에 쓴다. 태그와 별개로 스킬마다 1개. 값은 `SceneBuilder.Data`의 `Roles` 표가 정본이다. (v0.3, 조사 A8)

| 역할 | 스킬 |
|---|---|
| 단일 (기본 공격·보스 화력) | 공격속도, 멀티샷, 흡혈, 관통, 벽 튕김, 치명타 확률, 치명타 피해, 영웅의 기세 |
| 광역 (잡몹 떼) | 낙뢰, 불꽃 장판, 화살비, 유성 낙하, 독 구름, 회오리, 얼음 파편, 부메랑, 공격형 영웅 전용 액티브 (팔진도는 방어), 광역 조합 (뇌화 폭풍, 불꽃 발자국, 서리 창, 맹독 개화, 뇌신의 분노, 쌍 부메랑, 눈보라, 천궁, 영웅 조합) |
| 방어 (버티기·막기) | 회전 칼날, 강철 회오리, 방어력, 최대체력, 수호 방패, 철벽, 회피, 체력 재생, 불굴 |
| 없음 | 공격력, 이동속도, 배움, 쿨다운 감소, 기술 숙련 |
