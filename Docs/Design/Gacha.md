# 🎁 뽑기(상자) 설계

> 상위 문서: [GameDesign.md](../GameDesign.md) · 관련: [경제](Economy.md) · [과금](Monetization.md)
> 작성: 2026-10-25 · 상태: **초안 (확률·가격은 임시값)**

---

## 1. 원칙

| 원칙 | 이유 |
|---|---|
| **뽑기는 장비·유물** | 판 안 스킬, 기록, 조합, 영웅, 스킨은 뽑기로 팔지 않는다 |
| **확률을 전부 공개** | 한국 게임산업법(2024.3.22 시행) 의무 + 구글 플레이 정책 |
| **천장(확정 보장)이 있다** | 유료 뽑기는 운이 나빠도 끝이 보여야 한다 |
| **중복도 쓸모가 있다** | 중복 장비 → 장비 조각 → 원하는 장비 확정 교환 |
| **표시와 실제가 같은 데이터** | 화면에 보여주는 확률표와 실제 추첨이 **같은 ScriptableObject**를 읽는다. 둘이 어긋날 수 없게 |

> ⚠️ **"전설은 귀하다, 천장 없음"은 판 안 스킬 규칙이다.** 유료 뽑기는 별개 시스템이고, 돈을 내는 것이라 천장을 둔다.

## 2. 상자 종류

| 상자 | 가격 | 일반 ⚪ | 고급 🟢 | 희귀 🔵 | 전설 🟡 | 천장 |
|---|---|---|---|---|---|---|
| **일반 상자** | 🪙 5,000 | 70% | 27% | 3% | — | 없음 |
| **고급 상자** | 💎 250 또는 🎫 1장 | 50% | 35% | 13% | **2%** | **50회 안에 전설 1개 확정** |
| **고급 상자 10회** | 💎 2,250 (10% 할인) | 위와 같음 | | | | 1회 구매와 같은 누적 희귀 이상 보장 적용 |

- 등급을 먼저 뽑고 → 그 등급 장비 중 하나를 **균등하게** 뽑는다. 장비별 개별 확률도 표에 같이 보여준다.
- 일일 무료: **일반 상자** 광고 보고 하루 1회 (보상형 광고). 고급 상자는 무료로 주지 않는다 (Codex 4차: 무과금 전설이 15일까지 빨라지던 문제). **예외 딱 1번:** 튜토리얼 보스 격파 보상 🎫1 (UX 4장 "첫 고급 상자 무료", v1.0)

### 2-0. 장비 6칸 확률 공개 (2026-10-29)

등급마다 6슬롯이 같은 수(일반 6종, 고급·희귀·전설 각 12종)라 **등급 안 슬롯별 1/6**이다. 총 42종. 등급을 뽑은 뒤 그 등급 장비 균등 추첨을 유지한다. 50회 천장·가격은 유지하고, 희귀 이상 보장은 고급 상자 단일 구매와 10회 구매에 걸쳐 누적한다.

| 보통 회차 | 등급 확률 | 해당 슬롯 한 종류 전체 | 개별 장비 |
|---|---|---|---|
| 일반 상자: 일반 | 70% | 11.666667% | 11.666667% |
| 일반 상자: 고급 | 27% | 4.5% | 2.25% |
| 일반 상자: 희귀 | 3% | 0.5% | 0.25% |
| 고급 상자: 일반 | 50% | 8.333333% | 8.333333% |
| 고급 상자: 고급 | 35% | 5.833333% | 2.916667% |
| 고급 상자: 희귀 | 13% | 2.166667% | 1.083333% |
| 고급 상자: 전설 | 2% | 0.333333% | 0.166667% |

누적 보장 재추첨 표의 개별 확률: 희귀 86.7/12 = **7.225%**, 전설 13.3/12 = **1.108333%**. 천장 회차 전설 12종은 각각 **8.333333%**이다. 누적 보장 회차에도 먼저 일반 표로 뽑아 희귀 이상이 나오면 유지하므로, 회차 전체의 실제 등급 확률은 희귀 **86.695%**·전설 **13.305%**이다. [확률 보기]는 실제 42개 정의에서 슬롯 이름·등급·개별 확률과 보장 회차 개별 확률을 계산해 보여준다. 특정 슬롯 보장은 추가하지 않는다.

### 2-1. 보장 규칙 (구매 직전에 그대로 공개)
| 규칙 | 내용 |
|---|---|
| **천장 카운터** | 💎 보석·🎫 소환권으로 연 **고급 상자 전부가 같은 카운터**를 쓴다. 일반 상자는 카운터 없음 |
| **50회 천장** | 카운터가 50이 되는 회차는 **전설 확정**. 전설이 나오면 0으로 초기화 |
| **누적 10회 보장** | 구매 방식과 관계없이 고급 상자를 9회 연속 희귀 이상 없이 열면, **다음 회차가 희귀 이상 확정**. 보통 표에서 희귀 미만이면 희귀 이상 표로 다시 뽑는다 (재추첨 표: 희귀 86.7% · 전설 13.3%). 희귀 이상이 나오면 횟수를 다시 센다 |
| **저장** | 기존 뽑기 기록에서 최근 고급 상자 9개의 등급을 복원한다. 일반 상자를 많이 열어도 마지막 고급 상자 9개는 보존한다. 과거 기록의 장비 ID가 사라져 등급을 알 수 없으면 그 지점에서 연속 실패 계산을 끊는다 |
| **우선순위** | 천장(전설 확정)이 희귀 이상 보장보다 먼저. 10회 구매 도중에 천장에 닿으면 그 장이 전설 |
| **카운터 표시** | 상점 화면에 항상: "전설 확정까지 **37회**" |
| **카운터 보관** | 계정(서버)에 저장. 기기를 바꿔도 이어진다. 시즌이 지나도 초기화하지 않는다 |

### 2-2. 조건별 확률 공개 (화면에 이 3가지를 모두 보여준다)
| 회차 종류 | 일반 | 고급 | 희귀 | 전설 |
|---|---|---|---|---|
| 보통 회차 | 50% | 35% | 13% | 2% |
| 누적 보장 회차 (9회 연속 희귀 미만 이후) | — | — | 86.695% | 13.305% |
| 천장 회차 (50번째) | — | — | — | 100% |

### 2-3. 기대 비용 (참고)
- 보통 회차 2% + 누적 희귀 이상 보장 + 50회 천장이면 전설 1개까지 **평균 약 29.21회** ≈ 💎 약 7,301 (1회씩 구매)
- 원화로: 가정한 기준 환율(₩1,200 = 💎100)을 그대로 적용하면 **약 ₩87,616**. 실제 가격은 보석 상품과 소환권 사용 비율에 따라 달라진다
- 최악(50회): 1회씩 열면 💎 12,500, 10연으로 열면 💎 11,250
- **10회로만 열 때:** 첫 전설을 포함하는 묶음까지 평균 **약 3.24묶음 ≈ 💎 7,297**. 첫 전설 이전 회수의 기대값과 실제 묶음 구매 비용은 다르다
- 기존 출시 계획의 단순 가정(하루 💎 133 + 🎫 0.25~0.39)을 모두 상자에 쓰면 고급 상자 하루 약 0.78~0.92회 → **첫 전설까지 평균 약 32~38일**이다. 실제 구현 수입은 Economy 9장의 약 104/일 기준이며, 다른 보석 지출이 있으면 더 늦어진다. 조각 교환소로 원하는 장비를 확정으로 얻는 길도 있다

## 2-4. 유물 뽑기 (2026-10-29)

장비 상자와 별도 표·보장 횟수를 쓴다. [유물 4~6장](Relics.md)의 규칙이 원본이다.

| 항목 | 규칙 |
|---|---|
| 종류·보통 확률 | 24종, 희귀도 없음. 각 1/24 (약 4.166667%), 합계 100% |
| 1회 / 10회 | 고대 파편 100 / 900 또는 보석 100 / 900. 10회는 10% 할인 |
| 무료 | 광고 없이 매일 1회, `Clock.Today` 자정 갱신. 미사용분 이월 없음 |
| 보장 | 새 유물 없이 19회 → 20번째 미보유 중 균등. 무료·두 재화·10회 공통, 새 유물이 나오면 0 |
| 보장 회차 | 미보유 M종 각각 1/M, 나머지 0%. 전종 보유 후 보장은 쉬고 각 1/24. ★3 보장은 없음 |
| 중복 | ★1→2 중복 1개, ★2→3 추가 2개. ★3 중복은 파편 5 |
| 보석 순서 | `Wallet.TrySpendGems`로 무료분부터 차감. 파편 부족 시 보석 자동 대체 없음 |
| 첫 클리어 | 영웅 연결 8종은 첫 던전 클리어에도 지급. 이미 있으면 같은 중복 처리 |

**구매 바로 옆 [확률 보기]의 3가지 공개:** ① 24종 이름과 개별 확률(등급 없음) ② 보통/보장/전종 보유 조건별 확률·남은 보장 횟수 ③ 중복→별·초과 파편 전환. 비용·무료 사용 여부·사용 후 철회 제한 안내도 구매 전 보인다. 법·정책의 출시 전 확인 요구는 4장 그대로다.

파편 17/일, 기록 용량 300 우선, 7일째 개방 후 무료와 파편 10회만 사용하면 **약 199회·174일(5.8개월)**. 20,000계정·고정 난수 729, 영웅 8종 초기에 지급 가정. 장비 상자용 보석 133/일은 보존된다.

## 4. 확률 공개 (법·정책)

| 어디에 | 무엇을 |
|---|---|
| **구매 버튼 바로 옆** "확률 보기" | 등급별 확률, 장비별 개별 확률, 천장 규칙 |
| 게임 밖 웹페이지 (GitHub Pages 등) | 같은 내용. 게임 안에서 링크 |
| 광고·홍보물 | 확률형 아이템이 있다는 표시 |
| 확률이 바뀔 때 | 바꾸기 전에 공지, 변경 이력 보관 |

- **한국:** 「게임산업진흥에 관한 법률」 제33조와 시행령 별표 3의2. 유료(일부라도 유료 재화로 얻을 수 있는) 확률형 아이템의 종류와 확률을 표시해야 한다. 위반 시 시정명령 대상.
- **구글 플레이:** 무작위 아이템을 구매로 받는 기능은 **구매 전에, 구매와 가까운 위치에** 확률을 명확히 보여줘야 한다.
- **청약철회:** 유료 보석은 쓰지 않았다면 7일 안에 철회 가능하고, 상자를 연 뒤에는 철회가 제한된다. **구매 화면에 이 내용을 미리 고지**한다.
- ⚠️ 출시 전에 최신 법령과 정책을 다시 확인한다. (이 문서는 법률 자문이 아니다)

## 5. 화면 흐름

```
[상점] → 고급 상자 탭
  ├─ 가격, 천장 카운터("전설 확정까지 37회"), 누적 희귀 이상 보장 남은 횟수, [확률 보기]
  ├─ [1회 💎250]  [10연 💎2,250]   (일반 상자 탭: [🪙5,000] [광고 보고 무료 1회 (오늘 1/1)])
  ↓
[연출] 상자가 흔들림 → 등급 색깔로 빛남 (전설은 금빛 + 진동)
  ↓
[결과] 얻은 장비 목록 + 중복은 "🔩 +10" 표시 → [장착하러 가기]
```

- 연출은 **건너뛰기 가능**. 10연은 결과를 한 화면에 모아 보여준다.
- 지나친 사행성 연출(가짜 "거의 당첨" 연출)은 쓰지 않는다.

## 6. 구현 구조

| 클래스 | 역할 |
|---|---|
| `GachaTable` (ScriptableObject) | 상자별 등급 확률, 장비 목록, 천장 횟수. **화면 표시와 추첨이 둘 다 이걸 읽는다** |
| `GachaService` | 추첨, 천장 카운터 관리, 결과를 지갑·인벤토리에 반영 |
| `GachaSave` (저장 데이터) | 전설 천장 카운터와 뽑기 기록. 기록에서 누적 희귀 이상 보장 횟수를 복원 |
| `GachaLog` (저장 데이터) | 언제, 어떤 상자, 무엇이 나왔는지 기록 (고객 문의·검증용) |

**처리 순서 (중요):**
1. 재화 차감 → 2. 추첨 → 3. 결과와 천장 카운터를 **한 번에 저장** → 4. 연출
- 연출 도중 앱이 꺼져도 결과는 이미 저장돼 있어야 한다. 다시 켜면 "받은 장비" 화면을 보여준다.
- 재화만 빠지고 결과가 안 들어가는 일이 없어야 한다.

**보안 (결정 필요 → [Monetization.md 8장](Monetization.md#8-결정-필요)):** 추첨을 휴대폰 안에서만 하면 조작이 가능하다. 출시 때 서버 추첨(Unity Gaming Services의 Cloud Code)으로 할지 정해야 한다.

유물은 `RelicTable`과 `RelicGachaService`를 사용한다. 재화·결과·무료 날짜·보장·로그를 `SaveSystem.Commit`으로 한 번에 저장한다. 기기 안 추첨이며 출시 서버 검증은 기존 과금 8장 범위다.
