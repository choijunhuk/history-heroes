## 1. 이번 기획의 선택

개발자가 정한 것은 **신 vs 인류 구도, 종교 인물 허용, 플레이 가능한 신을 원하는 방향**이다.
아래 신 명단·획득 수치·시련 순서·출시 묶음은 그 방향을 구체화한 **이번 설계안**이다.

| 항목 | 선택 |
|---|---|
| 기존 게임 | 인간 영웅 9명(잔 다르크 포함), 던전 5구간, 보스맵과 기록을 유지 |
| 신 보스 | 5구간 망각의 왕 격파 뒤 **보스맵 안의 별도 난도 ‘신의 시련’**. 기존 보스를 교체하지 않음 |
| 플레이 신 | 토르·아누비스·스사노오·아테나 4명. 제우스는 먼저 보스로만 등장 |
| 희소성 | 실력으로 시련을 열고 장기 과제로 확정 획득. **신·신 조각 뽑기는 만들지 않음** |
| 힘 | 인간과 같은 능력치 범위·성장 한도. 차이는 멈추는 리듬과 전용 기술 |
| 성장 | 기존 영웅 레벨·각성, 장비 6칸, 수련·유물·룬·펫 사용. 별도 신성 성장판 없음 |
| 인간 확장 | 다음 여섯 명은 여자 영웅. 두 명씩 나눠 추가 |
| 참고 경계 | 『종말의 발키리』에서는 ‘신과 인류의 대립’ 구도만 참고. 디자인·줄거리·고유 인물·대사 차용 금지 |

### 기존 문서와의 관계

- 세계관 원본은 [Story](Story.md), 현재 5구간과 보스는 [Content](Content.md), 조작·기록은 [GameDesign 3·7장](../GameDesign.md)이다.
- [Heroes](Heroes.md)의 인간 9명 해금과 던전 10판 무료 선택은 유지한다. 신은 후속 확장의 별도 무료 획득 경로다.
- [Gacha](Gacha.md)의 **장비·유물만 뽑기**, [Monetization](Monetization.md)의 무과금 완주·기록 판매 금지를 따른다.
- 종교 인물 제외라는 예전 일반 원칙은 개발자 최신 결정으로 해제한다. 존중·출처 구분 원칙은 유지한다.
- [Ideas](../Ideas.md)의 여자 몸 부족·잔 다르크 보류 사유는 과거 기록이다. 현재 여성 부품·잔 다르크를 출발점으로 삼는다.

## 2. 이야기 — 신의 판결에 기록으로 답한다

| 요소 | 연결 |
|---|---|
| 망각의 군단 | 기존처럼 시간의 틈에서 기억을 먹는 가상의 적. 신이 만들었다는 설정을 덧붙이지 않음 |
| 신들의 판단 | 일부 신은 전쟁과 파괴가 되풀이되는 인간의 역사가 시간의 틈을 더 벌린다고 판단한다. 역사를 봉인해 망각의 확산을 막으려 한다 |
| 인류의 반론 | 실패를 지워 버리면 배운 것과 서로 지킨 기억도 사라진다. 영웅들은 바뀔 수 있다는 증거를 직접 남긴다 |
| 기록 수호자 | 클리오가 불러낸 영웅들이 맡는 역할명. 별도의 신이나 새 안내자를 추가하지 않음 |
| 클리오 | 기존의 시간의 기록관이자 오리지널 안내자. 역사 뮤즈에서 이름만 빌린 설정을 유지하고, 아테나 등과 혈연을 만들지 않음 |
| 1~5구간 | 망각의 군단에 빼앗긴 역사를 되찾는 기존 여정. 최종 보스는 계속 망각의 왕 |
| 왕 격파 뒤 | 되찾은 기록서를 신들에게 제시한다. 신들은 기록의 진위를 힘과 선택으로 시험하고, 봉인 결정을 보류한다 |
| 시련 승리 | 신을 죽이거나 신앙을 파괴하는 결말이 아님. 그 신이 인간의 가능성을 인정하고 동행할 길을 연다 |

**‘신 vs 인류’는 입장 차이에서 시작한다.** 모든 신을 악으로 묶거나 모든 인간을 선으로 그리지 않는다.
플레이 가능한 신은 봉인 대신 인류와 함께 기억을 지키기로 한 존재다. 다른 신의 시험에도 함께할 수 있다.
시련의 적은 신이 기록서에 비춘 **시험용 형상**이다. 소환 졸개도 기억의 모형이며 실제 망자·민족이 아니다.

### 이야기 노출

| 시점 | 길이·내용 |
|---|---|
| 다음 소규모 업데이트 | 망각의 왕 격파 뒤 클리오의 1장면: 되찾은 역사를 심판하려는 존재가 있다는 예고 |
| 첫 시련 입장 | 최대 3줄, 건너뛰기 가능. 클리오: “이 페이지를 지울지, 우리가 지킬지 보여 줘요.” (게임 창작 대사) |
| 신 동행 | 해당 신의 도감에 판단을 바꾼 이유 한 줄. 기존 망각의 왕 결말을 다시 쓰지 않음 |

정해진 수의 일대일 결투 대진표, 원작과 같은 인물 짝·반전·무기 결합 설정은 사용하지 않는다.

## 3. 신 보스 — 기존 패턴을 쓰는 후속 난도

### 3-1. 입장과 기록

| 항목 | 설계안 |
|---|---|
| 해금 | **기존 5구간 보스맵 망각의 왕을 본인 기록으로 최초 격파**. 기존 진행 조건보다 앞서 열지 않음 |
| 위치 | 보스 선택 화면의 [기존 보스 / 신의 시련]. 별도 큰 모드·6구간 던전은 만들지 않음 |
| 순서 | 토르 → 아누비스 → 제우스 → 스사노오 → 아테나. 앞 시련의 본인 기록 첫 승리로 다음 시련 개방 |
| 한 판 | 기존 원형 보스맵 1개, 목표 2~3분, 기록 1개, 레벨업·새 기록 저장 없음 |
| 사용 영웅 | 본인 기록에 담긴 인간·해금한 신 모두 가능. 신 전용 입장 조건 없음 |
| 기록 | 저장 당시 영웅·장비·성장 스냅샷 사용. 현재 신 해금·강화를 옛 인간 기록에 더하지 않음 |
| 재사용 | 패배해도 기록 유지. 임시 칸 기록도 사용 가능, 잠금은 사용을 막지 않음 |
| 연습·빌린 기록 | 보상·진행·신 조각 없는 연습만. 빌린 신 기록으로 영웅을 해금하지 못함 |
| 입장 비용 | 정식 도전 하트 1. 미격파 시련 패배는 해당 시련당 하루 최대 5회 환급, 연습은 무료 |
| 별·랭킹 | 기존 30별에 합산하지 않고 새 별 보상도 없음. 첫 격파 표식과 칭호만, 새 랭킹 없음 |

보스 형상·이름은 신화에서 가져오되, 아래 공격과 심판 이야기는 **전부 게임 각색**이다.
보스 체력·공격력은 해당 기존 보스의 조정값을 출발점으로 삼고, 고정 배수를 일괄 적용하지 않는다.

### 3-2. 신화와 패턴 배치

| 시련 | 신·기원 | 재사용할 보스·경기장 | 핵심 패턴 한 줄 | 시험하는 기록 |
|---|---|---|---|---|
| 1 | **토르**, 북유럽 신화의 천둥·망치 | 1구간 균열의 수문장 | 망치 내려치기 예고 → 직선 충격파 → 멈춰 쏠 빈틈 | 정지 단일 화력 |
| 2 | **아누비스**, 고대 이집트의 장례·죽은 자 수호 | 2구간 망령 군주 | 기억의 수호병 소환 → 졸개를 줄여 본체 보호를 걷음 | 광역·소환 정리 |
| 3 | **제우스**, 그리스 신화의 하늘·번개 | 3구간 강철 거상 | 번개 모양 탄막을 차례로 발사 → 탄 사이로 이동 후 정지 | 탄 차단·방어 |
| 4 | **스사노오**, 일본 신화, 오로치·검 전승 | 4구간 그림자 쌍둥이 | 같은 신의 두 시험 형상이 따로 움직임 → 열린 쪽에 집중 | 짧은 순간 화력 |
| 5 | **아테나**, 그리스 신화의 지혜·전쟁 | 5구간 망각의 왕 | 창·소환병·탄막을 단계별로 섞고 공격 뒤 빈틈을 줌 | 단일·광역·방어가 갖춰진 빌드 |

- 아누비스의 소환 보호는 기존 졸개당 피해 감소 규칙을 재사용한다. 신을 악신으로 바꾸는 설정은 붙이지 않는다.
- 스사노오의 두 형상은 쌍둥이 신이라는 뜻이 아니다. 그림자 쌍둥이의 기존 두 개체 처치 조건을 그대로 쓴다.
- 아테나의 방패는 외형이다. 영구 무적·투사체 완전 면역을 새로 붙이지 않는다.
- 기존의 체력 단계 전환·기믹은 원형 보스에 이미 있는 것만 쓴다. 새 함정·추가 패턴·새 AI는 첫 묶음에서 제외한다.
- 각 공격 뒤 근접 영웅도 다가가 **기본 공격 1~2회**를 넣을 수 있어야 한다. 단순 탄속 증가로 난도를 올리지 않는다.

### 3-3. 외형과 필요한 소품

현재 Quaternius CC0 몸·옷·휴머노이드 동작을 재사용한다. 몸 비율은 기존 영웅과 같은 슈퍼히어로형이다.
‘신답게’ 보이는 차이는 색, 머리 실루엣, 손 소품 한두 개로 낸다. 거대화해도 판정·예고선 범위를 가리지 않는다.

| 신 | 현재 부품으로 조립할 모습 | 새로 필요한 것 |
|---|---|---|
| 토르 | 남자 머리·`Male_Ranger`, 긴 머리·수염, 짙은 회색과 구리색 옷 | **망치 메시 1개**. 날개 투구·새 망토는 제외 |
| 아누비스 | 남자 머리를 숨긴 `Male_Ranger`, 검정·금색 옷, `Enemy_Staff` 지팡이 재사용 | **자칼 가면 1개**. 동물 몸·새 뼈대 불필요 |
| 제우스 | 남자 머리·`Male_Peasant`, 긴 흰 머리·수염, 흰색·청동색 옷 | 필수 새 소품 없음. 기존 번개 효과를 손 앞에 배치, 새 긴 로브 제외 |
| 스사노오 | 남자 머리·`Male_Ranger`, 긴 묶음머리처럼 배치한 기존 긴 머리, 청록·남색 옷 | **단순 검 메시 1개**. 기존 검 공격 동작 사용, 전용 투구 제외 |
| 아테나 | 여자 머리·`Female_Ranger`, 묶음머리, 청동·상아색 갑옷, `Enemy_TowerShield` 축소 재사용 | **창 1개·단순 투구 1개**. 새 치마·긴 천 시뮬레이션 제외 |

`Superhero_Male_FullBody`·`Superhero_Female_FullBody`는 머리·피부 조립의 기반이며, 위 옷과 별도다.
검·창·망치는 공격 애니메이션만 있다고 모델까지 있는 것으로 계산하지 않는다.
적 소품을 영웅 손에 옮길 때 위치·크기·여자 손 연결을 확인한다. 보스와 플레이 신은 같은 부품을 공유한다.

## 4. 플레이 가능한 신

### 4-1. 획득 — 유료 뽑기 대신 오래 남는 목표

| 단계 | 설계안 |
|---|---|
| ① 증명 | 해당 신의 시련을 본인 기록으로 처음 깨면 **그 신의 영웅 조각 10개**, 계정당 1회 |
| ② 주간 목표 선택 | 개방된 시련의 미해금 신 중 1명을 고름. 그 신을 **서로 다른 본인 기록 2개**로 격파하면 조각 5개 |
| ③ 주간 상한 | 모든 신 합쳐 **주 5개**. 첫 승리 전까지 목표 변경 가능, 첫 승리 뒤에는 그 주 목표 고정 |
| ④ 확정 해금 | 해당 신 조각 **30개를 소비**해 Lv1 ★1로 해금. 첫 10개 + 주간 보상 4회, 약 3~4주 |
| ⑤ 이후 성장 | 해금 후 그 신의 해금용 주간 목표·첫 격파 조각 지급은 종료. 각성은 기존 영웅 조각 획득처 이용 |

- ‘서로 다른 기록’은 [Modes 3-3](Modes.md#3-3-보스맵-별-조건)처럼 ID가 다르고 액티브·조합 구성이 2개 이상 달라야 한다.
- 첫 격파 승리는 같은 주의 목표 선택 후 이겼다면 주간 승리 1회로도 센다. 보상은 첫 격파 10개와 과제 5개로 구분한다.
- 월요일 **한국 시간 05:00**에 주간 승리·수령 여부만 초기화한다. 받은 조각·해금·시련 개방은 사라지지 않는다.
- 기간 한정·연속 출석 조건 없음. 쉬었다 돌아와도 이어 모은다. 4명 모두 해금하려면 주간 보상 총 16회가 필요하다.
- ‘신 조각’은 별도 지갑 재화가 아니라 **기존 영웅별 조각의 표시 이름**이다. 미해금 때 30개, 해금 후 각성 150개는 별도 비용이다.
- 해금 전 신 조각은 골드 상점·미션 랜덤 조각·패키지·일일 도전 보상 대상에서 제외한다. 수집 상한 30개이며 초과 지급하지 않는다.
- 해금 후에는 골드 상점 하루 3개(모든 영웅 합산), 각성 비용 10/20/40/80, 기존 영웅 보상 규칙을 따른다. 신이라 더 많은 조각을 팔지 않는다.
- 신 즉시 해금 상품·보석 해금·유료 조각·광고 배수는 두지 않는다. 한정 꾸미기는 나중에 확정 구매만 검토한다.

**신 뽑기를 고르지 않은 이유:** 현재 영웅 뽑기 금지와 충돌하고, 유물 뽑기와 보석을 두고 경쟁하기 때문이다.
장비·유물 뽑기의 확률·천장·중복 보상을 건드리지 않는다. 이번 설계에 신의 확률표가 따로 생기지 않는다.
장차 뽑기로 바꾸려면 과금 원칙부터 다시 결정하고, 개별·조건별 확률·천장·중복·비용 공개까지 별도 기획해야 한다.

### 4-3. 첫 네 후보의 기술

모두 대표 효과 1개·전용 액티브 1개·전용 진화 1개다. 아래 이름·효과는 신화 사실이 아닌 게임 창작이다.
전용 액티브는 인간과 같은 희귀 등급 Lv1~5·기록 비용 레벨당 3pt이며, 해당 영웅에게만 등장한다. 첫 판 첫 카드의 기존 전용 스킬 보장을 따른다.
진화는 전용 액티브 Lv5 + 표의 기존 패시브 Lv1 이상. 액티브를 대체하고 패시브는 남는다.
진화 결과는 레벨 없이 고정, 저장 10pt + 패시브 비용 별도라는 공통 시작값을 둔다. 재료 재획득·연쇄 조합은 금지한다.

| 신·직업 | 멈춰서 쓰는 기본 공격 | 대표 효과 한 줄 | 자동 액티브 한 줄 | 전용 진화 한 줄 |
|---|---|---|---|---|
| **토르·전사** | 짧은 부채꼴 망치 | **천둥의 무게**: 정지 기본 공격 3회째에 작은 충격파, 이동하면 횟수 초기화 | **귀환 망치**: 8초마다 앞쪽으로 망치를 보내고 되돌려 두 차례 타격 | **천둥의 귀환**: 귀환 망치 + 공격속도 → 귀환 지점에 좁은 낙뢰 1회 |
| **아누비스·법사** | 직선 모래 구체 | **저울의 표식**: 같은 적에 기본 공격 3회 명중 후 다음 기본 공격이 짧게 둔화 | **모래 수호상**: 9초마다 수호상 1기가 4초간 주변 적을 느리게 함, 직접 피해 없음 | **모래의 문**: 모래 수호상 + 최대체력 → 수호상 범위를 넓히고 적 진입 때 작은 모래 파동 1회 |
| **스사노오·전사** | 좁은 검 베기 | **바람의 간격**: 멈춘 뒤 첫 베기는 넓고 약하게, 연속 두 번째부터 좁고 강하게; 이동 시 초기화 | **바람 베기**: 7초마다 직선 검기 1줄, 적을 조금 밀어냄 | **폭풍의 길**: 바람 베기 + 관통 → 같은 방향 검기 3번, 길 밖의 적에는 닿지 않음 |
| **아테나·전사** | 짧은 직선 창 찌르기 | **판단의 방패**: 1초 정지하면 다음 적 탄 1발 차단, 이동 시 해제·재사용 8초 | **올빼미의 눈**: 10초마다 가까운 적 1체에 3초 표식, 그 적에 대한 기본 공격 명중 때 작은 추가 피해 | **수호자의 시선**: 올빼미의 눈 + 방어력 → 표식이 최대 3체, 기본 공격으로만 추가 피해 발동 |

- 토르의 충격파·아테나의 표식 추가 피해는 기본 공격에서만 파생한다. 연쇄·멀티샷으로 대표 효과 횟수를 다시 쌓지 않는다.
- 아누비스의 표식은 1체, 둔화는 최대 1초·같은 대상 재발동 간격 6초. 보스 둔화 세기는 일반 적의 30%로 시작한다.
- 아테나의 정지 준비는 이동 시 취소하고, 차단 성공부터 8초를 센다. 연속 정지로 방패를 무한 재충전하지 않는다.
- 신의 방어 효과도 기존 피해 감소·차단 상한에 포함한다. 완전 무적이나 공격을 지우는 광역 상시 방패는 없다.
- 숫자는 검증 전 시작값이다. 인간의 같은 역할보다 일괄 우월하면 수치·범위·재사용 시간을 줄인다.

제우스·포세이돈·시바·아폴론·오딘·헤라클레스는 이후 후보로 남긴다.
제우스는 테슬라와, 포세이돈은 광역 법사와 역할이 겹치므로 먼저 네 명의 차이를 확인한다.
시바의 팔·춤·상징, 헤라클레스의 영웅/신격 전승 차이는 출전과 제작 범위를 따로 정한 뒤 진행한다.

## 6. 도입 순서와 경제

S = 기존 화면·문구·재질 중심, M = 캐릭터 1명이나 패턴 재사용 1종, L = 획득·저장·기록·화면까지 연결하는 묶음.
★는 체감 가치이며 ★★★가 가장 높다. 공수·가치는 기획 추정이고 구현 완료 표시가 아니다.

| **다음 소규모 업데이트** | 왕 격파 뒤 예고 1장면·신화/각색 도감 표기·여자 영웅 A(선덕여왕·부디카) | S + M×2 | ★★★ | 기존 9명·장비 6칸·유물 뽑기의 남은 검증과 출시 필수 작업을 먼저 끝냄 |

| **출시 후 2차** | 아누비스·제우스 시련, 플레이 아누비스, 여자 영웅 B | L | ★★★ | 소환형·탄막형에서 실제로 다른 기록을 선택 |
| **출시 후 3차** | 스사노오·아테나 시련과 동행, 여자 영웅 C | L | ★★ | 두 개체전·복합전과 인간/신 균형 통과 |
| **그 이후** | 부처·아담 상세 설계, 추가 신·확정 구매 스킨 검토 | M~L | ★★ | 출전·묘사·새 소품 검토, 역할 중복 없음 |

‘다음 업데이트’는 이 기획 기준의 제안 순서다. 기존 로드맵을 건너뛰는 구현 지시가 아니다.
보스 러시는 기존 v1.1 계획대로 별도이며, 신의 시련 5종을 한꺼번에 먼저 만들지 않는다.

| 반복 골드 | 기존 보스맵의 300골드·하루 3회 보상 한도를 **기존 보스와 시련 합산**. 별도 일일 수입원으로 늘리지 않음 |
| 주간 조각 | 해금용 총 5개/주, 무작위 아님. 해금 후 각성 조각 수입은 기존 배분 안에서 선택, 추가 전용 보상 없음 |
| 유물 뽑기 | 24종 확률·가격·무료·천장 유지. 새 인간·신 첫 클리어에 새 유물을 자동 추가하지 않음 |
| 성장 비용 | 인간·신 모두 Lv30 골드 87,000, ★5 조각 150. 늘어난 인원만큼 수집 완성 비용 증가 |

인간 6명 + 신 4명의 추가 최대 성장 비용은 **골드 870,000·각성 조각 1,500개**, 별도로 신 해금 조각 120개다.
골드 870,000은 하루 10,100 기준 약 86일치이나 다른 지출을 무시한 값이다. 전원 완성 기간으로 쓰지 않는다.
경제 원본은 아직 8영웅 기준 계산이 남아 있다. 잔 다르크까지 포함한 9명 → 15명 → 신 4명 순서로 실제 수입·상점 배분을 다시 계산해야 한다.
전원 소유·전원 각성 보너스는 없고, 주력 인간 하나로도 진행할 수 있어야 한다. 상점 조각 한도를 이 문서만으로 올리지 않는다.

## 7. 위험과 출시 전 확인

| 위험 | 대응·통과 기준 |
|---|---|
| 신이 인간의 상위 호환 | 같은 성장·같은 빌드·같은 보스에서 처치 시간·피격·생존 비교. 인간보다 모든 상황에서 우세한 신은 출시 보류 |
| 멈추지 않아도 됨 | 보스 기본 공격 피해 비중 약 40% 이상, 서바이벌 약 30%. 빈틈마다 정지가 이동만보다 보스 처치 약 30% 이상 빠른지 확인 |
| 시련이 수치만 센 복사본 | 기존 패턴의 예고·안전 구역 유지. 단일·광역·방어 기록 3종이 서로 다른 시련에서 유리한지 검증 |
| 신이 없으면 못 깸 | 인간 9명 각각 일반·희귀+조합 기록으로 모든 시련 격파 가능. 신/전설 요구 문구·강제 상성 없음 |
| 기록·보상 오류 | 임시·잠금·옛 인간 기록, 신 기록 저장/복원, 패배 재사용, 앱 종료 중 보상·주간 경계·30개 중복 해금 검사 |
| 아트 비용 폭증 | 첫 토르는 망치 1개부터. 보스/동행 모델 공유, 새 몸·탈것·다중 팔·긴 옷 물리 제외. 여자 손 소품 위치 별도 확인 |
| 전투가 안 보임 | 아군 효과는 적 예고선보다 옅게. 번개·모래로 바닥을 덮지 않고 저사양 폰에서 시련·서바이벌 성능 확인 |
| 종교·문화 민감성 | 개발자는 등장 위험을 수용했다. 비하·개종·신앙의 우열·실제 신자 공격 금지, 출전/전승/각색을 구분 |
| 다른 작품과 유사 | 신화 원전·공공 소장품에서 상징을 확인하고 독립 디자인. 특정 작품의 의상 배색·얼굴·구도·대사·장면 재현 금지 |
| 장기 목표가 숙제화 | 일일 전용 과제 없음, 기한·연속 출석 없음. 기본 모드 보상은 그대로 얻고 시련은 선택적으로 도전 |

확인은 향후 구현의 통과 기준이며 **이 문서 작성으로 통과한 것이 아니다**.
각 묶음 구현 전 해당 Heroes/Skills/Story/Content/Modes/Economy 문서에 확정 세부안을 옮기고 시스템 지도 상태를 갱신한다.
