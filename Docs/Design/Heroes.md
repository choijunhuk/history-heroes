## 1. 공통 규칙
- 모든 영웅은 **"기본 공격은 멈춰야 나간다"**를 지킨다.
- 영웅마다 **대표 효과 1개 + 전용 액티브 1개 + 전용 조합 1개**가 있다.
- 기준 능력치: 체력 1,000 / 공격력 100 / 공격속도 1.0 (초당 1회) / 사거리 6 / 이동속도 5
- 해금: **진행으로 무료 해금**하거나 💎 1,500 / 영웅 패키지로 바로 해금. **영웅 뽑기는 없다.**

## 3. 🏹 칭기즈 칸 — 궁수 (입문 영웅)

> 📜 **사실:** 몽골 제국의 건국자. 몽골 기병은 말 위에서 활을 쏘는 기마궁수로 유명했다.
> 🎮 **각색:** 멈추는 순간 바로 쏘는 속사.

| 항목 | 내용 |
|---|---|
| 기본 공격 | 화살 1발, 단일 대상, 빠른 탄속 |
| **대표 효과: 기마 속사** | 멈추는 순간 **공격 준비 시간 0**. 첫 발은 피해 +50% |
| **전용 액티브: 만궁 연사** | 5초마다 부채꼴로 화살 5발 (Lv마다 +1발) |
| **전용 조합: 천호의 화살비** (진화) | 만궁 연사 Lv5 + 공격속도 → 부채꼴 화살이 2번 연속 |
| 플레이 감각 | "멈칫멈칫" 짧게 서면서 계속 쏘는 리듬 |

---

## 4. ⚔️ 관우 — 전사 (고수용)

> 📜 **사실:** 중국 삼국시대 촉나라 장수. 청룡언월도와 의리의 상징.
> 📖 **전승:** 『삼국지연의』의 "오관참장" (다섯 관문을 지나며 장수 여섯을 벰).
> 🎮 **각색:** 회전 베기, 연속 베기.

| 항목 | 내용 |
|---|---|
| 기본 공격 | 근접 부채꼴 베기 (120°), 맞은 적 전부에게 피해 |
| **대표 효과: 의리의 투지** | 받는 피해 -15%. 체력이 50% 아래면 공격력 +20% |
| **전용 액티브: 청룡 회전 베기** | 6초마다 제자리 회전 베기 (주변 전체) |
| **전용 조합: 오관참장** (진화) | 청룡 회전 베기 Lv5 + 방어력 → 회전 베기가 **5번 연속**, 회전 중 받는 피해 -50% |
| 플레이 감각 | **다가가서 멈추는** 위험한 플레이. 근접이라 "멈추면 쏜다"의 긴장감이 가장 크다 |
| 주의 | 원거리 보스에서 너무 불리하지 않게 보스 패턴에 "다가갈 틈"을 둔다 |

---

## 5. 💥 나폴레옹 — 총잡이

> 📜 **사실:** 프랑스 황제. 포병 장교 출신으로 포병 운용에 뛰어났다.
> 🎮 **각색:** 머스킷 연사와 대포 포격.

| 항목 | 내용 |
|---|---|
| 기본 공격 | 총알, 빠른 연사, 맞은 적을 살짝 밀어냄 |
| **대표 효과: 포병의 눈** | 기본 공격 3발마다 **포탄** (범위 피해 100%, 반지름 1.5). v0.3 벤치: 보스에 너무 강하고 잡몹엔 보통이라 총알을 약하게, 포탄을 넓게 ([v0.3-Validation](../Dev/v0.3-Validation.md)) |
| **전용 액티브: 대포 포격** | 7초마다 가장 적이 많은 곳에 포탄 3발 |
| **전용 조합: 아우스터리츠의 포화** (합체) | 대포 포격 Lv3+ + 불꽃 장판 Lv3+ → 포탄이 떨어진 자리에 불꽃 장판 |
| 플레이 감각 | 연사로 밀어내면서 몰린 적을 포탄으로 정리 |

---

## 6. ⚡ 니콜라 테슬라 — 법사

> 📜 **사실:** 교류 전기 시스템을 발전시킨 발명가. 무선 송전을 꿈꾸며 워든클리프 탑을 지었다.
> 🎮 **각색:** 과학을 마법처럼. 번개와 코일.

| 항목 | 내용 |
|---|---|
| 기본 공격 | 전기 구체, 맞으면 근처 적 1명에게 **튕김** |
| **대표 효과: 교류** | 기본 공격 튕김 +1 (총 2번) |
| **전용 액티브: 테슬라 코일** | 8초마다 코일 설치 (5초간 주변 적에게 번개) |
| **전용 조합: 워든클리프 탑** (합체) | 테슬라 코일 Lv3+ + 낙뢰 Lv3+ → 거대한 탑 설치, 화면의 적 전체에 주기적으로 번개 |
| 플레이 감각 | 코일을 깔아두고 그 주변에서 싸우는 **자리 잡기** 플레이 |

## 6-1. 🐢 이순신 — 총잡이 (수호 포수, 확장 결정 12: 새 영웅 첫째, 2026-10-28)

> 📜 **사실:** 조선 수군의 장수. 판옥선·거북선을 운용했고 학익진으로 알려져 있다. 진중에서 일기를 남겼다.
> 🎮 **각색:** 적은 가상의 망각의 군단 — 특정 나라와 싸우는 구도·대사는 쓰지 않는다 (GameDesign 4장 인물 관리).

| 항목 | 내용 |
|---|---|
| 기본 공격 | 총통 포탄 (느리고 무거움, 작은 밀어냄) |
| **대표 효과: 철갑** | 멈춰 있는 동안 받는 피해 -25%. 막은 피해(받은 피해 × 25/75)의 절반을 쌓아 **다음 기본 공격에 더한다** (상한 공격력 200%). 움직이면 쌓인 것이 2초에 걸쳐 사라진다. ★3 멈춤 받는 피해 -30% · ★5 쌓기 상한 300% |
| **전용 액티브: 거북선 돌격** (불) | 8초마다 가까운 적 쪽으로 거북선이 곧게 돌진 — 지나간 적 150% (레벨마다 +30%) + 밀어냄, 벽에 닿으면 멈춘다 |
| **전용 조합: 학익진** (진화) | 거북선 돌격 Lv5 + 최대체력 → 거북선 3척이 V자(학의 날개)로 돌격 (각 180%) + 지나간 자리 불길 2초 |
| 플레이 감각 | **멈춰 서서 맞으며 버티다, 쌓인 힘을 포탄 한 방에** — "멈춤"을 방어로 보상하는 첫 영웅 |
| 3D | 짙은 남색 옷 + 수염 + 조선 장군 투구 · 두정갑 가슴판 · 총통 (블렌더), 스킬용 작은 거북선, 동작 = 권총 쏘기 |
| 대사 | "죽고자 하면 살 것이다." · "아직 열두 척이 남았다!" · "나의 죽음을… 알리지 마라." |

## 6-2. 🎯 이성계 — 궁수 (명궁, 모으기 저격형, 2026-10-28)

> 📜 **사실:** 고려 말의 장수. 활 솜씨 일화가 많다. 🎮 왕이 된 뒤의 정치 이야기는 다루지 않고 장수 시절만.

| 항목 | 내용 |
|---|---|
| 능력치 | 체력 950 · 공격력 120 · 사거리 7 · 이동 5 · 5구간 보스 격파로 해금 |
| 기본 공격 | 큰 화살. **공격속도 대신 모으는 시간** (공격속도가 빠르면 빨리 모은다) |
| **대표 효과: 백발백중** | 멈춘 시간만큼 모인다: 0.4초 1단 · 0.9초 2단(관통, 피해 ×1.4) · 1.5초 3단(관통 + 치명타 확정 + 피해 ×2.5, **바로 발사**). 1·2단은 움직이기 시작할 때 놓는다. ★3 3단 ×3 · ★5 3단까지 1.2초 |
| **전용 액티브: 편전** | 5초마다 아주 빠른 작은 화살 3발(레벨마다 +1)이 화면에서 체력이 가장 많은 적에게 (각 60%) |
| **전용 조합: 신궁** (진화) | 편전 Lv5 + 치명타 피해 → 7발, 맞은 적에게 표식 6초: 다음 3단 화살 피해 +100% |
| 플레이 감각 | 칭기즈 칸 = 짧게 자주, 이성계 = **길게 멈춰 한 방** |

---

## 6-3. 🛠️ 레오나르도 다빈치 — 소환사 (발명가, 2026-10-28)

> 📜 **사실:** 화가·발명가. 비행 기계와 장갑 전차를 스케치했다. 🎮 **각색:** 실제로 만들지는 않았지만 게임에서는 조립해서 띄운다.

| 항목 | 내용 |
|---|---|
| 능력치 | 체력 900 · 공격력 70 · 공속 1.0 · 사거리 5 · 보석 2,000으로 해금 |
| 기본 공격 | 작은 석궁 화살 |
| **대표 효과: 작업대** | 멈춰 있는 1초마다 부품 1개, 3개면 **비행 기계** 조립 (최대 2대, 20초). 비행 기계는 **영웅이 멈춰 있을 때만** 같은 적을 쏜다 (공격력 35%, 기본 공격 종류). 움직이면 만들던 부품만 처음부터 (모은 부품은 남는다). ★3 한 발 50% · ★5 최대 3대 |
| **전용 액티브: 장갑 전차** | 9초마다 원뿔 전차가 6초(레벨마다 +1초) 동안 영웅 둘레를 돌며 0.6초마다 사방 8갈래 (각 30%) |
| **전용 조합: 나선 비행기** (합체) | 장갑 전차 Lv3+ + 회오리 Lv3+ → 전차가 떠올라 8초, 사방 8갈래 (각 35%) + 반경 2.4 적을 가운데로 끌며 초당 50% |
| 플레이 감각 | 멈춰서 기계를 모으고 **같이 쏘는** 공방 |

## 6-4. 🪶 제갈량 — 법사 (책사, 조종형, 2026-10-28)

> 📜 **사실:** 촉한의 승상·전략가. 🎮 **전승:** 팔진도·동남풍은 『삼국지연의』의 이야기 (각색 표시).

| 항목 | 내용 |
|---|---|
| 능력치 | 체력 900 · 공격력 85 · 공속 1.0 · 사거리 4.5 · 보석 2,000으로 해금 |
| 기본 공격 | 깃털 부채 바람 **3갈래** (각 45%, 짧게 날아감, 살짝 밀어냄) |
| **대표 효과: 동남풍** | 멈춰 있는 동안 내 둘레 반경 3 안의 **적 탄이 40% 느려진다**. ★3 반경 4 · ★5 55% |
| **전용 액티브: 팔진도** | 10초마다 돌기둥 8개 진을 4초(레벨마다 +0.5초): 돌기둥에 닿는 적 탄은 사라지고, 진 안에 든 적은 1초 헤맨다 (적마다 한 번). 돌기둥은 몸·내 탄을 막지 않는다 |
| **전용 조합: 칠성단의 바람** (합체) | 팔진도 Lv3+ + 회오리 Lv3+ → 진 안에 회오리 3개가 돌며 적을 가운데로 모으고 초당 40% (5초) |
| 플레이 감각 | 탄막 보스(강철 거상)에서 **멈출 용기**를 주는 영웅 |

> 잔 다르크(기수)는 무료 묶음에 여자 몸 부품이 없어서 뒤로 미룬다 (Ideas.md).
