## 1. 설계 원칙

| 원칙 | 내용 |
|---|---|
| **돈·광고를 요구하는 미션 금지** | "결제하기", "광고 보기", "보석으로 상자 열기" 같은 미션은 없다 |
| **다양하게 놀게 만든다** | 다른 영웅 쓰기, 조합 발견하기, 전설 없이 클리어하기, 다른 모드 해보기 |
| **하루 15~20분이면 일일 미션 끝** | 미션이 숙제가 되면 안 된다. 30분 플레이 기준이면 넉넉히 다 끝난다 |
| **못 해도 크게 손해 보지 않는다** | 출석은 연속이 끊겨도 초기화되지 않는다. 주간 미션은 주말에 몰아서 해도 된다 |
| **기록 용량은 보석으로 팔지도 주지도 않는다** | 기록 용량은 🪙 + 🏺로만 올린다. 미션·시즌 패스·업적 어디에도 "기록 용량 보석 구매/보상"은 없다 |
| **시간 압박 없음** | "3시간 남음!" 같은 알림으로 재촉하지 않는다. 남은 시간은 조용히 표시만 |

## 2. 일일 미션

### 2-1. 구성: 고정 2개 + 그날의 미션 4개 = 6개

| 구분 | 미션 | 활동 포인트 |
|---|---|---|
| 고정 | 게임 접속 | 10 |
| 고정 | **아무 모드나 2판 플레이** (던전·보스맵·서바이벌·무한의 균열·일일 도전, 사망해도 인정) | 20 |
| 랜덤 4개 | 아래 풀에서 하루 4개 | 기준 15~20 → **자동 조정되어 4개 합계가 항상 70** |
| **합계** | | **항상 정확히 100** |

- **특정 모드에서만 되는 랜덤 미션은 요일에 묶는다** ([Economy 4-1 주간 시간표](Economy.md)와 같은 요일 구성, Codex 6·7차):

  | 요일 | 나올 수 있는 모드 전용 미션 (하루 최대 1개) |
  |---|---|
  | 월~금 | 보스맵 도전, 일일 도전, 오늘의 영웅으로 던전 1판, 기록 1개 저장하기 |
  | 토 | 서바이벌 5분 이상 생존, 보스맵 도전, 일일 도전, 기록 1개 저장하기 |
  | 일 | 무한의 균열 5층 이상, 보스맵 도전, 일일 도전 |

  (기록 저장은 던전을 끝내야 할 수 있어서 던전이 있는 요일에만 나온다)

  나머지 랜덤 미션은 **어느 모드에서든 진행된다** (예: 적 300마리 처치, 조합 1개 만들기). → 시간표대로만 해도 **매일 100점**을 채울 수 있다.
- 하루 1회 무료 교체도 **그 요일에 나올 수 있는 미션 안에서만** 바뀐다.
- 아래 풀의 포인트는 "기준값"이다. 그날 뽑힌 4개의 합이 70이 아니면 비율대로 늘리거나 줄이고 5포인트 단위로 맞춘 뒤, 남는 차이는 가장 큰 미션에 더한다. → 어떤 조합이 뽑혀도 **하루 합계는 항상 100**이라 상자 구간(20/40/60/80/100)과 시즌 패스 경험치가 흔들리지 않는다.

### 2-2. 랜덤 미션 풀 (출시 때 16개)

| 분류 | 미션 | 포인트 | 노리는 것 |
|---|---|---|---|
| 전투 | 엘리트 3마리 처치 | 15 | 모든 요일 시간표에서 가능 (평일 던전 2판 = 4마리, 일 무한 20층 = 3마리 이상) |
| 전투 | 적 300마리 처치 | 15 | |
| 전투 | 피격 없이 방 3개 클리어 | 20 | 피하기 실력 |
| 전투 | 기본 공격으로 적 150마리 처치 | 15 | **멈추면 쏜다** |
| 빌드 | 조합 스킬 1개 만들기 | 20 | 조합 시스템 |
| 빌드 | 액티브 스킬 3개를 Lv3 이상으로 | 15 | |
| 빌드 | 패시브 4칸을 다 채우기 | 15 | |
| 영웅 | 오늘의 영웅으로 던전 1판 (매일 바뀜) | 20 | 여러 영웅 쓰기 |
| 영웅 | 영웅 레벨업 1회 (골드) | 15 | 골드 쓰기 |
| 모드 | 보스맵 도전 1회 (져도 인정) | 20 | 기록 시스템 |
| 모드 | 서바이벌 5분 이상 생존 | 20 | 서바이벌 |
| 모드 | 무한의 균열 5층 이상 | 20 | |
| 모드 | 일일 도전 공식 도전 1회 | 15 | |
| 기록 | 기록 1개 저장하기 | 15 | |
| 성장 | 장비 1개 장착 바꾸기 | 15 | |
| 도감 | 도감에서 영웅 이야기 1개 읽기 | 15 | 역사 테마 |

- 아직 열리지 않은 모드·기능의 미션은 풀에서 빠지고, **해금된 다른 미션으로 대신 채워진다.** (예: 서바이벌은 2구간 보스 격파 전, 일일 도전·무한의 균열은 3구간 보스 격파 전, 장비 미션은 1구간 보스 격파 전에는 안 나옴. 포인트 합계는 그대로 100)
- **대체 규칙 (미션 목록을 만드는 05:00에 적용, 한낮에 바뀌지 않는다):**
  - (a) 아직 해금하지 못한 영웅이 이름에 들어간 미션은 **"아무 영웅으로 같은 조건"**으로 바뀐다.
  - (b) 성장 미션의 대상이 이미 끝까지 올라가 있으면 (예: 장비 강화 - 모든 슬롯이 최대, 수련 - 전부 최대) **"골드 5,000 모으기"**로 바뀐다. 포인트는 그대로.
  - (c) 위 교체는 매일 **05:00에 미션 목록을 만들 때** 한 번만 한다. 하루 중에 해금·성장 상태가 바뀌어도 그날 목록은 그대로다.
- 하루에 1번 무료로 **미션 1개 바꾸기** 가능.
- 초기화: 매일 05:00 (한국 시간, 모든 문서 공통)

### 2-3. 활동 포인트 상자

| 포인트 | 보상 |
|---|---|
| 20 | 🪙 200 |
| 40 | 🪙 200 + 💎 10 |
| 60 | 🪙 300 + 💎 15 |
| 80 | 🪙 300 + 🔩 3 |
| 100 | 💎 25 + 🏺 5 |
| **하루 합계** | **🪙 1,000, 💎 50, 🔩 3, 🏺 5** |

- 활동 포인트 1 = **시즌 패스 경험치 1** (하루 최대 100). 시즌 패스를 열기 전(2구간 보스 격파 전)에도 **경험치는 숨겨진 채로 첫날부터 쌓인다.** ([8-1](#8-1-경험치))

## 3. 주간 미션

### 3-1. 미션 6개 (각 20 주간 포인트, 합계 120)

| 미션 | 노리는 것 |
|---|---|
| 일일 미션 상자(100포인트)를 4일 열기 | 꾸준함 (7일 중 4일이면 됨) |

| 서바이벌 또는 무한의 균열 합계 20분 플레이 (아직 둘 다 안 열렸으면 "던전 3판 추가 클리어"로 대체) | 다른 모드 |

| 주간 포인트 | 보상 |
|---|---|

- 주간 미션 하나 완료 = **시즌 패스 경험치 100** (주 최대 600)

## 4. 월간 미션 → 따로 두지 않는다 (추천)

- **이유:** 시즌 패스가 28일 단위라서, 월간 미션을 따로 두면 같은 일을 두 번 세는 셈이고 화면만 복잡해진다.
- **대신 "시즌 도전"**이 그 역할을 한다. 시즌(28일)마다 큰 목표 8개.

### 4-1. 시즌 도전 (시즌마다 8개, 예시)

| 시즌 도전 | 패스 경험치 |
|---|---|
| 4명의 영웅으로 각각 던전 클리어 | 100 |
| 조합 스킬 10번 만들기 | 100 |
| 아무 구간에서 ★ 3개 새로 따기 | 100 |
| 무한의 균열 30층 도달 (시즌 중 아무 주) | 100 |
| 서바이벌 10분 생존 2회 | 100 |
| 서로 다른 기록으로 보스 3번 격파 | 100 |
| 일일 도전 공식 도전 10일 참여 | 100 |
| 기본 공격으로 적 5,000마리 처치 | 100 |
| **합계** | **800** |

- 해금되지 않은 모드의 도전은 해금된 다른 도전으로 바뀐다.
- 시즌 도전 진행도도 시즌 패스를 열기 전부터 숨겨진 채로 쌓인다.

## 5. 출석부

### 5-1. 7일 반복 (연속 아님, **출석한 날 수**로 센다)

| 출석 일차 | 보상 |
|---|---|
| 1~6일째 | 🪙 500 + 💎 50 |
| 7일째 | 🪙 500 + 💎 50 + 🎫 1 |

- 하루 빠져도 처음으로 돌아가지 않는다. 다음 접속 때 다음 칸을 받는다.

### 5-2. 28일 누적 보너스 (시즌 기간 안에서)

| 누적 출석 | 보상 |
|---|---|
| 14일 | 🔩 20 |
| 28일 | 🔩 40 + 칭호 "꾸준한 수호자" (시즌마다 색이 다름) |

- 14일 + 28일 = 🔩 60 → 한 달 꾸준히 하면 **원하는 희귀 장비 1개 확정 교환** ([Gacha 3장](Gacha.md#3-중복과-조각))

## 6. 신규 유저 7일 미션

처음 7일 동안 **하루에 한 칸씩 열린다.** 날짜가 지나도 이전 칸은 계속 할 수 있다 (14일 안에).

| 일차 | 미션 (각 3~4개) | 그날 보상 합계 |
|---|---|---|
| 1 | 튜토리얼 끝내기 / 1구간 던전 클리어 / 첫 기록 저장 / 1구간 보스 격파 | 💎 100 + 🪙 3,000 |
| 2 | 장비 3칸 채우기 / 관우로 던전 1판 / 조합 1번 만들기 | 💎 80 + 🪙 3,000 |
| 3 | 2구간 던전 클리어 / 영웅 Lv5 달성 / 장비 강화 1회 | 💎 80 + 🎫 1 |
| 4 | 2구간 보스 격파 / 기록 2개 보유 / 일일 미션 상자 100 열기 | 💎 80 + 🪙 4,000 |
| 5 | 나폴레옹으로 던전 1판 / 룬 장착 / 서바이벌 3분 생존 / 피격 10회 이하로 던전 클리어 | 💎 80 + 🔩 20 |
| 6 | 3구간 던전 클리어 / 수련 1회 / 서로 다른 조합 2개 발견 | 💎 80 + 🪙 5,000 |
| 7 | 3구간 보스 격파 / 일일 도전 참여 / 영웅 Lv10 달성 / 별 6개 모으기 | 💎 100 + 🎫 1 |
| **전부 완료 보너스** | | 💎 100 + 🎫 3 + 🔩 40 |
| **7일 총합 (1회성)** | | **💎 700, 🎫 5, 🪙 15,000, 🔩 60** |

- **해금 순서에 맞춘다:** 서바이벌 미션은 5일차(2구간 보스 이후), 일일 도전 미션은 7일차(3구간 보스 이후)에 둔다. 느리게 진행해서 아직 해금 못 한 모드의 미션은 "던전 클리어" 같은 해금된 대체 미션으로 바뀐다 (보상은 그대로).
- 미션 순서가 그대로 **진행 가이드**가 된다. 처음 일주일에 해야 할 것을 자연스럽게 알려준다.

## 7. 업적 (영구, 1회성)

| 분류 | 업적 (단계) | 보상 (단계별) |
|---|---|---|
| **진행** | 구간 정복: 1 / 2 / 3 / 4 / 5구간 보스 격파 | 💎 50씩 |
| **진행** | 별 수집가: 별 10 / 20 / 30개 | 💎 50 / 100 / 150 |
| **전투** | 멈춤의 달인: 기본 공격으로 처치 1,000 / 10,000 / 50,000 | 💎 30 / 80 / 150 + 칭호 |
| **전투** | 그림자처럼: 피격 0으로 방 클리어 10 / 50 / 200회 | 💎 30 / 80 / 150 |
| **전투** | 엘리트 사냥꾼: 엘리트 처치 50 / 300 / 1,000 | 💎 20 / 50 / 100 |
| **빌드** | 조합 연구가: 조합 발견 1 / 3 / 6 / 전부 | 💎 30 / 60 / 100 / 200 + 칭호 |
| **빌드** | 전설의 순간: 전설 스킬 처음 획득 | 💎 50 |
| **빌드** | 전설 없이도: 전설 없이 구간 클리어 1 / 3 / 5구간 | 💎 50 / 100 / 150 |
| **영웅** | 드림팀: 영웅 2 / 3 / 4명 해금 | 💎 50씩 |
| **영웅** | 노련한 영웅: 한 영웅 Lv10 / 20 / 30 | 💎 30 / 60 / 100 |
| **영웅** | 만능: 4명 모두로 3구간 클리어 | 💎 150 + 칭호 |
| **기록** | 기록 보관가: 기록 저장 1 / 10 / 50회 | 💎 20 / 50 / 100 |
| **기록** | 맞춤 전략: 서로 다른 기록으로 보스 3 / 5명 격파 | 💎 80 / 150 |
| **모드** | 생존자: 서바이벌 10분 생존 1 / 10회 | 💎 50 / 100 |
| **모드** | 균열 탐험가: 무한의 균열 20 / 40 / 60 / 80층 | 💎 30 / 60 / 100 / 150 |
| **모드** | 매일의 도전자: 일일 도전 참여 7 / 30 / 100일 | 💎 30 / 80 / 150 |
| **도감** | 역사 탐구: 영웅 이야기 4 / 전부 읽기 | 💎 20 / 50 |
| **합계 (출시 콘텐츠 기준, 1회성)** | | **약 💎 3,700 + 칭호 3개** |

- 결제·광고 관련 업적은 없다.
- 업적 화면에 **다음 단계까지 남은 양**을 보여준다.

## 8. 시즌 패스 (28일, ₩6,500)

### 8-1. 경험치

| 출처 | 시즌 최대 |
|---|---|
| 일일 활동 포인트 (1포인트 = 1 XP, 하루 100) | 2,800 |
| 주간 미션 (1개 = 100 XP, 주 6개) | 2,400 |
| 시즌 도전 (1개 = 100 XP, 8개) | 800 |
| **합계 최대** | **6,000** |

- **경험치는 시즌 패스를 열기 전에도 숨겨진 채로 첫날부터 쌓인다.** (2구간 보스를 늦게 깨는 사람도 패스를 열면 그동안 쌓인 경험치로 따라잡아 완주할 수 있다)

## 10. 구현 메모
- 미션은 전부 **"이벤트를 듣는 카운터"** 하나로 만든다. 게임 쪽은 `MissionEvents.Raise("enemy_killed", 기본공격여부...)`처럼 사건만 알리고, 미션 시스템이 그걸 세어 진행도를 올린다. → 미션을 추가해도 전투 코드를 고치지 않는다.
- 미션 정의(ID, 조건, 목표 수, 보상)는 ScriptableObject 테이블. 미션 풀과 시즌 도전도 데이터만 바꿔서 교체한다.
- 초기화 시각(05:00 KST)은 **기기 시계를 믿지 않는다.** 기기 시간을 바꿔서 미션을 반복하는 꼼수가 있다. 서버 시간(UGS를 쓰면 서버, 없으면 마지막으로 받은 인터넷 시간)을 기준으로 한다. → [Monetization 8장](Monetization.md#8-결정-필요)의 서버 결정과 연결
