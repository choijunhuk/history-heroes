## 1. 넣을까 말까

| | 넣는다 ⭐ 추천 | 안 넣는다 |
|---|---|---|
| 장점 | 역사 테마와 잘 맞는다 (실제 역사·전승 속 동물). 화면에 귀여운 볼거리. 출시 후 **펫 스킨**이 매출원. 성장 경로 하나 추가 | 작업량이 줄어든다. 화면이 덜 복잡하다 |
| 단점 | 애니메이션 작업이 늘어난다. 잘못 만들면 "펫이 다 잡아줘서 멈출 필요가 없는" 게임이 된다 | 카피바라 고처럼 펫·탈것을 기대하는 유저에게 아쉬움 |

**추천: 넣는다. 단, "멈춤을 돕는 보조형"으로만.**
- 펫의 공격은 **약하고**, 대부분 **영웅이 멈춰서 기본 공격을 할 때 같이 움직인다.** → 펫이 오히려 "멈추면 쏜다"를 강화한다.
- 출시 범위는 **펫 4마리, 장착 1칸, 뽑기 없음**으로 작게.

## 2. 원칙

| 원칙 | 내용 |
|---|---|
| **힘 예산** | 펫 전체(레벨 + 인연 보너스)를 끝까지 올려도 **공격력 +5%, 체력 +5%**. 펫은 이 ATK/HP와 아래 **행동 효과**만 낸다. 공격속도·치명타·쿨다운 감소·이동속도·피해 감소 같은 **보조 능력치는 주지 않는다** (펫 몫 0) |
| **경험치 없음** | 판 밖 출처는 경험치 획득을 늘리지 않는다. **펫도 예외가 없다.** 흰 비둘기는 보석을 *대신 주워올 뿐* 경험치 양은 같다. (Codex 5차: 펫 레벨을 유료 골드로 앞당길 수 있어서 경험치 예외를 없앰) |
| **멈춤을 돕는다** | 펫의 피해는 영웅 전체 피해의 **10% 이하**. 피해를 주는 효과는 **멈춤과 연결**하고, 이동 중 효과는 피해가 아니라 **밀치기·위치 조절**만 |
| **펫마다 놀이가 다르다** | 4마리가 **서로 다른 플레이어 행동**에 반응한다 (멈춤 유지 / 계속 이동 / 위기 / 탐색). 숫자만 다른 펫은 만들지 않는다 (개발자 요청, 2026-10-25) |
| **눈에 보인다** | 효과가 발동하면 펫이 **화면에서 직접 행동**한다 (날아가 찍기, 질주, 막아서기, 물어오기). 아이콘만 켜지는 효과 금지 |
| **판 안 규칙 불변** | 펫은 스킬 카드, 등급 확률, 조합, 리롤에 영향이 없다 |
| **뽑기 없음** | 펫은 플레이로 확정 획득 |
| **팔지 않는다** | 펫 자체는 팔지 않고, **펫 스킨만** 확정 구매 (출시 이후) |

## 3. 펫 목록 (출시 4마리) — 펫마다 다른 놀이

### 3-0. 한눈에 비교

| | 🦅 사냥매 | 🐎 적토마 | 🐴 마렝고 | 🕊️ 흰 비둘기 |
|---|---|---|---|---|
| **반응하는 행동** | **멈춰서 버티기** (2초 이상 정지) | **계속 움직이기** (1.5초 이상 이동) | **위험한 순간** (적 투사체가 다가옴) | **돌아다니기** (방 탐색) |
| **놀이 한 줄** | "오래 서 있을수록 사냥매가 급강하" | "달리면 적을 들이받으며 길을 뚫는다" | "멈춰 있어도 마렝고가 막아준다" | "비둘기가 보석과 보물을 물어온다" |
| 화면에서 보이는 것 | 하늘로 솟았다가 급강하, 표식 | 영웅 옆에서 질주, 먼지, 적이 튕겨남 | 영웅 앞을 막아서며 투사체를 몸으로 받음 | 날아가서 보석·보물을 물고 돌아옴 |
| 강한 상황 | **단일 보스** | **근접 영웅**, 몰려오는 적 | **탄막** (3구간 강철 거상) | **서바이벌**, 레벨업 빨리 |
| 잘 맞는 빌드 | 🏹 연사형 | ⚔️ 관우, 🛡️ 칼날 탱커형 | 🏹 연사형, 법사 | ⚡ 번개 광역형, 성장형 |
| 약한 상황 | 계속 피해야 하는 방 | 오래 서서 쏘는 보스전 | 근접 몸싸움 | 단일 보스 (모을 게 없음) |
| 인연 영웅 | 칭기즈 칸 | 관우 | 나폴레옹 | 니콜라 테슬라 |
| 획득 | **튜토리얼 보스** (첫 펫, 펫 칸과 함께) | 1구간 보스 최초 격파 | 3구간 보스 최초 격파 | 🧟 서바이벌 첫 클리어 (서바이벌은 2구간 보스 격파 후 열림) |

> **핵심:** 같은 빌드라도 어떤 펫을 데려가느냐에 따라 **"서서 버틸지, 달릴지"가 달라진다.** 그래서 펫 선택도 보스·모드에 맞춰 고민하게 된다.

### 🦅 칭기즈 칸의 사냥매 — "멈춰서 버티기"
> 📜 **사실:** 몽골인들은 매사냥을 즐겼다. · 📖 **전승:** 칭기즈 칸의 매가 독이 든 물그릇을 쳐서 그를 구했다는 이야기가 전해진다.

| 항목 | 내용 |
|---|---|
| 발동 | 영웅이 **2초 이상 멈춰 있으면** 사냥매가 하늘로 솟구친다 (게이지가 차오르는 게 보임) |
| 행동: 급강하 | 체력이 가장 높은 적에게 급강하 → 공격력 30% 피해 + **사냥 표식** |
| 사냥 표식 | 5초 동안 그 적에게 영웅의 **기본 공격 치명타 확률 +25%** |
| 재사용 | 급강하 후 6초. 다시 2초 멈춰야 발동 |
| 움직이면 | 솟구치던 사냥매가 영웅 어깨로 돌아온다 (게이지 초기화) |
| Lv5 각성 | 표식 대상이 죽으면 **표식이 가장 가까운 적에게 옮겨간다** |
| Lv10 각성 | 4초 이상 멈추면 **두 번 연속 급강하** |
| 플레이 감각 | 보스의 큰 빈틈에 **딱 서서 버티는** 플레이가 보상받는다 |

### 🐎 적토마 — "계속 움직이기"
> 📖 **전승:** 『삼국지연의』에서 여포에 이어 관우가 탄 명마. "사람 중엔 여포, 말 중엔 적토"라는 말이 전해진다.

| 항목 | 내용 |
|---|---|
| 발동 | 영웅이 **1.5초 이상 계속 움직이면** 적토마가 옆에서 질주 시작 (갈기가 불꽃처럼 빛남) |
| 행동: 질주 | 질주 중 이동속도 **+15%**, 앞을 막는 적을 **들이받아 밀쳐낸다** (공격력 10% + 넉백, 적마다 1초 간격) |
| 멈추면: 기세 | 질주하다 멈추는 순간 **2초 동안 기본 공격 피해 +20%** ("달려와서 멈추고 몰아친다") |
| 재사용 | 질주는 상시. 기세는 4초에 한 번 |
| Lv5 각성 | 질주 중 지나간 길에 **먼지 구름** (적 이동속도 -30%, 2초) |
| Lv10 각성 | 기세 지속 2초 → 3초, 기세 중 받는 피해 -15% |
| 플레이 감각 | **치고 빠지기.** 특히 관우처럼 다가가서 멈춰야 하는 근접 영웅과 잘 맞는다 |

### 🐴 마렝고 — "위험한 순간"
> 📜 **사실:** 나폴레옹이 탔던 것으로 유명한 아랍 종 회색 말. 여러 전투에 함께했다. (이름은 마렝고 전투에서 따왔다)

| 항목 | 내용 |
|---|---|
| 발동 | **적 투사체가 영웅에게 다가오면** (닿기 0.3초 전) |
| 행동: 막아서기 | 마렝고가 영웅 앞을 가로막고 투사체 **1발을 몸으로 받아낸다** (영웅 피해 0) |
| 재사용 | 7초 (화면에 말굽 아이콘으로 남은 시간 표시) |
| 위기 보너스 | 체력 30% 아래면 재사용 7초 → 4초 |
| Lv5 각성 | 막아낸 투사체를 **쏜 적에게 되돌려 보낸다** (그 투사체 피해의 100%) |
| Lv10 각성 | 한 번에 **2발까지** 막는다 |
| 플레이 감각 | 탄막 속에서도 **조금 더 오래 서서 쏠 수 있는 여유**. 피하기가 서툰 사람에게도 좋다 |
| 주의 | 근접 공격(돌진병 몸통 박치기)은 막지 못한다 → 근접 몸싸움에는 약함 |

### 🕊️ 테슬라의 흰 비둘기 — "돌아다니기"
> 📜 **사실:** 테슬라는 말년에 비둘기들을 돌봤고, 특히 흰 비둘기 한 마리를 아꼈다고 전해진다.

| 항목 | 내용 |
|---|---|
| 발동 | 항상. 영웅 주변을 맴돌다가 **떨어진 것을 물어온다** |
| 행동: 물어오기 | 화면에 떨어진 **경험치 보석·골드를 하나씩 날아가서 가져온다** (영웅이 안 가도 됨) |
| 행동: 보물 찾기 | 던전 방마다 **숨은 보물 1개**를 찾아 표시 (골드 또는 체력 회복 열매 10%) → 영웅이 가서 줍는다 |
| 멈추면 | 영웅이 멈춰 있으면 가까운 적 1명에게 약한 전기 (공격력 15%, 2초마다) |
| Lv5 각성 | 골드를 가져올 때 **5% 확률로 2배** (경험치는 그대로) |
| Lv10 각성 | 보물 찾기에서 **회복 열매 확률 증가** + 서바이벌에서 30초마다 자석 효과 (화면 보석 전부 흡수) |
| 플레이 감각 | **레벨업이 빨라진다.** 판 안 빌드가 일찍 완성 → 성장형 플레이. 단일 보스에선 할 일이 적다 |
| 주의 | 레벨업 카드(확률·조합)도, **경험치 양도** 건드리지 않는다. 보석을 빨리 모아줄 뿐이라 레벨업이 "조금 일찍" 올 수는 있지만 총량은 같다 |

### 효과 수치 확인
| 펫 | 직접 피해 비중 (영웅 전체 피해 대비) | 판 밖 예산 |
|---|---|---|
| 사냥매 | 급강하 30% / 6초 → 약 3% + 치명 보조 | 레벨·인연 +5% 안 |
| 적토마 | 들이받기 10% → 약 2% + 기세 보조 | 〃 |
| 마렝고 | 되돌리기(Lv5) 약 2~4% | 〃 |
| 흰 비둘기 | 전기 15% / 2초 → 약 4% | 〃 |
- 모두 **10% 이하** ✅. 펫이 혼자 적을 정리하는 일은 없다.
- 효과 수치(치명 +25%, 피해 +20%, 막기 1발 등)는 판 밖 예산(공격력·체력 +5%)과 별개인 **"놀이 효과"**다. 대신 각 효과가 **특정 행동을 할 때만** 켜지도록 해서 항상 강하지 않게 한다. 적토마의 질주 이동속도 +15%처럼 수치가 있어도 **질주 중에만 켜지는 행동 효과**이고, 계정에 영구히 붙는 보조 능력치가 아니다.

## 4. 펫 성장

| 항목 | 내용 |
|---|---|
| 레벨 | Lv 1 ~ 10 |
| 레벨당 | 공격력 +0.3%, 체력 +0.3% (Lv10 = **+3%**) |
| 효과 강화 | **Lv 5, Lv 10에서 "각성"** — 숫자가 아니라 **새 행동**이 생긴다 (3장 각 펫의 각성 참고) |
| 인연 보너스 | 인연 영웅과 함께 쓰면 공격력·체력 **+2%** 추가 |
| 최대 | 3% + 2% = **+5% / +5%** ✅ |
| 비용 | Lv n → n+1: 🪙 **1,500 × n** (Lv1→2: 1,500, Lv9→10: 13,500) |
| 총 비용 | 펫 하나 🪙 67,500, 4마리 🪙 270,000 |

- **골드만 쓴다.** 새 재료(펫 먹이 등)를 만들지 않는다.
- 레벨 효과(+0.3%/Lv)는 **장착한 펫 하나만** 적용된다. 4마리를 다 키운다고 쌓이지 않는다. (힘 예산 유지)

> ⚠️ 골드 소비처가 많아진다 (영웅 레벨 + 장비 슬롯 강화 + 룬 + 펫). [Economy.md](Economy.md)에서 월 골드 수입과 함께 다시 맞춰야 한다.

## 5. 장착과 모드

| 항목 | 규칙 |
|---|---|
| 장착 칸 | **1칸** (튜토리얼 보스 격파 후, Systems.md 3장과 같음) |
| 영웅별 | 영웅마다 따로 고른다. 같은 펫을 여러 영웅이 동시에 써도 된다 |
| 던전·서바이벌 | 적용 |
| 보스맵 | 기록에 저장된 펫 (ID + 레벨) 사용 — 장비와 같은 "만들 당시 고정" 규칙 |
| 기록 비용 | 펫은 기록 용량을 쓰지 않는다 |

### 화면 위 동작
- 펫은 영웅 뒤를 따라다닌다. 충돌 판정 없음 (적이 펫을 공격하지 않음)
- 영웅이 멈추면 펫도 멈추고 효과 이펙트 → **"멈추면 다 같이 공격한다"**는 그림을 보여준다

## 6. 화면 흐름

```
[영웅 탭] → 영웅 선택 → [펫] 칸
  └─ 칸 터치 → [펫 목록] 4마리 (없는 펫은 실루엣 + 얻는 방법)
        └─ 펫 터치 → [상세]
              그림, 이야기 (📜 사실 / 📖 전승), 효과, "인연: 관우 ❤️"
              [장착] [레벨업 🪙 6,000]
```

- 인연 영웅에게 맞는 펫을 끼우면 하트 아이콘과 "+2%" 표시

## 7. 구현 구조

| 클래스 | 종류 | 역할 |
|---|---|---|
| `PetData` | ScriptableObject | `id`, 인연 영웅 ID, 효과 종류, 레벨별 효과 수치, 애니메이션 |
| `PetTable` | ScriptableObject | 레벨당 능력치, 인연 보너스, 레벨 비용 |
| `PetCollection` | 저장 데이터 | 펫 ID별 레벨 (0 = 없음) |
| `HeroPetLoadout` | 저장 데이터 | 영웅 ID별 펫 ID |
| `PetController` | 런타임 (MonoBehaviour) | 따라다니기, 영웅의 "멈춤/공격" 이벤트 구독, 효과 발동 |
| `PetStatProvider` | 런타임 | 장착 펫 레벨 + 인연 → 스탯 보너스 (출처 = 펫) |

- `PetController`는 영웅의 `OnBasicAttack` / `OnStopped` / `OnMoved` 이벤트를 구독한다. **판 끝, 기록 복원 때 구독 해제** ([GameDesign 12-2 Apply 계약](../GameDesign.md#12-2-설계-원칙))

### 직접 짜볼 부분 (연습)
- [ ] 사냥매 `UpdateDiveGauge(isStopped, deltaTime)`: 멈춰 있으면 게이지를 채우고, 움직이면 초기화하고, 2초가 차면 체력이 가장 높은 적에게 급강하 (8~12줄)

### 펫 행동 구조
- 펫마다 **트리거(무엇에 반응) + 행동(무엇을 함)**을 따로 정의한다: `PetTrigger` (멈춤 유지 / 이동 지속 / 투사체 접근 / 항상) × `PetAction` (급강하 / 질주 / 막아서기 / 물어오기)
- 새 펫을 추가할 때 트리거와 행동을 조합하면 된다 → 출시 이후 펫이 늘어도 "다 비슷한 펫"이 되지 않게 **트리거 × 행동 표에서 빈칸을 채우는 식**으로 설계
