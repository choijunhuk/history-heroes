## 1. 세계관 (짧게)

> 역사가 지워지기 시작했다. **"망각의 군단"**이 시간의 틈으로 쏟아져 나와 사람들의 기억을 먹어치운다.
> 시간의 수호자는 역사 속 영웅들을 불러낸다. 칭기즈 칸, 관우, 나폴레옹, 테슬라가 한 편이 되어 싸운다.

- 적은 전부 **가상의 존재**(망각의 군단)다. 실제 국가·민족과 싸우지 않는다.
- 다른 시대 영웅들이 한 팀이 되는 **드림팀 재미**를 살린다. 영웅끼리의 짧은 대사로 개성을 보여준다. (예: 나폴레옹 "키가 작다고? 포탄은 높이 난다!")

## 2. ⏱️ 한 판 구성과 플레이 시간

### 2-1. 모드별 목표 시간

| 모드 | 한 판 시간 | 이유 |
|---|---|---|
| **던전 모드** | **약 8~10분** | 출퇴근·쉬는 시간 한 번에 끝나는 길이. 아처의 한 챕터와 비슷 |
| **보스맵** | **약 2~3분** | 기록을 골라서 짧고 굵게 |
| **서바이벌** | **10분** | 뱀서 장르 표준. 길지만 가끔 하는 모드 |
| **첫 판 (튜토리얼)** | **약 5분** | 첫 경험은 짧고 성공으로 끝나야 한다 |

### 2-2. 던전 한 판 = 방 15개

| 방 | 종류 | 내용 | 걸리는 시간 |
|---|---|---|---|
| 1~4 | 일반 전투 | 적 2종, 적 수 적음. 빌드 시작 | 방당 25~30초 |
| **5** | ⭐ **엘리트** | 강한 적 1 + 졸개. 처치 시 **확정 레벨업** | 45초 |
| 6 | 🎁 **보상 방** | 전투 없음. 셋 중 하나: 체력 회복 / 스킬 카드 1장 더 / 골드 | 10초 |
| 7~9 | 일반 전투 | 적 3종, 패턴 섞임 | 방당 30~35초 |
| **10** | ⭐ **엘리트** | 강한 적 2. 확정 레벨업 | 50초 |
| 11 | 🎁 **보상 방** | 위와 같음 | 10초 |
| 12~14 | 일반 전투 | 적 4종, 가장 어려움 | 방당 35~40초 |
| **15** | 👹 **중간 보스** | 구간의 중간 보스 (보스맵 보스와 다름) | 60~90초 |

- **전투 시간 합계 약 7분 + 레벨업 카드 고르는 시간 약 1~2분 = 약 8~10분**
- 방 사이에는 문을 지나는 1~2초 연출만. 로딩이 없어야 한다.

### 2-3. 레벨업 리듬

| 시점 | 누적 레벨업 | 느낌 |
|---|---|---|
| 1분 | 2~3회 | 빠르게 빌드 방향을 정함 |
| 3분 (5번 방 엘리트 뒤) | 6회 | 첫 조합이 보이기 시작 |
| 6분 (10번 방 엘리트 뒤) | 10~11회 | 조합 1개 완성 가능 |
| 9분 (끝) | **약 15회** | 빌드 완성 |

- 레벨업은 초반에 빠르고 후반에 느리다. (경험치 필요량 = 기본 × 레벨^1.3, 임시)
- 엘리트 방의 확정 레벨업 덕분에 **5번, 10번 방이 기대되는 순간**이 된다.

### 2-4. 판이 끝나면
```
클리어 or 사망
  → 결과 화면 (시간, 처치 수, 골드, 만든 조합, 새 발견 레시피)
  → 기록 저장 화면 (용량 안에서 남길 스킬 고르기)
  → 로비 (다음: 보스 도전 / 다시 던전)
```

## 3. 구간 (챕터) — 출시 때 5개

| 구간 | 이름 | 분위기 | 새 적 | 보스맵 보스 | 보스가 시험하는 것 |
|---|---|---|---|---|---|
| 1 | **균열의 초원** | 밝음, 입문 | 돌진병, 궁병 | 🛡️ 균열의 수문장 | 큰 빈틈 → **멈춤 타이밍** 배우기 |
| 2 | **잊힌 성채** | 돌, 횃불 | 방패병, 투척병 | 👻 망령 군주 | 잡몹 계속 소환 → **광역 빌드** |
| 3 | **녹슨 공방** | 톱니, 증기 | 분열체 | ⚙️ 강철 거상 | 탄막 → **칼날 탱커형, 회피** |
| 4 | **그림자 협곡** | 어두움 | 소환사 | 🌑 그림자 쌍둥이 (2체) | 둘이 따로 움직임 → **단일 순간 화력** |
| 5 | **망각의 왕좌** | 보라, 웅장 | 전부 강화형 | 👑 망각의 왕 | 위 패턴 전부 → **완성된 빌드** |

- 구간마다 적 체력 ×1.35, 공격력 ×1.2 (임시)
- 각 구간 보스맵 최초 격파 → 다음 구간 개방 + 해금 보상 ([경제](Economy.md#3-획득처-source), [영웅](Heroes.md#2-한눈에-보기))

## 4. 적 (망각의 군단)

**모든 적은 공격 전에 예고하고, 공격 후 빈틈이 있다.** ([3-2 전투 원칙](../GameDesign.md#3-2-전투-원칙-멈추면-쏜다가-재밌으려면))

| 적 | 행동 | 예고 | 빈틈 | 노리는 것 |
|---|---|---|---|---|
| **돌진병** | 플레이어에게 직선 돌진 | 0.8초 빨간 선 | 돌진 후 1.2초 멈춤 | 피하고 → 멈춰서 쏘기 |
| **궁병** | 직선 화살 1발 | 0.6초 조준선 | 1초 재장전 | 옆으로 피하기 |
| **방패병** | 정면 공격을 막음, 천천히 접근 | — | 방패를 내리는 순간 | 옆으로 돌아가기, 튕김·관통 |
| **투척병** | 곡선으로 폭탄 투척 (떨어질 자리 표시) | 1초 원 표시 | 2초 재투척 | 범위 밖으로 이동 |
| **분열체** | 죽으면 작은 것 2개로 분열 | — | — | 광역 피해 |
| **소환사** | 졸개를 주기적으로 소환, 도망다님 | 소환 1초 전 마법진 | 소환 직후 1.5초 | 우선 처치 대상 |

- **엘리트** = 일반 적의 강화판 (크기 1.5배, 체력 ×5, 패턴 1개 추가)

## 5. 서바이벌 맵 (출시 때 1개)

| 시간 | 일어나는 일 |
|---|---|
| 0~2분 | 돌진병·궁병 소수. 빌드 시작 |
| 2~4분 | 적 2배. 첫 엘리트 (확정 상자) |
| 4~6분 | 방패병·분열체 등장, 사방에서 몰려옴 |
| 6~8분 | 적 최대치 근처. 두 번째 엘리트 |
| 8~10분 | 망각의 군단 대행진 (화면 가득) |
| **10분** | 👑 서바이벌 보스 등장 → 처치 시 클리어 |

- 적 수 상한 300 ([GameDesign 8-5](../GameDesign.md#8-5-기술-주의점-휴대폰-성능))
