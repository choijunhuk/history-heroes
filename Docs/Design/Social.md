# 🤝 소셜 설계 — 랭킹, 친구, 길드

> 상위 문서: [GameDesign.md](../GameDesign.md) · 관련: [모드](Modes.md) · [경제](Economy.md) · [운영](LiveOps.md) · [과금](Monetization.md)
> 작성: 2026-10-25 · 상태: **초안 (보상 수치는 임시값. [Economy 4장](Economy.md#4-획득처-source--핵심-표)과 다시 맞춘다)**

---

## 1. 설계 원칙

1. **소셜은 힘이 아니라 자랑과 함께하는 이유를 준다.** 랭킹·친구·길드 보상은 칭호, 프레임, 소량 재화다. **쌓이면 격차가 벌어지는 힘**(장비, 대량 🎫, 영구 능력치)은 주지 않는다.
2. **사람이 적어도 쓸쓸하지 않게.** 인디 게임은 처음에 유저가 적다. 전체 순위 1만 등 중 9,998등은 재미없다 → **백분위와 친구 순위**를 먼저 보여준다. 길드는 사람이 모인 뒤에 연다.
3. **기록 시스템과 엮는다.** 이 게임만의 소셜은 "**기록을 보여주고, 빌려주고, 같이 쓰는 것**"이다.
4. **서버가 필요한 기능은 서버에서 검증한다.** 랭킹 점수, 선물, 기록 빌리기는 휴대폰이 아니라 서버(Cloud Code)가 처리한다.
5. **자유 채팅은 출시 때 넣지 않는다.** 욕설·사기·미성년자 보호를 혼자 관리할 수 없다. 정해진 문구와 이모트만 쓴다.

## 2. 🏆 랭킹

### 2-1. 랭킹 종류

| 랭킹 | 점수 기준 | 동점일 때 | 초기화 | 영웅별 탭 | 출시 |
|---|---|---|---|---|---|
| **무한 모드 최고 층** ([Modes](Modes.md)) | 도달한 층 | 더 빨리 도달한 쪽 | **시즌 (28일)** | ✅ | **v1.0** |
| **서바이벌** | 10분 클리어 시 **처치 수**, 실패 시 생존 시간 | 받은 피해가 적은 쪽 | **주간** | ✅ | **v1.0** |
| **일일 도전** ([Modes](Modes.md)) | 같은 조건(같은 시드·영웅)으로 얻은 점수 | 클리어 시간 | **매일** | — (조건이 고정) | v1.1 |
| **보스 최단 처치** (보스별) | 처치 시간 | 남은 체력이 많은 쪽 | **주간** | ✅ | v1.1 |
| **조합 도감 수집률** | 발견한 레시피 수 | 먼저 달성한 쪽 | 없음 (누적) | — | v1.1 |

- **친구 순위**: 위 모든 랭킹에 [전체 / 친구] 탭. 친구 순위는 사람이 적어도 바로 재미있다.
- **영웅별 탭**: "관우 무한 모드 1위"처럼 좋아하는 영웅으로 경쟁할 수 있다. 같은 데이터를 영웅으로 걸러서 보여준다.
- **빌린 기록**으로 한 판, **오프라인**으로 한 판은 랭킹에 들어가지 않는다. (3-3, 5장)

### 2-2. 순위 보여주는 방법: 전체 순위 + 백분위 (리그는 나중에)

| 방식 | 장점 | 단점 |
|---|---|---|
| **전체 Top 100 + 내 백분위** | 만들기 쉬움. 사람이 적어도 동작 | 하위권은 동기가 약함 |
| **리그** (30명 그룹, 브론즈~마스터 6단계, 주간 승급·강등) | 비슷한 실력끼리 경쟁. 하위권도 "이번 주 승급"이 목표 | 그룹을 채울 사람이 충분해야 함. 서버 로직이 복잡 |

- **v1.0:** 전체 Top 100 + "상위 **12%**" 백분위 + 친구 순위
- **리그 도입 조건:** 하루 활성 유저가 **1,000명 이상으로 4주 유지**될 때 (그 전에는 30명 그룹이 반쯤 비어 있게 된다)

### 2-3. 초기화 시각
- 모든 초기화는 **한국 시간 새벽 5시** (UTC 20:00). 자정에 끝나면 밤늦게 하는 유저가 압박을 받는다.
- 일일 = 매일 05:00 · 주간 = 월요일 05:00 · 시즌 = 28일 (시즌 패스와 같은 주기)
- 시즌이 끝나면 1~3위를 **명예의 전당**에 영구 기록한다. (닉네임, 영웅, 층)

### 2-4. 보상 (우편함으로 지급)

**무한 모드 시즌 (28일마다)**
| 순위 | 보상 |
|---|---|
| 1~3위 | 칭호 "시대의 전설" + **시즌 한정 프레임** + 💎 300 + 명예의 전당 |
| 상위 1% | 칭호 "역사의 수호자" + 시즌 프레임 + 💎 300 |
| 상위 10% | 시즌 프레임 + 💎 150 |
| 상위 50% | 💎 50 |
| 참여 (1층 이상) | 🪙 2,000 |

**서바이벌 주간 · 보스 최단 처치 주간 (랭킹마다 각각)**
| 순위 | 보상 |
|---|---|
| 상위 1% | 주간 배지 (프로필 표시 1주) + 💎 50 |
| 상위 10% | 💎 30 |
| 참여 | 🪙 1,000 |

**일일 도전:** 상위 10% 💎 10, 참여 🪙 500 (도전 자체 보상은 [Modes](Modes.md))

- **상한 계산 (상위 10% 유저 기준):** 시즌 💎 150/28일 + 주간 💎 30 × 2개/주 + 일일 💎 10/일 → **하루 약 💎 24**. 무과금 목표(💎 120/일)의 약 20%. 참여만 하면 하루 약 🪙 500~800.
- 🎫, 장비, 🧩, 능력치는 **랭킹 보상에 넣지 않는다.**

### 2-5. 부정행위 방지 (서버 검증)

휴대폰 안에서 혼자 하는 게임이라, 점수를 조작해서 보내는 건 막기 어렵다. 그래서 **단계별로** 막는다.

| 단계 | 방법 | 출시 |
|---|---|---|
| 1. 직접 쓰기 금지 | 휴대폰이 랭킹에 바로 점수를 쓰지 못한다. **Cloud Code 함수 `SubmitRun`만** 쓸 수 있다 | v1.0 |
| 2. 판 시작 등록 | 랭킹 판을 시작할 때 서버가 `runId`와 **랜덤 시드**를 준다. 제출 때 `runId`가 없거나, 이미 쓴 것이거나, 너무 빨리 끝났으면 거절 | v1.0 |
| 3. 타당성 검사 | 층당 최소 시간, 레벨업 횟수 상한, 처치 수 ÷ 시간 상한, 받은 피해 0인데 고층 등 **말이 안 되는 기록 거절** | v1.0 |
| 4. 카드 재현 검사 | 레벨업 카드는 서버 시드로 뽑는다 → 제출된 "고른 카드 순서"가 그 시드로 **실제로 나올 수 있었는지** 서버가 다시 계산 | v1.1 |
| 5. 기기 무결성 | Google **Play Integrity API**로 변조된 앱·루팅 기기 표시 (랭킹 제출만 제한) | v1.1 |
| 6. 이상치 보류 | 상위 1%에 갑자기 들어온 기록은 **자동 보류 → 수동 확인 후 반영** | v1.0 (수동) |

- 적발 시: 1회 → 해당 기록 삭제 · 2회 → 시즌 랭킹 제외 · 3회 → 랭킹 영구 제외. (이용약관에 근거를 적는다, [LiveOps 15장](LiveOps.md#15-부정행위해킹-대응))
- **덤:** 판의 랜덤을 서버 시드로 정하면 **일일 도전(모두 같은 시드)**도 같은 장치로 만들 수 있다.

## 3. 👥 친구

### 3-1. 친구 추가

| 방법 | 내용 |
|---|---|
| **친구 코드** | 계정마다 8자리 코드 (예: `HH7K-3Q9P`). 복사·공유 버튼 |
| **닉네임 검색** | 정확히 일치하는 닉네임만 (무작위 찾기 방지) |
| **최근 만난 플레이어** | 기록을 빌려준/빌린 상대, 같은 길드원 (출시 후) |
| **추천** | 비슷한 구간 진행도의 최근 접속 유저 5명 (하루 1회 새로고침) |

| 한도 | 값 |
|---|---|
| 최대 친구 | **50명** |
| 받은 요청 보관 | 30개 (7일 지나면 자동 삭제) |
| 하루 보낼 수 있는 요청 | 20개 |

- **차단**과 **신고**(닉네임, 프로필 문구)를 프로필에서 바로 할 수 있다.
- 30일 넘게 접속하지 않은 친구는 목록에서 회색으로 표시하고, 정리 버튼을 준다.

### 3-2. 친구 선물

**하트 시스템이 있을 때 (Economy 추천안 B)**
| 항목 | 값 |
|---|---|
| 보내기 | 친구 1명당 하루 **❤️ 1** (보내는 사람은 하트가 줄지 않는다) |
| 받기 한도 | 하루 **❤️ 5**까지 (그 이상은 우편함에 7일 보관, 다음 날 받기) |
| 보낸 사람 보상 | 하루 처음 5번 보낼 때 🪙 50씩 (최대 🪙 250) |

**하트가 없을 때 (Economy 안 A 또는 C)**
| 항목 | 값 |
|---|---|
| 보내기·받기 | 🪙 50, 하루 받기 **20회까지** (최대 🪙 1,000) |

- [모두 보내기] [모두 받기] 버튼. 선물을 강요하는 알림은 보내지 않는다.

### 3-3. ⭐ 친구 기록 빌리기 (이 게임만의 소셜)

친구가 공개한 기록을 빌려서 **보스에 도전**한다. "저 친구는 이 보스를 어떤 빌드로 깼지?"를 직접 체험하는 기능이다.

| 규칙 | 값 | 이유 |
|---|---|---|
| 공개 범위 | 각자 기록 슬롯 중 **1개를 "대표 기록"**으로 지정해 공개 (비공개 가능) | 자랑하고 싶은 기록만 |
| 빌리기 횟수 | 하루 **1회** (= 보스 도전 1판) | 남의 기록에 기대지 않게 |
| 같은 친구 | 하루 1번 | |
| 도전 가능 보스 | **내가 이미 열어둔 구간의 보스만** | 진행을 건너뛰지 못하게 |
| 하트 | ❤️ 1 (일반 보스 도전과 같음) | |
| **최초 격파 인정** | **❌ 안 함.** "연습 승리"로 기록 | "기록은 노력의 결과" 원칙. 친구 덕에 구간을 건너뛰면 진행 설계가 무너진다 |
| 이겼을 때 | 🪙 500 + 보스 도감에 **"이 보스를 깬 빌드"** 공략 메모가 남음 | 다음엔 내 기록으로 깨게 돕는다 |
| 기록 주인 보상 | 내 기록이 빌려질 때마다 🪙 100 (하루 5회까지 = 🪙 500) + "도움 횟수" 누적 | 좋은 기록을 공개할 이유 |
| 랭킹 | 빌린 기록 판은 **보스 최단 처치 랭킹 제외** | |
| 스냅샷 | 친구 기록 그대로 (장비·영웅 레벨 포함, 내 성장은 안 더함) | [기록 규칙 7-3](../GameDesign.md#7-기록-시스템--보스맵--이-게임의-핵심)과 같음 |

- 빌린 기록에는 친구 닉네임과 프레임이 보스전 화면에 표시된다. (함께 싸우는 느낌)
- 대표 기록이 패치로 용량을 넘으면, 주인이 다시 고르기 전까지 빌려줄 수 없다.

### 3-4. 친구 프로필

| 항목 | 내용 |
|---|---|
| 기본 | 닉네임, 칭호, 프레임, 대표 영웅 + 스킨, 계정 레벨 |
| 진행 | 깬 구간, 무한 모드 최고 층, 서바이벌 최고 기록 |
| 수집 | 조합 도감 %, 영웅 4명 각성 단계 |
| **대표 기록** | 스킬 목록 미리보기, 비용, 만든 날짜, 이 기록으로 깬 보스 → [빌리기] |
| 접속 | "오늘", "3일 전" 처럼 대략적으로 (정확한 시각은 개인정보) |
| 한 줄 소개 | **정해진 문구 중 고르기** (예: "관우 장인", "매일 출석", "조합 수집가") — 자유 입력 없음 |

## 4. 🏰 길드

> **추천: 출시 후 (v1.2 안팎)에 연다.** 이유는 4-8장.

### 4-1. 기본 규칙

| 항목 | 값 |
|---|---|
| 인원 | **20명** (길드 레벨에 따라 25 → 30) |
| 역할 | 길드장 1 · 부길드장 2 · 길드원 |
| 만들기 | 🪙 50,000 (보석이 아니라 골드 — 돈으로 막지 않는다), 3구간 클리어 이상 |
| 가입 방식 | 자유 가입 / 승인 후 가입 / 초대만 (길드장이 선택) |
| 가입 조건 | 최소 깬 구간 (선택) |
| 탈퇴 후 재가입 | **24시간 대기** (보상 돌려막기 방지) |
| 길드장 부재 | 7일 미접속 시 부길드장 → 가장 기여도 높은 길드원 순으로 자동 위임 |
| 길드 이름·소개 | 이름은 금칙어 검사, 소개는 **태그 선택식** ("초보 환영", "매일 접속", "보스 집중" 등) |

### 4-2. 길드 출석
| 항목 | 값 |
|---|---|
| 개인 출석 | 하루 1회 → 🪙 300 + 🏅 길드 코인 10 + 길드 경험치 10 |
| 출석 인원 상자 | 오늘 출석 **10명** → 전원 🪙 500 · **15명** → 🪙 1,000 · **20명** → 🪙 1,500 + 💎 10 |

### 4-3. 길드 보스 (주간 레이드) ⭐ 기록과 연결

| 항목 | 내용 |
|---|---|
| 일정 | 월요일 05:00 ~ 일요일 05:00 도전, 일요일은 정산·휴식 |
| 도전 횟수 | 하루 **2회** (무료, 하트 소모 없음) |
| 방식 | **내 기록 하나를 골라서** 90초 동안 보스에게 준 피해를 기록. 길드원 피해가 **합산**된다 |
| 단계 | 보스 체력을 다 깎으면 다음 단계 (더 강해짐). 1~10단계 |
| **주마다 바뀌는 보스 패턴** | 이번 주는 "탄막형", 다음 주는 "소환형"… → **이번 주 보스에 맞는 기록을 만들어 오는 것**이 길드 기여 |
| 개인 보상 | 도전 1회당 🪙 500 + 🏅 20 |
| 주간 보상 (전원) | 도달 단계 × 🏅 50 + 단계 × 💎 10 (10단계 = 💎 100/주) |

- 피해량이 적어도 **참여 자체가 보상**이 되게 한다. 기여도 순위는 길드 안에서만 보인다.

### 4-4. 길드 상점 (🏅 길드 코인)

| 상품 | 가격 | 한도 |
|---|---|---|
| 🪙 5,000 | 🏅 100 | 주 10회 |
| 🔩 장비 조각 10 | 🏅 200 | 주 5회 |
| 🎫 고급 소환권 1 | 🏅 1,000 | **주 1회** |
| 룬 (원하는 태그) | 🏅 1,500 | 시즌 1회 |
| 길드 한정 프레임·칭호 | 🏅 3,000 | 1회 |

- 🏅 주간 최대 획득 (매일 출석 + 하루 2회 보스 + 10단계): 70 + 280 + 500 = **약 🏅 850/주**

### 4-5. 길드 레벨
| 레벨 | 필요 경험치 (누적) | 보상 |
|---|---|---|
| 1 | — | 20명 |
| 3 | 2,000 | 길드 문장 색 선택 |
| 5 | 6,000 | 25명, 상점에 🔩 상품 추가 |
| 8 | 15,000 | 길드 문장 모양 추가 |
| 10 | 30,000 | 30명, 길드 한정 프레임 |

- 길드 경험치: 출석 10, 보스 도전 20. **능력치 버프는 주지 않는다.** (힘 격차 금지)

### 4-6. 소통 (자유 채팅 없음)
- **정해진 문구 20개 + 이모트 10개**: "보스 같이 잡아요!", "이번 주 탄막형이에요", "고마워요", "좋은 기록이네요" 등
- **길드 게시판** = 길드장 공지 1줄 (태그 + 정해진 문구 조합)
- 출시 후 사람이 늘고 신고·관리 도구가 갖춰지면 **필터 채팅**을 검토한다.

### 4-7. 관리
- 금칙어 목록(한국어·영어 욕설, 광고 문구) 검사 → 서버에서도 한 번 더
- 신고 3회 누적 → 이름 자동 가림 → 운영자 확인 후 강제 변경
- 운영자 도구: 길드 이름 변경, 길드장 교체, 해체 (Cloud Code 관리 함수)

### 4-8. 왜 출시 후인가

| 걱정 | 내용 |
|---|---|
| **빈 길드** | 유저가 적으면 20명 길드에 3명. 출석 인원 상자, 길드 보스 합산이 다 의미가 없어진다 |
| **관리 부담** | 이름·신고·분쟁을 혼자 처리해야 한다 |
| **서버 비용·작업량** | 길드는 Unity Gaming Services에 전용 기능이 없어 Cloud Save + Cloud Code로 직접 만들어야 한다 (구현 전 최신 서비스 확인) |
| **출시 범위** | 이미 v1.0에 영웅 4명·장비·룬·서바이벌이 있다 |

- **도입 조건:** 하루 활성 유저 **1,000명 이상 4주 유지** + 친구 기능 사용률 20% 이상
- **그 전 대안:** 친구 기록 빌리기(3-3)가 "함께하는 느낌"을 먼저 준다
