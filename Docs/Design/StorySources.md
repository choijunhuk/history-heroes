# 이야기 출처

## 새 영웅 유물 (2026-10-29)

게임 속 물건의 외형과 대사는 각색이다. 아래 자료가 실제 유물의 외형이나 영웅의 실제 발언까지 뒷받침한다는 뜻은 아니다.

| 유물 | 확인한 내용 | 출처 |
|---|---|---|
| 난중일기 | 이순신이 전쟁 중 직접 쓴 일기 | [국가유산포털](https://www.heritage.go.kr/heri/mem/selectHaejeDetail.do?listGubun=list&pageIndex=1&s_asno=00760000&s_cnum=0001&s_code1=99&s_code2=11&s_code3=&s_ctcd=00&s_hgsv=0&s_kdcd=11&s_page=0001&searchCond=&searchDisp=1&searchGubun=&searchPage=1) |
| 이성계의 활 | 이성계의 뛰어난 활솜씨. 특정 현존 활의 복원이라고 하지 않는다 | [한국학중앙연구원 한국민족문화대백과사전: 태조](https://encykorea.aks.ac.kr/Article/E0059033) |
| 다빈치의 톱니바퀴 도면 | 다빈치의 필사본 속 톱니바퀴·기계 장치 그림. 완성품으로 만들었다는 주장은 하지 않는다 | [Leonardo3 Museum: Codex Atlanticus 579r](https://www.leonardo3.net/en/l3-research-center/l3-collection/robot-soldier-1294.html) |
| 전출사표 사본 | 후대에 출사표를 베끼고 새긴 탁본이 전한다. 게임 사본을 제갈량의 친필이라고 하지 않는다 | [국립역사박물관 소장품: 출사표 탁본](https://collections.culture.tw/Object?RNO=MzcxMDg%3D&SYSUID=14) |

- 제갈량 유물은 **전출사표**로 특정한다. 후출사표는 저자에 논쟁이 있어 이번 사실 설명에 쓰지 않는다 ([중국 공공기관의 설명](https://study.bjwomen.gov.cn/thought/knowledge/2022/05/20/3994.shtml)).
