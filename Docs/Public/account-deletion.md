# History Heroes (역사 영웅) 계정 삭제 안내

개발자: choijunhuk · 마지막 갱신: 2026-11-01

History Heroes(역사 영웅)의 게임 계정과 그 데이터를 지우는 방법입니다. 두 가지 중 편한 쪽을 쓰세요.

## 1. 게임 안에서 지우기 (바로 처리)
1. 게임을 켜고 로비 오른쪽 위 **설정**을 누릅니다.
2. 아래 **계정** 묶음의 **계정 삭제**를 누릅니다.
3. 안내를 읽고 **계정과 진행 모두 지우기**를 누릅니다. 카카오 계정을 연결했다면 카카오 로그인 창이 한 번 뜹니다 (연결을 끊으려면 카카오가 다시 확인해야 해서).

인터넷에 연결돼 있어야 합니다. 끝나면 게임이 처음 화면(동의)부터 새로 시작합니다.

## 2. 게임 밖에서 요청하기 (앱을 지웠거나 켤 수 없을 때)
**choijunhuk2007@gmail.com** 으로 메일을 보내 주세요.

- 제목: `History Heroes 계정 삭제 요청`
- 내용: 게임 안 **사용자 ID** (설정 → 정보 · 약관 · 크레딧 → 정보, 12자리 영문·숫자)와 같은 화면의 **게임 계정 ID**. 둘 다 적어 주시면 서버에서 계정을 바로 찾을 수 있습니다 (클라우드 저장에 두 번호가 함께 기록됩니다).
- ID를 모르면: 그렇다고 적어 주세요. 앱을 다시 설치해 같은 카카오 계정을 연결한 뒤 게임 안에서 지우는 방법 등, 계정을 찾는 방법을 답장으로 안내합니다.

요청을 받으면 **영업일 기준 7일 안에** 지우고, 끝나면 답장으로 알려 드립니다.

## 지워지는 것
| 무엇 | 어디 |
|---|---|
| 게임 계정 (Unity 게임 계정 ID, 연결된 카카오 회원번호) | Unity Technologies 서버 |
| 클라우드 저장 (게임 진행 전체) | Unity Technologies 서버 |
| 카카오 연결 (우리 게임과 카카오 계정의 연결) | 카카오 — 게임 안에서 지울 때 끊습니다. 메일로 요청한 경우 카카오톡 → 설정 → 카카오계정 → 연결된 서비스 관리에서 직접 끊을 수 있습니다 |
| 이 기기의 진행 · 백업 | 휴대폰 (게임 안에서 지울 때) |

- 지운 계정과 진행은 **되돌릴 수 없습니다.**
- 남은 유료 보석 · 상품도 함께 사라집니다.
- **결제 기록은 지우지 않고 따로 보관합니다:** 서버 결제 장부(상품, 구글 주문 번호, 구매 토큰의 해시값, 시각, 지급 내역)는 전자상거래법이 정한 기간(5년) 동안 법령상 의무 · 분쟁 처리에만 쓰려고 보관한 뒤 지웁니다 (개인정보 처리방침 3장).
- 게임이 서버에 따로 만들어 두는 사본(백업)은 없습니다. 다만 Unity · 카카오가 자기 서비스를 운영하려고 보관하는 기록(접속 기록 등)은 각 회사의 개인정보 처리방침과 보관 기간을 따르며, 우리가 지울 수 없습니다.
